## 실행
- `index.html`을 더블클릭해 브라우저(Chrome/Edge/Safari/Firefox 최신)로 연다 → **시작하기**(Enter).
- 세로 모바일(360×740) 기준 레이아웃. 데스크톱에서는 가운데 정렬된 360px 폭으로 플레이한다. 화면 높이가 작으면 맵이 비율을 유지한 채 줄어든다.

## 규칙 요약 (브리프 고정 수치 그대로)
- 탑 HP 10. 적이 탑에 닿으면 일반/빠름 -1, 단단함 -2, 보스 -5(펜타클 보호막이 먼저 흡수).
- 정답 마나 +3/+4/+5(난이도 1/2/3), 자동 회복 1마나/5초. 마나 원천은 이 둘뿐(적 처치 보상 없음).
- 소환 5마나, 강화 Lv2 4마나, Lv3 6마나(프로토타입은 Lv3까지, `cost.upgrade[2]=8`은 Lv4용 예약).
- 웨이브 5개, 웨이브 전/사이 5초 휴식(카운트다운 표시, 문제는 계속 풀 수 있음). 5웨이브에 보스 "망각의 왕".
- 콤보 3: 다음 소환 -2 / 콤보 5: 전체 공격력 +30% 10초 / 콤보 8: 궁극기(광역 폭발, 방어력 무시) 1회. 8콤보 주기로 반복(11/13/16…). 오답 시 콤보 0.
- 오답 → 해당 문항이 **봉인 목록**에 등록(세션 동안 유지), 2초간 답 잠금(정답 표시).
- 문제 방치 7초부터 테두리 점멸, 10초에 자동 교체 + "회피" 기록(콤보는 유지, 정답률 분모에는 포함).
- 결과: 클리어/함락, 별(★1 클리어, ★2 탑 HP ≥ 6, ★3 정답률 ≥ 80% 그리고 최대 콤보 ≥ 5). 봉인 목록 표시, **해제 퀴즈** 1문항(정답 시 봉인 해제 + 다음 판 시작 마나 +3), 다시하기.

## 카드 · 적
| 카드 | 아이콘/도형 | 역할 | Lv1 → Lv3 |
|---|---|---|---|
| 완드(불) | 🔥 / 삼각형 | 단일 고화력 | 피해 24→62, 1.1→0.9초 |
| 컵(물) | 💧 / 원 | 둔화 | 피해 5→12, 둔화 35→55% |
| 소드(바람) | 🗡️ / 마름모 | 빠른 연타·2체 | 피해 7→15, 0.4→0.3초, 2체 |
| 펜타클(땅) | 🪨 / 사각형 | 탑 보호막 | 보호막 +1 / 12→6초 (최대 5) |

적: 안개 조각(원, 일반), 속삭임(삼각형, 빠름), 침묵 덩어리(사각형, 방어 3), 망각의 왕(별 모양+👑, 방어 5, 둔화 저항 50%). 색각 이상을 고려해 속성·적은 색 + 도형 + 아이콘 문자로 구분하고, 정답/오답은 색 + ✓/✗로 표시한다.

## BALANCE (파일 상단 `const BALANCE = {...}`)
| 키 | 의미 |
|---|---|
| `tower.hp`, `tower.shieldCap` | 탑 HP, 보호막 최대치 |
| `mana.start/max/regenAmount/regenEvery/byDifficulty` | 시작 마나, 상한, 자동 회복, 난이도별 정답 마나 |
| `cost.summon`, `cost.upgrade[]`, `maxLevel` | 소환·강화 비용, 최대 레벨 |
| `quiz.idleWarnSec/idleSkipSec/correctDelay/wrongLockSec` | 방치 경고·교체 시간, 정답 후 지연, 오답 잠금 |
| `combo.*` | 콤보 보상 임계값(3/5/8), 할인량, 버프 배율·시간, 주기 |
| `ult.damage` | 궁극기 피해(방어 무시) |
| `waves.prepSec/breakSec/hpScalePerWave` | 첫 준비·웨이브 간 휴식, 웨이브당 적 HP 증가율(W5 = ×5) |
| `stars.*` | 별 기준 |
| `review.bonusMana` | 해제 퀴즈 정답 보너스 |
| `cards.<type>.lv[]` | 카드 레벨별 `dmg/cd/range/targets/slow/slowSec/shieldEvery` |
| `enemies.<type>` | `hp/speed(px/s)/armor/dmg/r/slowResist` |
| `waveList` | 웨이브별 그룹 `{type, n, gap}` (그룹은 순서대로 등장) |

문제는 `QUESTIONS` 배열(30문항, `c[0]`이 정답, 표시 때 섞음, `d` 난이도). 과목 팩 교체 시 이 배열만 바꾸면 된다.

## 알려진 한계
- 사운드·이미지·애니메이션 연출 최소(도형+색). 일시정지 없음, 탭이 숨겨지면 루프가 멈춘다(브라우저 RAF 특성).
- 저장 없음: 봉인 목록·해제 보너스는 새로고침하면 사라진다. 메타 진행(카드 조각/수집)·튜토리얼 스테이지(3웨이브)·메이저 아르카나 3종 중 2종(전체 둔화, 탑 회복)은 미구현.
- 문제 형식은 4지선다만(짧은 입력형 없음). 문제 덱은 무작위 순환이며 난이도 적응 없음.
- 카드 판매/재배치, Lv4, 타깃 우선순위 변경 없음. 키보드만으로는 강화 슬롯을 고를 수 없다(강화는 탭/클릭).
- 밸런스는 봇 시뮬레이션 기준 1차값. 알려진 문제: 8슬롯×(5+4+6)=120마나면 판이 포화되어 후반엔 문제 풀이가 의미를 잃음, 빠른 찍기가 성실한 보통 풀이와 마나 효율이 비슷함, 문제를 푸는 플레이어에겐 난이도가 거의 없음.
