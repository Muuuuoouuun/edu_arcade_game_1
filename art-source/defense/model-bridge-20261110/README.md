# 카르·발리스타·나무 병사 모델 인계

별도 `codex/arcana-stage-experience-20261106`의 `bec804114a26a85a800379058463f4e9fd0bf2cf`에서 실시간 모델과 Blender 파일을 그대로 가져온 제작용 사본이다. 각 경로·SHA-256·GLB 클립 목록은 [manifest.json](manifest.json)에 기록한다. 게임이 이 사본을 아직 불러오지 않는다.

- 카르: `kar-walk`, `kar-slam`, 8방향 진입·정지와 리셋 클립. 1,320,844바이트, 메시 13개.
- 발리스타: `frontier-ballista-release` 클립. 230,188바이트, 메시 7개.
- 나무 병사: 보행과 공격이 별도 GLB에 들어 있다. 각각 134,616 / 138,612바이트, 메시 8개씩.

메시 수는 draw call이나 실기기 성능 측정값이 아니다. Blender 파일·GLB는 원본 그대로며, 생성 스크립트와 의존성·내보내기 과정을 이 디렉터리로 이식한 것은 아니다. Frontier의 방향·크기·높이·타격 시점·규칙은 현재 캠페인과 다르므로 자동 적용하지 않는다. 실전 연결 전 GLB 리그/피벗·애니메이션, 기존 엔진 상태와 명중 시점, 접지·가림, 사거리와 입력, 저사양 GPU를 별도 검증한다.
