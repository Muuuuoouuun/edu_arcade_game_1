2026-11-12 전체 통합에서 기존 통합 계보에 없던 43개 원본(37개 누락 경로와 6개 대안 버전)을 격리 보존했다. 현재 타워·폰트·게임 진입·도구를 덮어쓰지 않는다. manifest.json에 원본 경로·Git blob·해시를 기록했다.
