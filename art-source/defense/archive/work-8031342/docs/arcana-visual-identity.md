# 아르카나 수비대: 설산 타워 시각 기준

## 세계관과 형태

아르카나는 작은 장난감처럼 읽히는 판타지 방어전이다. 전투 아트의 반복 요소는 낮고 두꺼운 원형 석조 기단, 돌출된 블록과 어두운 줄눈, 따뜻한 황동 이음쇠, 강한 색의 깃발과 한눈에 보이는 원소 표식이다. 모델은 위에서 내려다보는 정사영에 가까운 시점에서도 기단·몸체·발사부가 분리되어야 한다. 기존의 아홉 타워와 설산 배경을 기준으로 삼았다.

## 설산의 재료와 색

| 용도 | 방향 | 기준색 |
|---|---|---|
| 깊은 틈과 그림자 | 차가운 먹색으로 블록 경계 확보 | `#131f29` |
| 풍화된 돌 | 청회색에 명도 차이를 주어 분리 | `#293b47`, `#3b4f57` |
| 눈과 석재의 밝은 면 | 순백보다 푸른 회백색 | `#c2e0e3` |
| 금속 | 차가운 배경에 대비되는 오래된 황동 | `#6b4f2b`, `#ad6b1f` |
| 얼음의 초점 | 밝은 청록의 각진 면과 약한 발광 | `#1aa1cf` |
| 수호 문장 | 짙은 남색 바탕의 눈꽃 | `#041329` |

색은 제작용 출발점이며 조명과 색 관리에 따라 실제 렌더 색은 달라진다. 지역의 냉색이 바탕을 이루고 따뜻한 금속은 이음새·문장 테두리에 제한한다. 원소의 의미는 색만이 아니라 수정 실루엣과 눈꽃 문양으로도 구분한다.

## 적용한 시안

`frost-guardian`은 앞선 `frost-beacon`을 보존하면서 위 기준을 적용한 설산 수호탑이다. 분리된 돌 블록과 줄눈은 작은 화면에서 형태를 읽게 하고, 남색 문장과 네 개의 보조 수정은 다른 속성과 구분되는 표식이다. 석재·눈·황동·천의 색 변화는 128px 이미지 맵으로 제작해 GLB에 포함했다. 각진 수정, 볼트, 금속 받침은 실제 메시다. 이미지 맵의 미세한 결은 축소 시 사라질 수 있으므로 큰 돌의 명도 차이와 실루엣을 우선한다.

- 편집 원본: `art-source/defense/frost-guardian.blend`
- 배포 가능한 독립 모델과 렌더: `public/defense/models/frost-guardian.glb`, `frost-guardian.png`
- 생성 스크립트: `tools/blender/build_frost_guardian.py`
- 비교: 모델 작업실에서 기존 서리 수정탑 시안과 서리 수호탑을 번갈아 선택한다.

재생성은 위 3개 결과물을 덮어쓴다. Blender 원본을 수동으로 고쳤다면 먼저 다른 이름으로 보관한다.

```bash
blender -b --python-exit-code 1 --python tools/blender/build_frost_guardian.py
```

현재 시안은 작업실용이며 전투의 아홉 타워나 속성·밸런스에 추가되지 않았다. 실제 게임에 쓰려면 타워의 역할을 정하고, 정사영·크기·발 기준을 기존 아틀라스에 맞춰 비교한 뒤 전투 장면과 모바일 기기에서 확인해야 한다.
