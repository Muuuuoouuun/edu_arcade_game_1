# 영웅 무기: 속성·형태·재질 시안

여섯 영웅의 무기를 따로 살펴보는 정적 3D 원형이다. 기존 `data.ts`, 전투 엔진의 기본 공격 속성과 캐릭터 아틀라스를 기준으로 삼았다. 게임상 속성과 시각적 소재를 구별한다. 이안의 청색 수정이나 루나의 녹색 덩굴은 외형이며 별도 얼음·자연 피해를 뜻하지 않는다.

| 영웅 | 게임의 기본 공격 | 실루엣·재료 표현 | 문화와 설정의 범위 |
|---|---|---|---|
| 이안 | 불 | 짙은 나무 지팡이, 금속 발톱, 청색 수정과 작은 불씨 | 기존 인간 마법사의 이미지에 기초한 판타지 소품 |
| 리엘 | 물리 | 굽은 나무 활과 현·화살, 녹색 잎 장식과 가죽 그립 | 기존 엘프 명사수를 위한 숲 이미지 |
| 브론 | 충격 | 짧고 넓은 쇠망치, 강철 타격면과 황동 보강대, 나선형 가죽 손잡이 | 기존 드워프 공병의 작업 도구 이미지 |
| 청운 | 번개 | 곧은 검, 청록색 손잡이, 금속 가드, 붉은 번개선이 있는 종이 부적 | 기존의 동방 도사 설정을 따르는 창작 시안. 문양은 실제 주문이나 특정 종교의 문자가 아니다. |
| 카르 | 충격 | 브론보다 큰 석제 망치 머리, 어두운 철 보강과 산 모양 표식 | 설산에서 만나는 전사의 창작 시안. 특정 실존 민족의 역사적 무기로 단정하지 않는다. |
| 루나 | 물리 | 나무 지팡이, 휘감긴 덩굴, 가지와 녹색 수정 | 기존 수인 드루이드와 숲·영물 이미지를 바탕으로 한 판타지 소품. 늑대는 별도로 공격한다. |

## 원본과 사용

- 편집 가능한 원본은 `art-source/defense/hero-armory.blend`다. 6개 컬렉션과 재질 이미지 맵이 포함된다.
- 각 GLB와 투명 PNG는 `public/defense/models/`의 `ian-staff`, `riel-bow`, `bron-hammer`, `cheongun-sword`, `kar-hammer`, `luna-staff`다. GLB에 질감이 들어 있어 별도 이미지 요청이 없다.
- 모델 작업실의 **모델 종류 → 영웅 무기**에서 선택해 회전·확대·메시를 보고 GLB를 내려받는다. 현재 시안은 정적 모델이어서 발사 버튼은 비활성화된다.
- 디스플레이 받침과 무기 고정 지지대도 GLB 메시다. 손에 장착하거나 전투에서 사용하기 전에는 받침·지지대를 분리하고 손 위치, 크기, 방향, 모션 및 기존 스프라이트와의 일치를 조정해야 한다.
- 기존 영웅 스프라이트, 전투 효과, 속성 계산은 바꾸지 않았다. 문화권의 역사적 고증이나 게임 내 국가·민족 설정을 확정한 결과물이 아니다.

```bash
blender -b --python-exit-code 1 --python tools/blender/build_hero_armory.py
```

재생성은 위 `.blend`, GLB와 PNG 6종을 덮어쓴다. 수동으로 고친 원본은 별도 이름으로 보관한다.

## 확인

Blender에서 6개 컬렉션과 내장 재질 이미지를 다시 열었다. GLB 6개의 내장 이미지·텍스처 UV, 투명 PNG, 모델 작업실의 분류 전환과 다운로드 경로를 점검했다. Chromium의 1440×900, 390×844, 320×740에서 모델을 로드했으며 실제 모바일 기기 성능과 전투 중 가독성은 별도로 확인해야 한다.

기존 타워 분기도 같은 속성 체계를 사용한다. 관통·연발 석궁은 물리, 화염탑은 불, 뇌전탑은 번개, 파쇄포는 충격, 물폭탄포는 물이다. 현재 작업실에는 화염·관통·물폭탄포 3D 모델이 있고, 뇌전·파쇄·연발 분기의 3D 모델은 이번 결과에 포함되지 않는다. 서리 수호탑은 전투 규칙에 연결되지 않은 시안이다.
