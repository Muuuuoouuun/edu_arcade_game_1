# 아르카나 API 교차 검토 및 제작 기록

2026-11-09. 환경변수의 자격 증명 값은 기록하지 않았다. API는 개발 중 독립 검토에 사용했으며 게임 실행 시 호출하거나 게임에 키를 포함하지 않는다.

## 호출 및 확인

- OpenAI와 Anthropic의 고유 자격 증명 7개에 대해 모델 목록 조회로 인증을 확인했다. OpenAI 1개와 Anthropic 5개는 성공했고 `ANTHROPIC_API_KEY_JUNGSANGHWA`는 HTTP 401이었다. 이름이 다른 환경변수가 같은 키를 공유하는 경우는 한 번만 확인했다. 인증 성공은 한도·잔액·모든 모델의 사용 권한을 보장하지 않는다.
- 각 서비스에서 사용할 모델 목록을 조회한 후 GPT-4.1 mini와 Claude Haiku 4.5에 동일한 타워 생성 스크립트를 각각 1회 전달해 부분 생성과 렌더 생략을 검토했다. API 응답의 사용량은 각각 입력 8,826 / 출력 800 토큰과 입력 10,576 / 출력 570 토큰이다. 실제 청구액과 나머지 계정의 사용량은 여기서 확인할 수 없다. 제시된 달러 상한을 시스템에 설정하거나 다른 사용량과 합산한 것은 아니다.
- 둘 다 새 PNG가 없는 경우 잘못된 참조가 생길 수 있다고 지적했다. Claude는 `--only`가 나머지 모델의 목록을 지우는 문제도 발견했다. GPT는 목록이 하나로 줄어드는 동작을 문제로 판단하지 않았고, 두 모델의 제안은 기존 PNG가 남아 있어도 오래되었을 가능성을 구분하지 못했다. 따라서 코드와 격리된 실제 Blender 실행으로 별도 확인했다.

## 결과

- `--only`는 기존 목록의 나머지 항목을 보존한다. `--skip-render`는 실제 파일 유무와 재생성 여부를 기록한다.
- 새 서리 수정탑 시안의 `.blend`, GLB, 투명 PNG를 만들고 모델 작업실에 추가했다. 기존 게임 전투 자산과 규칙에는 연결하지 않았다.
- 기존 36개 밸런스 시뮬레이션 조건을 다시 실행했다. 정예 2-4에서 3타워 전략은 패배, 전체 확장 자동 전략은 승리했다. 이는 정해진 자동 조작 모델의 결과이며 사람의 체감 난이도나 실제 기기 성능을 의미하지 않는다.
- 자동 테스트 90개, 빌드, 격리된 부분 재생성, GLB 재가져오기와 투명 PNG를 확인했다. 세부 재생성 방법은 `arcana-asset-pipeline.md`를 참조한다.
- Chromium에서 1440×900과 390×844로 새 시안을 선택하고 모델 로드·발광 미리보기·다운로드 경로·가로 넘침을 확인했다. 이는 자동화된 브라우저 검증이며 실기기 성능 평가는 아니다.
