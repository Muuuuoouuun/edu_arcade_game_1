# 과거 카메라 각도 비교 — 보존본

이 폴더는 이전 `work` 작업 공간의 미추적 각도 비교 자료를 2026-11-10에 보존한 사본이다. 이안은 임시 프록시이며 최종 캐릭터 모델이 아니다. 30·35·45·60도 자료는 과거 비교 실험으로, 카메라의 최종 선택이나 실제 게임 적용을 뜻하지 않는다.

원래 상대 경로 구조를 보존하지만 현재 게임에서 불러오지 않는다. HTML·스크립트는 당시 프로젝트 루트와 별도의 Vite 설정을 전제하며 이 보존 위치에서 바로 실행되도록 이식한 것은 아니다. 당시 비교는 예전 2D 지도 이미지를 선택적으로 사용한다. 현재 게임의 3D 전장에 연결하지 않는다. 원본 미커밋 파일은 이전 작업 공간에도 그대로 남아 있다.

현재 지침과 Frontier 3D 브랜치는 [프로젝트 통합 기준](../../../../docs/arcana-project-direction.md)을 참조한다.
