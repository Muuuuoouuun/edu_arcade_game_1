# 아르카나 전투 시점 비교

> 이후 방향 변경: 이 문서는 초기 시점 비교 기록이다. 현재 전투·거점의 맵은 이미지 배경이 아닌 3D 지형이며, 최신 범위는 [3D 전장 방향](arcana-3d-direction.md)을 따른다.

2026-11-09. 기존 전투 2D 원화와 30°·35°·45°·60°의 3D 렌더를 숲 전장에 모의 배치해 비교했다. 각도는 **수평선에서 아래로 내려다보는 각도**다.

## 무엇을 비교했나

- 이안은 파란 모자·얼굴·로브·지팡이의 겹침을 알아보기 위한 단순 전신 **임시 모델**이다. 기존 게임의 완성 원화나 완성 리그가 아니다.
- 화염탑은 기존 `fire-tower-crafted.glb`를 사용했다. 세 렌더에서 방위각은 35°, 정사영 배율은 7.8로 고정하고 내려다보는 각도만 바꿨다. 조명·대상도 같다.
- 비교 페이지는 기존 숲 배경과 새로 그린 단순 숲 시안을 전환한다. 단순 숲은 참고 이미지의 명료한 바닥 색면·큰 지형 덩어리·유닛 대비를 아르카나의 숲에 맞게 재해석했다. 양쪽 모두 기존 게임 경로와 건설 지점 좌표를 사용하지만, 적·체력바·숲 장식은 비교를 위한 모의 배치이며 실제 전투 화면이나 충돌 규칙이 아니다. 기준 이미지는 실제 게임의 이안과 화염탑 아틀라스다.
- 각 대상의 4개 이미지에 같은 공통 투명 영역을 적용한다. 게임의 영웅 84·타워 100 월드 단위에 맞춰 배치하므로 **각도 간 각 대상의 표시 배율은 동일**하다. 기존 원화의 카메라 각도는 측정하지 못했다.
- 화면 선택 390px은 전장 최대 폭 374px, 320px은 최대 304px로 표시한다. 비교 화면이 그보다 좁으면 추가 축소된다. 900×600 전장을 기준으로 한 근사치이며 실제 브라우저 UI와 기기 설정에 따라 달라질 수 있다.

## 관찰과 잠정 선택

| 각도 | 이 표본에서 보인 차이 | 판단 |
|---|---|---|
| 30° | 이안의 얼굴과 타워 옆면이 가장 잘 보인다. 타워 윗면은 다른 각도보다 적게 보인다. | 캐릭터 정체성 우선의 비교 후보 |
| 35° | 얼굴과 타워 윗면을 함께 보여 준다. 기존 타워 렌더의 약 33°와도 가깝다. | **우선 기준**으로 사용할 만하다 |
| 45° | 타워 윗면이 더 드러나지만, 단순 이안의 모자 챙이 얼굴을 더 가린다. | 배치 중심의 대안. 얼굴 가림을 조정한 완성 모델로 재검토 |
| 60° | 윗면과 배치 관계는 더욱 잘 보이지만 임시 이안은 모자에 얼굴 대부분이 가려진다. | 높은 시점 후보. 캐릭터 머리·모자 형상을 함께 조정해야 한다 |

참고 이미지의 높은 시점과 명확한 색면은 가독성에 유용하다. 첨부된 참고의 플레이 인상을 고려하면 45°를 다음 실험의 우선 후보로 두고 60°를 대조한다. 현재 임시 이안은 60°에서 얼굴이 잘 보이지 않으므로, 실제 느낌을 확인할 때는 각도만 올리지 말고 모자 챙·얼굴 방향·실루엣도 같이 설계해야 한다. 이안은 임시 형태이고 실제 게임의 유닛 밀도·공격·입력을 재현하지 않았으므로, 35°는 확정값이 아니다. 전신 이안의 최종 모자·얼굴·무기·공격 포즈와 실제 설산/숲 전투를 확인한 뒤 결정한다. 비교 페이지를 추가한 것이며 게임 카메라나 스프라이트는 교체하지 않았다.

## 결과물과 재현

- 비교 페이지: `camera-comparison.html` (`npm run dev` 후 `/camera-comparison.html`, 모델 작업실 하단에서도 이동)
- 8개 투명 렌더: `public/defense/camera-comparison/ian-proxy-{30,35,45,60}.png`, `fire-tower-{30,35,45,60}.png`
- 임시 모델과 카메라 원본: `art-source/defense/ian-camera-proxy.blend`
- 생성 스크립트: `tools/blender/render_camera_comparison.py`. 실행 전 `fire-tower-crafted.glb`가 필요하며, 위 렌더와 `.blend`를 덮어쓴다.

```bash
blender -b --python-exit-code 1 --python tools/blender/render_camera_comparison.py
npm run dev
```

비교 페이지의 1.35배 확대는 900×600 중 중앙 약 667×444만 보이므로 시작 지점과 마을이 화면 밖으로 잘린다. 팬·미니맵·경고는 이 시안에 구현하지 않았다. 실제 게임에 확대를 도입하려면 입력 좌표와 화면 밖 위협 알림을 별도 구현하고 검증해야 한다.

PNG의 투명도·512×512 크기·프레임 여백과 각도별 이미지 차이를 확인했다. Chromium 1500px·390px·320px 폭에서 5개 비교 카드, 화면 크기 전환, 가로 넘침 및 페이지 오류를 확인했다. 테스트 90개와 빌드가 통과했다. 실제 모바일 기기에서의 성능 및 플레이어 대상 시인성 평가는 별도로 필요하다.
