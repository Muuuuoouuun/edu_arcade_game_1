# 타워 선택 시안 2차 · 2026-11-12

기존 A~D 타워 시안은 사용자가 모두 보존하도록 선택했다. 기존 시안의 실루엣·소재·청록/금색의 방향을 참고해 4종씩 다섯 장을 새로 제작했다. 각 장의 A~D는 해당 장 안에서만 구분한다.

| 장 | 분야 | 시안 A / B / C / D |
| --- | --- | --- |
| [1](01-forest-ranged.png) | 숲·원거리 | 쌍발 석궁 / 엘프 활탑 / 드워프 기계 발리스타 / 나무 감시탑 |
| [2](02-fire-volcanic.png) | 화염·화산 | 용광로 / 공중 화염 수정 / 용암 박격포 / 불꽃 등롱 |
| [3](03-lightning-eastern.png) | 뇌전·동방 | 관측대 / 부적 종탑 / 번개 비석 / 코일 발사탑 |
| [4](04-water-frost.png) | 물·서리 | 물레방아 펌프 / 서리 수정탑 / 수압 대포 / 극지 등대 |
| [5](05-siege-support.png) | 공성·지원 후보 | 중박격포 / 생명의 등롱 / 보호 수정 / 정찰 관측탑 |

모두 선택용 생성 이미지다. 기능명은 외형을 설명하는 후보이며 신규 치유·방패·정찰 규칙의 확정을 뜻하지 않는다. 각 디자인은 아직 Blender 모델이나 게임 자산이 아니다. 원본 선택지에 덮어쓰지 않는다.
