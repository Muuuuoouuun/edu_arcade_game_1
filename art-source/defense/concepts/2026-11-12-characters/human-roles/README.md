# 인간 영웅·용병·NPC·생성 병사 시안 · 2026-11-12

기본 캐릭터 비율과 질감을 유지해 인간 캐릭터만으로 확장한 5장·20종의 외형 후보다. 기존 1~10번에 이어 11~15번을 사용한다. 모든 후보는 성인 인간이며 얼굴·연령·체형·장비에 차이를 주었다.

각 이미지의 A는 왼쪽 위, B는 오른쪽 위, C는 왼쪽 아래, D는 오른쪽 아래다. `12-A`, `13-C`, `14-D`처럼 선택한다.

## 외형으로 역할 구분

- 영웅·지휘관: 대표 무기와 실루엣, 강한 인상, 개인 장식으로 구분한다.
- 용병: 수선된 방패·개별 장구·여행 장비로 경험과 개성을 표현한다.
- 마을 NPC: 앞치마·장부·약초 바구니·음식 쟁반 등 직업 도구와 친근한 표정이 중심이다.
- 기본 보병: 청록·아이보리 제복, 단순한 강철 투구·가죽 벨트·황동 버클을 공유한다. 창·검·활·석궁과 방패 형태로 병과를 구분한다.
- 지원 병과: 같은 수비대 제복 안에서 지팡이·의료 가방·수리 도구·군기로 역할을 구분한다.

5개 결과의 전신·A~D 배치·인간형 얼굴과 역할 구분을 시각적으로 확인했다. 비율 수치는 제작 목표이며 실제 메시 실측값이 아니다. 명칭은 외형 후보 식별용이며, NPC 거래·용병 고용·병사 생산 또는 소환·지원 능력 등의 게임 규칙은 확정하거나 구현하지 않았다. 실제 GLB·리깅·게임 적용도 포함하지 않는다. 선택 후 전장 크기 가독성·손과 장비 결합·측면/후면·모션 간섭·병력 군집에서의 구분을 확인한다.
