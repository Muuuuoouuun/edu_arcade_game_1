# 추가 테마 캐릭터 시안 · 2026-11-12

5개 결과의 전신·A~D 배치·기본 비율과 재질 방향을 시각적으로 확인했다. 명칭은 후보 식별용이며 새 지역·종족 설정·전투 역할은 확정하지 않는다. 실제 GLB·리깅·게임 적용은 포함하지 않으며, 선택 이후 전장 크기 가독성·측면/후면·손잡이와 관절·모션 간섭을 검증한다. 기존 원본과 보정판은 보존한다.
