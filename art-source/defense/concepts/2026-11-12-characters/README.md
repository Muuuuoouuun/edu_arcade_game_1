# 테마별 캐릭터 선택 시안 · 2026-11-12

[용병·영웅·인간형 보스 16~20번](mercenaries-heroes-bosses/README.md)을 추가했다. 전열·특수 용병 8종, 근접·비전 영웅 8종, 보스 지휘관 4종의 외형 후보다.

[인간 캐릭터 11~15번: 영웅·용병·NPC·기본 보병·지원 병과](human-roles/README.md)를 추가했다. 기본 비율·질감을 유지한 20종의 외형 후보다.

[추가 테마 6~10번: 사막·화산·천공·늪지·별빛 유적](additional-themes/README.md)도 기본 캐릭터 비율·질감에 맞춰 제작했다.

기존 세계관과 참고 이미지를 바탕으로 제작한 선택용 이미지다. 새 인물명·영입·전투 역할·지역 해금은 확정하지 않는다. 전신·문화·무기·재질과 종족을 비교하는 자료이며 실제 GLB나 리깅 모델이 아니다. 기존 6영웅은 유지한다.

후속 요청에 따라 **[기본 테마 보정판](base-theme-v2/README.md)**을 제작했다. 아래 최초 시안은 복식·무기·종족 아이디어 자료로 보존하며, 이후 비율과 질감은 [기본 캐릭터 기준](../../../../docs/arcana-character-art-standard.md)과 보정판을 우선한다. 후보 번호는 동일하다.
