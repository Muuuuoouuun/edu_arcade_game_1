## 제작과 동작

`blender -b --python tools/blender/build_human_guard.py -- --samples 96 --size 768`

생성기는 이미지 픽셀을 메시로 변환하지 않는다. 얼굴·갑옷·옷·방패·창을 편집 가능한 개별 메시로 만들고, GLB에서는 같은 관절에 붙은 표면을 합친다. Blender 전방은 +Y, 위는 +Z이며 GLB 전방은 -Z, 위는 +Y이다. 발바닥과 루트 기준 지면은 0이다.

| 클립 | 길이 | 내용 |
| --- | --- | --- |
| `human-guard-idle` | 2초 | 상체의 작은 호흡과 머리 움직임, 반복 |
| `human-guard-walk` | 0.8초 | 제자리 양발 교대와 팔 움직임, 반복 |
| `human-guard-thrust` | 1초 | 준비·창 내밀기·복귀. 최대 전방 도달은 0.4초 |

창과 방패는 각 팔 관절의 자식으로 고정한다. 0.4초는 이 모델에서 창끝이 가장 앞으로 나오는 시각이며, 게임의 피해 판정을 발생시키는 이벤트가 아니다. 실제 연결 시 엔진의 명중 시각에 맞춰 클립을 샘플링해야 한다.

## 검증과 남은 작업

`python tools/tests/check-human-guard.py`는 실제 GLB의 3개 클립·길이·반복/복귀·루트 고정·장비 종속 관계·파일 해시를 확인한다. 60Hz로 관절 변환을 보간해 양발 메시가 지면 아래로 내려가지 않는지, 창의 최대 전방 도달이 0.4초인지 확인한다. 기본·보행·찌르기의 실제 렌더를 살펴 얼굴, 옷 형태, 장비 전체가 보이는지 검토했다.

현재는 **개발용 모델 시제품**이다. 시안의 손그림 질감을 재현한 최종 텍스처, 스킨 리깅, 발 IK, 갑옷/몸/무기의 모든 방향 간섭, 실제 전장 크기 가독성, 모바일 성능은 아직 검증하지 않았다. 새 병과·소환·생산·고용이나 캠페인 전투 추가가 확정된 것은 아니다. 게임 원본 자산과 기존 영웅 모델은 덮어쓰지 않았다.
