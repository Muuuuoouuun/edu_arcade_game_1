# 전투용 성문 원본

2026-11-06에 기존 `concepts/2026-10-29/castles/` 4종을 참고해 네이티브 이미지 생성으로 제작했다. 이 PNG는 생성 결과 그대로 보관하며, 실제 3D 모델이나 Blender 렌더라고 표시하지 않는다.

공통 제작 기준: 투명 배경, 지면판 없는 단일 성문, 약간 높은 정면 시점, 따뜻한 좌상단 조명과 차가운 그림자, 작은 전투 크기에서 구분되는 실루엣. 녹음 성채는 나무뿌리·이끼·녹색 지붕, 청강 요새는 석조 보루·청색 깃발·황동, 운령 산성은 한국식 기와 문루·주홍 깃발, 황혼성은 고딕 첨탑·자주색 깃발·보라색 창을 사용한다.

`sources.json`은 원본 크기와 alpha > 24인 영역의 경계를 기록한다. 여백을 잘라내지 않고, 화면 배치 시 보이는 영역의 바닥·중심을 정렬하는 용도다. 운령은 넓고 황혼성은 높으므로 같은 사각형으로 늘이지 않는다. 미세한 반투명 외곽은 원본에 남아 있다.

`npm run art:gates`는 FFmpeg로 가로 512px WebP를 만들고 원본/배포 파일 해시와 `gateArt.ts` 배치값을 갱신한다. 네 배포 파일 합계는 약 326KB이며 실제 화면에서는 선택된 테마 하나를 불러온다. 로딩 실패 시 기존 SVG 성문을 표시한다.
