## 사라져 보인 원인

파일이 전부 삭제된 상태는 아니었다. 최신 main은 과거 캠페인 3D 지형을 비활성 자료로 보존하고 기본 원정에 베이크 이미지를 표시했다. 실제 3D 변경 전장과 러시는 다른 진입점에 있었다. 이 대화의 3D 배우 연결·새 병사·컨셉 제작물은 과거 main 기반 작업 트리에 미커밋 상태로 남아 최신 통합 결과에 포함되지 않았다. `/workspace/edu_arcade_game_1`의 `work`도 별도 과거 작업 트리였다.

사용자가 참조한 두 Codex 대화는 `read_thread`를 각각 여러 번 호출했으나 `connection closed before server request was answered`로 본문을 받지 못했다. 그 대화 내용을 읽었다고 가정하지 않고 최신 원격 main, [전체 병합 기록](arcana-world-planning/full-merge-2026-11-12.md), 실제 코드·모델·실행 결과를 대조했다.

## 실제 변경

- 최신 main을 같은 작업 트리에 병합하고 원정의 `DefenseBoard`에 단일 Three.js 장면을 연결했다. 기본 전장과 원정 카드에서 과거 지도 이미지 로딩을 제거했다. WebGL 미지원 시 벡터 지형으로 대체한다.
- 기존 카르·브론·관통 석궁 Lv2·나무 병사에 **이안과 기본 석궁·마법·포격 Lv1**을 추가했다. 새 저장에서도 해금 우회 없이 이안과 기본 타워의 3D 표현을 볼 수 있다. 다른 분기·영웅·적·성문·효과는 기존 표현을 유지한다.
- 최신 엔진의 이동 거리·속도·방향을 읽어 보행과 정지 방향을 맞췄다. 나무 병사의 넉백으로 보행 클립이 거꾸로 흐르던 표현도 수정했다. 피해는 엔진이 판정한다.
- 이안은 기존 공격 메시 한 개에 이름·부모가 일치하는 보행 애니메이션 데이터만 결합했다. 원본 GLB는 수정하지 않았다. `npm run models:battle-starters:check`가 결과와 출처 해시를 재검증한다.
- 기본 석궁·포격은 조준부만 회전하고 마법탑의 기단은 고정한다. 클립 접촉 시각은 이안 .15초, 기본 석궁 .1초, 기본 포격 .28초, 기본 마법 .15초다. [자산 목록](../public/defense/models/battle/manifest.json).
- 작업실은 최신 모델 목록·동작 반복·정지 자세·걸음 선택·자동 화면 맞춤에 인간 창방패병의 호흡·보행·찌르기와 이전 Frontier/카르 디테일 후보를 함께 유지한다. 신규 인간 병과 규칙은 추가하지 않았다.
- 컨셉 사진, Blender 원본, 모델·검토 도구와 이전 기록을 Git에 보존했다. 과거 작업 트리를 삭제하거나 원본 파일을 덮어 복구하지 않았다.

## 검증

- `npm test`: **723개 통과**.
- `npm run build`, `npm run build:mobile`: 통과. 모바일 자산 검사 **4개 통과**, 원정 GLB 8개의 용량·SHA-256 일치와 변경 전장·러시·군단 자산 보존 확인.
- `tools/check-battle-models.cjs`: **6개 시나리오 통과**. 새 게임 이안·기본 3타워, 카르·관통·나무, 실제 공격 상태, PC 키보드·모바일 가로 터치, 정지/컨텍스트 복구, 개별 GLB 실패, WebGL 미지원, 인간 병사 작업실.
- `tools/check-arcana-entries.cjs`: PC·모바일 가로에서 타이틀 입구, 변경 전장 3모드 GLB 지형·플레이 시작, 러시 마을→전투·정지/재개, 군단 직접 배치→전투 검증 통과.
- 체력바 숨김 스타일과 3D 적 선택 영역의 충돌을 수정하고 브라우저 회귀 검사에 포함했다.
- 이안 복합 GLB 재생성 검사, 인간 병사 GLB 60Hz 접지·무기·루프·해시 검사 통과.

브라우저는 Chromium SwiftShader, 모바일은 화면/터치 에뮬레이션이다. 실제 Android GPU·발열·FPS·APK 설치·전체 모드 완주 검증은 아니다. 원정에 남은 SVG 표현과 3D 모델 간 깊이, 모든 무기와 효과 출발점의 정렬 및 전 모델의 최종 질감은 후속 검토 범위다.
