## 지형 구현

숲·설산 각각 단일 경로/두 경로인 총 4개 지형을 Blender 메시로 제작했다. 높이가 있는 길 가장자리, 분리된 포장석, 목재 교량의 판자·기둥·뒤 난간, 고지대의 석재 받침·계단을 포함한다. 기존 회화 배경 위에 투명 렌더를 겹치며, 게임은 2.5D SVG 렌더링을 유지한다.

`tools/export-terrain-layout.ts`가 실제 `getPaths`·`getSlots`에서 지형 좌표를 추출한다. `tools/blender/build_terrain.py`는 900×600 논리 좌표의 윗면이 정사영 카메라에서도 같은 위치에 보이도록 모델 좌표를 보정한다. 최종 이미지는 1800×1200 WebP다. 경로의 모든 꺾임 지점이 원래 좌표와 0.01 논리 단위 미만 차이인지 생성 시 검사한다.

```bash
npm run models:terrain
```

- 편집 원본과 PNG: `art-source/defense/terrain-{forest|snow}-{single|expanded}.{blend|png}`
- 전투 에셋: `public/defense/terrain/`의 WebP 4개와 해시·투영 좌표 manifest
- 화면 연결: `src/components/DefenseTerrain.tsx`

교량 앞 난간은 SVG로 그리며 유닛과 같은 Y 정렬에 넣어 앞뒤 가림을 표현한다. 터치와 클릭을 가로채지 않는다. 숲의 교량 중심은 기존 경로와 일치하고, 설산의 푸른 얼음 구간은 기존 가속 범위 x=300~520에 맞춘다. 고지대의 기존 사거리 보너스는 그대로다.

지형 로딩 중이거나 실패하면 기존 길·교량 표현을 유지한다. 맵을 바꿀 때 이전 지역의 지형이 남지 않도록 현재 에셋 경로와 완료된 로딩 경로를 비교한다. 렌더된 높낮이는 시각 표현이며, 이번 변경에서 통행 금지·경사 속도·절벽 충돌·실시간 지형 카메라를 추가하지 않았다.

## 돌진과 피격 반응

기존 위치 선택 돌진에 **경로상의 적 1회 타격**을 추가했다. 기본 물리 피해 36, 넉백 힘 100, 경로 중심에서 28 논리 단위 이내를 판정한다. 기존 최대 거리 200, 이동 속도 750, 재사용 시간 5초를 사용한다. 신규 피해는 영구 훈련·전직에 추가 비례하지 않는다.

매 시뮬레이션 단계의 시작점과 끝점 사이 선분을 검사하므로 빠르게 지나간 적도 판정한다. 이번 돌진에서 맞힌 적 ID를 기록해 여러 프레임에 걸쳐 겹쳐도 한 번만 피해를 준다. 새 돌진에서만 목록을 초기화한다. 사망 정산은 기존 처치·보상 함수를 사용하고, 죽은 적이 같은 단계에서 성문까지 진행하지 않게 바로 제거한다. 일시정지는 이동·타격·재사용 시간 모두를 멈춘다.

돌진은 영웅 무적·보스 충전 차단을 제공하지 않는다. 충전 차단은 기존 필살기 규칙을 유지한다. 적 밀림은 기존 질량·넉백 면역에 따르며, 무거운 보스에게도 같은 밀림 거리를 적용하지 않는다.

넉백 속도 35 이상에서는 속도에 비례한 짧은 궤적, 7 초과~35 미만에서는 발밑 먼지와 몸을 누르는 반응을 사용한다. 동작 줄이기에서는 이 추가 장식을 끈다. 이 연출 변경 자체는 기존 넉백 힘·질량·마찰을 바꾸지 않는다.

## 확인 범위와 후속 작업

전장 좌표와 렌더의 대응, 돌진의 선분 판정·중복 피해·중복 보상 방지, 기존 보행 회귀를 자동 검사한다. 실제 UI에서는 스토리 해금 예시 저장으로 진입한 뒤 이동·건설·웨이브 시작·돌진·일시정지를 조작한다. 예시 저장은 영웅과 스테이지 접근을 위한 것이며 전투 중 피해·승패를 주입하지 않는다.

브라우저 검증과 실제 Android 기기 성능·촉감·사용자 재미 검증은 구분한다. 지형 메시의 미세 장식 확대, 길을 막는 충돌, 안개재의 표지석 장치와 보스 경로 변경은 후속 범위다.
