원격 main `2eabc76`, Claude `bf7c1c6`·`04ee376`, 깨끗한 단일 작업 트리와 실행 중인 작업을 확인했다. Claude 53회차의 영웅 공격 소리 예외 기획을 읽었으며 이번 시각 작업에 포함하지 않았다. 기존 지형·성문·통나무 병사·영웅 진입/보행 복귀·서리늑대 동작을 보존한다.

## 컨셉과 현재 화면에서 고른 차이

[원본 원거리 동작 컨셉](../art-source/defense/atlases/ranged-motion.png)과 실제 PC/모바일 전투를 비교했다. 리엘의 초록 후드·금발·긴 귀·곡선 활을 유지하면서, **제자리 사격에서 화살을 놓은 자세가 고정 회수 이미지로 바뀌는 구간**을 선택했다. 이동 중의 여덟 걸음 복귀는 기존 구현을 계속 사용한다.

새 0.12초 실제 관절 클립은 기존 사격 0.10초의 해제 자세에서 시작해 원래 준비 자세로 끝난다. 그리는 손이 짧은 호를 따라 돌아오며 팔꿈치와 손목의 연결을 다시 계산한다. 손은 클립 0.06초에 시위의 화살 걸림점에 도착하고 새 화살이 나타난다. 몸통·머리는 0.08초까지 안정되고, 망토·머리카락은 조금 늦게 0.12초에 정리된다. 두 장화는 같은 위치와 자세를 유지한다.

새 형상이나 재질 변경은 없다. 기존 입체 모델의 실제 팔·몸통·천 관절을 움직이고 같은 카메라로 다시 베이크했다. 축소된 전장에서는 손의 세부 이동보다 **화살을 놓은 상태 → 손 회수 → 재장전**의 구분을 우선한다.

## 전투 연결

`motion.speed <= 0.5`인 리엘 영웅/용병의 일반 공격 회수에 적용한다. 방향은 기존 공격과 같은 현재 위치→목표의 8방향 구간을 사용한다. 필살기·돌파·이동 중 보행 복귀가 새 회수보다 우선한다.

| 공격 경과 시간 | 표시 |
| --- | --- |
| 0.16–0.175초 미만 | 기존 화살 해제 자세 |
| 0.175–0.22초 미만 | 손을 되돌리는 베이크: 클립 0.04초 |
| 0.22–0.27초 미만 | 재장전 후 천이 정리되는 베이크: 클립 0.10초 |
| 0.27–0.28초 | 같은 공격 방향의 기존 준비 자세 |

발사 0.10초·재장전 표시 0.22초·공격 길이 0.28초·투사체 소켓·피해·이동은 유지한다. 게임 상태 필드를 추가하거나 공격 길이를 늘리지 않는다. 일시정지·배속은 기존 공격의 경과 시간을 따른다. 동작 줄이기는 기존 준비/해제 이미지로 표시하고 새 중간 동작을 생략한다.

새 회수 세트가 실패하면 기존 사격 표시를 사용한다. 기본 사격/보행 세트 실패도 기존 삽화 대체를 따른다. 새 회수 실패가 이동 중 복귀를 막지 않고, 이동 중 복귀 이미지 실패도 제자리 회수를 막지 않는다. 전투는 계속 2.5D이며 GLB 요청·유닛별 WebGL을 추가하지 않는다.

## 검증 결과

- GLB 13키·49보간 시점: 시작 오차 최대 4.19e-7, 준비 자세 끝 오차 2.69e-7. 양발 변환 고정, 밑창 최소 높이 약 0.005. 팔꿈치/손목 보간 연결 틈 최대 0.00194 모델 단위(384px 카메라에서 약 0.11픽셀), 활대/시위 투영 틈 최대 약 0.000016픽셀. 재장전부터 손과 화살 걸림점 일치 확인.
- 편집 원본 130메시의 시작/끝 월드 변환이 기존 사격/준비와 최대 2.99e-7 이내로 일치한다. 30개 해시, PNG 16장·WebP 16셀의 크기/알파 경계, dist 11개 파일 일치 검사 통과. 최소 투명 여백 16픽셀.
- 아트 테스트 98개 통과. 전체 279개 중 278개 통과. 실패 1건은 기준 커밋 복사본에서도 재현된 기존 수학 게임 `(3×7)/5`의 `4 !== 4.2`다. 타입 검사·프로덕션 빌드 통과.
- 스테이지 1·4·5·8×영웅/용병 총 14,400스텝의 모든 전투 상태가 기준과 동일했다. 비교에서 제외한 필드는 없다.
- 60Hz의 2/4/6틱 화면 게시 및 모든 시작 오프셋에서 적어도 한 중간 회수 자세를 확인했다. 임의 프레임 저하에서 두 자세가 모두 보인다는 보장은 아니다.
- 실제 DefenseBoard PC 1440×900·터치 390×844·320×844와 동작 줄이기·회수/사격/보행/이동 복귀 이미지 실패를 포함한 1,024시점 검사 통과. 영웅/용병·8방향·각 표시 구간·필살기/돌파/이동 우선순위 확인, 페이지 예외·전투 GLB 요청 0건, 가로 넘침 없음.
- 실제 전투 UI PC/390px에서 입장·마우스/터치 이동·웨이브·일시정지/재개·1/2배속·동작 줄이기를 조작했다. 두 화면 모두 8개 보행 자세와 각 배속에서 손 회수/재장전 중간 자세를 관측했다. 회수 중 정지하면 자세가 유지되고 동작 줄이기 해제 시 같은 자세와 시뮬레이션 시간으로 돌아온다. 발사 전 회수 표시는 0건이다. 초기 모바일 시험은 확대 해제 직후 레이아웃 변경으로 첫 터치가 취소돼, 최종 시험에서는 레이아웃 안정 후 실제 터치 이동을 다시 확인했다.
