# 카르 · 제자리 강타 회수

2026-11-08, 컨셉 개발 55회차. 기준 `ebcdf9be05d2e472f944b1a5f4b03db39f890fad`, 소유 브랜치 `codex/arcana-stage-experience-20261106`.

원본 `art-source/defense/atlases/melee-motion.png` 첫 줄과 실제 전투 화면을 비교했다. 붉은 머리·흰 털망토·양손 망치의 실루엣을 유지하면서, 몸과 장비가 함께 돌아오는 기존 제자리 회수에 무게 차이를 추가했다. 몸이 먼저 안정되고 큰 망치·모피·수염이 뒤따르는 실제 관절 동작이다.

원격 main `2eabc76`, Claude nice `bf7c1c6`, wizard `67fc1c4`는 이전 회차 이후 그대로다. main 위 통합 개발 70커밋을 보존했다. 서리늑대 체형·보폭·피격/처치, 영웅 방향 공격, 포탑 반동, 숲 지형·성문은 기존 기록을 확인해 반복하지 않았다. 직전 카르 보행 진입·이동 복귀에 이어 아직 없는 제자리 회수를 선택했다. Claude 58회차 리엘 활 두께·방향 검토는 별도 후보로 유지한다.

## 실제 동작

- `kar-reset-0`: 원본 강타 프레임 44(0.43초)에서 원본 대기 프레임 1로 이어지는 0.14초·100fps·11관절 GLB 클립.
- 몸·머리는 0.10초에 먼저 안정된다. 망치는 0.02초, 털망토는 0.025초, 수염은 0.03초 늦게 시작하고 0.14초에 복귀한다. 망치 머리는 작은 바깥/위쪽 호를 그린다.
- 두 발의 전체 월드 변환은 고정된다. 몸의 어깨와 실제 망치 그립에서 상완·팔꿈치·전완을 계산해 양손 연결을 유지한다.
- 영웅·용병의 제자리 공격에 적용한다. 방향은 공격 당시 `from→to`를 사용하며 현재 보행 방향에 끌려가지 않는다. 기존 0.28초 타격, 반동, 0.56초 공격 길이는 유지한다.
- 0.42~0.44초 기존 회수 유지 → 0.44~0.49초 회수 → 0.49~0.54초 안정 → 0.54~0.56초 기존 대기. 중간 베이크는 새 클립 0.04/0.12초다. 실제 공격의 타격/종료 시각 비율에 맞춰 표시한다.
- 이동 중에는 기존 현재 걸음 복귀가 동작한다. 돌진·필살기·동작 줄이기에는 새 회수를 사용하지 않는다. 새 세트의 이미지 실패는 기존 강타·보행·준비·이동 복귀에 영향을 주지 않는다.

엔진 변경은 없다. 전투는 두 중간 자세를 선택하는 베이크 2.5D이며 작업실은 단일 실시간 3D 장면이다. 전투의 연속 관절 보간, 이동하는 월드 좌표에서의 발 고정, 지형 IK는 구현하지 않았다.

## 산출물·재생성

```bash
npm run models:kar-reset
npm run models:kar-reset:pose-check
npm run models:kar-reset:check
```
