# 녹음 성문: 침입 피해와 관절 반응

2026-11-07 KST / 2026-11-06 UTC, 여덟 번째 컨셉 개발 회차. 녹음 성문은 기존에 실제 아치 구조와 유닛 가림을 갖췄지만, 침입 피해 때 건물은 움직이지 않고 화면의 돌파 표시만 나타났다. 이번에는 무거운 석재와 가벼운 목재·등불을 구분하는 짧은 충격 반응을 연결했다.

## 컨셉과 움직임

`art-source/defense/concepts/2026-10-29/castles/verdant-citadel.png`의 석조 아치, 목재 전망대와 매달린 등불을 기준으로 삼았다. 기존 `forest-gate.blend`와 정적 GLB·이미지는 보존하고, 별도 원본에서 목재 중앙 지붕·좌우 전망대·좌우 등불의 강체 관절 5개를 만들었다.

목재는 최대 약 5도 반동하고 등불은 최대 23도 흔들린 뒤 반대쪽으로 작게 움직이며 복귀한다. 석조 기둥·아치·기초·뿌리는 고정된다. 실제 물리 시뮬레이션이나 파괴 모델이 아닌, 편집 가능한 관절 키프레임 클립이다. 통로와 지면 위치는 움직이지 않는다.

원격 Claude의 [`bc9b513`, 43회차 타이밍 기획](https://github.com/Muuuuoouuun/edu_arcade_game_1/blob/bc9b51389137b50a77f02d8c8b64a2b18e4a967c/docs/arcana-direction-loop/cycles/43-logic.md)을 읽고, 연출이 엔진 결과를 바꾸지 않는 원칙을 적용했다. 해당 문서의 히트스톱·슬라임 밝기 제안은 이번 범위에 넣지 않았다.

## 산출물과 재생성

```bash
npm run models:forest-gate-impact
# 정적 원본을 바꿨다면 먼저 실행
npm run models:forest-gate
npm run models:forest-gate-impact
```

- 제작 코드: `tools/blender/build_forest_gate_impact.py`
- 편집 원본: `art-source/defense/forest-gate-impact.blend`
- 공통 카메라 PNG 4장: `art-source/defense/forest-gate-impact/`
- 실제 3D: `public/defense/models/forest-gate-impact.glb`, `forest-gate-impact` 단일 클립 0.6초
- 전투: `forest-gate-impact-atlas.webp`, 2048×512, 약 124.5KB
- 정지 미리보기: `forest-gate-impact.png`
- 카메라·원본 해시·19시점 경계·관절·파일 해시: `forest-gate-impact.json`

정적 성문의 원본 해시가 메타데이터와 다르면 제작기가 중단하므로, 바뀐 카메라나 크기를 낡은 배치 계약과 섞지 않는다. 512×512 카메라·배율·접지점은 정적 성문과 같다. 원본 프레임 1·3·7·12를 베이크하며 프레임 19에서 복귀한다. GLB 시간은 0~0.6초다. Blender에서 GLB를 재가져온 경우 시작 프레임은 0이므로 원본의 1~19와 GLB의 0~18을 비교한다.

GLB는 관절과 재질별 24개 메시, 22,630개 삼각형, 약 1.43MB다. 원본의 개별 부품은 그대로 편집할 수 있다. 전투에서는 아틀라스만 로드한다. 작업실의 기존 성문 항목 `/model-lab.html?model=forest-gate`는 이 클립의 `침입 충격` 버튼을 제공한다.

## 피해 사건과 전투 시간

엔진이 기존 침입 피해를 처리한 같은 단계에서 `breach.targetGate`에 `village` 또는 `outpost`를 기록한다. 피해량·누출 수·승패·보상 계산은 바꾸지 않았다. 성문은 자기 대상으로 기록된 실제 침입 효과만 읽고, 최신 사건 한 개의 반응을 재생한다. 여러 사건의 각도를 더하지 않는다. 대상 표식이 없는 기존 효과는 정적 성문을 유지한다.

| 효과의 시뮬레이션 나이 | 표시 |
| --- | --- |
| 0~0.12초 | 충격 포즈 |
| 0.12~0.29초 | 반대쪽 반동 |
| 0.29~0.46초 | 작은 잔여 움직임 |
| 0.46~0.60초 | 원래 자세 |
| 효과 종료 | 정적 성문 이미지 |

일시정지는 같은 시점을 유지하고 2배속은 같은 동작을 절반의 실제 시간에 재생한다. 동작 줄이기에서는 관절 움직임 없이 기존 체력·돌파 표시를 유지한다. 모션 아틀라스만 실패하면 정적 모델, 기본 모델까지 실패하면 기존 삽화/SVG를 사용한다. 정렬 기준과 포인터 이벤트 설정은 유지된다. 성문 컴포넌트에는 포즈 번호와 사건 ID만 전달해 정적 구간의 불필요한 갱신을 줄였다.

## 검증 결과

- 원본 재열기 및 GLB 재가져오기 19시점: 고정 부품의 행렬 이동량 0, 마지막 관절의 원래 자세 대비 오차 0, 아치 통로 유지. 정지 PNG와 기존 원본 렌더의 평균 채널 차이는 약 `2.86e-6`(최대 1/255)로 크기·접지 위치가 같다.
- 기준 커밋 `cfde248`과 1·4·5·8 스테이지 × 무건설/두 타워 패턴 8개를 프레임별로 비교했다. 새 대상 표식을 제외한 모든 상태가 같았다.
- 관련 58개 검사 통과. 전체 187개 중 186개 통과, 기존 수학 엔진 `(3 × 7) ÷ 5`의 4/4.2 불일치 1건만 남아 있다. 빌드 통과.
- Playwright·Chromium 1440×900 / 390×844 실제 UI에서 자연 발생 침입으로 마을 체력 20→19와 성문 반응의 일치를 확인했다. 일시정지/재개와 4포즈를 확인했으며, 실제 시간은 PC 1배 605ms / 2배 304ms, 모바일 602ms / 300ms였다.
- 실제 1-4 스테이지에서 마을 피해는 `[19,12]`, 확장 거점 피해는 `[19,11]` 체력과 각각의 성문 반응으로 확인했다. 자동 검사에서는 동시 침입, 보스 피해, 최종 패배/확장 거점 파괴 이후 효과 정리와 보상 불변도 확인했다.
- 고정 상태의 전투 컴포넌트에서 양쪽 대상·포즈 경계·동작 줄이기·모션/기본 이미지 실패를 검사했다. 작업실에서 관절 움직임, 정확한 원위치 복귀, 메시 보기, 동작 줄이기, GLB 실패 시 PNG 표기를 확인했다. 예상 밖 페이지 오류 없음.

적용 범위는 모델이 있는 숲 녹음 테마다. 다른 테마·설산, 실제 Android 기기 성능, 음향·진동의 추가 조정은 남아 있다. 다음 후보는 브론의 방향별 보행과 공격 전환이다. 이번 회차는 예약 활성 상태를 조회하거나 변경하지 않았다.
