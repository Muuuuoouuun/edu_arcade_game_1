# 군단 방패병 · 정면 방어와 혼합 편성 시험

기준 `0dcc3ee`, 2026-11-11. [93회차 조합 측정](../arcana-direction-loop/cycles/93-mode.md)의 궁수 집중 편성 우위를 통합 엔진에서 다시 시험했다. 별도의 영구 성장이나 보상을 추가하지 않고, 방패병이 전열에서 버티는 이유를 한 가지 추가한다.

## 규칙

방패병이 현재 바라보는 **정면에서 자기 자신에게 가해지는 적 공격 피해의 70%**를 막는다. 정면은 기존 2D 전장의 좌우 `facing`과 공격자 x 좌표로 판정하며, x가 같으면 정면이다. 뒤에서 맞는 공격은 전부 받는다. 차단된 공격의 기존 충격선은 청록색이며, 차단되지 않은 충격은 주황색이다. 피해 적용과 공격 쿨다운은 기존 시점에 각각 한 번 일어나고, 별도의 공격·무적 시간·아군 피해 전가를 만들지 않는다. 모든 적과 보스의 직접 공격에 적용되지만, 보스가 성문까지 도달하면 기존과 같이 즉시 패배한다.

이것은 **자신을 보호하는 상시 정면 방어**이지, 적의 경로를 막거나 뒤의 아군을 자동으로 보호하는 광역 방패가 아니다. 좌우만 구분하므로 같은 x의 위아래 공격은 실제 입체 각도에 따른 방어가 아니다. 차단량과 판정 방향을 병종 설명 및 준비 화면 도움말에 표시한다.

## 측정 방법과 결과

`node --experimental-strip-types tools/audit-legion.ts`는 실제 UI와 같은 1/60초 고정 스텝에서 초기 600G로만 소환하고, 전투 중과 웨이브 사이에 보충하지 않은 채 다음 웨이브를 시작한다. 시뮬레이션은 결정적이고 무작위 플레이어나 실제 사람의 조작이 아니다. 혼합은 방패 2부대·궁수 1부대·마법사 1부대·영물 1마리(550G)이며 같은 편성을 네 장소에 놓는다.

| 편성 | 기준 | 정면 70% 차단 |
| --- | --- | --- |
| 궁수 5부대 450G | 승리, 마을 HP20, 15명 전원 생존 | 동일 |
| 혼합 앞쪽 | 4웨이브 패배, 181처치 | 4웨이브 패배, 246처치 |
| 혼합 성문 쪽 | 4웨이브 패배, 194처치 | 4웨이브 패배, 281처치 |
| 혼합 북쪽 | 3웨이브 패배, 152처치 | 승리, HP20, 282처치 |
| 혼합 남쪽 | 3웨이브 패배, 144처치 | 승리, HP10, 272처치 |

같은 네 배치에서 정면 차단 50%·60%는 0승, 65%는 1승, 70%는 2승이었다. 70%는 이 시험에서 혼합의 두 배치를 살린 가장 낮은 **시험값**이지 전역 최적값이 아니다. 궁수 다섯 부대는 여전히 더 적은 골드로 무손실 승리하므로 단일 조합 지배를 해결했다고 볼 수 없다. 특히 더 큰 손실 없이 승리하는 원거리 전용 해법과 남는 소환 골드 문제는 다음 게임성 작업이다.

검사: 군단 엔진에서 여섯 적 종류·보스의 정면 차단, 뒤 공격, x 동일 경계, 방패 이외 병종, 공격 쿨다운 중 중복 피해 방지, 중단된 시뮬레이션 및 기존 보스 돌파·승패·보상 규칙을 시험한다. 1/20초 실험은 같은 엔진에서 다른 결과를 만들 수 있어 최종 비교에 사용하지 않았다. 실제 플레이어의 전략 선호·재미와 실기기 성능은 미측정이다.

KR2 Claude Opus 5.5의 실제 코드 검토는 같은 틱에 앞 대상이 먼저 처치되는 경우, 후반 웨이브 배율과 차단의 곱, 같은 x에서 y가 다른 보스 공격을 추가 경계로 제시했다. 세 경우는 엔진 실행 테스트로 따로 확인했으며, 모델의 코드 검토 자체를 플레이 검증으로 취급하지 않는다.
