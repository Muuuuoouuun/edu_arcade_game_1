# 군단 방패병 · 실제 모델과 강타

2026-11-11. 군단의 약 23px 가로 화면에서 기존 도형 방패병의 투구·몸통·청록 방패가 풀밭과 섞이고 카드와 전투 모습도 달랐다. 창수 컨셉 `art-source/defense/concepts/2026-10-29/heroes/spear-guardian.png`의 남청·주홍·상아 재료를 유지하고, `claude/wizardly-shannon-zqnwg0` 92회차 방패병 초안을 바탕으로 큰 방패·금색 가장자리·짧은 창과 몸을 실제 메시로 제작했다. 긴 창이 몸을 축소하지 않도록 몸 높이를 기준으로 같은 크기에 맞춘다.

편집 원본은 `art-source/defense/legion-shield.blend`, 실제 애니메이션 GLB는 `public/defense/models/legion-shield.glb`다. 몸통과 양쪽 어깨 관절이 움직이며 양발은 지면에 남는다. `art-source/defense/legion-shield-frames/`의 같은 정사영 카메라 렌더 세 장을 `legion-shield-atlas.webp`에 결합해 카드와 전장이 공유한다. 규격·출처·크롭·접지·파일 해시는 `legion-shield.json`에 기록한다. 재생성은 `blender -b --python tools/blender/build_legion_shield.py`, 모델 작업실은 `/model-lab.html?model=legion-shield`다.

현재 군단 엔진은 타격 시 피해가 즉시 적용되므로, 방패를 공격 **시작과 같은 프레임**에 내밀고 0.10초부터 반동한 뒤 0.22초에 기본 자세로 돌아온다. 효과에 공격자 ID를 보존해 가까운 다른 병사의 타격으로 잘못 재생하지 않는다. 판정·피해·보상·스폰은 바꾸지 않는다. 동작 줄이기에서는 기본 자세를 고정하고, 일시정지와 배속은 게임의 효과 시간에 따른다. 이미지가 실패하면 기존 캔버스 방패병과 SVG 카드로 대체한다.

KR1 Fable의 실제 844×390 정지 화면 검토에서 작은 방패의 금색 무늬와 배경 대비가 약하다는 지적을 받았다. 이에 테두리·십자를 두껍게 바꿨다. 같은 23×27px 분석 표본에서 금색 화소는 19개에서 43개가 되었고 평균 밝기 110.3은 92회차의 풀밭 기준 145와 34.7 차이가 난다. 이 표본은 이미지 분석이며 모션이나 실기기 성능을 입증하지 않는다.

군단 전투는 기존 Canvas2D에 24KB WebP를 공유하며 유닛당 WebGL을 만들지 않는다. 58개 메시와 11,488개 평가 삼각형을 포함한 GLB는 작업실 검토용이다. 기존 32단위 진형에서 병사가 겹치는 문제, 세로 방향에서의 실루엣과 이동 중 발 디딤은 별도 검토·동작 제작이 필요하며, 실제 휴대기기 성능·플레이어 재미는 아직 측정하지 않았다.
