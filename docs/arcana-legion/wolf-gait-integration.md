# 군단 전장의 서리늑대 보행 연결

2026-11-11. `main` `7459b61`의 군단 전투를 기존 통합 계보에 가져오면서, 원본 화면의 서리늑대가 두 정지 자세와 몸 전체의 위아래 이동만 반복하던 차이를 고쳤다. 원래 컨셉의 낮고 긴 회백색 몸, 어두운 발, 사족 보행을 기존 3D 제작물의 여덟 포즈로 표현한다. **새 모델을 만들거나 군단 전장을 실시간 3D로 전환한 것은 아니다.** 군단은 Canvas2D에 3D 원본에서 베이크한 이미지를 사용한다.

- 같은 늑대의 편집 가능한 원본 `art-source/defense/frost-wolf.blend`, GLB `public/defense/models/frost-wolf.glb`, 공통 카메라 렌더와 `frost-wolf-trot-atlas.webp`, 메타데이터 `frost-wolf.json`을 재사용한다. 가로 모바일에서 긴 몸과 발이 구분되도록 군단 전장의 표시 크기는 43에서 54 논리 단위로 늘렸다. 재생성은 `npm run models:wolf`, 원본 설명은 [서리늑대 모델](../arcana-silverfrost-model.md)이다. 이번 회차는 원본이나 모델 파일을 수정하지 않았다.
- 군단 엔진의 실제 경로 진행 거리가 화면 크기에 맞춘 보폭의 여덟 단계를 선택한다. 적이 멈춰 공격하면 보행 위상도 멈추고, 배속·일시정지와 이동 둔화도 시뮬레이션을 따른다. 몸 전체에 인위적으로 더하던 튀기를 늑대에서 제거했다.
- 보행·피격은 같은 카메라 크기와 발의 `groundY`를 쓴다. 동작 줄이기는 안정된 고정 자세다. 보행 이미지를 못 불러오면 기존 모델 자세, 그 이미지도 실패하면 기존 설산 삽화, 삽화도 실패하면 단순 형태로 대체한다. 소환 카드 이미지가 실패하면 빈 이미지 대신 아이콘을 표시한다. 피해·공격 시점·보상·경로는 변경하지 않았다.
- 사용자 요청에 맞춰 군단 전투에서 상시 체력·웨이브·골드 등 정보 HUD와 개체 체력 막대를 숨겼다. 소환·시작·배속·일시정지 및 오류 안내는 유지한다. 기존 캠페인과 3D 변경 전장 진입도 보존한다.

전체 자동 테스트 585개, 웹 빌드와 모바일 빌드가 통과했다. PC와 가로 모바일 Chromium에서 실제 배치·전투·정지·배속·회전·동작 줄이기·두 단계 이미지 실패를 확인했다. 이미지 둘이 모두 실패할 때 공통 선택기가 로드하지 않은 다른 아틀라스를 고르던 회귀를 수정하고, 실제 설산 삽화로 대체되는 것을 확인했다. 모바일 패키지에 지형과 늑대 보행/피격/삽화 파일이 남는지도 검사했다.

브라우저 검증 재현: `npm run dev -- --host 127.0.0.1 --port 3123`을 실행한 뒤 `node tools/tests/legion-wolf-browser.cjs`. 다른 서버는 `BASE` 환경 변수로 지정한다. 브라우저 가로 화면 재현은 실제 Android GPU 성능이나 사람 대상 재미 검증이 아니다. 늑대의 옆모습 한 방향 베이크를 뒤집어 사용하므로 세 경로의 대각선에 맞춘 새 방향별 베이크와 실제 기기 성능은 후속이다.
