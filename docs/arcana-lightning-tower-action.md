원격 main `2eabc76`, Claude wizardly `895335c`의 48회 운영 기록을 확인했다. 서리늑대·여섯 영웅·화염탑의 완료 작업을 유지하고, 아직 정적이던 번개 Lv.2 한 단위를 선택했다. PR #81의 번개 표적·연쇄 로직은 이번 변경에 포함하지 않는다.

## 컨셉에서 전투로

[원본 모듈 컨셉](../art-source/defense/concepts/2026-10-29/props/six-tower-modules.png)의 청동 구조물·푸른 수정·무거운 석조 기초를 유지한다. 기존 전투에서는 포탑 전체가 흔들리고 수정 주변의 평면 효과가 돌아갔다. 이번에는 양옆 수정 전극의 받침에 실제 회전축·강철 베어링·청동 칼라를 만들고, 발광 고리에는 강철 지지 고리를 추가했다.

두 전극과 고리가 안으로 모여 충전한 뒤 펼쳐지고 반동·복귀한다. 중앙 수정·피뢰침·석조 기초는 고정된다. 고리 동작을 중복시키던 평면 궤도 효과는 이 모델에서 제거하고 충전 예고와 발사광은 유지했다. 피뢰침 끝을 공통 카메라로 투영해 발사광·투사체 출발점에 연결했다. 원본 루트 배율 1.6을 포함한 좌표다.

- [편집 가능한 Blender 원본](../art-source/defense/lightning-tower-action.blend): 개별 메시·베벨·3개 강체 관절과 키프레임.

- [공통 카메라 렌더](../public/defense/models/lightning-tower-action.png)와 [6포즈 PNG](../art-source/defense/lightning-tower-action/): 640×640, 기존 정사영 카메라·조명·바닥 기준.
- [전투 WebP](../public/defense/models/lightning-action-atlas.webp): 2304×384, 109,466 bytes. 디코드 RGBA 3,538,944 bytes. 포즈별 크기 보정 없이 같은 크롭을 사용한다.
- [메타데이터](../public/defense/models/lightning-tower-action.json): 원본·생성기·산출물 해시, 관절/실제 수정 중심 좌표, 소켓, 경계, 기초 고정 검사, 모델 예산.

## 타이밍과 검증

준비 0–0.15초를 모으기/완충으로 나누고, 엔진 발사 뒤 0.24초를 방출/반동/복귀로 나눈다. 각 주요 베이크 자세는 시뮬레이션 시간 75–80ms를 차지한다. 명목 30Hz 게시·1/2배속·100개 위상에서 모든 주요 자세가 표시되며 발사 전에 방출 자세가 나오지 않는다. 일시정지는 같은 상태를 유지하고 동작 줄이기에서는 중립 모델과 필수 예고를 사용한다. 피해·표적·연쇄·발사 시점은 변경하지 않았다.

- `npm run build` 통과. 전체 테스트 232개 중 231개 통과. 기존 수학 문제 `(3 × 7) ÷ 5`의 `4 !== 4.2` 실패는 기준 커밋의 파일로도 재현했다. 최종 산출물 재생성 후 art 테스트도 통과했다.
- 편집 원본과 재수입 GLB의 40프레임 검사: 기초 이동 0, 종료 자세 오차 0, 실제 전극 메시 이동 확인. 중앙 수정과 양옆 수정의 삼각형 교차 0. 6포즈의 크롭·알파·해시 검사 통과.
- Chromium 1440×900 및 터치 390×844 실제 UI: 건설→뇌전 분기→웨이브, 1/2배속, 발사 중 일시정지/재개, 동작 줄이기, 전체/확대 전장 확인. 프레임 0–5 표시, 조기 방출 0, 페이지 오류 0.
- 전투 보드 5가지 조건(PC/모바일/동작 줄이기/아틀라스 실패/기본 이미지 실패)×7상태 검사. 피뢰침 소켓과 효과 중심 오차 <0.000057px, 시작 투사체도 일치. Lv.3·화염탑 대체 경로 독립 유지, 전투 GLB 요청 0.
- 작업실 PC/모바일: 실제 클립 변화·복귀, 메시 보기·회전·동작 줄이기, GLB 실패 시 PNG 표시 통과.
