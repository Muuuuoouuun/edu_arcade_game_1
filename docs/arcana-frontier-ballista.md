# 변경 전장의 실제 발리스타 조준·발사

2026-11-09 KST · 컨셉 개발 57회차. 기준 `acbbe6874c8bb1a740c52ff1dafb0cae571f0ea9`, 소유 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉과 선택

`art-source/defense/atlases/tower-models.png`의 목재 활대·황동 보강·석조 기초와 실제 변경 전장 PC/모바일 가로 화면을 비교했다. 기존 2.5D 발리스타의 관절 제작은 완료되어 있다. 이번 차이는 별도 3D 전장에서 작은 상자 포탑의 기초까지 회전하고, 줄이 잠깐 나타나는 동시에 피해가 발생한다는 점이다. 원래 제작한 발리스타를 재사용해 이 전장에 연결했다.

## 실제 구현

- 기존 `piercing-ballista-action.blend`의 145개 편집 메시와 활대·시위·장전탄 관절을 보존했다. 조준 플랫폼 아래에 고정 기초가 있고 플랫폼 안에 새 반동 받침 관절을 넣었다. 재부모화 전후의 중립 월드 변환이 같아야 생성기가 통과한다.
- 상부만 초당 최대 5라디안으로 가장 짧은 방향을 따라 조준한다. 0.10초에 시위가 풀리며 발사하고 받침이 뒤로 최대 0.16 저작 단위 이동한 뒤 0.4초에 재장전을 끝낸다. 정상 반복 발사 간격은 0.8초다. 발사 중에는 방향·대상 ID를 고정한다.
- 실제 GLB 발사 소켓의 위치에서 3D 탄을 내보낸다. 탄 끝이 소켓과 일치하며, 초당 32 전장 단위로 대상의 몸 쪽을 따라간다. **탄 도착 때** 피해와 명중 효과가 생긴다. 탄은 발사 당시 피해량을 보관하므로 비행 중 강화로 피해가 바뀌지 않는다. 대상이 먼저 사망하면 다른 적에게 순간 이동하지 않고 사라진다.
- 강화는 같은 모델의 기초 표식 1~3개로 표시한다. 몸을 늘리지 않아 접지와 발사 소켓 높이가 유지된다. 레벨별 완전히 다른 새 건축물을 제작한 것은 아니다.
- 포탑마다 독립적인 조준/클립 시간을 평가하지만, 보이는 포탑들의 같은 관절 표면은 `InstancedMesh`로 묶어 그린다. 모델 표면 7개가 포탑 수에 비례하는 렌더 호출로 늘지 않는다. 탄 몸통과 탄두도 각각 하나의 인스턴스 집합이다. 전체 전장은 기존 단일 장면/렌더러를 유지한다.
- 일시정지는 조준·클립·탄·피해를 멈춘다. 배속은 시뮬레이션 시간에 적용한다. 동작 줄이기는 기계 동작을 준비 자세로 고정하고 조준과 탄의 게임 정보는 유지한다. GLB 실패 시 고정 기초와 회전 활대의 기본 입체 모형으로 동일한 전투를 진행한다.

GLB는 재질별 원본 색을 정점 색으로 보존한 단일 재질을 쓴다. 작업실 GLB와 작은 화면용 전장 GLB는 각각 별도 지오메트리이며 정지 이미지가 아니다. WebP는 베이크 참고 산출물이고 현재 3D 전장의 포탑은 GLB로 렌더링한다. 원본 재질의 세부 금속 광택은 단일 재질에서 단순화된다. Blender 4.3.2의 이 실행 빌드에는 OpenImageDenoise가 없어 Cycles 32샘플·노이즈 제거 끔으로 렌더했다.
