## 컨셉 대비 개선

- 실제 수면을 -0.575→-2.6, 강바닥을 -1.5→-4.5로 낮췄다. 기존 하나의 지반 받침을 두 육지로 나누어 교량 아래가 실제로 열린 협곡이 되게 했다.
- 두 강변에64개 편집 가능한 암벽 구간을 만들었다. 풀 가장자리·회색 암반·어두운 하부의 세 층과 꺾인 면이 높이와 재질을 구분한다. 암벽은 통행 금지 구간 x3..9 안쪽에만 있다.
- 교량에는16개 목재 상판,6개 석조 받침,하부 장선과4개 사선 보강재를 제작했다. 다리 위 통행 높이0.36과 기존 폭·충돌 규칙은 유지한다.
- 기존 모델의 강변 x2..3/9..10은 걸을 수 있는데도 시각 지형이 강바닥으로 기울어져 있었다. 새 통행면은 강변까지 게임 높이와 일치한다. 예: 고지 `(2.5,-20)`의 발 기준과 지형 사이 차이3.05→약9.5e-8, 저지 `(2.9,12)`의 차이1→0월드 단위.

전투 규칙·맵 크기·봉화/수정/보상·이동 속도는 바꾸지 않았다. 지역 확장이나 신규 상호작용, 완성된 컨셉 미술로 보고하지 않는다. 기존 캠페인은 베이크2.5D이고 이 변경은 독립 실시간3D 훈련 전장이다.
