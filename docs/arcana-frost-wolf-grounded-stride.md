# 서리늑대의 평평한 발 접지와 방향별 보폭

2026-11-07 KST, 컨셉 개발 루프 30회차. 기준 `2bdec742a4b32a9437109574c18d6ab16d1b9f5a`, 소유 브랜치 `codex/arcana-stage-experience-20261106`.

## 선택한 차이

은서리 늑대 컨셉 `art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png`와 현재 설산 전투를 직접 비교했다. 회백색 갈기·짙은 발·청백색 눈과 체형은 앞 회차에서 구현됐지만, 보행은 다리 전체가 회전해 발도 약 25도 기울고 이동 40 논리 단위마다 한 주기를 반복했다. 컨셉의 발을 짚는 자세에 맞춰 **무릎·발목 분리, 평평한 지지 발, 방향별 이동 보폭**을 이번 단위로 선택했다. 기존 체형·재질·기본 보행·피격·쓰러짐 원본은 보존했다.

원격 main `2eabc76`, Claude 기획 `bf7c1c6`/`f84397e`와 최근 통합 기록을 확인했다. 리엘을 포함한 영웅의 기본 방향 공격, 포탑 Lv.2/Lv.3 조준·반동, 교량·성문은 이미 구현돼 있어 다시 만들지 않았다. Claude의 리엘 검토 기획은 현재 통합 모델과의 차이를 먼저 확인해야 한다.

## 구현

- 상부 다리·무릎/뒷발목·발을 나눴다. 대각선 발 쌍이 번갈아 지지하며, 발바닥은 바닥과 평행하게 유지되고 회수하는 발은 0.22 모델 단위 높아진다. 몸·목·꼬리도 작게 무게를 옮긴다.
- 지지 구간에서 발은 몸의 전진 속도만큼 뒤로 움직인다. 1주기 실제 보폭 1.68 모델 단위를 공통 카메라에 투영해 8방향 보폭을 생성한다. 기본 표시 크기 73에서 한 주기는 방향에 따라 약 9.85–23.36 전장 단위다.
- `walkCycles`/`walkHeading`을 전진 구간별로 누적한다. 방향 전환 때 이전 이동을 새 보폭으로 다시 계산하지 않으며, 넉백은 보행을 되감거나 방향을 뒤집지 않는다. 모바일 확대 크기도 보폭에 반영한다.
- 실제 8방향 렌더를 사용하므로 좌우 반전하지 않는다. 피격·밀림·동작 줄이기는 기존 우선순위를 유지한다. 방향 이미지 하나라도 실패하면 기존 보행, 기본 이미지도 실패하면 기존 삽화로 표시한다. 체력바 높이는 기존 기준을 유지한다.
- 작업실은 기존 단일 WebGL 장면에서 GLB를 재생한다. 새 모델에 경계 기반 카메라 맞춤을 적용해 세로 화면의 코끝 잘림을 수정했다. 전투에는 GLB 요청이나 새 WebGL 렌더러가 없다.
- 피해량·발사 시점·이동 속도·웨이브 규칙은 바꾸지 않았다.

GLB는 17개 움직이는 관절, 66메시, 2,300삼각형, 0.8초 반복 클립이다. 전투용 추가 압축 이미지는 320,372바이트, 전체 방향 이미지를 디코딩하면 약 16MiB다. 기존 대체 이미지도 유지하므로 이 수치는 전체 게임 메모리 사용량이 아니다.

## 남은 범위

평면에서 제작한 강체 관절 보행이며 지형 IK나 스킨 변형은 아니다. 전투는 8개 정지 포즈를 순환하므로 포즈 사이의 미세한 발 미끄러짐과 방향 전환의 단계감은 남는다. 피격·쓰러짐은 기존 단일 방향이므로 보행과 연결될 때 방향이 바뀔 수 있다. 모바일 검증은 Chromium 뷰포트 에뮬레이션이며 실제 Android GPU·메모리는 측정하지 않았다.

다음 후보는 리엘 등 영웅의 보행→방향 공격 전신 전환과 축소 화면의 자세 가독성이다. 서리늑대의 후속은 방향별 피격/쓰러짐 또는 경사면 접지가 필요할 때 별도 단위로 진행한다.
