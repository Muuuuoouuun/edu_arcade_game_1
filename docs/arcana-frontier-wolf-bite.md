# 서리 협곡 늑대의 접지된 물기

기존 [은서리 늑대 컨셉](../art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png)과 실시간 3D 전장의 물기를 비교했다. 이전에는 모델 전체가 앞으로 이동해 지지 발이 미끄러지고, 피해가 발생하는 순간에도 턱이 계속 벌어졌다. 이제 기존 보행에서 발을 짚은 뒤 목과 머리가 앞으로 뻗고, 준비 중 벌어진 턱이 접촉에 맞춰 닫힌 후 돌아온다. 꼬리는 준비와 회수에 작게 반응한다.

새 동작은 기존 `frost-wolf-stride` GLB의 목·머리·턱·꼬리 관절을 전투 시뮬레이션 시간으로 조절한다. 당시 구현은 네 발과 몸통을 평소 지지 자세에 남겼으며, 후속 [체중 이동](arcana-frontier-wolf-bite-brace.md)이 발 지지를 보존하면서 몸통을 움직인다. 피해·사거리·0.28초 타격·보상 규칙은 바꾸지 않는다. 걷던 자세에서 기존 0.18초 착지 전환을 보존하고, 동작 줄이기는 보행과 물기 동작을 생략한다. 새 Blender 애니메이션이나 물리 시뮬레이션은 만들지 않았다. 기존 [편집 원본·공통 렌더·GLB·전투 WebP·메타데이터와 재생성 명령](arcana-frost-wolf-grounded-stride.md)을 그대로 사용한다. 적용 범위는 서리 협곡의 단일 실시간 3D 장면이며 캠페인은 기존 2.5D다.

## 검증

- 평지의 같은 자세에서 지지 발 중심의 0.18→0.28초 이동은 0.0644→0 전장 단위였다. 네 지형·8방향·8출발 걸음의 31시간 표본에서도 착지 후 발 중심은 고정되고 발바닥이 보이는 표면을 관통하지 않았다. 당시 5ms 관절 회전 표본의 최댓값은 0.0417rad 미만이었다. 이는 검증한 위치에 대한 수치이며 보행 중 급회전의 발 고정을 뜻하지 않는다.
- 실제 3D 전장에서 공격 전 체력 100과 접촉 후 92를 확인했다. PC·가로 모바일에서 동일 장면의 준비·타격 전후 화면을 비교하고 실제 이동, 일시정지·2배속·동작 줄이기와 늑대 GLB 실패 대체를 확인했다. 동일 3D 모델만 확대한 관절 검토 화면도 비교했다.
- `npm test`, `npm run build`, `npm run build:mobile`, `npm run models:wolf-stride:check`를 실행한다. 브라우저 화면은 에뮬레이션이며 실제 휴대기기 성능이 아니다.
- 근접한 영웅이 늑대 머리를 가리던 차이는 [영웅 표면 가림 처리](arcana-frontier-wolf-bite-visibility.md)로 일부 개선했다. [체중 이동 후속](arcana-frontier-wolf-bite-brace.md)은 런타임의 작은 몸통 압축을 추가했다. 별도 물기 애니메이션 GLB, 보행 중 급회전 발 고정과 실제 Android/iOS GPU 검증은 남아 있다.
