# 변경 전장: 실제 3D 공간과 세 가지 훈련 모드

2026-11-09 KST, loop 56. 기존 원정은 3D 원본을 베이크한 2.5D 그대로이며, 이번 변경은 `/frontier.html`의 독립 실시간 3D 훈련 전장이다. 원정 준비 화면의 **변경 전장** 링크로 들어간다. React가 HUD·모드·입력을 관리하고 Three.js의 단일 장면/렌더러가 지형·건물·유닛·효과를 렌더링한다. 원정 저장이나 성장 보상에 훈련 결과를 합산하지 않는다.

## 컨셉과 공간

원격 main의 `c43a0f45` 개별 영웅·극지/열대 전장 컨셉을 통합 계보에 보존했다. 해당 원본과 기존 숲/캐릭터 컨셉을 실제로 확인했다. 숲 전장의 성문·굽은 진입로·큰 영웅 실루엣을 이어받고, 평면 배경 위 장식 대신 넓이 64×64의 이동 가능한 지형, 높이 4.6의 북쪽 지대, 강 바닥 -1.5, 수면 -0.575, 다리 상판 0.36을 만들었다. 투시 카메라의 영웅 추적/전체 보기/확대·축소와 실제 깊이 가림이 있다. 다리 난간·절벽은 실제 메시다. 보행 충돌은 강을 막고 다리만 연결한다.

현재 지형·병사·포탑은 공간/게임 규칙을 검증하는 초기 모델이다. 새 극지/열대 컨셉의 완성도 높은 미술 작업이나 전체 캠페인 3D 전환 완료를 뜻하지 않는다.

## 실제로 다른 세 모드

| 모드 | 조작/활동 | 목표와 보상 |
| --- | --- | --- |
| 타워 디펜스 | 고정 전체 카메라, 4개 지점 포탑 건설 60/강화 90, 영웅 이동 없음 | 8/10/12마리의 3웨이브, 성문 180체력 방어. 처치 금화 14, 웨이브 보상 50 |
| 변경 지휘 | 땅 클릭/탭으로 영웅·지원병 3명 이동, 다리 횡단, 가까운 전초 포탑 건설, 집결/복귀, 충격파 | 3웨이브 방어 + 동쪽 봉화 점령. 3초 점령 보상 120은 한 번만. 분대 공유 체력 180 |
| 영웅 원정 | WASD/방향키 또는 터치 방향패드/땅 탭, Q 공격, E 충격파, Space 돌진, F 상호작용 | 수정 3개·처치 6회 후 출구에서 직접 상호작용. XP 처치당 30, 레벨당 필요 XP 60×레벨, 레벨업 최대체력 +15/회복 25/공격 +3 |

모드마다 비허용 행동을 엔진에서도 차단한다. 솔로에 포탑·자동 웨이브가 없으며 타워 디펜스에 영웅 직접 조작이 없다. 분대 지원병이 이동·공격하고 체력을 공유한다. 도시 경제/일꾼 생산/자원 채취/세부 분대 선택 등 완성된 RTS 시스템은 아직 없다.

## 원본 및 재생성

- 편집 원본: `art-source/defense/frontier-terrain.blend`, 266개 개별 오브젝트.
- 실시간 지형: `public/defense/models/frontier-terrain.glb`, 재질별 14메시/11,604삼각형.
- 공통 카메라 렌더: 같은 경로의 PNG/WebP. WebP는 베이크 참고 산출물이며 이 화면의 3D 지형을 대신하지 않는다.
- JSON: 카메라, 좌표/크기, 원본·내보내기·렌더·생성기 SHA-256.
- `npm run models:frontier-terrain` / `npm run models:frontier-terrain:check`.
- 기존 숲 성문과 카르 보행/공격 GLB를 실시간 재사용한다. 이번 카르 정지 제작은 [별도 기록](arcana-kar-stop-settle.md)에 있다.

단일 WebGL 렌더러를 사용한다. 지형은 재질별 병합, DPR 최대 1.25, 정적 그림자 512, 동적 유닛 접지 그림자를 사용한다. 장면 종료 시 RAF·리스너·GPU 자원을 정리한다. GLB 실패 시 기본 **입체 메시**로 계속하고, WebGL 자체 실패 시 시작을 막고 안내한다. 숨긴 지형 충돌 메시와 다리 상판에 입력 레이를 쏜다. 일시정지는 시뮬레이션/애니메이션 시간을 고정하고 배속은 같은 시뮬레이션 시간에 적용한다. 동작 줄이기는 카메라 보간·보행 애니메이션·수정 회전을 줄인다.
