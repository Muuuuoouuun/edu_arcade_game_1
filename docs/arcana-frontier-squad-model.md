# 변경 지휘의 석궁 지원병

2026-11-10 UTC · 컨셉 개발 83회차 · 기준 `165161dc9e22db6bcf1ede3b72d2a59fd2948bee`.

[녹음의 심장 컨셉](../art-source/defense/concepts/2026-11-06/verdant-heart.png)과 기존 3D 지휘 화면을 비교했다. 숲 장비의 청록색 천·금속·목재와 잡은 무기의 명확한 실루엣을 참고했다. 이전 지원병은 걷지만 얼굴 없는 상자 몸통 옆에 무기가 떠 있었다. 별도 종이나 정해진 영웅을 묘사한 원본이라고 주장하지 않는 신규 지원병 디자인이다.

작은 청록 천 갑옷·넓은 금속 어깨·금속 투구와 장화에 양팔·손·소형 석궁을 가진 실제 3D 모델이다. 손·팔·석궁은 같은 반동 관절에 붙고 두 발은 독립한다. 기존 1.2 전장 단위의 이동 거리 기반 좌우 보행·접지, 개별 방향, 0.16초 정지, 실제 발사 시점의 0.18초 조준/반동을 사용한다. 발사선은 발사 당시 석궁 끝 `squad-muzzle`을 기준으로 하며 매우 가까운 적에게 선이 역행하지 않도록 거리를 제한한다. 동작 줄이기는 보행과 반동을 줄이고 발사 방향과 선은 유지한다. 발사·피해·이동·경로·보상은 바꾸지 않았다.

전장에서는 공통 지오메트리/재질을 세 인스턴스가 공유하고 기존 단일 Three.js 장면을 사용한다. 각 유닛의 4표면을 별도 메시로 그리며 유닛마다 렌더러를 만들지 않는다. 로딩 전과 GLB 오류·불완전한 관절에는 기존 입체 병사를 유지한다. 새 모델이 준비되면 임시 모형의 자원을 해제한다. 기존 2.5D 캠페인에는 지원병 모델을 연결하지 않았다.

## 원본과 재생성

```sh
npm run models:frontier-squad
npm run models:frontier-squad:check
node --experimental-strip-types --test src/games/frontier/squadView.test.ts src/games/frontier/effectsView.test.ts
```

- `art-source/defense/frontier-squad.blend`: Blender 4.3.2, 42개 편집 메시, 양쪽 발·무기/손의 관절, 발사 소켓, 4개 보행 미리보기 자세. 전장 보행은 GLB 클립 재생이 아니라 시뮬레이션 거리에 따른 절차적 관절 변환이다.
- `public/defense/models/frontier-squad.glb`: 4표면·1,060삼각형·125,448바이트. 하나의 버텍스 색 재질과 Z-up→Y-up 변환을 사용한다. 모델 작업실에서는 실제 GLB의 고정 자세를 회전해 볼 수 있다.
- `art-source/defense/frontier-squad/walk-{0,1,2,3}.png`: 통나무 병사와 같은 384px 정사영 카메라; `frontier-squad-atlas.webp`는 이 네 포즈의 전투 크기 베이크, `frontier-squad.png`는 작업실 폴백이다. 이 이미지들은 기존 캠페인 런타임에 연결하지 않았다.
- `frontier-squad.json`: 생성 명령·카메라·방향·소켓·삼각형·입출력 SHA-256. 모바일 패키지는 새 GLB를 오프라인 자산으로 보존한다.

## 검증과 한계

- 편집 원본의 양손과 석궁 접촉, 네 자세의 지지 발을 검사한다. 실제 GLB는 경사·교량·상판 경계 세 표본 위치×8방향×8걸음의 발 정점 36,864개와 8방향/동작 줄이기 두 조건에서 발사선과 실제 소켓 일치를 검사한다. 매우 가까운 표적에서는 발사선 시작을 제한하므로 소켓과 의도적으로 다를 수 있다. 표본 검사는 모든 지형·방향의 완전한 접지나 물리 충돌을 보증하지 않는다.
- GLB 성공/중단/손상, 3인 공유, 교체 시 기존 18개 지오메트리·재질 dispose와 단일 캔버스를 실제 WebGL 장면에서 확인했다. 작업실 PC/가로 모바일의 GLB·회전·와이어와 GLB/PNG 실패도 확인했다.
- PC·가로 모바일에서 실제 지휘 조작, 이동·발사, 일시정지·2배속·동작 줄이기와 숲/설산 화면을 확인했다. 모바일은 브라우저 터치 에뮬레이션이다. 실제 지면 클릭/터치로 이동 목표가 바뀌는 것을 확인했다. 전체 테스트 517개와 웹·모바일 빌드가 통과했고, 모바일 배포본에서 타이틀→캠프→지휘 전장과 GLB·보행·일시정지를 확인했다.

현재 팔·손·석궁은 한 강체 관절로 반동한다. 팔꿈치 IK나 개별 시위·장전 애니메이션, 급회전 중 발 고정, 교량 밖으로 걸친 발의 수면 접지와 실제 Android/iOS GPU 성능은 구현·검증하지 않았다. 지도 밖 확장과 전체 캠페인 실시간 3D 전환도 이번 범위가 아니다.

Chromium SwiftShader 844×242의 동일한 지원병 3명 장면에서 3초 예열 후 5초씩 순차 측정했다. 이전→이후 드로 호출 56→53, 삼각형 46,396→49,192, GPU 지오메트리 247→236, 평균 프레임 간격 81.63→84.13ms, p95 100.1→100.0ms였다. 짧은 소프트웨어 표본으로 성능 향상을 뜻하지 않는다. 실제 WebGL에서 지원병 표본 픽셀 `[97,122,112]`이 앞쪽 불투명 가림 물체로 `[255,0,255]`가 되는 것을 확인했다.
