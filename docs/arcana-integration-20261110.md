# 독립 앱과 컨셉 개발 계보 통합

2026-11-10 통합 기준은 개발 브랜치 `0530370ebe91d717c7c274ee6f1649852d42b6b7`와 main `b175a9f7a3b400dff1a819d4d79b8e79ac8e5d9e`다. 독립 앱과 Android 포장, 전투 규칙 수정, 로컬 수학 엔진을 개발 계보에 합쳤다. 기존 지형·성문·유닛의 2.5D 전장, 제작 원본과 작업실, 별도의 실시간 3D 변경 훈련 전장도 유지한다. 변경 훈련의 보상은 원정 세이브에 합산하지 않는다.

모바일 출력에는 원정뿐 아니라 마을에서 연결되는 3D 훈련 전장과 실제 사용 GLB, 경량 카르 또는 설산 지형을 읽지 못했을 때 사용할 원본 모델을 포함한다. 제작 작업실과 다른 미니게임은 모바일 출력에서 제외한다. 필수 모델 누락은 `npm run build:mobile`의 자산 검사에서 실패한다. 3D 훈련은 기존 단일 Three.js 장면을 사용하고, 네이티브 백그라운드 신호에 일시정지하며 명시적 재개를 기다린다.

전체 게임 테스트 499개와 모바일 출력 계약 1개, 웹·모바일 빌드를 통과했다. Chromium에서 PC 1440×900, 가로 터치 844×390의 타이틀·마을·원정·일시정지, 모바일 3D 숲/설산 전환과 성문 자산, 브론·늑대·숲 성문 작업실 동작을 확인했다. 기존 버전 1 저장 fixture와 카르·지형 GLB 로딩 실패 시 대체 원본도 검사했다. 앱 백그라운드·뒤로가기는 브라우저에서 신호를 모의했고 Capacitor 자산 동기화까지 확인했다. 이 환경에는 Android SDK가 없어 통합 후 APK 빌드·lint·실기기 성능 및 설치는 확인하지 않았다.

이 통합은 기존 모델과 아트의 연결을 유지하는 작업이다. 새 컨셉 아트·새 3D 모델 제작, 전체 전장의 3D 전환, 모든 전투 모드의 UI 간소화는 이 기록의 완료 범위가 아니다. 다른 Claude 작업 브랜치들은 별도 개발 내용으로 남겨 두고 main은 자동 변경하지 않는다.
