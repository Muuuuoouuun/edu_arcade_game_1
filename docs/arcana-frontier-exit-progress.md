# Frontier 솔로 출구의 현장 목표 표시

기준 `886b651c612ed5c08691240610e9825d78defa1d`. 기존 솔로 전장은 HUD에 수정과 처치 진행도를 보여주지 않아, 금색 고리만으로는 탈출 조건을 알기 어려웠다. `art-source/defense/concepts/2026-11-09/polar-battlefield.png`의 차가운 돌·청록색 수정·금속 대비를 참고하여 기존 Three.js 장면에 작은 석조 발판과 수정 3개, 처치 표식 6개를 배치했다. 조건을 모두 만족하면 고리가 청록색으로 바뀐다. 새로 만든 모델 자산이 아니라 기존 장면에서 생성하는 절차형 메시다.

조건은 엔진과 표시가 공유한다. 수정 정확히 3개와 처치 6회 이상을 얻고 실제 출구 반경 4 안에서 상호작용해야 승리한다. 표시물의 중심은 전경 지형의 가림을 줄이도록 안쪽으로 옮겼으며 발판 전체가 상호작용 반경 안에 있다. 입력 판정과 승리 규칙은 바꾸지 않았다. 시간이 흐르는 고리 효과는 시뮬레이션 시간에 따르고 동작 줄이기에서는 정지한다. 솔로 이외 모드에는 표시물이 생기지 않는다.

검증: `node --experimental-strip-types --test src/games/frontier/exitView.test.ts src/games/frontier/engine.test.ts`, `npm run build`. Playwright로 PC와 가로 모바일에서 실제 모드 선택, 이동, 상호작용, 일시정지·재개 및 배속을 조작했고, 모바일 회전, 동작 줄이기, 지형 GLB 로딩 실패 시 대체 지형과 다른 두 모드의 표시물 부재도 확인했다. 미획득·부분·완료 시각 상태는 실제 장면에 제어된 상태를 주입해 비교했다.

가까운 모바일 카메라에서는 영웅이나 지형이 금색 표식 일부를 가릴 수 있다. 표시물을 이동해도 모든 시점에서 여섯 표식 전체가 보이는 것은 아니다. 실제 플레이로 모든 수정을 수집하고 여섯 적을 처치해 승리하는 전체 진행과 실기기 성능은 이번 검증에 포함되지 않았다.
