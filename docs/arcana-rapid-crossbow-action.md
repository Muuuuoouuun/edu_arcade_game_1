# 연발 석궁 Lv.2 — 방향별 조준과 실제 장전 기구

2026-11-07 KST. 기준 `a21eefb882187e253bc6ab18a923c001ae55c955`, 브랜치 `codex/arcana-stage-experience-20261106`.

원격 main `2eabc76`, Claude `895335c`/`bf7c1c6`, 진행 중인 작업과 최근 기록을 확인했다. 열린 PR #81의 번개 표적·연쇄 로직과 겹치지 않는다. 서리늑대·여섯 영웅의 방향별 동작은 이미 구현되어 있다. 이번에는 **정지 이미지 전체를 뒤집고 흔들던 연발 석궁 Lv.2**를 선택했다. 기존 모델을 유지하면서 조준·발사·탄창 이송을 한 단위로 완결할 수 있어 포탑 후속 작업을 진행했다.

기획·게임성에서는 기존 연발 분기의 빠른 발사 간격을 유지하고, 디자인·모델링에서는 붉은 깃 탄창과 목재 기초의 구분을 살린다. 구조는 기존 베이크 2.5D 전투와 단일 3D 작업실을 사용한다. 모바일은 전체 전장의 작은 실루엣과 확대 전장의 장전 동작을 각각 검토했다. 새로운 피해·교육·재화 규칙은 추가하지 않았다.

## 컨셉과 구현

[모듈 컨셉](../art-source/defense/concepts/2026-10-29/props/six-tower-modules.png)의 목재·금속 활대와 기존 연발 모델의 붉은 깃 탄창·깃발을 보존했다. 공통 카메라의 정사영 배율 7.5와 전투 표시 배율 1.16, 바닥 위치도 유지한다. 기초와 깃발은 고정하고 상부만 8방향으로 조준한다.

활대 양쪽·시위·장전 화살에 실제 관절을 연결했다. 탄창 아래에는 강철 이송 레일과 황동 받침을 만들고 탄창 왕복·장전 레버 회전·되감기 바퀴 회전을 연결했다. 발사 때 장전 화살을 감추고, 당기기 이후 새 화살이 나타나며 중립으로 돌아온다. 원본의 개별 메시와 재질·베벨은 편집 가능하다. 초기 렌더에서 발견한 받침 배율 오류를 수정한 뒤 32장을 모두 다시 렌더했다.

전투는 **준비 → 발사 → 당기기 → 이송**의 4포즈를 사용한다. 기존 발사 시점 0.1초와 반동 0.24초를 그대로 따르고, 세 후속 자세를 각각 80ms 유지한다. 실제 GLB는 100fps 키프레임의 0.34초 클립이며 관절 사이를 연속 보간한다. 화살의 표시 여부는 STEP 보간이라 축소된 화살이 서서히 자라지 않는다. 활대 끝에 맞춰 시위를 매 프레임 다시 계산한다.

발사 당시 목표 방향과 등급을 투사체에 보존한다. 원본 화살촉을 카메라로 투영해 섬광과 **날아가는 화살의 끝**을 맞췄다. 목표 추적·강화·판매 이후에도 이미 발사한 탄의 출발점은 바뀌지 않는다. 동작 줄이기는 준비 자세를 유지한다. 아틀라스 한 방향이나 기본 이미지가 실패하면 해당 동작 세트 전체를 기존 표시로 대체한다. Lv.3와 관통 발리스타는 독립적으로 유지한다.

## 남은 범위
