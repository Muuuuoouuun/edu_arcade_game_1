# 이안의 제자리 시전 회수

2026-11-08 · 컨셉 개발 43회차. 기준 `85d573f`, 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉 대비 개선

`art-source/defense/atlases/ranged-motion.png` 첫 행의 뻗은 지팡이와 세운 대기 자세를 실제 PC·모바일 화면과 비교했다. 이동 중 시전 진입·복귀는 앞 회차에서 완료됐지만, 제자리에서는 기존 회수 이미지에서 대기로 바로 바뀌었다. 이번에는 두 발을 짚은 채 몸의 반동을 먼저 정리하고, 손목이 작은 호를 그리며 지팡이를 세운 뒤 망토가 따라 멈춘다. 기존 파란 모자·금장 코트·수정 지팡이의 체형과 재질을 보존한 실제 관절 애니메이션 작업이다.

시작 시 main `2eabc76`, Claude `bf7c1c6`/`c0d0367`과 통합 개발 계보를 확인했다. 원격은 이전 회차와 같았고 단일 작업트리가 깨끗했다. 완료된 서리늑대·이안 이동 시전·포탑 작업과 최근 Claude 54회차의 리엘 망토 시험을 검토했다. 진행 중인 겹치는 편집은 없었으며 기존 Vite 서버를 유지했다.

## 실제 모델과 전투 표시

- 실제 `ian-reset-0` 클립: **0.12초, 100fps, 8관절**. 시작은 기존 시전 0.15초 자세, 끝은 원본 대기 자세와 일치한다.
- 몸통·머리·반대팔은 0.085초에 정리한다. 지팡이팔·손목은 0.015초, 망토는 0.025초 뒤에 회수를 시작한다. 손목과 반대팔의 작은 옆 방향 호, 몸통의 0.012 모델 단위 하강을 추가했다.
- 두 다리의 월드 변환은 클립 전체에서 고정된다. 이는 모델 평면의 발 고정이며 지형 IK는 아니다.
- 영웅·용병 이안의 정지 상태(속도 0~0.5)에 적용한다. 이동 복귀와 기존 시전 진입을 유지하고 필살기·돌진·동작 줄이기의 기존 표시를 우선한다.
- 새 이미지 하나라도 실패하면 기존 시전 세트로 돌아간다. 이동 복귀·진입 세트의 실패는 제자리 회수를 막지 않는다. 기존 시전/보행 핵심 세트가 실패하면 기존 공통 대체 표시를 따른다.

| 공격 경과 | 표시 |
| --- | --- |
| 0.15~0.21초 | 기존 발사 자세·효과 |
| 0.21~0.225초 | 발사 자세 유지 |
| 0.225~0.27초 | 몸 반동 회수, 뒤따르는 지팡이 — 클립 0.04초 |
| 0.27~0.32초 | 지팡이를 세우고 망토 정리 — 클립 0.10초 |
| 0.32~0.33초 | 기존 대기 이미지 |
| 이후 | 기존 대기 |

발사 0.15초·전체 공격 0.33초·소켓·투사체·피해·이동·보상·엔진 상태는 변경하지 않았다. 60Hz 시뮬레이션의 2/4/6틱 게시 간격 및 모든 시작 오프셋에서 중간 회수 자세가 최소 한 번 표시된다. 임의의 낮은 프레임률에서 모든 자세가 표시됨을 보장하지는 않는다.

전투는 두 중간 포즈를 베이크한 2.5D이며, 작업실은 단일 실시간 3D 장면에서 실제 관절을 보간한다. 유닛별 WebGL 렌더러를 추가하지 않았다.

## 산출물·재생성

```bash
npm run models:ian-reset
npm run models:ian-reset:pose-check
npm run models:ian-reset:check
```

Blender 4.3.2·FFmpeg·Cycles CPU 48샘플. 기존 `ian-mage.blend`를 읽어 별도 파일로 저장한다.

| 산출물 | 위치·규격 |
| --- | --- |
| 생성기·검사기 | `tools/blender/build_ian_reset.py`, `tools/check-ian-reset.mjs` |
| 편집 원본 | `art-source/defense/ian-reset.blend`, 135개 메시와 `Ian reset 0 / 관절` 액션 |
| 실제 3D | `public/defense/models/ian-reset.glb`, 1클립·1,393,944바이트 |
| 공통 카메라 | `art-source/defense/ian-reset-frames/`, 384×384 PNG 16장 |
| 전투 베이크 | `public/defense/models/ian-reset-{0..7}-atlas.webp`, 방향별 2셀·384×192 |
| 규격·해시·미리보기 | `public/defense/models/ian-reset.json`, `ian-reset.png` |

## 검증

증거 폴더 `/tmp/arcana-hourly-20261108-1140/`에 기준 커밋·소유 브랜치·범위·수용 기준·미완료 상태, 전후 화면과 검사 로그를 기록했다.

- 전체 테스트 **298개 중 297개 통과**, 타입 검사·프로덕션 빌드 통과. 실패 1개는 기준 커밋에서도 재현한 기존 수학 게임 `(3×7)/5`의 4/4.2 불일치다. 새 회수 관련 테스트는 모두 통과했다.
- GLB 저작 13시점·보간 49시점에서 양쪽 다리 변환이 고정된다. 시작 오차 최대 약 `2.07e-7`, 대기 끝 오차 약 `1.47e-17`, 밑창 최소 높이 약 `0.005`. 해시 30개 통과.
- 클립 0.04초의 회전 진행도는 몸통 약 45.6%, 지팡이팔 14.3%, 망토 6.7%로 실제 시간차를 확인했다.
- `.blend`를 다시 열어 135개 메시의 시작/끝 월드 변환을 원본과 비교했다. 최대 오차 약 `1.47e-17`이다.
- PNG 16장·WebP 16셀의 크기·알파·경계 통과. 최소 투명 여백 18px, 빌드 파일 11개가 원본과 동일하다.
- 스테이지 1·4·5·8×영웅/용병 8게임·14,400스텝에서 기준 엔진과 제외 필드 없이 전체 상태가 동일하다. 배속·일시정지·돌진·필살기·강화를 포함한다.
