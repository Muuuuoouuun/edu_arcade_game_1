# 승인 스틸컷 기반 제작 기준

2026-11-13 KST 사용자 결정: “이거 기준 잡기, 푸시 됐나 이런형태로 제작”. 직전에 생성한 **전투 4장 + 생산·타워 2장**을 이후 제작의 공통 시각 목표로 확정한다. 최초 스틸컷 1장도 기준 원본으로 함께 보존한다. 이전 문서와 시각 방향이 충돌하면 이 기준이 우선한다.

## 승인 이미지

원본과 SHA-256은 [이미지 폴더](../art-source/defense/concepts/2026-11-13-approved-gameplay/README.md)에 보존한다. 이 이미지들은 생성형 콘셉트이며 실제 게임 캡처가 아니다.

| 기준 | 제작에 반영할 내용 |
| --- | --- |
| 최초 스틸컷 | 전체 캐릭터 비율, 청록 지붕·석재·목재, 밝은 입체감과 재질 |
| 숲 방어전 | 두 진입로, 높낮이 있는 잔디 언덕, 분명한 전투 동선 |
| 성문 수비전 | 성문과 성벽의 두께, 엄폐물, 영웅과 적의 전투 간격 |
| 다리 방어전 | 입체 교량·물·절벽, 지형에 맞는 이동과 접지 |
| 골렘 보스전 | 넓은 광장, 보스의 체급, 영웅 실루엣과 효과의 구분 |
| 생산 마을 | 농장·제재소·채석장·대장간·창고와 일꾼·운송의 연결 |
| 타워 건설·강화 | 석궁탑·대포탑·얼음탑의 형태 구분, 설치 미리보기와 강화 패널 |

## 모드 공통 제작 규칙

- **모델:** 큰 머리와 짧고 두툼한 팔다리, 둥글게 다듬은 모서리, 명확한 얼굴·손·무기. 도마뱀의 잎 후드·꼬리·쇠뇌, 브론의 주황 수염·룬 망치, 포포의 흰 털·파란 갑옷·원형 방패를 유지한다. 같은 캐릭터는 모드마다 새로 디자인하지 않는다.
- **표면:** 잎맥·비늘·가죽 봉제선·수염 덩어리·목재 결·금속 가장자리·얼음 면을 큰 형태로 읽히게 제작한다. 모든 재료를 같은 플라스틱 광택으로 처리하지 않는다. UV와 색상/노멀 맵을 실제 게임 렌더에서 보존한다.
- **렌더:** 따뜻한 주광과 차가운 보조 명암, 부드러운 접촉 그림자, 밝고 선명한 색. 외곽선은 형태를 보조하되 두꺼운 검은 선과 계단식 명암이 모델의 볼륨을 가리지 않게 조정한다. 현재 툰 셰이더의 숫자를 고정하지 않고 승인 이미지의 결과를 기준으로 맞춘다.
- **환경:** 청록색 입체 기와, 두꺼운 돌벽, 목재 기둥, 층이 있는 잔디·절벽·강·다리. 바닥과 건물을 평면 이미지로 대체하지 않는다. 통로와 건설 공간을 충분히 남긴다.
- **카메라:** 위에서 비스듬히 내려다보는 3D 시점. 얼굴·무기·지형 높이가 함께 읽혀야 한다. 생산 모드에서는 더 넓게 보되 같은 비례와 재질을 유지한다. 정확한 FOV·거리·각도는 실제 화면 비교로 정한다.
- **동작:** 발 접지 → 이동에 맞는 보행 → 준비·공격·복귀가 이어져야 한다. 쇠뇌 발사, 망치 강타, 눈덩이 투척의 실루엣과 효과를 구분한다. 상체 공격과 하체 이동을 독립적으로 처리한다.
- **UI:** 청록·짙은 회색 바탕과 금색 테두리, 큰 아이콘, 짧은 한글. 전투는 체력·웨이브·조이스틱·공격 버튼, 생산은 자원·수확·건설 목록, 타워는 설치 위치·비용·강화를 중심으로 구성한다. UI가 전투 중심부를 가리지 않게 한다.

## 제작 순서와 완료 판정

1. 기존 영웅 3종의 형상·재질·조명을 승인 최초 컷과 동일한 화면 크기로 비교해 보정한다. 모델 파일, 텍스처, 동작 클립을 공통 자산으로 관리한다.
2. 숲 전장 한 구역에 완성형 성문·집·수풀·지형·그림자를 연결해 실제 실행 화면의 기준 장면을 만든다.
3. 같은 자산으로 성문·다리·보스전의 구도와 공간을 확장한다.
4. 생산 건물과 일꾼의 생산·운송 동작, 타워 배치·강화의 시각 피드백을 같은 스타일로 제작한다. 경제 수치와 저장 계약은 별도 규칙 문서에서 정한다.
5. PC와 모바일 가로 화면에서 실제 캡처를 승인 이미지와 나란히 비교한다. 얼굴·무기 가독성, 재료 구분, 접지·장비 관통, 경로/건설점 구분, UI 가림, 로딩 오류와 기기 성능을 확인한다.

이미지에 표시된 웨이브·시간·자원·강화 비용은 예시이며 밸런스 확정값이 아니다. 이미지 속 모든 건물·효과가 구현됐다는 의미도 아니다. 이번 변경은 **제작 기준과 원본 이미지의 저장**이다. 기존 PR #110은 Rush 영웅 3종의 질감·호흡·보행·공격을 적용했으며, 전체 게임이 이 스틸컷 품질에 도달한 상태는 아니다.
