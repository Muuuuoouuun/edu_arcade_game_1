# 아르카나 수비대 시안 갤러리

[기획 색인](README.md) · [에셋 목록과 해시](asset-manifest.json)

생성 이미지 33장 원본. 실제 구현 화면·완성 애니메이션·게임용 스프라이트가 아닌 시각 콘셉트다.

짐승 비교 시트는 왼쪽 펫 / 가운데 몬스터 / 오른쪽 수인이다. 도깨비·서양 판타지는 왼쪽 작은 동행자(흡혈귀는 박쥐 사역마) / 가운데 전투형 / 오른쪽 지적인 동료형이다. 진화 순서를 뜻하지 않는다.

포탑 시트는 위쪽 쇠뇌·대포·수정탑, 아래쪽 서리·봉인·등불탑이다. 스킬 시트는 좌상 창수, 우상 부적술사, 좌하 흡혈귀, 우하 오크다.
