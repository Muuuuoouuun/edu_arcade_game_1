## 기존 구현과의 관계
이 문서는 기존 영웅·용병 캠페인의 확장 기획이다. 저장소의 별도 카드 수비 모드 문서인 [arcana-guard](../arcana-guard/README.md)와 적용 범위를 혼합하지 않는다. 카드 모드의 타로 분류·퀴즈·마나 규칙을 이번 세계관의 확정 사항으로 가져오지 않는다.

통합 기준 717b93e의 루트 README에는 숲·설산 8스테이지, 6영웅, 기존 타워·전직·성장이 기술돼 있다. 이 기획은 그 구현이나 기존 인물 이름을 수정하지 않는다. 새로운 이름과 모드 조건은 통합 담당이 게임 데이터와 대조해 채택해야 한다. 기존 구현의 자세한 기록은 [작업 분담](../arcana-workstreams.md)을 참고한다.

## 원본과 제작 인계
이미지는 art-source/defense/concepts/2026-10-29/에 PNG 원본 그대로 보존한다. 생성 날짜 전체를 의미하는 것이 아니라 이번 아카이브 묶음의 기준일이다. public 아래 배포 에셋에 추가하지 않았으므로 런타임이 자동으로 불러오지 않는다.

배경이 포함된 일러스트와 비교 시트는 그대로 스프라이트·아이콘·3D 모델로 사용할 수 없다. 게임 적용에는 작은 크기용 실루엣 단순화, 투명 배경 분리, 카메라·비율 통일, 리깅과 동작 제작이 필요하다. 키포즈는 동작 검토 자료다. 창수 공격 시트는 인접한 창대가 이어져 보이는 부분이 있어 프레임 분리가 필요하다.

이번 묶음의 검증 범위는 문서 링크, 이미지 존재·PNG 무결성·해시·크기, Git 변경 범위다. 게임 코드 변경이나 플레이 테스트는 포함하지 않는다.

## 2026-10-30 캠페인 적용
성 테마 4종의 삽화를 WebP로 변환해 거점에 연결하고, 같은 양식의 성문을 전장에 구현했다. 녹음 성채는 처음부터, 청강 요새는 1-2, 운령 산성은 1-3, 황혼성은 2-4 방어 후 선택할 수 있다. 이 이름들은 외형 양식으로 사용하며 새로운 지역이나 인물을 확정하지 않는다. 이번 테마는 전투 수치나 성별 특수 능력을 바꾸지 않는다. 원정 지역·영웅·장비·보상은 기존 캠페인 규칙을 따른다.

시설은 거점 그림 아래 실제로 해금된 기능만 따로 표시한다. 외형 선택은 `playground:defense:appearance:v1`에 저장하며 기존 캠페인 저장 형식을 변경하지 않는다. 저장을 사용할 수 없는 환경에서도 현재 플레이에는 적용한다. 원정 준비와 정찰에서 선택형 수비대 관찰노트를 열 수 있으며, 퀴즈나 열람 여부를 진행 조건에 넣지 않는다.

배포 이미지는 `public/defense/themes`의 1200px/600px WebP 8개, 총 1,769,914바이트다. 33개 PNG 원본은 계속 제작 자료로 보존한다. `npm run art:themes`로 FFmpeg/libwebp를 통해 비율을 유지한 크기 변환과 압축을 재현할 수 있다. 배경 삽화 속 도로는 실제 전투 지형으로 사용하지 않는다.
