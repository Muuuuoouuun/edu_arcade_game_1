# 교육 요소 방향 — 선택해서 알아가는 수비대 관찰노트

기준일: 2026-10-30 (Asia/Seoul). 적용 대상은 기존 영웅·용병 원정 캠페인이다. 별도 카드 수비 모드의 문제 풀이·마나 규칙을 캠페인에 가져오지 않는다.

## 방향

재미있는 전투에서 재료와 현상을 먼저 경험하고, 궁금할 때 짧은 설명을 읽는다. 교육 내용은 정답을 요구하는 관문이 아니라 전술을 이해하는 선택 도구다. 전투 성공·동료 합류·보상·지역 해금은 관찰노트를 읽었는지에 의존하지 않는다. 읽기 기록이나 학습 점수도 수집하지 않는다.

이 방향은 기존 세계관의 지역 탐험 → 구조 → 방문자 → 거점 성장 흐름과 맞는다. 숲에서는 나무와 불, 제재소에서는 금속과 절연, 설산에서는 열과 얼음을 배운다. 새로운 관계는 새 적의 외형과 공격 반응으로 먼저 보여 준다. 문제를 맞혀야 공격할 수 있거나, 오답 때문에 기존 전투력을 잃는 규칙은 추가하지 않는다.

## 이번 구현

`DefenseFieldGuide`는 기본 접힘 상태의 선택형 관찰노트다. 재료 항목도 선택해서 펼치며, 각 항목은 **전장 규칙**과 **자연의 원리**를 분리한다. 플레이어가 스스로 여는 기존 정찰·원정 준비 공간에서 사용할 수 있다. 컴포넌트 자체는 전투를 멈추거나 재개하지 않는다. 전술 정찰에서 열면 기존 전술 일시정지 규칙을 따른다.

표시 대상은 `getWavePlan`의 실제 편성에서 선별한다. 특정 웨이브가 전달되면 그 편성만, 웨이브가 없으면 현재 스테이지의 네 웨이브만 사용한다. 저장된 클리어 기록을 임의로 변경하거나 아직 다른 지역에만 나오는 몬스터를 미리 해금하지 않는다. 거점에서 붙일 때는 해금된 스테이지에서만 제공한다.

| 재료 | 전투에서 쓸 힌트 | 자연의 원리와 경계 |
| --- | --- | --- |
| 나무 | 새싹·나무 적과 고목왕의 불 약점, 물 내성 | 나무는 조건이 맞으면 탄다. 수분에 따라 잘 타는 정도가 다르다. 식물이 물 공격에 강하다는 피해 규칙은 판타지다. 나무가 녹는다고 설명하지 않는다. |
| 얼음 | 빙결 기사·서리군주의 불·충격 약점 | 얼음은 열을 받으면 녹고 충분한 충격으로 깨질 수 있다. 피해 배율은 과학 수치가 아니다. 서리늑대의 마법 약점을 실제 늑대나 얼음의 성질로 일반화하지 않는다. |
| 돌 | 돌 갑옷병의 충격 약점·불 내성 | 돌이 나무처럼 타지 않는 것과 열에 무조건 안전한 것은 다르다. 열 변화나 충격으로 갈라질 수 있다. |
| 금속·젖음 | 금속이나 젖은 적을 통해 가까운 적에게 이어지는 연쇄 번개 | 대부분의 금속은 도체다. 아주 순수한 물은 전기가 잘 통하지 않지만 소금·미네랄이 녹으면 전도성이 커진다. 적 사이를 한 번 더 뛰는 공격과 범위는 게임 규칙이다. 직접 번개 피해 증가라는 미구현 효과를 설명하지 않는다. |
| 절연 | 절연 슬라임의 번개 저항·연쇄 차단 | 고무·유리 등은 전류가 잘 흐르지 않는 재료다. 완전한 전기 무적이나 모든 상황의 안전을 뜻하지 않는다. |

피해 배율·내성·연쇄 공격이 이 세계의 전투 규칙이라는 짧은 문장을 노트 끝에 둔다. 전기와 물을 다루는 실제 행동이나 실험을 유도하지 않는다. 젖음 설명에서는 아주 순수한 물과 이온이 녹아 있는 물의 전도 차이를 구분한다.

## 다음 개발 순서

1. **전투 반응의 가독성:** 이미 존재하는 약점 타격·젖음·연쇄 차단을 모양과 짧은 효과로 더 잘 보이게 한다. 노트를 읽지 않아도 배치 선택의 결과를 알 수 있어야 한다.
2. **한 판 한 관찰:** 결과 화면에서 실제로 사용한 조합 한 가지만 선택해 짧게 되짚는다. 효과가 발생하지 않았으면 발견했다고 표시하지 않는다. 읽지 않고 다음 원정을 시작할 수 있다.
3. **지역 현상:** 기후·지형을 전술 선택과 연결한다. 과학 법칙에서 가져온 조건과 판타지 보정 수치를 콘텐츠 데이터에서 분리한다. 한국적 건축·설화는 창작과 역사적 사실을 구분한다.
4. **선택형 연습장:** 원하는 타워 조합을 놓고 반응을 비교할 수 있는 공간을 검토한다. 별도의 학습 평가나 보상 필수 조건은 두지 않는다.

## 다른 게임과의 역할

| 게임 | 교육 요소를 넣을 자리 |
| --- | --- |
| 판타지 디펜스 | 재료·지형·전술의 관계를 경험하고 선택형 노트로 확인 |
| 수학 스피드 | 짧은 연산 자체가 핵심 플레이. 속도와 정확도의 균형은 난이도로 조절 |
| 단어·상식 퀴즈 | 기억을 꺼내는 문제와 간단한 피드백을 중심에 배치 |
| 과학 카트 | 아이템 상자 전 예고된 선택으로 보상을 만들고, 오답 뒤 한 줄 설명. 운전 조작을 막는 장문 팝업은 피함 |

같은 허브에 있다는 이유로 모든 게임에 동일한 퀴즈를 넣지 않는다. 특히 디펜스의 학습량을 늘리기 전에 전투 재미와 모바일 조작을 먼저 검증한다.

## 검증 기준

- 노트를 한 번도 열지 않아도 모든 기존 전투·보상·진행이 동일하다.
- 실제 스테이지·웨이브에 없는 재료를 관찰했다고 표시하지 않는다.
- 게임 설명의 약점·내성은 현재 엔진과 일치한다. 전도는 직접 피해 배율과 혼동하지 않는다.
- 접힘 버튼은 키보드와 터치로 조작할 수 있고, 작은 화면에서도 글과 버튼이 잘리지 않는다.
- 교육 효과를 검증한 상태라고 주장하지 않는다. 이후 플레이 테스트에서는 재미, 재도전 의사, 전술 선택을 먼저 관찰하고, 플레이 후 개념 이해는 별도로 확인한다.
