# 특성·영웅 스킬·포탑·마을·버프·성 테마
상태: 구현 전 기획 초안. 숫자·배율·비용·편성 인원·정확한 해금 시점은 미검증이며 확정하지 않는다.

## 진행과 자원
거점 준비 → 영웅·펫 편성 → 포탑 설치·웨이브 → 구출·보상 → 마을 성장.
원정 보상 골드·재료는 영구 성장에, 전장 보급은 해당 전투의 설치·강화에 사용한다. 전투 중 포탑 강화는 전투 종료 후 초기화한다.

## 특성
- 고유 특성: 영웅 정체성을 만드는 고정 능력.
- 전문화: 성장 시 두 방향 중 선택; 거점에서 자유 변경, 전투 시작 후 고정.
- 원정 특성: 해당 원정에서만 적용되는 지역 대응 능력.

| 영웅 | 전문화 A | 전문화 B |
| --- | --- | --- |
| 산성 창수 | 철벽: 고정 위치에서 방어 | 유격: 이동 후 첫 공격·저지 |
| 부적술사 | 봉쇄: 이동·행동 방해 | 수호: 보호막·상태 해제 |
| 흡혈귀 | 결투: 단일 강적·회복 | 군무: 박쥐·그림자로 다수 견제 |
| 오크 지휘관 | 돌격: 순간 공격 집중 | 규율: 진형·지속 방어 |
| 드루이드 | 동행: 한 펫 협공 | 군집: 여러 소환체 견제 |
| 바바리안 | 광전: 높은 분노의 공격력, 회복 효율 감소 | 철벽: 분노를 소비해 피해 감소 |

## 영웅 스킬
초기 조작은 자동 기본공격 + 고유 특성 + 직접 사용하는 액티브 1개를 제안한다.
| 영웅 역할 | 고유 특성 | 액티브 |
| --- | --- | --- |
| 산성 창수 | 자리를 지키면 저지 능력 증가 | 파수선: 전방 방어 영역으로 뒤쪽 아군 보호 |
| 부적술사 | 봉인 종료 뒤 짧은 둔화 | 금줄 결계: 지정 범위 적 구속 |
| 흡혈귀 귀족 | 본인 직접 공격으로 제한적 회복 | 밤의 쇄도: 그림자 돌진으로 경로상의 적 공격 |
| 오크 지휘관 | 주변 동료 스킬 뒤 다음 공격 강화 | 집결 깃발: 범위 아군 공격 속도 강화 |
| 오우거 수호자 | 밀쳐내기 저항·복수 적 저지 | 철벽 호위: 주변 아군 피해 일부 부담 |
| 트롤 약초사 | 낮은 체력 아군 회복 효율 증가 | 재생의 안개: 범위 지속 회복 |
| 드루이드 | 주인·펫 같은 대상 협공 | 사냥 명령: 집중 대상 지정·펫 임시 보호막 |
| 불씨 도깨비 | 가까운 포탑 주기적 정비 | 화로 과충전: 선택 포탑의 다음 몇 공격에 화염 |

보스 구속은 둔화 또는 경직 수치로 변환할 수 있다. 흡혈 회복은 추가 피해·반사·회복 효과가 다시 발동시키는 순환을 허용하지 않는다.

## 포탑
설치 → 전문화 선택 → 선택 방향 강화의 3단계.
| 포탑 | 기본 역할 | 분기 A | 분기 B |
| --- | --- | --- | --- |
| 쇠뇌탑 | 빠른 단일 공격 | 연사·약한 적 처리 | 관통·정예 견제 |
| 대포탑 | 느린 범위 공격 | 넓은 폭발 | 좁고 강한 방어구 파괴 |
| 마력 수정탑 | 마법 피해 | 연쇄 | 단일 집중 광선 |
| 서리탑 | 이동 둔화 | 넓고 약한 둔화 | 좁고 강한 냉각 |
| 부적 봉인탑 | 행동 방해 | 지속 둔화 | 간헐적 짧은 구속 |
| 지원 등불탑 | 주변 지원 | 영웅 회복 | 포탑 공격 지원 |
공성형 적이 포탑을 공격하는 규칙을 제안한다. 수리·영웅의 전방 보호가 이에 대응한다. 이는 기존 엔진에 이미 존재하는 규칙으로 간주하지 않는다.

## 마을
야영지 → 정착 마을 → 성채. 핵심 기능은 인물 구출·지역 사건과 연결한다.
| 시설 | 초기 | 성장 후 |
| --- | --- | --- |
| 대장간 | 장비 제작·기본 강화 | 전문화·고유 효과 조정 |
| 훈련소 | 전투 연습 | 전문화·조합 시험 |
| 공방 | 기본 포탑 | 새 설계도·강화 분기 |
| 약초원·치유소 | 회복 물자 | 정화·보호 물자 |
| 숙영지·여관 | 대화·방문자 | 개인 의뢰·영입·편성 저장 |
| 성벽·성문 | 기본 방어 | 내구도·시설 자리·비상 장치 |
불씨 도깨비 합류 후 화로·작업 소리·진열 장비가 늘고, 상인 도깨비 합류 후 장터와 방문자가 늘어나는 식으로 시각화한다.

## 버프
| 종류 | 출처 | 효과 |
| --- | --- | --- |
| 격려 | 지휘관·깃발 | 짧은 공격 속도 강화 |
| 수호 | 창수·결계·물자 | 보호막 또는 피해 감소 |
| 재생 | 트롤·약초원·등불 | 지속 회복 |
| 집중 | 정찰·표식 | 지정 대상 공격 집중 |
| 과충전 | 도깨비·공방 | 횟수가 제한된 포탑 강화 |
| 환경 적응 | 원정 준비·장비 | 한기·안개 등 대응 |

동일 이름은 가장 강한 효과 하나를 적용한다. 다른 효과의 합산·상한 수치는 밸런스 검증 후 정한다. 회복·추가 공격의 무한 재발동을 막고 연속 구속에 일시 저항을 준다. 범위·남은 시간은 화면에 표시한다.

## 성 테마
외형과 거점 방어 장치를 묶는다. 효과는 거점 방어전에 적용하고 원정은 해당 지역 규칙을 따른다.
| 테마 | 외형 | 대표 방어 규칙 | 판단 |
| --- | --- | --- | --- |
| 운령 산성 | 기와·돌벽·표지석·부적탑 | 표지석 보호로 결계 충전, 한 경로 둔화 | 여러 경로 압박에 병력 분산 |
| 황혼성 | 첨탑·해자·수정·박쥐 감시탑 | 주기적 달빛 구역에서 영웅 스킬 회전 강화 | 구역 위치에 맞춘 재배치; 모든 영웅 사용 가능 |
| 청강 요새 | 쇠뇌·대포·강철 성문·보급소 | 비상 보급을 성문 수리 또는 포탑 강화에 사용 | 사용 시점과 투자처 |
| 녹음 성채 | 거목·뿌리벽·약초밭·비콘 | 생명력을 회복 또는 뿌리 제어에 사용 | 장기전 유지와 순간 피해 대비 |

## 스토리와 랭킹
사용자는 두 모드의 존재와 점수 랭킹을 결정했다. 다음 상세 방식은 제안이다.
- 스토리: 지역 탐험·영입·장비·마을의 누적 성장.
- 랭킹: 주간 고정 도전. 영웅 성장 수준·선택 목록·포탑 예산·성 테마·맵·웨이브·환경·이벤트 조건을 동일하게 맞춘다.
- 반복 도전 허용, 개인 최고 기록만 반영. 규칙 버전이 달라지면 순위를 분리한다.
- 초기에는 종료 지점이 있는 전투를 사용한다.
- 점수 구성 후보: 웨이브 달성 + 거점 보존 + 추가 목표 + 상한이 있는 전투 시간 보너스.
- 완주가 작은 시간 차이보다 중요하도록 가중치를 정한다. 준비·일시정지 시간은 제외한다.
- 적을 남겨두거나 소환물을 반복 처치해 점수를 무한히 늘리지 못하게 한다.
- 동료 희생을 일괄 감점하지 않아 희생 전술의 가능성을 남긴다.
- 안개재 야간 수비는 경로 변화·환영 단서를 모든 참가자에게 동일하게 제공하는 도전 후보.

## 검증 범위 제안
첫 실험은 숲·설산 기반, 동료 4명·장비 12개·유물 4개 정도와 전문화 한 쌍, 쉬운/기본 난이도, 고정 랭킹 전투 하나로 시작할 수 있다. 후속 시안의 모든 종족·성·포탑을 동시에 구현한다는 의미가 아니다. 수치·경제·출전 인원·스킬 조작은 재미·가독성·모바일 조작 검증 후 확정한다.
