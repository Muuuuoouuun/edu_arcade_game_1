## 해결한 기술 충돌

- **Rush 9개 경로:** package, HTML, 폰트 문자 목록/바이너리, main/render/CSS/town/townScene. 새 규칙과 마을 개선을 기존 성채·실제 1.2m 경사·높이 기반 조준·피해 재질·동작 줄이기·저장 복구에 연결했다. 영웅 단순화 외곽선에도 독립 피해 재질을 유지했다.
- **폰트:** 한쪽 WOFF2를 선택하지 않고 병합된 소스 전체의 문자 357개로 다시 생성했다. 생성 시 필요한 Brotli를 실행 환경에 설치했다. 저장소 의존성은 변경하지 않았다.
- **마을 알림:** `town-reward` 중복 ID를 제거하고 새 상단바 기준 위치와 기존 저장 실패 재시도 UI를 함께 유지했다.
- **UI 지침:** 원격 체력바·회복 숫자·보스 문구가 상시 UI로 복원되지 않도록 기존 조작/스킬 중심 표시를 유지했다. 회복은 월드 고리로 전달한다. 속도 변주의 흔적은 동작 줄이기에서 생략한다.
- **과거 캠페인 3D 배경:** 최신 원정 컴포넌트·카드·스타일은 유지한다. 대안의 좌표/메시 모듈과 테스트를 연구 자료로 보존하고 원문에 현재 비활성 상태를 명시했다.
- **중복 이력:** 적 기획/군단은 동일 패치의 기존 포함을 확인했다. 과거 work의 별도 모델링 원본은 격리하고, 최신 모델·진입점·설정·빌드 도구는 유지했다.

병합 마커와 미해결 Git 충돌은 남기지 않는다. 실제 방향 선택을 과거 파일의 우연한 채택으로 확정하지 않는다.

## 제품 결정이 필요한 항목과 권장안

| 항목 | 선택이 필요한 이유 | 권장안 |
| --- | --- | --- |
| 공통 마을 허브 | 새 기획은 원정/군단을 Rush 기반 마을로 모으지만 과거 Rush는 독립 앱 방향도 있음 | 한 앱·공통 허브로 진행. 현재 모든 모드 입구와 별도 훈련은 보존 |
| 모드 간 경제 | 기획은 원정·군단 보상을 공통 마을로 수입하나 현재 저장·정산은 별도 | 당장은 별도 저장 유지. 환산율·소급 지급·중복 정산·이전 실패 복구를 정한 뒤 이전 |
| 기존 캠페인의 3D 전환 | 보존한 배경 시안은 배우·입력·가림을 한 장면에서 처리하지 않음 | 새 입체 전장은 단일 장면으로 완성. 기존 2.5D 원정 전환은 작은 실제 플레이 구간부터 검증 |
| 모드별 조작·판 길이 | 원정의 탭 이동/돌진 4~5분 제안과 Rush 쌍스틱 2~3분의 목적이 다름 | 차이를 유지. 조작을 일괄 덮어쓰지 않고 원정은 이동·전술, Rush는 직접 전투·마을 수비 |
| 다음 콘텐츠 순서 | 재설계 하늘섬 제안과 기존 군단 단일 편성 우위 문제가 공존 | 1막·군단의 선택 문제를 먼저 개선하고 새 지역은 한 장면씩 검증 |

재설계 문서의 `merge`는 합성 퍼즐 장르 전환이 아니라 **4테마 이후 두 지역 규칙을 함께 쓰는 5막 합류**다. 가로 화면, 교육·퀴즈를 보상 관문으로 삼지 않기, 조작·스킬 외 전투 상시 HUD 숨김, 예약 중지는 기존 결정이므로 다시 선택받지 않는다. 북유럽·열대·괴수 시트는 향후 미술 자산 풀로 보존하며 실제 캠페인 해금에 자동 편입하지 않는다.

## 검증과 전달 경계

- 전체 테스트 699개, Rush 세부 검사 94개, 기존 별도 prototype 검사 63항목 통과.
- 웹 빌드, 모바일 빌드 및 모바일 패키지 검사 3개 통과.
- 원격 115개 tip과 로컬 계보의 조상 관계 확인. 아트 18장 및 과거 원본 43개의 무결성 확인.
- PC1280×720·모바일844×390 Rush 실제 키보드/터치 경사 왕복·공격·2배속·정지/재개 통과. 피해/회복·새 전투 초기화·동작 줄이기·성채 GLB 실패 대체도 통과했다. 체력 단계 검사는 제어된 상태 주입이며 실제 플레이 피해와 구분한다.
- 같은 장면에서 영웅 body 7,804삼각형을 유지하고 hull 7,804→3,900, 전체 35,246→31,342, draw calls 35와 dropped 0을 확인했다. 단순화 모듈 차단 시 원본 hull로 복구되고 모바일 실제 입력도 통과했다. 실기기 FPS 향상 주장은 하지 않는다.
- PC·모바일에서 타이틀 3입구→원정→군단의 실제 배치/전투 시작/정지/거점 복귀, 변경 전장 3모드의 포탑 건설·집결 이동·직접 이동/공격 입력·정지/모드 복귀를 확인했다. 페이지 오류·HTTP 오류 0건, 상시 정보 HUD 숨김을 확인했다. 공격 입력 검증을 피해량·전체 승리 검증으로 확대하지 않는다.
- 실제 UI 증거는 저장소 밖 `/workspace/arcana-full-merge-evidence-20261112/`에 보관했다. Browser 플러그인의 연결 JS 도구가 현재 제공되지 않아 기존 Playwright/Chromium 경로를 사용했다. 모바일은 터치 에뮬레이션이며 실제 휴대기기 GPU·전체 모드 완주·새 주술사 우선 처치의 재미는 이 검증 범위가 아니다.

통합 결과는 개발 브랜치에 전달한다. main 반영은 기존의 “자동 main 병합 금지” 지침과 대상 선택을 구분해 처리한다. 서비스 배포·예약 재개·강제 푸시·공유 브랜치 삭제는 하지 않는다.
