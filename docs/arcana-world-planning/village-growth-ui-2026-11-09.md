# 마을과 성장 UI — 구현 기록과 다음 기획

2026-11-09, Asia/Seoul. 거점은 컨셉 아트와 주민의 변화를 먼저 보여 주고, 동료 선택·영구 강화·원정 준비는 목적별로 나눈다. 오락성과 시각적 완성도를 우선하며 대화나 교육 읽기를 출전 조건으로 삼지 않는다. 이 문서는 이번 실제 구현과 아직 없는 NPC·가방·아이템 기능을 구분한다.

## 이번 실제 구현

기본 진입은 **마을**이며 메뉴는 **마을 / 동료 / 성장 / 원정** 네 개다. 마을에서는 기존 테마 아트를 유지하고 문을 연 시설을 먼저 살펴본다. 브론의 대장간에서 강화 행동으로 연결되고, 다른 시설에서는 동료 편성으로 이동한다. 시설 클릭이 독립 NPC 대화·상점·제작을 실행하는 것은 아니다.

- **마을:** 큰 풍경, 다음 목적지, 구한 마을과 다음 동료, 시설 상세와 이동 버튼, 외형 테마 선택.
- **동료:** 해금된 이안·리엘·브론·청운·카르·루나 중 출전 영웅 한 명을 무료 선택. 이름과 해금 순서는 유지한다. 전투 용병 고용은 별도라는 안내를 추가했다.
- **성장:** 브론의 기존 모델 렌더와 공용 장비 패널. 현재/다음 단계의 공격력, 강화 비용, 보유 성장 골드와 강화 후 잔액을 표시한다. 강화 확인·취소, 완료 안내, 골드 부족·최종 단계·대장간 잠금 상태를 구분한다.
- **원정:** 지역·스테이지·난이도·구조 요청·보상을 확인하고 별도 전투 화면으로 진입한다. 하단 출발 도크는 원정 탭에만 표시한다.

홈의 풍경은 모바일에서 약360–370px, 다른 탭의 풍경은 약175px로 줄였다. 긴 아트를 지나야 메뉴를 찾던 부담을 줄이고, 강화 선택에 필요한 정보에 공간을 배정했다. 기존 스타일의 탭별 숨김 규칙을 유지하면서 새 레이아웃을 덧붙였다.

이미지는 실제 브라우저 캡처다. 일부 화면은 기능 검증을 위한 저장 fixture로 해금·골드를 설정했으며, 처음부터 모든 스테이지를 플레이해 얻은 진행 기록은 아니다. 브론 이미지는 기존 모델의 렌더이며 이번에 새로 모델링했다고 표시하지 않는다.

## 경제와 저장 계약

성장 골드 **G**는 캠페인에 남는다. 공용 강화는 브론 합류 후Lv0→5이며 단계마다 공격력+8%, 총+40%다. 비용은100·180·260·340·420G다. 기존 `trainCampaign`이 대장간 해금·상한·잔액을 검사하며, 이번 작업에서 새로운 강화 재화나 가격을 도입하지 않았다.

전투 코인은 해당 원정의 타워 건설·속성 분기·용병 고용에 사용한다. 용병은 해금된 다른 영웅 한 명을120전투코인으로 고용하며 다음 원정에 다시 준비한다. 타워Lv1→2/3, 전투 전직 역시 영구 공용 장비와 별개다. 현재 영구 강화 배율은 영웅·타워뿐 아니라 용병·펫의 기존 공격 계산에도 적용된다.

방문자는 이미 해금된 동료다. 합류 소식 확인은 `seenVisitors`를 기록하며 영웅을 구매하는 과정이 아니다. 추가 퀘스트는 승리와 조건 충족 시 스테이지별80G를 한 번 자동 지급한다. 거점에 미수령 보상을 쌓거나 '받기' 버튼을 새로 만드는 설계는 현재 계약과 맞지 않는다.

캠페인 키 `playground:defense:v1`, 외형 키 `playground:defense:appearance:v1`, 허브 통계 키 `playground:v1`를 유지한다. 이번 UI는 새 아이템 필드를 캠페인에 넣지 않았다. 미래 아이템 저장은 `normalize`가 모르는 필드를 제거한다는 점과 버전 불일치 처리까지 고려해 마이그레이션을 별도로 설계한다. 버전 숫자만 바꾸거나 임의 필드를 붙이는 방식은 사용하지 않는다.

## NPC와 마을 동료의 후속 기획

다음 표의 신규 대화·행동은 **기획**이며 아직 구현된 NPC 시스템이 아니다. 화면에는 기존 인물을 먼저 활용하고, 같은 기능을 가진 새 인물을 불필요하게 늘리지 않는다.

| 인물 / 역할 | 화면에서 할 일 | 데이터와 연결 | 구현 경계 |
| --- | --- | --- | --- |
| 청록 마을의 촌장 | 다음 구조 요청과 그 마을을 지킬 이유를 한두 문장으로 설명 | 기존 `campaignRequest`, `stageReason` | 발신자 문구는 현재 존재. 대화 패널은 후속 |
| 서리산맥의 전령 | 설산 개방·위험·이번 구조 대상을 전달 | 기존 스테이지 해금·기후·목표 | 새 퀘스트 수령 절차를 요구하지 않음 |
| 브론 | 공용 강화의 현재/다음 결과를 보여 줌 | 기존 `training`, `gold`, `trainingCost` | 대장간→성장 이동과 강화는 구현. 제작·개별 장비는 미구현 |
| 리엘 | 출전 동료와 적 편성에 대한 짧은 준비 안내 | 기존 영웅 선택·정찰 정보 | 정찰 초소와 동료 화면은 존재. 추가 대사는 후속 |
| 청운 | 도원에서 속성·전술의 선택 이유를 짧게 안내 | 기존 선택형 전장 안내 | 설명 읽기를 진행 조건으로 하지 않음 |
| 보관인 — 역할명 초안 | 획득 경위·장비 보관·장착 상태를 정리 | 미래 인벤토리 | 고유 이름·외형·영입 조건 미정. 신규 NPC 및 가방 기능 미구현 |

카르·루나를 포함한 기존 여섯 영웅 이름과 역할은 변경하지 않는다. 장기 기획의 불씨 도깨비 장인은 브론을 대체하는 새 기본 대장장이가 아니라 지역 전문화 후보로 남긴다. '찾아오는 느낌'은 실제 클리어로 열린 시설과 합류한 동료의 변화로 먼저 전달한다. 타이머·뽑기·불필요한 알림 점을 기본 성장 동기로 추가하지 않는다.

## 아이템·유물 화면의 상태안

현재 게임에는 아이템 인벤토리·장착 슬롯·장비 드롭·유물 전투 효과가 없다. 아래는 [기존 장비 기획](cast-and-items.md)의 **동료별 무기1·방어구1, 수비대 공용 유물1** 원칙을 유지하는 후속 설계다. 공용 장비Lv와 별개의 시스템이므로 동일한 명칭이나 수치로 혼동시키지 않는다.

| 화면 상태 | 보여 줄 내용 | 가능한 행동 / 검증 |
| --- | --- | --- |
| 아직 얻은 아이템 없음 | 보관인이 맡을 역할, 첫 획득처 한 곳 | 기존 원정으로 이동. 잠긴 빈 슬롯을 구매 압박처럼 표시하지 않음 |
| 보유했으나 미장착 | 원본 이미지·이름·획득 이유·적용 대상 | 선택하여 상세 보기. 미구현 시안에서는 실제 장착 완료를 가장하지 않음 |
| 장착 가능 | 현재 장비와 후보의 고정 효과·교체 대상 | 무기/방어구는 해당 동료, 유물은 수비대 공용1칸이라는 범위를 표시 |
| 이미 장착 | 장착 대상과 현재 효과 | 해제/교체. 수량·슬롯 중복을 저장 계층에서 검증 |

| 최대 강화 | 현재 효과와 최종 단계 | 다음 단계/추가 결제를 표시하지 않음 |
| 저장 실패 | 현재 세션 적용 여부와 재접속 시 위험 | 경고를 최종 확정 단계에도 표시. 저장 실패 시 정책을 별도 결정 |

조류 나침반·폭풍 옥종은 [후속 컨셉](followup-2026-11-09.md)에 있는 **효과·수치 미정** 보상 유물 후보다. 기존 구조대의 등불·동행의 방울·이름패 등의 후보를 대체하지 않는다. 새 유물은 전투 수치를 먼저 늘리기보다 어느 구조 사건에서 얻었고 어떤 선택을 바꾸는지부터 정한다. 보관인과 가방 탭은 실제 보유·장착 계약이 생기는 단계에서 추가한다.

## 검토 반영과 검증 한계

Fable API는 화면 역할 분리, 자동 지급 설명, 결정에 필요한 강화 전후값과 잔액, 기존 NPC 재사용을 제안했다. 그중 실제 기능이 있는 네 메뉴를 구현했고, 제안된 가방 탭과 신규 NPC 시스템은 아직 추가하지 않았다. 배지나 다섯 번째 메뉴를 제안했다는 이유만으로 완성 기능으로 취급하지 않는다.

Opus API가 지적한 **확정창의 저장 실패 경고 누락**은 확정창에도 같은 경고를 추가해 보완했다. 두 가설은 전체 소스와 대조했다. `camp-art.css`에는 이미 비동료 섹션의 로스터와 공통 소개를 숨기는 규칙이 있고, `DefenseGame`은 거점과 전투를 조건부로 마운트하므로 새 캠페인 진행이 동일 거점 인스턴스에 남는다는 가정은 현재 구조에 맞지 않는다. 이에 불필요한 동기화 effect나 중복 CSS를 추가하지 않았다. 강화 설명은 교육 콘텐츠가 아니라 지속 기간·소비 재화에 대한 결정 정보이므로 남겼다.

통합 담당자의 검증 결과는 **테스트170개 통과, 빌드 통과**다. 이 문서 작성자는 소스와 전달된 기록을 검토했으며 해당 검사를 직접 재실행했다고 주장하지 않는다. 브라우저 `after.json`은 다음을 기록한다.

- 새 캠페인 마을 진입, 잠긴 대장간의 원정 안내.
- 저장 fixture(1·2클리어,300G,Lv0)에서 시설→성장,Escape 취소와 포커스 복귀, 확정100G 한 번 차감 및Lv1/+8%.
- 새로고침 후 성장 보존, 무료 브론 선택, 해금 테마 선택·저장.
- 360/390/844/1440px에서 페이지 가로 넘침 없음.
- 골드 부족 비활성, 최대Lv5/+40%에서Lv6 표시 없음, 원정에서 별도 전투 화면 진입.
- 기록된 브라우저 오류 없음.

최종 `edge.json`에는 네 탭의 보이는 버튼 높이44px 이상, 동료 탭에서만 로스터 표시, 이미 지급된 퀘스트 문구 확인 시 추가 골드 지급 없음, 저장 실패의 확정창 경고와 메모리 내 강화 유지,Tab 포커스 순환과Escape 닫기가 기록되어 있다. 오류·실패 항목은 없다. 테마 카드는 이미지를 위에, 이름·해금 조건을 아래에 배치하도록 마지막 스타일도 정리했다.

fixture 검사는 상태 전환·지급 계약·레이아웃 검증이다. 전체 캠페인의 실제 난이도·재미, 장시간 전투, Android 실기기 성능이나 상용 출시 품질을 증명하지 않는다. API 검토도 제공된 소스와 화면에 대한 판단이며 직접 플레이 측정과 구분한다.
