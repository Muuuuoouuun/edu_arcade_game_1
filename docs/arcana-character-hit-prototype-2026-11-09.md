# 북극곰·도마뱀 피격 시안

## 제작 단계와 범위

- 콘셉트: `art-source/defense/concepts/2026-11-09/{polar-bear-guardian,gecko-ranger}.png` 기존 이미지. 북극곰은 흰 털·푸른 방패·닻망치, 도마뱀은 잎 두건·꼬리·씨앗 쇠뇌를 유지한다.
- 새 이미지: `art-source/defense/concepts/2026-11-09/motion/guardian-ranger-hit-reference.png`. 두 기존 콘셉트를 입력으로 OpenAI 이미지 생성 도구에서 2026-11-09에 생성했다. 2행 3열은 각 캐릭터의 대기·피격·복귀 포즈다. 생성 결과를 직접 확인해 방패를 앞세운 무거운 반응과 무기를 놓지 않는 작은 반응 및 꼬리의 후속 동작을 참고했다. 그림은 해부학·완성 모델의 정확한 청사진이 아니다.
- 편집 가능한 모델 원본: `art-source/defense/prototypes/{polar-bear,gecko-ranger}/*.blend` 및 `tools/blender/build_{polar_bear,gecko}.py` 기존 파일. 이번에는 생성 스크립트를 실행하거나 기존 모델을 변경하지 않았다.
- 실제 애니메이션: `src/model-lab-hit.ts`는 기존 GLB의 독립 노드에 0.48초 회전 키프레임을 생성한다. 0.09초에 피격, 0.25초에 반동, 0.48초에 복귀한다. 북극곰은 몸·방패 팔·머리·망치 팔, 도마뱀은 몸·머리·쇠뇌와 잡은 팔·꼬리를 움직인다. 선형 쿼터니언 보간을 쓴다. 발 노드는 그대로다. 이 코드는 편집 가능한 애니메이션 원본이며 GLB 내부의 새로운 클립이 아니다.
- 작업실: 피격 버튼은 두 시안에만 나타난다. 새 입력 시 현재 동작을 멈추고 재시작하며 기존 강타·발사와 전환한다. 동작 줄이기 설정에서는 재생하지 않는다. 캠페인, 전장, Android 패키지에는 연결하지 않았다.
- 이전 동작: 곰의 준비·타격·회복 0.8초, 도마뱀의 조준·발사 반동·복귀 1초는 기존 GLB에 이미 있다. 새로운 걷기·호흡 대기 클립, 발사체 및 피격 판정은 없다.

## 검증과 한계

- 자동: `npm run build`, `npm test` (166개), `node --experimental-strip-types --test tools/tests/model-lab-hit.test.mjs` (2개) 통과. 실제 GLB를 로드해 0.09초 몸 회전, 정적 발 노드의 월드 위치, 10ms 간격 유한 회전, 마지막 복귀를 검사한다. 이것은 발 메시 관통이나 모든 메시 충돌을 증명하지 않는다.
- Chromium 소프트웨어 WebGL: `npm run dev`를 실행한 뒤 Playwright가 설치된 환경에서 `node tools/tests/model-lab-browser.cjs`. 390×844 및 844×390에서 두 모델 로딩, 피격 반복·피격에서 공격 전환·종료를 확인했다. 의도적으로 GLB 요청을 차단했을 때 PNG 대체와 피격 버튼 비활성화를 확인했다. 테스트 키 하나가 작업실 조작 후 보존됨을 확인했으며 실제 캠페인 저장 데이터의 마이그레이션 검증은 아니다. 모바일 세로 정지 화면을 직접 확인했으나, 피격 각 프레임의 관통·무기 궤적과 48~64px 실루엣은 아직 시각 검수하지 않았다.
- Android 실기기 성능·터치·화면 방향·전투 저장은 미실행. 작업실에서 방패·망치·쇠뇌의 관통, 카메라별 실루엣과 반복 이음새를 프레임 단위로 독립 검수해야 한다. 이 변경은 모델 품질이나 게임 적용 승인이 아니다.
