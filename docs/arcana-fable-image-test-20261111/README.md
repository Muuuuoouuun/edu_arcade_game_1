# Fable 5.2 이미지 기반 디테일 검토 시험

2026-11-11. 카르의 기존 정지 렌더 [`kar-barbarian.png`](../../public/defense/models/kar-barbarian.png)를 Anthropic 공식 Messages API의 `claude-fable-5-2`에 첨부했다. 사용자가 낮은 effort 시험을 허용한 뒤 `thinking: adaptive`, `effort: high`, 출력 한도 3,000토큰으로 망치와 갑옷의 작은 화면 구분에 관한 관찰 한 가지와 개선 두 가지를 요청했다.

응답 모델 `claude-fable-5-2`, 종료 사유 `end_turn`, 입력 359 / 출력 855토큰(그중 추론 401토큰), 본문 406자다. [응답 원문](response.md) · [요청과 사용량 메타데이터](receipt.json). 실제 과금액은 계정의 사용 내역과 모델 가격에서 확인한다.

모델은 망치 머리의 실루엣은 읽히지만 손·자루 주변은 뭉칠 가능성이 있다고 보았다. 자루를 더 드러내고 건틀릿을 단순화하거나 망치 끝의 형태를 과장하는 안을 제시했다. 원본 정지 이미지에 대한 의견이며, 실제 작은 픽셀 크기·측면·움직임·실기기 전투를 직접 검사한 결과가 아니다. 의견을 사실이나 적용 완료로 취급하지 않는다.

이 시험은 하나의 이미지와 `high` effort에서 답변 반환을 확인했다. 이전 `max` 호출에서 답변이 없었던 원인을 증명하거나 다른 이미지와 모델에 대한 성공을 보장하지 않는다. 기존 GLB·Blender 원본과 게임을 수정하지 않았다.
