기준 `717b93e`에 세계관 자료 `8e09b96`과 별도 3D 수학 실험 `f6d2dd7`을 이력을 보존해 통합했다. 아르카나는 지역·세계관이며 기존 숲·설산, 영웅·용병 캠페인을 유지한다. 카드·퀴즈·마나 규칙은 별도 실험의 규칙이다. 세계관 문서와 33개 원본 시안은 확정 인물이나 배포용 게임 에셋이 아니다. 캠페인에 적용되지 않은 제안으로 전문화, 장비, 버프, 성 방어와 동등 조건의 점수 랭킹이 남아 있다.

캠페인 전직 선택에 실제 효과를 표시하고 실험실의 화면 제목을 캠페인과 구분했다. 기존 전투 규칙과 저장 형식은 변경하지 않았다.

검증: `npm test` 90/90, `npm run build` 성공, 별도 2D 시뮬레이션 `npm run test:prototype` 63/63 및 750판 성공. 캠페인 Chromium 합성 플레이는 390×844와 1366×768에서 허브·거점·건설·웨이브·일시정지, 모바일 2웨이브 후 전직 선택과 1-1 승리·방문 수락·보상·거점 복귀와 1-2 해금까지 확인했다. 320×568과 844×390에서는 버튼 경계만 확인했다. 실기기 및 사용자 플레이는 실시하지 않았다.

별도 3D 실험의 브라우저 테스트는 파일 URL이 환경 정책으로 차단되어 localhost에서 실행했다. 통합 트리에서 한 실행은 스크린샷 시간 초과로 끝까지 완료하지 못했다. 별도로 원본 `f6d2dd7`의 배포 빌드에서는 브라우저 검사 33/33이 통과했다(이후의 제목 변경은 제외). 소환·답변·강화·진행·결과·복습·카메라·일시정지 등을 검증했다. 좁은 화면에서 슬롯 중심 간격이 48px 미만인 경우가 있어 터치 충돌 가능성을 추가 검증해야 한다. 캠페인 모바일 세로 화면은 전장과 조작부 사이 여백이 크다. 밸런스 시뮬레이션에서 1-4 정예 무타워 승리가 가능했으므로 사람의 실제 플레이와 함께 평가해야 한다.
