# 개발 루프 인계 목록

> **현재 통합 기준 (2026-11-09):** 아래의 가로 전용 문구는 당시 인계 기록으로 보존한다. 화면 방향은 기록 간 차이가 있어 현재 미확정이며, 확인 전까지 기존 세로·가로 지원을 제거하지 않는다. 제품 방향과 검증 상태는 [모바일 통합 현황](../arcana-mobile-integration.md)을 따른다.

2시간 기획 루프(67회차부터, 그전 3시간) → 1시간 개발 루프. 기준: 67회차(2026-11-09 20:10 KST, 주제: **67회차부터 사용자 요청으로 모델링·게임 모드·로직(세계관·게임 세팅)**, 새 관점 **다른 캐릭터·필살기·레벨에 따른 이펙트**(67), **사용자 요청: 애니메이션·타격 디벨롭(41) + 게임성, 특히 맵 크기·활용과 조작(60)**). **main `355e573`**(PR #60~#102)과 대조했다. PR #60부터 개발 PR의 base는 main이고, 개발 루프는 매 회차 이 파일을 읽기 전용으로 읽는다. **사용자 결정(2026-11-09)**: 모바일은 **가로 모드만**(세로 없음) — 화면 기준은 가로 배율 0.505~0.572. 근거는 사용자가 이 루프 세션에 직접 쓴 말(2026-11-09 01시대 KST) “모바일에서는 세로모드없음, 가로모드만 있음”. #93 통합 주석(방향 미확정)과 다르므로 64회차에 사용자 확인을 청함 — 확인 전까지 개발 쪽 주석대로 기존 지원은 보존. **확정 제약**: 방어 캠페인에서 재료 학습·관찰노트는 승리·보상·진행의 관문이 되면 안 된다(개발 루프 지시문의 기존 규칙). 이 목록의 후보도 이 제약 안에서만 쓴다.

**인계가 없어서 쌓인 재작업**(15회차 2-1): 슬라임(#30)·돌 갑옷병(#41)·나무 병사(#46)·빙결 기사(#52) 네 모델이 이 목록의 설계와 다르게 만들어져 약 3~4 개발 주기 분량의 재작업 후보가 생겼다. 서리늑대·보스는 아직 만들어지지 않았다.

**몬스터 제작 규격**(10회차 2-4): 일반 몬스터는 개발 브랜치의 절연 슬라임·돌 갑옷병과 같은 384×384 프레임, 1152×384 3포즈 아틀라스(walk-a·walk-b·hit), Cycles 96 샘플을 쓴다. 비슷한 크기 계열은 직교 스케일을 맞춘다(돌 갑옷병 6.6). 영웅·보스는 640px 규격을 유지한다. **모든 몬스터 모델은 64px 흑백 실루엣으로 다른 몬스터와 구분되어야 한다**(14회차 2-1).

이 문서는 **제작 후보 목록**이다. 기획 루프는 게임 코드를 바꾸지 않는다. 채택·제작 여부는 개발 루프와 사용자가 정한다. 각 후보의 자세한 설계는 출처 회차 문서에 있다.

## 먼저 할 다섯 개 (19회차)

A 후보 중 **곧 할 일의 재작업을 막는가 / 플레이어에게 보이는가 / 작게 끝나는가**로 골랐다. 자세한 이유는 [19](cycles/19-ops.md) 2-1.

1. **이식 규칙 한 장** — 모든 모델은 64px 흑백으로 기존 것과 구분 / 고목왕은 보라 균열을 빼고 옮김 / 카르는 원래 그림대로 옮기지 않음 / 이안 결정은 따뜻한 색. 보스·영웅 이식 전에 적용.
2. **상태 칩에 엔진 알림 허용 목록 표시** — 규격은 [19](cycles/19-ops.md) 3-1.
3. ✅ **완료(PR #63)** — **대체 전용 회화 시트 지연 불러오기** — `monster-models.webp`(594,058 B)는 지금 바로 대상.
4. **패배 조언에 재료 힌트** — 종류별 돌파 수 + 관찰노트 문장. **32회차 수정**: 지금 코인 조언 뒤 **둘째 줄**로, 원인이 아니라 효율 문장으로(“…가 가장 많이 뚫었어요. 불·충격이면 코인을 덜 써요.”). 측정상 진 판 72판 모두 코인이 원인이었고, 같은 타워로 코인만 다 써도 57판 모두 이겼다([32](cycles/32-ops.md)).
5. ✅ **완료(PR #64, 호박색)** — **절연 슬라임 보라 제거** — 재질 값만 바꾸고 다시 렌더. **38회차 렌더 확인**: `build_slime.py`의 SLIME·SLIME_DARK 두 줄만 호박색 `(.62,.33,.05)`·`(.3,.13,.02)`으로 바꾸면 64px에서 돌과의 회색 차가 1 → 32로 ‘구분’이 된다. 아틀라스 24,820 B. 호박색 선택은 묶음 ②의 ‘슬라임 호박색’, 보라 제거 자체는 결정 불필요([38](cycles/38-model.md) 3장).
