# 개발 루프 인계 목록

3시간 기획 루프 → 1시간 개발 루프. 기준: 12회차(2026-11-03 09:07 KST). 개발 통합 브랜치 `codex/arcana-development-loop-20261030` `6074003`과 대조했다.

**몬스터 제작 규격**(10회차 2-4): 일반 몬스터는 개발 브랜치의 절연 슬라임·돌 갑옷병과 같은 384×384 프레임, 1152×384 3포즈 아틀라스(walk-a·walk-b·hit), Cycles 96 샘플을 쓴다. 비슷한 크기 계열은 직교 스케일을 맞춘다(돌 갑옷병 6.6). 영웅·보스는 640px 규격을 유지한다.

이 문서는 **제작 후보 목록**이다. 기획 루프는 게임 코드를 바꾸지 않는다. 채택·제작 여부는 개발 루프와 사용자가 정한다. 각 후보의 자세한 설계는 출처 회차 문서에 있다.
