### 정체성 기준 (1회차 제안, 사용자 확정 대기)

1. **재료를 읽는 수비대** — 적의 몸이 무엇으로 되어 있는지(나무·얼음·돌·금속·송진…) 보고 대응을 고른다. 전투의 핵심 판단이자 선택형 관찰노트의 근거다. 적의 외형은 재료가 먼저 읽혀야 한다.
2. **구조하고 함께 산다** — 지역을 구하면 그곳 사람이 거점에 남아 시설과 동료가 된다. 적에게도 그 지역의 사정이 있다. 모든 사건을 하나의 흑막으로 묶지 않는다(사용자 결정).
3. **동서양이 같은 화폭에** — 반실사 회화 톤, 청록·먹청·상아·주홍 + 황동. 서양 판타지와 한국적 산촌·설화가 같은 재질·조명 규칙을 쓴다.

**확정 제약 (기존 규칙, 38회차에 반영)**: 개발 루프 지시문에 처음부터 있던 규칙이다. “방어 캠페인에서 재료 학습과 관찰노트 읽기는 승리·보상·진행의 관문이 되면 안 된다.” 모바일 전환 문서도 “재료 상성·관찰노트는 최소·선택형 교육으로 유지”한다고 적는다. 기준 1(재료를 읽는 수비대)은 이 제약 안에서만 쓴다. 재료 대응은 효율·표시·발견으로 보상하고, 이기거나 보상을 받는 조건으로 걸지 않는다.

**사용자 결정 (다른 루프 문서에 기록됨)**: 2026-11-06 Android 설치판 우선 경로(Capacitor, 같은 저장소)를 선택했다. Godot 전환은 이번에 하지 않는다(`docs/mobile-app-transition.md`).

**사용자 결정 (2026-11-09 01시대 KST, 이 루프에 직접)**: **모바일은 가로 모드만, 세로 모드 없음.** 화면·가독성 측정은 가로 배율 0.505~0.572(844 × 390에서 0.535)로 한다. 세로 확대 보기(0.74)·세로 전체 보기(0.43)는 모바일 기준이 아니다.

사용자가 수정하면 이 절을 갱신하고 회차 기록에 남긴다.

### 저입력 회차 (19회차 추가)

지난 회차 이후 **사용자 결정도, 개발 통합 브랜치 변경(새 PR)도 없으면** 그 회차는 짧게 쓴다: 세 분야 점검은 표 한 줄, 주 분야는 작은 단위 하나(설계서 하나 또는 정정 하나), 인계 목록과 기록은 갱신, 새 질문은 만들지 않는다. 둘 중 하나라도 생기면 평소 회차로 돌아간다. 주기(67회차부터 2시간)는 사용자가 정한다.

### 회차 문서 형식

1. 기준 — 회차 번호, KST 시각, 기준 커밋, 주 분야.
2. 세 분야 짧은 점검 — 분야별 현재 상태 1줄 + 발견 1~3개(근거 파일 경로).
3. 주 분야 디벨롭 — 제안은 **제안**, 사용자 결정은 **결정**으로 표시. 세 축 통과 여부.
4. 모델링 설계서 1~2개 — 아래 형식.
5. 개발 루프로 넘길 제작 후보 — 작은 단위, 완료 판단 포함.
6. 사용자에게 물을 것 — 최대 3개.
