## 기존 1시간 개발 루프와의 관계

[1시간 개발·자가 점검 루프](../arcana-development-loop.md)는 **구현**(모델 제작·코드·모바일 QA)을 담당한다. 이 3시간 루프는 **기획·방향**을 담당하며 게임 코드·에셋·저장 형식을 바꾸지 않는다. 산출물은 `docs/arcana-direction-loop/` 안의 문서뿐이다. 이 루프의 모델 설계서는 개발 루프가 고를 수 있는 **제작 후보**이고, 채택 여부는 개발 루프 또는 사용자가 정한다.

## 판단 기준

모든 제안은 아래 세 축을 통과해야 채택 후보가 된다. 통과하지 못한 항목은 기각 사유와 함께 기록한다.

| 축 | 질문 |
| --- | --- |
| 게임성 | 플레이어가 고를 이유가 있는가? 강한 조합과 약한 조합의 결과가 화면에 보이는가? 졌을 때 바꿀 행동을 알 수 있는가? |
| 오락성 | 다음 한 판을 하고 싶은가? 새로 발견할 것이 남아 있는가? 손맛(타격감·예고·반응)이 있는가? |
| 정체성 | 아르카나만의 것인가? 아래 **정체성 기준**과 맞는가? 다른 게임의 고유 설정을 가져오지 않았는가? |

### 정체성 기준 (1회차 제안, 사용자 확정 대기)

1. **재료를 읽는 수비대** — 적의 몸이 무엇으로 되어 있는지(나무·얼음·돌·금속·송진…) 보고 대응을 고른다. 전투의 핵심 판단이자 선택형 관찰노트의 근거다. 적의 외형은 재료가 먼저 읽혀야 한다.
2. **구조하고 함께 산다** — 지역을 구하면 그곳 사람이 거점에 남아 시설과 동료가 된다. 적에게도 그 지역의 사정이 있다. 모든 사건을 하나의 흑막으로 묶지 않는다(사용자 결정).
3. **동서양이 같은 화폭에** — 반실사 회화 톤, 청록·먹청·상아·주홍 + 황동. 서양 판타지와 한국적 산촌·설화가 같은 재질·조명 규칙을 쓴다.

사용자가 수정하면 이 절을 갱신하고 회차 기록에 남긴다.
