## 2. 가로 화면에서 실제로 보이는 키

크기 규칙(`DefenseBoard.tsx`)
- 영웅 84(전직 94), 몬스터 68(새싹 54, 늑대 73, 고목왕 115, 서리군주 135)에 각 그림의 `displayScale`을 곱한다.
- 작은 전장에서는 `unitScale`(전장 폭 482px이면 1.065, 454px이면 1.12)을 영웅·몬스터에 더 곱한다.
- 타워는 92 + 4 × 레벨이고 `unitScale`이 없다.
- 각 그림의 불투명 영역 높이로 **보이는 키**를 CSS px로 냈다.

| 무엇 | 보이는 키 (844 × 390) | 800 × 360 |
| --- | --- | --- |
| 새싹 도적 | 19px | 19px |
| 절연 슬라임 · 서리늑대 | 29 · 31px | 28 · 30px |
| 금속 병사 · 나무 병사 · 빙결 기사 · 돌 갑옷병 | 34 · 35 · 36 · 36px | 33~36px |
| **브론(Blender 모델, `displayScale` 1.2)** | **35.7px** | 35.3px |
| 이안 46회차 초안(같은 규격) | 34.5px | 34.1px |
| 이안 · 청운 · 리엘(지금 그림) | 38 · 39 · 41px | 38~40px |
| 카르 · 루나(지금 그림) | 46 · 46px | 46px |
| #84 북극곰 · 도마뱀 시안(같은 규격 가정) | 38 · 37px | 37px |
| 쇠뇌 Lv1 · 포탑 Lv2 · 마법탑 Lv2 | 48 · 53 · 56px | 45~53px |
| 고목왕 · 서리군주 | 59 · 72px | 58 · 71px |

**읽은 것**
- **Blender 영웅은 보통 몬스터와 키가 같다**(35.7 대 34~36px). 그림 영웅(38~46px)보다 10~25% 작다.
  - 46회차 이안 초안을 그대로 옮기면 이안이 지금보다 작아져(38 → 34.5px) 몬스터 사이에 묻힌다.
  - 영웅을 구분하는 것은 지금 발밑 고리(타원 30 × 12)뿐이다.
- 크기 순서는 타워(48~56) > 영웅 ≈ 몬스터(34~36) > 슬라임·늑대 > 새싹(19)이고, 보스(59~72)가 가장 크다.
  - 플레이어가 움직이는 유일한 캐릭터(60회차)가 화면에서 크기로 드러나지 않는다.

**읽은 것**
- 북극곰은 **브론과 모양이 거의 같다**(방패 + 망치, 겹침 0.71). 하얀 털 덕분에 밝기로만 갈린다. 그러니 털은 어둡게 하면 안 된다.
- 그런데 하얀 털은 **설산 전장에서 배경과 16밖에 차이 나지 않는다.** 극지(#82 극지 해안 전장 포함)가 고향인 영웅이 고향 맵에서 가장 안 보인다.
  - 대비는 털이 아니라 **갑옷·방패 테두리 같은 어두운 면**으로 만들어야 한다.
- 도마뱀 궁수는 리엘과 같은 ‘초록 궁수’ 계열이지만 모양(꼬리·쇠뇌)이 달라 구분된다(겹침 0.43). 50회차의 리엘·루나 같은 혼동은 없다.

## 4. 제안

### A. 결정 없이 진행해도 되는 것 (인계 A)

1. **Blender 영웅 규격의 `displayScale` 1.2 → 1.32**
   - 브론과 앞으로 옮길 영웅(이안 초안 포함)에 같은 값을 쓴다.
   - 결과: 보이는 키가 브론 35.7 → 약 39px, 이안 초안 34.5 → 약 38px가 된다. 그림 영웅(38~41px)과 맞고 보통 몬스터(34~36px)보다 한 단계 크다.
   - 땅 기준점(groundY 550)은 그대로라 발 위치는 바뀌지 않는다.
   - 완료 판단
     - 가로 844 × 390에서 영웅이 같은 줄의 보통 몬스터보다 키가 크다.
     - 타워(48px 이상)보다는 작다.
     - `art.test.ts` 통과.
2. **새 영웅 시안의 전장 대비 기준**
   - 영웅 몸의 평균 회색이 두 전장(숲 116·설산 156) 배경과 각각 **25 이상** 차이 나야 한다. 이번 측정에서 브론은 31·71이다.
   - 북극곰처럼 밝은 몸은 어두운 갑옷·방패 테두리 면적을 늘려 설산 대비를 맞춘다. 털 색은 브론과 갈라지는 단서라 그대로 둔다.
   - 시안이 게임 영웅이 되기 전에 확인한다(#84 문서의 ‘적용 전 확인’에 더함).

### B. 결정이 필요한 것
