## 2. 히트스톱이 결과를 바꾸지 않는 조건

### 2-1. 지금 UI 루프 (`DefenseGame.tsx`)

- 매 프레임 실제 경과 시간(최대 0.1초)에 배속을 곱해 `accumulated`에 더한다. `1/60`초씩 `stepDefense`를 부르며 뺀다.
- 일시정지·숨김·차단 중에는 `accumulated = 0`이다.
- 엔진(`engine.ts`)에는 `Date.now`·`performance.now`·`Math.random`이 **없다.** 같은 입력과 같은 단계 순서면 결과가 같다.

**결론 — 구현 원칙(필수)**: 히트스톱은 **멈춘 동안 경과 시간을 `accumulated`에 더하지 않는** 방식이어야 한다.
- 프레임만 건너뛰고 시간을 계속 쌓으면, 멈춤이 끝난 프레임에 밀린 단계를 한꺼번에 따라잡는다. 멈춤이 사라지고 화면이 튄다.
- 그래서 ‘멈춤 끝 시각’을 두고, 그 전까지 `elapsed`를 0으로 본다.
- 그러면 엔진이 부르는 단계 순서는 같고 실제 시간만 늦어진다. 승패·보상·판 시간(엔진 시간)은 그대로다.

### 2-2. 측정 — 3단계 멈춤이 판마다 몇 번, 얼마나

41회차 3단계 사건을 기록했다. main 사본, 72판(8스테이지 × 난이도 3 × basic·auto·active, 도구 기본 영웅 = 1-1 이안, 나머지 카르)이다. 처치마다 마지막 공격의 출처를 남겼다. 세는 줄을 넣어도 결과는 41회차와 같다(72/72).
- 필살기 명중
- 서리군주 충전 끊기
- 영웅 근접 공격의 무거운 적(돌·얼음·금속·나무) 처치
- 보스 처치(90ms, 대기 없음)

| 전략 | 대기 없음: 판당 멈춤 / 멈춘 시간 / 1초 최대 | **대기 0.6초**: 판당 멈춤 / 멈춘 시간 / 판 시간 대비 최대 / 1초 최대 |
| --- | --- | --- |
| basic | 12.0번 / 607ms / 2 | 12.0번 / 603ms / 0.90% / 2 |
| auto | 7.2번 / 370ms / 2 | 7.2번 / 368ms / 0.65% / **1** |
| active (필살기 사용) | 19.5번 / 987ms / **3** | 17.6번 / 889ms / 1.85% / **2** |

무거운 적 처치 3,152번 중 영웅 근접으로 끝난 것이 834번이다.

**읽은 것**
- 3단계 멈춤은 판당 7~18번, 합쳐서 **1초 미만**이다(판 시간의 2% 이하). 판이 체감상 길어지지 않는다.
- 대기 0.6초가 있으면 1초에 최대 2번이다. 41회차 완료 판단(1초 2번 이하)을 지킨다. 대기가 없으면 필살기를 쓰는 판에서 3번까지 몰린다.
- 원거리 영웅(이안·리엘·청운·루나)은 ‘영웅 근접 처치’가 없어서 멈춤이 더 적다. 근접 영웅(카르·브론)일 때 손맛이 더 큰 셈이다. 역할 차이로 둔다.

### 2-3. 테스트 기준 (제안)

1. 루프의 시간 계산을 순수 함수로 뺀다. 예: `advanceClock(accumulated, elapsed, speed, stopUntil, now) → {steps, accumulated}`.
   - 테스트 ①: 멈춤 구간에서는 `steps = 0`이고 `accumulated`가 늘지 않는다.
   - 테스트 ②: 멈춤이 끝난 첫 프레임에 밀린 단계가 생기지 않는다(1프레임 분량만).
2. 같은 입력 열을 ‘멈춤 있음’과 ‘없음’으로 돌린 최종 상태가 같다. 엔진 단계 수와 `time`도 같다. 기존 408번 줄(60Hz 루프) 테스트와 같은 방식이다.
3. 3단계 대기: 0.6초 안에 두 번째 사건이 오면 멈추지 않는다. 보스 처치는 대기와 상관없이 멈춘다.

## 3. 소리·진동 단서와 타격 시점

- `combatCueFor`는 프레임마다 단서 하나를 고르고, 진동은 0.2초 간격 제한이 있다.
- 3단계 멈춤은 **사건이 일어난 프레임 다음부터** 시작한다(같은 프레임의 단계는 이미 끝났다). 그 프레임의 소리·진동 단서와 같은 순간이다.
- 그래서 단서 우선순위에 ‘3단계’를 따로 둘 필요는 없다.
  - 보스 처치는 PR #71의 큰 충격파 고리가 이미 ‘충격파’ 단서로 잡힌다.
  - 필살기는 ‘필살기’ 단서로 잡힌다.
  - 영웅 근접 처치는 ‘근접’ 단서로 잡힌다.
- 진동만 41회차 표(12ms, 보스 [30,40,60])로 더한다.
