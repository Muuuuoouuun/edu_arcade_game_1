## 2. 참고 그림에서 잰 것

참고 그림
- `public/defense/ranged-motion.webp` 둘째 줄: 준비 (37,398,325,337) · 타격 (367,420,414,319) · 회복 (775,450,289,288)
- `public/defense/atlas.png` 1칸 (350,65,265,255)
- 비교용 루나: 같은 시트 넷째 줄

그림 속 리엘
- 초록 두건, 긴 금발, 뾰족 귀
- 초록 망토, 갈색 가죽 흉갑과 치마 갑주, 어두운 각반, 갈색 장화
- 덩굴과 잎이 감긴 나무 활(키만 함), 등 화살통
- 빛나는 초록 화살

- 둘 다 금빛 머리, 초록 망토, 갈색 가죽이다. 루나의 여우 귀와 상아색 치마, 리엘의 두건과 활이 다를 뿐 밝기가 비슷하다.
- 이안을 옮길 때는 브론과 모양으로 구분됐다(46). 리엘은 **루나와 밝기로도 갈라야** 한다.

**② 화살은 활보다 한참 뒤에서 나온다**
- 그림 속 화살촉(밝은 초록) 위치는 준비 칸 (33.4, −38.9), 타격 칸 (47.6, −40.5)이다. 발 기준 게임 단위, `displayScale` 1·1.3으로 환산했다.
- `ElfDraw`(준비 활 표시)는 발 기준 (20, −40)에 놓인다. 화살촉 구슬은 다 당겼을 때 (43, −40)이다.
- 실제 화살 투사체는 (0, −27)에서 그려진다.
- 그래서 타격 순간 화살이 그림의 화살촉보다 **48단위(390px 화면에서 약 21px) 뒤**, 몸 한가운데서 나온다.
- 화살 속도 650이면 그림 속 화살촉 위치까지 약 0.075초 걸린다.
- 47회차에 따르면 영웅 투사체 가운데 리엘의 화살이 가장 많다(192판에서 6,557발). 46·47회차의 ‘발사점’ 제안이 가장 크게 효과를 내는 영웅이다.

**③ 준비가 가장 짧다**
- 리엘의 `hitAt`은 0.10초다. 전투판은 약 30Hz로 그려지므로(47) 준비 포즈는 1배속 3장, 2배속 1.5장이다.
- 그래서 준비 포즈는 당기는 중간이 아니라 **다 당긴 끝 모습** 한 장이어야 한다.

## 3. 설계서 — 리엘 (엘프 명사수)

| 항목 | 내용 |

| 규격 | 이안·브론과 같다. 640px, 직교 5.8, 카메라 (7,10,7) → (0,0,1.7), 땅 (320,550), `displayScale` 1.2, 오른쪽 보기. 초안은 `build_mage_draft.py`의 스튜디오·관절 틀을 그대로 쓴다 |
| 실루엣 | ① 앞쪽(화면 오른쪽) **세로로 긴 활 호**(높이 약 3.0, 몸보다 조금 큼)가 첫 단서 ② 둥근 두건 꼭대기(머리끝 약 3.2, 이안 모자 3.8보다 낮음, 위로 솟는 귀 없음) ③ 등 뒤 화살통 깃 세 개 ④ 뒤로 흘러내리는 머리 덩어리. 루나의 여우 귀·지팡이 둥근 머리와 위쪽 모양이 다르다 |
| 부위·메시 | 장화·각반(움직이지 않음), 가죽 치마 갑주 판 6장, 흉갑, 망토(`cape`), 두건(머리 묶음), 머리 덩어리(`hair`, 늦게 따라감), 뾰족 귀(두건 옆으로 나옴), 얼굴. 활은 곡선 관 메시 + 덩굴 감기 + 잎 6장. 시위는 위·아래 두 막대가 `nock` 빈 객체에서 만난다. 화살은 `arrow` 묶음(자루 + 초록 촉 + 깃), 화살통 |
| 재질·색 | 망토·두건 **짙은 숲 초록** 바탕 약 (.015,.07,.025) (**54회차 정정: (.006,.026,.009)** — 이 값은 64px 회색 92로 목표를 넘음) — 64px 회색 90 이하를 목표로 루나보다 어둡게. 가죽 (.20,.09,.035), 금발 (.78,.56,.24)(이안과 같은 값), 금빛 테 얇게. 화살촉만 발광 초록(`ElfDraw`의 `#d6ffa0`·`def-green-core`와 같은 계열) |
| 관절 | `body`·`head`·`hair`·`bow-arm`·`bow`·`draw-arm`·`nock`·`arrow`·`cape`. 다리와 뿌리는 고정(브론 계약) |
| 포즈 | **대기**: 활을 아래로, 화살은 화살통에(`arrow` 숨김). **준비**: 활 팔을 앞으로 곧게, 당기는 손이 뺨까지, 시위가 V자, 화살촉이 `ElfDraw` 구슬 자리(발 기준 약 (43, −40)) 근처. **타격**: 당기는 손이 뒤로 펴지며 놓음, 시위 곧게, 화살 숨김(투사체가 대신), 망토·머리가 뒤로. **회복**: 활을 조금 내리고 반 걸음 물러난 자세(0.06초, 2배속에서는 10번 중 1번 안 그려짐 → 대기와 비슷해도 된다) |
| 매니페스트 | 포즈마다 `nock_px`·`arrowhead_px`(프레임 px)를 남긴다. 46회차 `muzzle`에 쓴다(준비 구슬 = 준비 화살촉, 투사체 시작 = 타격 화살촉) |
