**읽은 것**
- 이름과 효과는 잘 맞는다. 세계관 쪽(이름)과 게임 세팅(엔진) 사이에 어긋남은 없다.
- 그런데 **효과는 화면 어디에도 쓰여 있지 않다.** 사거리·연쇄·연소 같은 기본 공격 특성은 카드의 ‘특성’ 한 줄로 나오는데, 필살기는 이름뿐이다.
- 그래서 플레이어가 알 수 없는 것이 셋 있다.
  - 전장 전체에 맞는다는 것 — 67회차: 화면의 고리는 범위처럼 보인다.
  - 영웅마다 피해가 1.8배까지 다르다는 것(90 대 165)
  - 서리군주 충전을 끊는다는 것 — 2-4의 핵심 필살기 타이밍(69회차)
- 동료를 고를 때 필살기 차이로 고를 이유가 화면에 없다(게임성: 선택의 근거).

## 3. 제안 (결정 불필요, 인계 A) — 문구만

- 동료 카드 필살기 줄과 필살기 버튼 길게 누르기(또는 첫 사용 전 한 번)에 **한 줄 설명**을 붙인다.
- 공통 줄은 하나로 둔다.
- 숫자 대신 말로 쓴다. 실제 값은 장비·전직에 따라 바뀌고, 떠오르는 피해 숫자가 이미 보여 준다.

| 영웅 | 한 줄 (초안 함수 `skillSummary`가 만든 그대로) |
| --- | --- |
| 이안 | 전장의 모든 적에게 불꽃 피해 · 불이 붙어요 |
| 리엘 | 전장의 모든 적에게 피해 |
| 브론 | 전장의 모든 적에게 충격 피해 · 밀어내요 |
| 청운 | 전장의 모든 적에게 번개 피해 · 4초 느려져요 |
| 카르 | 전장의 모든 적에게 강한 충격 피해 · 멀리 밀어내요 |
| 루나 | 전장의 모든 적에게 약한 피해 · 5초 느려져요 |
| 공통 | 20초마다 · 웨이브가 끝나면 다시 충전 · 서리군주의 충전을 끊어요 |

- 전직 뒤에는 같은 함수가 강화형이면 ‘+40%’, 제어형이면 ‘4초 느려져요’를 붙인다(지금 전직 문구와 같은 규칙).

**초안 코드**
- 파일
  - [`logic-drafts/skillSummary.ts`](../logic-drafts/skillSummary.ts) → `src/games/defense/skillSummary.ts`
  - [`logic-drafts/skillSummary.test.ts`](../logic-drafts/skillSummary.test.ts)
- 내용
  - 사실표 `SKILL_FACTS`(피해·원소·밀어내기·둔화·연소)와 문구 함수 하나
  - 테스트는 여섯 영웅의 **실제 시전**에서 살아남은 적마다 피해 = 표의 피해 × 원소 배율, 둔화·연소·밀어내기가 표와 같은지 본다. 문구가 엔진에서 벗어나면 테스트가 깨진다.
- main 사본에서 **2/2 통과**, 전체 `npm test` 170개 그대로.
- 나중에 엔진도 이 표를 읽게 하면(지금 `engine.ts`의 숫자 세 곳), 69·70회차의 P1 조정이 표 한 곳의 수정으로 끝난다.
