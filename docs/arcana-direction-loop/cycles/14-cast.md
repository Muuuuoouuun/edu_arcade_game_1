## 2. 캐릭터 디벨롭

모든 항목은 **제안**이다.

### 2-1. Blender 몬스터의 실루엣이 하나로 모인다

빙결 기사 렌더(`ice-knight-atlas.webp`)를 직접 열어 보고 앞의 두 모델과 나란히 비교했다.

| 모델 | 몸 구조 | 원래 회화 그림의 실루엣 | 잃은 것 |
| --- | --- | --- | --- |
| 돌 갑옷병 (#41) | 각진 공 덩어리 | 바위 골렘 | 없음 (원래도 덩어리) |
| 나무 병사 (#46) | 각진 공 덩어리 | 가지 팔을 뻗은 나무 괴물 | 세로로 긴 줄기, 가지 팔 (12회차) |
| 빙결 기사 (#52) | **각진 공 덩어리** + 얼음 가시 + 얇은 얼음 검 | **투구(눈 틈·볏)를 쓴 곧은 자세의 기사**, 결정 판금 어깨, 큰 결정 검 (`monster-models.png` 둘째 줄) | 투구, 곧은 자세, 판금, 큰 검 → ‘기사’가 아니라 ‘얼음 골렘’으로 읽힌다 |

- 셋이 거의 같은 몸에 **색만 다르다**(회색·갈색·파랑). 64px 전장에서 종류를 색으로만 구분하게 된다.
- **색각 이상 플레이어**는 갈색 나무 병사와 회색 돌 갑옷병을 구분하기 어렵다. 그런데 둘은 정반대의 대응(불 / 충격)을 요구한다. 정체성 기준 1(재료를 보고 대응을 고른다)이 색 하나에 기대게 된다.
- 01회차 사정의 빙결 기사는 “얼어붙은 방벽을 지키던 **갑주**”다. 기사 실루엣이 사정을 보여 준다.

**제안: 재료마다 몸 구조를 하나씩**

| 몬스터 | 몸 구조 (흑백에서 남는 것) |
| --- | --- |
| 돌 갑옷병 | 낮고 넓은 둥근 덩어리 (현행 유지) |
| 나무 병사 | 세로로 긴 원기둥 토막 + 가지 팔 (12회차 수정안) |
| 빙결 기사 | **곧게 선 판금 기사**: 볏 달린 투구와 눈 틈, 평평하고 각진 결정 판(공이 아니라 판), 몸 길이만 한 결정 검 |
| 금속 병사 | 역삼각 판금 몸, 가로 바이저 (10회차) |
| 절연 슬라임 | 낮은 방울 (현행) |
| 새싹 도적 | 작은 그루터기 + 위로 솟은 새싹 (10회차) |
| 서리늑대 | 네발 + 등 위로 솟은 결정 가시 (3-1) |

**검사 규칙(제안)**: 몬스터 모델을 만들 때 **64px 흑백 실루엣**으로 다른 몬스터와 구분되는지 확인한다. 이 검사는 결정이 필요 없는 품질 검사라 인계 A에 넣는다. 빙결 기사를 다시 만드는 일은 B(외형 결정)에 둔다.

### 2-2. 아군 늑대와 적 늑대

서리늑대(적)와 루나의 늑대 영물(아군)은 둘 다 흰 늑대다. 3장의 안개 늑대(06회차)까지 오면 전장에 늑대가 셋이다. 회화 그림에서는 지금 이렇게 구분된다(`public/defense/snow-atlas.png` 셋째·넷째 칸).

| | 루나의 늑대 (아군) | 서리늑대 (적) | 안개 늑대 (3장 적) |
| --- | --- | --- | --- |
| 몸 | 작고 둥근 흰 털 | 크고 각진 흰 털 | 먹빛 털 |
| 결정 | 없음 | 등·꼬리·발에 파란 얼음 결정 | 없음, 청록 연기 |
| 목 | **녹색 보석 목걸이** | 없음 | 없음 |
| 눈 | 녹색 | 빨강 | 청록 |

Blender로 옮길 때 이 구분이 무너지기 쉽다(2-1처럼 몸을 단순화하면 결정이 줄고 크기 차이가 사라진다).

**규칙(제안)**: **아군 동물은 목걸이를 하고, 적 동물은 목걸이를 하지 않는다.** 지금 그림이 이미 따르는 규칙을 명시하는 것이다. 4장의 아군 박쥐(2-4)에도 같은 규칙을 쓴다.

### 2-3. 개발 루프의 다음 대상 — 서리늑대

개발 루프는 `monster-models.png`의 회화 포즈 묶음(나무·얼음·돌·서리늑대)을 차례로 Blender로 옮기고 있다. 남은 것은 서리늑대다. 서리늑대는 아군 늑대와 겹칠 위험(2-2)이 있으므로, 이번 회차에 모델 설계서를 쓴다(3-1). 이 설계는 **지금 그림을 충실히 옮기는 것**이 기본이라 사용자 결정 없이 쓸 수 있다. 인계 A에 넣는다.

새싹 도적·금속 병사의 긴급 표시는 ‘다음 차례’가 아니라 ‘그 다음’으로 낮춘다. 대신 개발 루프가 보스(고목왕·서리군주)로 넘어갈 수도 있다. 고목왕의 보라는 01·09회차 제안과 직접 부딪치므로 인계 B의 고목왕 항목에 **보스 모델링 시 확인** 표시를 단다.

### 2-4. 4장 동료 두 사람의 전투 정체성 (10회차 자리 구체화)

이름·사연은 사용자 결정 대기다. 원화: `western/orc-variants.png` 오른쪽(푸른 망토의 판금 지휘관, 긴 검), `western/vampire-variants.png` 오른쪽(진홍·흑 귀족, 레이피어)·왼쪽(박쥐 사역마), `heroes/hero-skill-effects.png` 아래 두 칸(깃발 빛 고리, 박쥐 그림자 돌진).

| | 지원 (오크 지휘관 계열) | 군집 (귀족 ‘군무’ 계열) |
| --- | --- | --- |
| 속성 | 물리 (긴 검) | 물리 (박쥐) |
| 기본 공격 | 근거리 베기, 느림. 본인 피해는 낮다 | 본인은 레이피어 찌르기, 박쥐 셋이 따로 가장 가까운 약한 적을 문다 |
| 고유 특성 | 주변 영웅·용병의 공격 간격 −5% (상시, 반경 100). 12회차 상한 −30%에 포함 | 박쥐는 맞아도 사라지지 않고 2초 뒤 돌아온다 |
| 전직 `power` | **선봉**: 본인 피해 ×1.4 | **밤의 무리**: 박쥐 3 → 5마리 |
| 전직 `control` | **규율**: 깃발 지속 8 → 12초 | **그림자 걸음**: 박쥐에 물린 적 0.4초 둔화 |
| 필살기 | **집결 깃발**(기획 이름): 깃발 반경 150, 8초, 공격 간격 −20%·이동 +15% (12회차 규칙) | **밤의 쇄도**(기획 이름): 바라보는 방향으로 그림자 돌진, 경로상의 적 공격 |
| 함께 쓰면 | 브론 ‘공병 대장’과 겹치면 상한 −30% | 유물 ‘빈 이름패’(첫 타 +40%)와 박쥐 다수가 맞물려 **약한 무리**에 아주 강하다. 보스에는 약하다(12회차 유물의 대가와 같은 방향) |
| 아군 표시 | 깃발에 수비대 문장(주홍 매듭) | 아군 박쥐는 **먹청 몸 + 상아 날개 막 + 목의 주홍 매듭**(2-2 규칙). 4장 보스의 적 박쥐는 **진홍 날개 막 + 보라 눈**(09회차 황혼 지역 색) |

물리 영웅이 넷이 된다(리엘·루나·창수 + 둘). 4장은 물리에 약한 박쥐 막이 주력 재료라 이 장에서 빛나고, 3장 안개(물리 0.6)에서는 약하다. 장마다 쓸 영웅이 바뀌는 것이 08회차 ‘장마다 주력 속성을 바꾼다’의 의도다.
