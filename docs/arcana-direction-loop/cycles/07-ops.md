- 이 루프의 01~06회차 문서는 이 브랜치에만 있다. main에도 통합 브랜치에도 없다.

- 개발 루프가 잘못한 것이 아니다. **넘겨줄 통로가 없었다.** 같은 일이 고목왕·새싹 도적·카르에서도 생길 수 있다.

이번 회차에 이 루프가 바로 한 것:
1. README 규약에 **통합 브랜치를 함께 읽는 단계**를 추가했다. 이 루프는 통합 브랜치를 병합하지 않고 읽기만 한다.
2. 개발 루프가 한 장으로 볼 수 있는 [인계 목록](../handoff.md)을 만들었다. 결정이 필요 없는 후보와 결정을 기다리는 후보를 나누고, 이미 만들어진 것과의 차이를 적었다.
3. 06회차 문서에 정정 표시를 남겼다.

남은 것은 사용자 결정이다(6장 질문 1). 인계 목록을 개발 루프가 읽는 곳에 두려면 통합 브랜치로 가는 PR이 필요하다.

### 2-2. 완벽 방어 보너스는 거의 자동이다

개발 브랜치 PR #33은 마을 피해 없이 막은 웨이브에 전투 코인 +25를 준다(`FLAWLESS_BONUS`). PR #34는 ‘완벽!’ 표시와 문구를 더했다.

통합 브랜치 `1da8a0c`를 별도 작업 폴더에 꺼내 `tools/balance-defense.ts` 36조건을 실행했다(2026-11-02, 결과는 저장소 밖에 보관).

| 전략 | 조건 수 | 4웨이브 모두 피해 0 (마을 체력 20) |
| --- | --- | --- |
| auto, active | 18 | **18 (100%)** |
| basic | 9 | 6 |
| 타워를 짓는 전략 합계 | 27 | **24 (89%)** |
| none (타워 없음) | 9 | 0 (6패) |

타워를 지으면 거의 언제나 웨이브마다 +25를 받는다. 기본 웨이브 보상 45의 55%가 조건 없이 붙는 셈이다. 03회차가 지적한 ‘추가 퀘스트가 저절로 달성된다’와 같은 유형이다. 코인이 늘면 타워가 늘고, 다시 완벽 방어가 쉬워진다. 건설 판단의 긴장이 줄어든다.

‘완벽!’ 표시가 주는 손맛(PR #34)은 좋다. 문제는 코인의 크기와 조건이다. 시뮬레이션은 자동 전략 기준이며 사람은 더 자주 샐 수 있다. 웨이브별 누수율을 측정하는 것이 먼저다(4장 후보 1).

### 2-3. 골드 경제 재계산 (04회차 아이템 + 3장)

기본 원정, 추가 퀘스트 모두 달성 기준. 퀘스트 보상은 03회차 계단안(`40 + 10×스테이지`)을 적용했다.

**1~2장**

| 수입 | 금액 | 사용처 (03·04회차 제안) | 금액 |
| --- | --- | --- | --- |
| 첫 클리어 8회 | 2,240 | 공용 장비 Lv1~5 (현행) | 1,300 |
| 추가 퀘스트 8회 | 680 | 시설 2단계 4곳 + 보급소 개설 | 1,300 |
| | | 유물 4종, **개당 150 G로 하나씩 구매**(새 제안) | 600 |
| 합계 | **2,920** | 합계 | **3,200** |

모두 사려면 280 G가 모자란다. 반복 클리어(스테이지 1~8 평균 75 G) 3~4판이면 채워진다. 캠페인을 끝낸 뒤 “조금 더 하면 다 갖춘다”는 거리다. 반복을 강요하는 수준이 아니다.

**3장 (05회차 초안)**

| 수입 | 금액 | 사용처 (제안) | 금액 |
| --- | --- | --- | --- |
| 첫 클리어 4회 (100 + 40×9~12) | 2,080 | 길잡이 집 개설 + 2단계 (안내인) | 200 + 300 |
| 추가 퀘스트 4회 (40 + 10×9~12) | 580 | 창수 훈련장 2단계, 부적술사 신당 2단계 | 300 + 300 |
| | | 3장 유물 2종 (안개·짚종이 재료용, 08회차) | 250 × 2 |
| 합계 | **2,660** | 합계 | **1,600 (60%)** |

**규칙 제안**: 장마다 영구 사용처를 그 장 수입의 약 60%로 둔다. 나머지는 보급품(50~70 G, 원정마다 하나)으로 흐른다. 공용 장비 상한(Lv5)은 올리지 않는다. 숫자 하나로 강해지는 성장을 늘리지 않기 위해서다(04회차 원칙).
