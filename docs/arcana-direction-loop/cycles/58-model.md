## 2. 시험 — 활 팔이 게임 크기에서 이어져 보이나

**시험 방법**
- 50회차 설계서는 활 두께를 ‘반지름 0.07 이상(이안 지팡이와 같은 이유)’이라고 적었다. 이를 실제로 확인했다.
- 영웅 초안과 같은 카메라 계약(640, 직교 5.8, (7,10,7), 땅 (320,550))을 썼다.
- 활 팔만 높이 3.0, 휘어짐 0.45의 호로 만들어 흰색 발광으로 구웠다.
- 반지름 4가지와 **방향 2가지**를 비교했다.
  - 마주봄: 활 면이 화면 오른쪽(쏘는 방향)과 위를 품어 카메라를 향함
  - 옆면: 활 면이 카메라 쪽으로 누움
- 게임 크기로 줄였다. 640 프레임은 390px 화면에서 약 43 CSS px이다(84 × 1.2 × 0.43). 2배 화소면 87px이다.
- 호의 중심선을 따라 알파 0.5 이상인 점의 비율(이어짐)을 쟀다.

| 반지름 | 43px 이어짐 (마주봄 / 옆면) | 87px 이어짐 (마주봄 / 옆면) |
| --- | --- | --- |
| 0.04 | 63% / 5% | 100% / 98% |
| 0.055 | 90% / 95% | 100% / 100% |
| **0.07** | **100% / 100%** | 100% / 100% |
| 0.09 | 100% / 100% | 100% / 100% |

| 방향 | 43px에서 호의 가로 휘어짐 | 87px |
| --- | --- | --- |
| 마주봄 | **3.3px** | 6.7px |
| 옆면 | 0px(곧은 막대로 보임) | 0px |

**읽은 것**
- 반지름 **0.07**이면 1배 화소에서도 활 팔이 끊기지 않는다. 50회차 값이 맞다.
  - 0.04는 1배 화소에서 63%만 이어져 점선처럼 보인다.
- 두께보다 **방향**이 중요하다. 옆면으로 들면 활이 곧은 막대가 되어 이안 지팡이와 같은 모양이 된다.
  - 활 면이 쏘는 방향과 위쪽을 품도록 들면 3.3px 휘어짐이 남는다. 그래서 ‘활’로 읽힌다.
