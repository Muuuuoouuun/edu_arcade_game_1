### 2-2. 지역 고유 색 — 색으로 흑막을 만들지 않는다

사용자 결정 “모든 사건을 단일 공통 배후로 묶지 않는다”를 **색 규칙**으로 옮긴다.

| 지역 | 고유 색 (그 지역의 적·보스·지형에만) | 근거 |
| --- | --- | --- |
| 숲 (1장) | 이끼 녹색, 나무 갈색 | 현행 지형 `forest.png` |
| 설산 (2장) | 얼음 파랑, 눈 흰색 | 현행 서리늑대·서리군주 |
| 안개재 (3장 후보) | 안개 청록, 먹빛 | 05회차, `angaejae-enemy-lineup.png` |
| 황혼 (4장 후보, 서양) | **보라, 진홍** | 황혼성 삽화의 보라 수정, `western/vampire-variants.png`의 진홍·흑 |

**규칙**: 한 지역의 고유 색은 사정이 이어지지 않는 다른 지역의 적에게 쓰지 않는다.
- 숲의 고목왕 균열 보라 → 01회차 안대로 바꾼다(3장의 이유 추가).
- 숲의 절연 슬라임 보라 → 인계 A(08회차)의 호박색 수정이 이 규칙으로 더 분명해진다.
- 황혼성 테마는 원래 황혼 지역의 초대 표식이므로 보라 수정을 **그대로 둔다**(05회차 3-3).

### 2-3. 의미 색 — 속성과 표식이 같은 색을 다투지 않게

01~08회차 제안을 모아 보니 **청록**이 세 가지 뜻(고목왕의 생명 빛, 물 속성, 안개)을 동시에 가졌다. 속성 색과 겹치면 “물 공격인가?”로 읽힌다.

| 의미 | 색 | 쓰는 곳 |
| --- | --- | --- |
| 불 | 주황 | 화염탑, 이안, 연소 |
| 번개 | 노랑 | 뇌전탑, 청운의 부적 |
| 충격 | 황토·흰 충격파 | 파쇄포, 브론, 카르 |
| 물 | **청록** | 물폭탄포, 부적술사, 물먹은 부적 |
| 물리 | 회백 | 석궁, 리엘, 창수 |
| 수비대 표식·주의 | 주홍 | 매듭, 완장, 파수꾼 경고선(06회차) |
| 생명·회복 | **연두** | 고목왕이 진정할 때의 빛(01회차 **수정**: 청록 → 연두), 회복 효과 |

- 청록은 **물**로만 쓴다. 3장 안개는 지역 고유 색이지만 지형과 적의 몸에만 쓰고, 공격 효과에는 쓰지 않는다.
- 이 표는 정체성 기준 3(동서양이 같은 화폭에)의 실행 규칙이다. 01회차 문서의 고목왕 생명광 색을 이번 회차에 고쳤다(수정 표시).

### 2-5. 4장 골격 — 황혼 지역 (서양)

05회차 추천 순서(3장 운령, 4장 서양)를 따르는 **구조만**의 초안이다. 지역 이름·역사·인물은 사용자 결정 대기이므로 쓰지 않는다.

| 요소 | 골격 | 규칙 확인 |
| --- | --- | --- |
| 원인 유형 | **계승**: 오래된 영지의 다음 수호자 자리를 두고 두 세력이 다툰다. 둘 다 일부는 옳다. | 3장(봉인)과 겹치지 않음. 운령의 ‘계약’(마른나루)과도 다름 |
| 적의 성격 | 각 세력이 자기 편이 옳다는 것을 증명하려고 보낸 시험 | 기준 2(적에게도 사정) |
| 보스 대응 | **목표 우선순위**: 크게 맞으면 박쥐 떼로 흩어지는 보스. 흩어진 박쥐를 먼저 잡을지 본체가 다시 모일 곳을 지킬지 고른다. | 화력(1장)·타이밍(2장)·배치(3장)와 다름 |
| 주력 속성 | **물리·충격**. 처음으로 물리에 약한 재료가 생긴다. | 08회차 ‘장마다 주력 속성을 바꾼다’ |
| 새 재료 후보 | 박쥐 날개 막(얇은 막: 물리 1.5, 불 1), 판금 갑주(충격 1.5, 물리 0.6) | 3장 물·번개와 다름 |
| 지역 고유 색 | 보라·진홍 | 2-2 |
| 원화 | `western/vampire-variants.png`(박쥐 사역마·날개 괴수·귀족), `western/orc-variants.png` 등 4종, `heroes/hero-skill-effects.png` 아래 두 칸, 황혼성 삽화 | 원화가 계열 단위로만 있음 |
| 해결 유형 | 공동 수호(두 세력이 함께 지키는 규칙) | 화해(1장)·분배(2장)·열림(3장)과 다름 |
