## 2. 결과 화면은 다음 한 판을 가리키나

### 2-1. 지금 결과 화면 (`DefenseGame.tsx`)

| 자리 | 이긴 판 | 진 판 |
| --- | --- | --- |
| 수치 | 격퇴 · 방어 웨이브 · 성장 골드, **약점 명중 N번**(#72), 난이도 보너스 | 같음 |
| 다음 줄 | “다음 요청 · 1-3 서리 낀 옛길 — 청운 합류 예정” + (있으면) “남은 추가 퀘스트 · {문구} (+80 G)” | “다음엔 · {패배 조언}” |
| 버튼 | 거점으로 돌아가기 / 다음 원정 바로 출발 / 게임 허브로 | 거점으로 / 같은 스테이지 다시 하기 / 허브로 |

- **추가 퀘스트를 이번 판에 달성해도 화면이 알려 주지 않는다.** `reward.questReward`(80 G)는 성장 골드 합계에만 섞인다.
- 약점 명중 수는 비교할 대상(지난 판·최고 기록)이 없다. 숫자만 뜬다.

### 2-2. 측정 — ‘남은 추가 퀘스트’ 줄이 실제로 뜨는가

40회차 첫 판 조건 측정(main 사본)에서 타워를 지어 이긴 판만 다시 셌다. 퀘스트를 못 채워서 그 줄이 뜨는 판이 몇 판인지 봤다. 1-3·2-1 초안은 필살기·용병 고용을 하지 않은 판으로 셌다. 측정한 배치가 이 둘을 하지 않기 때문이다.

| 스테이지 | 지금(마을 체력) → 40회차 초안: 여유 / 기본 / 정예 |
| --- | --- |
| 1-1 | 0 → 0/7 · 0 → 0/7 · 0 → 0/7 (그대로) |
| 1-2 | 0 → 8/14 · 0 → 8/14 · 1 → 8/14 (강화 안 한 판) |
| 1-3 | 0 → 21/21 · 0 → 21/21 · 4 → 19/19 (필살기 안 쓴 판) |
| 2-1 | 0 → 28/28 · 0 → 28/28 · 0 → 25/25 (용병 안 부른 판) |
| 2-3 | 1 → 4/35 · 1 → 9/32 · 3 → 13/22 (돌파된 판) |
| **합계** | **10/294 (3%) → 192/294 (65%)** |

**읽은 것**
- 지금은 ‘남은 추가 퀘스트’ 줄이 이긴 판의 3%에만 뜬다. 결과 화면이 다음 한 판의 이유를 거의 주지 않는다.
- 40회차 초안이면 65%에 뜬다. 그리고 그 줄이 **바로 다음에 할 조작**을 알려 준다. 예를 들어 1-3을 필살기 없이 이기면 “남은 추가 퀘스트 · 필살기를 써서 옛길 지키기 (+80 G)”가 뜬다. 결과 화면이 조작 안내의 전달 통로가 된다.
- 이 줄은 재료와 상관이 없다. 확정 제약과 맞는다.

## 3. 제안 — 결과 화면 ‘다음’ 줄의 규칙

360px에서 결과 화면이 길어지지 않도록 **이긴 판의 ‘다음’ 줄은 두 줄까지**로 한다.

| 순서 | 이긴 판 | 조건 |
| --- | --- | --- |
| 1 | “다음 요청 · {다음 스테이지} — {동료} 합류 예정” (지금 것) | 늘 |
| 2a | **“추가 퀘스트 달성 +80 G”** — 기념물 묶음(③)이 정해지면 “· 거점에 {기념물}이 놓였어요”를 덧붙임 | 이번 판에 처음 달성(`reward.questReward > 0`) |
| 2b | “남은 추가 퀘스트 · {문구} (+80 G)” (지금 것) | 아직 못 채움. 2a와 함께 뜨지 않음 |

- **2a는 결정 불필요(인계 A)**: 이미 계산되는 값을 보여 주기만 한다.
- 기념물 문장은 묶음 ③(26·29회차) 결정 뒤에 붙인다.
- 약점 명중은 지금처럼 수치 줄에 둔다. ‘스테이지 최고 기록’ 비교는 새 저장 필드가 필요하다. 지금은 넣지 않는다(뒤로 미룸).
- **진 판**: 지금 패배 조언(코인 → 강화 → 돌파) 그대로. 재료 힌트는 32회차대로 둘째 줄 효율 문장이다(인계 ‘먼저 할 다섯 개’ 4번).

**40회차 퀘스트 초안과 함께 볼 것**
- 초안이 들어가면 2b 줄이 65%의 판에서 다음 조작을 가르친다. 퀘스트 개편(묶음 ④)의 효과가 결과 화면에서 바로 보인다.
- 2b가 뜬 판에서는 버튼 ‘다음 원정 바로 출발’ 옆에 작은 글자 버튼 ‘추가 퀘스트 다시 하기’(같은 스테이지)를 두는 것을 권한다. 지금은 거점으로 돌아가 같은 스테이지를 다시 골라야 한다.
