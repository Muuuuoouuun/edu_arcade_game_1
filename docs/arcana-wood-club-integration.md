# 통나무 병사의 몽둥이·체형과 보행 통합

2026-11-07 KST 회차. 기준 `1e6bb2072faeceee38c9e36eb6067ac30146d9f5`, 소유 브랜치 `codex/arcana-stage-experience-20261106`. 원격 main `2eabc766085ce9fd35c37546343844f3b2ab5ca8`의 나무 병사 변경을 이 개발 브랜치에 통합했다. 개발 브랜치를 main에 병합하거나 서비스를 배포하지 않았다.

## 선택 근거

원격 `4e21c33`은 직립 주황 목재·초록 눈·긴 가지·통나무 몽둥이를 만들었지만, 기존 3포즈 제작 경로에서 출력한 원본/아틀라스였다. 이 브랜치에는 이미 나이테·뿌리 관절·작은 등 잎과 8단계 보행·실제 GLB가 있었다. 원격 산출물만 교체하면 보행과 피격, 작업실의 몸이 달라지므로 **두 완료 작업을 하나의 편집 원본과 움직임으로 통합**했다.

실제 비교한 자료는 Claude 34회차 `wood-log-compare-cycle34.webp`, 현재 개발 브랜치 모델과 PC/모바일 전투, 원격 main의 새 3포즈 렌더다. 팔각 통나무와 밝은 단면은 돌 병사와의 재료 구분에 유리하므로 유지하고, 곧게 선 몸·초록 눈·쥔 무기로 실루엣을 보강했다. 기존 늑대·영웅 방향 동작·포탑·성문 작업은 반복하지 않았다. Claude 최신 `3488663`의 이안 4포즈/수정 발사점 제안은 이미 이 개발 브랜치의 이안 모델과 8방향 소켓으로 구현된 범위다. 다른 편집 세션과 열린 PR은 없었다.

## 실제 구현

- 몸통을 가늘고 높게 세우고 머리와 가지 높이를 조정했다. 따뜻한 목재·초록 수액 눈을 적용하면서 기존 나이테 단면·어두운 입 홈·뿌리 고리·작은 잎 덩어리를 보존했다.
- 통나무 몽둥이는 가는 손잡이·굵은 타격부·나이테 끝면·뿌리 묶음·옹이로 구성된 실제 메시다. 손 안을 통과하는 손잡이 중심에 `club-grip` 관절을 두고 엄지로 감쌌다. 무기 머리를 중심으로 돌려 손과 떨어지는 구조를 피했다.
- 무기를 든 팔은 10도, 빈 팔은 24도 진폭으로 움직인다. 손목은 4도로 늦게 따라오며 기존 발·머리·잎 보행과 함께 움직인다. 대체용 두 보행 포즈도 무기를 같은 방식으로 든다.
- 정강이가 발바닥 아래로 내려오던 기존 구조를 짧게 조정했다. 접지 계산에 발 단면의 나이테 고리도 포함했다. 피격 자세도 두 발의 실제 최저점을 바닥에 맞춘다.
- GLB 보행은 1초, 32fps/33키프레임이다. 전투의 8포즈는 정확히 원본 프레임 `1,5,9,13,17,21,25,29`에 해당한다. 기존의 52 논리 단위 이동당 한 주기, 넉백 시 보행 억제, 일시정지·배속 규칙을 유지했다.

몽둥이를 드는 보행과 기존 피격 반응을 구현한 것이다. 적의 새로운 공격 판정이나 몽둥이 공격 클립을 추가한 것은 아니다. 전투 엔진·보행 상태 계산·Board 입력/판정 코드는 변경하지 않았다.

## 카메라와 납품물

정사영 카메라의 크기를 5.6에서 6.3으로 넓혀 긴 가지와 무기를 포함했다. 지면 기준 `(192,317.61)`은 유지하고 전투 표시 배율을 `384/360`에서 `384/320 = 1.2`로 보정해 모델의 월드 단위 크기가 카메라 확대로 축소되지 않도록 했다. 보행·피격 모두 같은 384px 카메라와 크롭 `(0,8,384,364)`를 공유한다.

```sh
npm run models:wood
npm run models:wood -- --check
```

첫 명령은 Blender 4.3.2/Cycles CPU 96 samples와 ffmpeg로 전체 산출물을 재생성한다. 두 번째 명령은 산출물을 덮어쓰지 않고 11포즈와 61개 보행 시점의 전체 메시 바닥/화면 경계를 검사한다. `--skip-render`는 기존 렌더를 사용하는 옵션이므로 형태·재질·카메라를 바꾼 뒤에는 전체 재생성을 사용한다.

| 산출물 | 경로/규격 |
| --- | --- |
| 생성 코드 | `tools/blender/build_wood.py` |
| 편집 원본 | `art-source/defense/wood-soldier.blend` |
| 공통 카메라 PNG | `art-source/defense/wood-frames/wood-soldier-*.png`, 11장 |
| 실제 작업실 모델 | `public/defense/models/wood-soldier.glb`, 미리보기 `wood-soldier.png` |
| 전투 WebP | `wood-soldier-atlas.webp` 3포즈, `wood-soldier-walk-atlas.webp` 8포즈 |
| 규격/해시 | `public/defense/models/wood-soldier.json`, 원본 해시·카메라·클립·포즈 경계·그립·배포 파일 해시 |

최종 GLB 666,908바이트, 8,624삼각형, 작업실 메시 객체 113개(GLB 메시 정의 100개), 9재질이다. 두 WebP 합계 115,200바이트이며 전체 RGBA 디코딩 크기는 6,488,064바이트로 프레임 수와 해상도는 종전과 같다. 실제 Android GPU 메모리 측정값은 아니다. 전투는 GLB를 내려받지 않는 베이크 2.5D, 작업실은 기존 단일 WebGL 장면이다.
