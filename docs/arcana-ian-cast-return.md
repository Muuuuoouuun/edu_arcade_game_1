# 이안의 시전에서 현재 걸음으로 복귀

2026-11-08 · 컨셉 개발 42회차. 기준 `48ba0d4`, 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉 대비 개선

`art-source/defense/atlases/ranged-motion.png` 첫 행의 지팡이를 앞으로 뻗고 회수하는 자세와 실제 PC/모바일 전장을 비교했다. 앞 회차의 보행→시전 진입은 완료됐지만, 공격 종료 뒤에는 발과 지팡이가 현재 걸음으로 바로 바뀌었다. 이번에는 몸이 먼저 돌아오고 지팡이·손목·망토가 뒤따르며 보행으로 이어진다. 기존 체형과 재질을 보존한 관절 애니메이션 작업이다.

main `2eabc76`, Claude `bf7c1c6`/`c0d0367`은 시작 당시 이전 회차와 같았다. Claude 54회차의 리엘 망토 시험과 세계관 문서의 준비→타격→회복, 실제 이동 기반 보행 원칙을 확인했다. 완료된 서리늑대와 이안 시전 진입을 다시 제작하지 않았다.

## 실제 3D와 전투 연결

- 실제 `ian-return-0`~`ian-return-7` 클립은 각각 **0.12초, 100fps, 8개 관절**이다. 시작은 기존 0.15초 발사 자세, 끝은 각 보행 자세와 일치한다.
- 몸통·머리·반대팔이 먼저 회수되고, 지팡이팔·손목은 0.02초, 망토는 0.025초 지연해 따라온다. 몸통과 무기를 한꺼번에 같은 속도로 되돌리지 않는다.
- 돌아오는 발을 낮게 들어 다음 걸음을 준비한다. 반대쪽 밑창은 지면 높이를 유지한다. 발의 수평 위치는 보행으로 옮겨지므로 **월드 좌표의 발 고정이나 지형 IK가 아니다**.
- 공격 방향과 현재 이동 방향이 같은 8방향 구간에서만 적용한다. 매 화면 갱신마다 현재 누적 이동 거리의 걸음을 골라, 공격 시작 시의 `walkEntry`로 보행이 멈추지 않게 한다.
- 정지·방향 불일치·동작 줄이기는 기존 회수를 유지한다. 필살기와 돌진이 우선한다. 새 복귀 이미지 하나라도 실패하면 기존 시전/보행 세트로 돌아가며, 기존 진입 이미지와 독립적으로 실패 처리한다.

| 공격 경과 | 전투 표시 |
| --- | --- |
| 0.15~0.21초 | 기존 마법탄 발사 자세와 효과 |
| 0.21~0.225초 | 발사 자세 잠깐 유지 |
| 0.225~0.27초 | 몸의 무게 회수, 지팡이는 뒤따름 — 클립 0.04초 베이크 |
| 0.27~0.32초 | 현재 보폭 회수 — 클립 0.10초 베이크 |
| 0.32~0.33초 | 현재 보행 이미지와 일치 |
| 이후 | 기존 보행 |

**0.15초 발사, 0.33초 공격 길이, 발사 소켓, 투사체·피해·이동·보상 규칙은 변경하지 않았다.** 엔진 코드나 상태 필드 변경도 없다. 60Hz 시뮬레이션의 2/4/6틱 화면 게시 간격과 모든 시작 오프셋에서 중간 복귀가 최소 한 번 표시된다. 임의의 낮은 프레임률에서 모든 자세가 보인다는 뜻은 아니다.

전투는 두 중간 WebP를 사용하는 2.5D다. 모델 작업실은 하나의 실시간 3D 장면에서 실제 관절을 보간한다. 유닛별 WebGL 렌더러를 추가하지 않았다.

## 산출물·재생성

```bash
npm run models:ian-return
npm run models:ian-return:pose-check
npm run models:ian-return:check
```

Blender 4.3.2, FFmpeg, Cycles CPU 48샘플로 제작했다. 기존 `ian-mage.blend`·`ian-mage-walk.blend`를 읽으며 해당 원본은 덮어쓰지 않는다.

| 산출물 | 위치·규격 |
| --- | --- |
| 생성기·검사기 | `tools/blender/build_ian_return.py`, `tools/check-ian-return.mjs` |
| 편집 원본 | `art-source/defense/ian-return.blend`, 메시 135개와 `Ian return N / 관절` 액션 세트 |
| 실제 3D | `public/defense/models/ian-return.glb`, 8클립, 1,447,892바이트 |
| 공통 카메라 렌더 | `art-source/defense/ian-return-frames/`, PNG 128장·384×384 |
| 전투 베이크 | `public/defense/models/ian-return-{0..7}-atlas.webp`, 방향마다 16셀·3072×192 |
| 규격·해시·미리보기 | `public/defense/models/ian-return.json`, `ian-return.png` |
| 작업실 | `/model-lab.html?model=ian-return`, 복귀 걸음 1~8 선택·실제 재생·끝 자세 유지 |

정사영 배율 6.8, 원본 지면 `(192,330)`, 전투 셀 지면 `(96,165)`를 공유하며 포즈별 크기 보정을 하지 않는다. GLB는 21,122삼각형·14재질이다. 런타임은 내보내기 36개 메시 객체, 로더에서 재질 primitive가 나뉘어 37개 메시로 표시된다. WebP 합은 **503,372바이트**, 추가 RGBA 픽셀 합 추정은 **18MiB**다. 실제 GPU 메모리 측정은 아니다.

## 남은 범위

두 중간 베이크 사이의 연속 관절 보간과 공격·이동 방향이 다른 복귀는 미구현이다. 정지 시전의 회수는 기존 자세를 사용한다. 월드 좌표 발 고정·지형 IK·실제 Android 메모리와 프레임 성능은 후속 범위다. 다음 후보는 이안 제자리 시전의 회수, 또는 방향 전환을 포함한 복귀다. 이번 회차는 예약 설정을 조회·변경하거나 Claude API를 호출하지 않았다.
