# 아르카나 러시 · ARCANA RUSH 1.0

**통합 개발판(2026-11-11):** 마을 거점의 러시 링크와 웹·모바일 빌드에 이 시제품을 연결했다. 가로 전투에서는 조작 버튼만 남기고 상시 정보 HUD를 숨기며, 저장 실패 시 현재 창의 성장과 보상을 보존한다. 상세 구현과 검증 범위는 [통합 기록](integration-20261111.md)을 따른다. 아래의 독립 브랜치 회차 기록은 당시 스냅샷이다.

**직접 싸우고, 탑을 세우고, 마을을 지켜라.** 영웅을 손으로 조작해 싸우는 실시간 전투와, 마을 둘레에 탑을 세우는 웨이브 방어를 한 판(약 2~3분)에 섞은 시제품입니다. 아르카나 세계관(사용자 IP)을 쓰는 별도 모드이며, 기존 아르카나 수비대 캠페인과 저장 데이터를 건드리지 않습니다.

## 6분야 디벨롭 (2026-11-14, [97회차](cycles/97-six-areas.md))

사용자 목표 ‘모델링·게임 맵·맵 크기·맵 요소·몬스터·디펜스를 자체 평가 80점까지’와 추가 요청(기본 캐릭터, 렌더링)을 했다. 점수와 근거는 [goal-6areas.md](goal-6areas.md)에 있다(84 / 83 / 82 / 81 / 82 / 80, 렌더링 81).
- **전장**: 스테이지마다 배치가 다르다. 숲은 시냇물·다리·통나무, 눈은 빙판·바위산이다. 북쪽 끝 관문에서 적이 나오고, 적이 오는 길은 마을 앞 길 위 화살표가 알려 준다.
- **몬스터**: 적이 커지고 얼굴·무기가 생겼다. 눈 지역 7~9스테이지에 서리늑대 떼가 나온다. 고목왕·서리군주는 모양이 다르고, 서리군주는 포효로 바리케이드를 부수고 탑을 4초 얼린다.
- **디펜스**: 탑이 단계·분기마다 모양이 다르다. 길목에 바리케이드(가시 강화·수리)를 세운다. 탑 자리는 6곳이고 탑은 4개까지라, 마을 앞에 둘지 옆길 전초에 둘지 고른다.
- **영웅·렌더링**: 영웅 3종을 Blender 원본에서 다시 빌드했다. 높음 품질에서 실제 그림자와 마무리 패스가 켜진다.
- **균형**: 권장 전투력을 다시 쟀다(7·8·10스테이지가 내려감). 캠페인은 약 13판, 47분이다(전에는 16판, 60분).

## 통합판: 원정 흡수 (2026-11-13, [96회차](cycles/96-merge.md))

흩어져 있던 모드를 러시 하나로 합쳤다(사용자 결정: ‘원정까지 러시로 흡수’).
- **입구 하나**: 사이트 첫 화면(`index.html`)이 러시로 바로 간다. 옛 모드 고르기(원정, 전술 훈련, 군단 방어)는 회귀 점검용 `/?modes=1`에만 남는다.
- **원정 지도**: 10스테이지가 두 지역의 마을이다. 청록의 숲 1-1~1-5, 서리산맥 2-1~2-5.
  - 마을의 ‘지도’ 단추로 연다.
  - 마을마다 편지(이야기), 마지막 웨이브 대장, 합류할 동료가 보인다.
- **동료**: 첫 승리에서 원정 동료가 찾아온다(리엘, 브론, 청운, 포포, 카르, 루나). 이안은 처음부터 있다.
  - 동료는 마을 건물을 하나씩 맡는다. 이야기만이고, 수치는 그대로다.
- **옛 저장**: 원정을 하던 사람의 기록(지킨 마을, 골드, 훈련)을 처음 한 번 왕국으로 가져온다. 옛 저장은 지우지 않는다.
- **디자인 하나**: 창·버튼·정보 막대를 키아트와 UI 기준 시트 하나로 맞췄다([아트 기준](art-direction.md) ‘통합 UI 기준’).

## 1.0 (2026-11-13)

브롤스타즈풍 렌더에 킹샷식 마을 성장과 PvE 웨이브 방어를 더한 모바일 웹 게임이다. 완성 기준과 근거는 [completion.md](completion.md)에 있다.

### 하는 법

1. **타이틀**에서 ‘마을로’를 누른다. 조작법은 타이틀의 ‘조작법’을 펼치면 나온다.
   - 왼쪽 화면 끌기로 이동한다.
   - 공격 버튼을 탭하면 자동 조준, 끌면 직접 조준이다.
   - 보라 필살 버튼을 누른다.
   - 노란 원 위에서 탑을 짓는다.
2. **마을**에서 ‘지도’ 단추로 원정 지도를 열고 마을(스테이지)을 고른 뒤 출전한다. 권장 전투력 알약이 초록이면 갈 만하고, 주황이면 마을을 더 키운다.
3. **전투**는 다섯 웨이브(약 2~3분)다. 남은 마을 체력으로 별 1~3개를 받는다.
4. 받은 식량·목재로 **건물·강화·영웅 훈련**을 올리고, 목표를 받는다. 처음부터 스테이지 10까지 약 16판, 1시간이다(`tools/rush-campaign.ts`).
5. 마을을 처음 지키면 그 마을의 **동료**가 찾아온다. 2-5 서리 왕좌의 결전을 처음 이기면 **원정 완료** 화면이 나오고, 지도의 서리 요새에 **끝없는 도전**(∞)이 열린다.

### 설치·실행·배포

- 개발: `npm run dev` → `http://localhost:3100/rush.html`
- 빌드: `npm run build`. 결과는 `dist/`이고, 정적 파일로 어디든 올릴 수 있다. 러시 입구는 `dist/rush.html`이다.
- 휴대폰 홈 화면 설치: 배포한 `rush.html`을 열고 브라우저 메뉴에서 ‘홈 화면에 추가’를 누른다. 매니페스트·아이콘은 `public/rush/`에 있고, Chrome 설치 검사 오류는 0이다.
- 저장: 기기 브라우저 저장소에 둔다. 왕국은 `arcana-rush:kingdom:v1`, 설정은 `arcana-rush:settings:v1`, 그래픽은 `arcana-rush:quality:v1`, 옛 원정 가져오기 표시는 `arcana-rush:legacy-import:v1`이다. 설정의 ‘진행 초기화’는 왕국만 지운다.

### 알려진 한계·사용자 결정 대기

- **Android 앱**: 독립 앱 껍데기를 만들어 두었다. `bash tools/rush-app/build.sh`가 아래를 차례로 한다.
  - 사이트를 빌드하고 `rush.html`을 시작 화면으로 둔다.
  - Capacitor Android 프로젝트(앱 ID `io.github.muuuuoouuun.arcanarush`, 이름 ‘아르카나 러시’, 1.0 아이콘 5개 밀도, 진동 플러그인)를 만들고 동기화한다.
  - Android SDK가 있으면 디버그 APK까지 빌드한다.
  - 컨테이너에서는 SDK 설치 직전까지 확인했다. 앱 시작 화면에서 전투가 돌고, 오류와 실패한 요청이 0이다.
  - **1.0 범위 밖(사용자 결정 2026-11-13)**: 1.0은 웹 설치판이다. APK는 사용자가 Android SDK 라이선스에 동의한 뒤 `build.sh`를 한 번 돌리면 나온다.
- **실기기 대신 측정한 것**
  - 진동: `tools/rush-haptics-check.cjs`. 켜면 웨이브 시작에 `[30,50,50]`, 끄면 0회다.
  - 성능 대리: `tools/rush-perf-check.cjs`. CPU 4배 느리게 해서 적 50의 전투가 주 스레드 한 프레임에 약 7.5~13 ms다(60fps 예산 16.7 ms 안). GPU 비용은 소프트웨어 렌더라 재지 못한다.
  - 소리·음악: `tools/rush-audio-check.cjs`. 템포가 설계와 같고, 클리핑이 없고, 끄면 무음이다. 전투 효과음은 음악보다 6 dB 넘게 위다(측정으로 찾아 전투 음악을 10.5 dB 낮춤). 자세한 값은 [completion.md](completion.md) C11에 있다.
  - 실제 손맛·귀로 듣는 느낌은 1.0 기준에서 우선 뺐다(사용자 결정). 출시 전 실기기에서 확인하기를 권한다(백로그 9).
- 끝없는 도전은 점수 모드다. 다 키운 봇도 3~8웨이브에서 진다. 쉽게 하려면 막(보호막)이 지렛대다(C8).

### 만든 이들

아르카나 러시 팀. 개발 도움은 Claude(Anthropic)이고, 균형·진행 측정과 음악은 Opus·Fable 하위 에이전트가 맡았다. 키아트·아이콘은 OpenAI 이미지 생성(게임 모델 렌더를 참고 이미지로)이다. 글꼴은 Bagel Fat One(SIL OFL)이고, 엔진은 three.js·TypeScript·Vite다.


**방향 (2026-11-10 결정)**
- **플레이는 킹샷식**입니다: 마을 성장과 PvE, 실시간 PvP 없음.
- **디자인·그래픽·렌더 톤은 브롤스타즈풍**입니다: [아트 기준](art-direction.md).

- 실행: `npm run dev` → `http://localhost:3100/rush.html`
  - `?demo=1`은 자동 시연, `?seed=N`은 고정 시드, `?speed=2`는 배속, `?debug=1`은 FPS·드로콜 표시입니다.
- 엔진 선택 근거: [엔진·프레임워크 조사](engine-research-2026-11.md) · 렌더 톤: [art-direction.md](art-direction.md)
- `?freeze=N`은 N틱에서 시뮬레이션을 멈춥니다. 같은 시드의 자동 시연과 함께 쓰면 전후 비교용으로 같은 장면이 나옵니다.
- `?sheet=1`은 적 4종과 영웅을 단색 배경에 한 줄로 세운 모델 시트입니다(실루엣 비교용, 11회차).
- `?quality=high|low`는 그래픽 품질을 그 판만 고정합니다(12회차). 평소에는 일시정지 화면의 ‘그래픽’ 버튼(자동/높음/낮음)으로 고르고, `arcana-rush:quality:v1`에 저장합니다.

## 구현 내역 (회차별)

- **프레임 렌더 (97회차)**: 높음 품질에 실제 그림자(그림자 지도 한 장), 따뜻한 빛과 차가운 그림자의 3단계 툰, 바닥 덧칠과 구름 그림자, 움직이는 물(거품 띠·구름 비침), 마무리 패스(가장자리 다듬기·색 보정·효과 빛남)를 더했습니다. 낮음은 전처럼 한 번에 그리고 발밑 원판 그림자를 씁니다. 마을 화면도 같은 빛·그림자·물을 씁니다. 규칙은 [art-direction.md](art-direction.md) ‘프레임 렌더’, 측정은 [97회차](cycles/97-frame.md)에 있습니다.
- **스테이지 1~10 (03회차)**
  - 단계마다 적 체력·수·피해가 오르고, 스테이지 10은 마을 강화 없이는 집니다(테스트로 고정).
  - 남은 마을 체력으로 별 1~3개를 받고, 새 별마다 한 번 보너스가 있습니다. 다음 스테이지는 별을 얻으면 열립니다.
- **탑 분기 (15회차)**: Lv1 탑을 Lv2로 올릴 때 화염(맞은 자리 1.3m에 30% 범위 피해)과 냉기(1초 동안 이동 65%, 보스 85%) 중 하나를 고릅니다. 터치는 버튼 두 개, 키보드는 E(화염)·R(냉기)입니다. 느려진 적은 반투명 얼음 껍질을 쓰고, 풀리기 직전에 깜빡입니다(16회차). `?sheet=1&frost=1`로 크게 볼 수 있습니다.
- **보스 부르짖음 (33회차)**: 스테이지 6부터, 보스 체력이 처음 절반 아래로 내려가면 그 자리에서 1초 동안 몸을 부풀리며 포효하고(주황 경고 원) 마을 쪽 반원에 투척병 3마리를 부릅니다(34회차). 한 판에 한 번이고, 포효 중에 보스를 쓰러뜨리면 부르지 못합니다.
- **셋째 영웅 눈곰 포포 (39회차)**: 스테이지 4에서 별을 얻으면 합류합니다. 눈덩이를 포물선으로 던져 반지름 1.6m 안의 적 모두에게 피해를 주고 1.2초 늦춥니다. 위에서 떨어져 방패병이 막지 못합니다. 필살기는 3초 늦추는 눈보라입니다.
- **방패병 (27회차)**: 스테이지 6부터 나오는 적입니다. 정면에서 온 영웅 화살은 25%만 들어갑니다. 브론의 휘두르기, 필살기, 탑은 막지 못합니다.
- **영웅 조각 (26회차)**: 스테이지에서 새 별 하나마다 2개, 스테이지 3 이상 승리마다 1~3개를 얻습니다. 영웅 훈련은 Lv3부터 조각이 듭니다(Lv10까지 28개).
- **오늘의 첫 승리 (32회차)**: 하루(기기 현지 날짜) 처음 이긴 전투에 식량 +100, 목재 +100, 조각 +3을 더 줍니다. 받을 수 있을 때 출전 버튼에 표시가 붙습니다.
- **끝없는 도전 (46회차)**: 스테이지 10에서 별을 얻으면 스테이지 줄 끝 ∞ 칩이 열립니다. 스테이지 10 난이도에서 다섯 웨이브를 되풀이하고, 한 바퀴마다 적 체력 ×1.35·수 ×1.2·피해 ×1.15가 됩니다. 마을이 무너질 때까지의 웨이브 수가 최고 기록으로 남고, 보상은 웨이브 수에 비례합니다(조각은 5웨이브마다 1개). 2바퀴부터는 바퀴마다 변주가 하나씩 붙습니다(빠른 걸음 → 방패 행렬 → 쌍둥이 보스, 52회차). 5·10·15·20웨이브를 처음 넘으면 조각 3·6·10·15개를 더 받습니다(51회차).
- **영웅 특기 (45회차)**: 영웅마다 하나, Lv0~3. 궁수 ‘매의 눈’(화살 부채를 좁힘), 브론 ‘긴 망치’(휘두르기 거리 +0.25m씩), 포포 ‘눈사태’(눈덩이 범위 +0.15m씩)입니다. 다음 레벨 n에 조각 3n개가 들고, 그 영웅의 훈련 Lv 2n+1이 필요합니다.
- **금고 (38회차)**: 마을 강화입니다. 레벨마다 전투 시작 골드 +12G(Lv5에서 +60G, 시작 60G의 두 배)이고, 성 Lv까지 올릴 수 있습니다. 3D 마을의 성 뒤 오른쪽에 금화 더미가 커지는 보물고로 섭니다.
- **대장간 (20회차)**: 마을 강화 하나가 탑 분기를 함께 키웁니다. 레벨당 화염 범위 피해 +5%p, 냉기 둔화 +0.15초이고, 성 Lv까지 올릴 수 있습니다.
- **영웅 훈련 (14회차)**: 영웅마다 레벨이 있습니다(최대 성 Lv × 2). 마을의 영웅 버튼으로 카드를 열고 식량·목재로 훈련합니다. 레벨당 체력·공격 +10%이고, 출전하는 영웅에게만 적용됩니다.
- **그래픽 품질 (12회차)**: 높음·낮음 두 단계와 자동(기본)이 있습니다. 낮음은 렌더 배율 상한을 2에서 1.25로 낮추고, 지형 외곽선·섬 장식을 끄고, 파티클을 절반으로 줄입니다. 캐릭터 외곽선과 팀 색은 그대로입니다. 자동은 전투 중 3초 평균이 40fps 아래면 한 번 낮음으로 내립니다.
- **적 모델 2차·서리늑대 (97-A회차)**: 적 6종에 얼굴·무기·갑옷을 넣고 1.1~1.3배 크게 그립니다(충돌 크기는 그대로). 눈 지역에서는 털옷을 입습니다. 고목왕과 서리군주는 모양도 다릅니다. 스테이지 7~9에는 빠른 서리늑대 무리가 돌격병 몇을 대신해 나오고, 웅크렸다가 덮칩니다. [기록](cycles/97a-monsters.md)
- **적 실루엣 (11회차)**: 돌격병은 작고 둥근 몸에 머리 위 뼈 몽둥이, 투척병은 청록 망토에 높은 모자와 가로 활, 거한은 넓고 낮은 몸에 큰 주먹, 보스는 두 팔을 든 Y자에 가시 왕관입니다. 네 종류가 빨강·청록·호박·보라로 갈립니다.
- **덤불과 상자 (10회차)**: 덤불 안의 영웅은 1.8m 밖 적에게 보이지 않습니다(공격하면 1초 드러남). 나무 상자는 이동과 탄을 막고 부서집니다.
- **두 번째 영웅 브론 (09회차)**: 근접 망치 부채꼴, 체력이 높고 앞에서 막는 역할. 스테이지 2에서 별을 얻으면 합류하고, 마을 상단 영웅 버튼으로 고릅니다.
- **3D 마을 (08회차)**: 섬 마을의 건물 6종이 레벨에 따라 3단계로 커집니다. 건물 표지를 눌러 강화합니다. 표지는 글자 아이콘·레벨·강화 가능 점만 있는 44px 배지입니다(17회차).
- **마을 (킹덤 메타 v0, 02회차)**
  - 흐름: 타이틀 → 마을 → 출전 → 결과 보상 → 마을.
  - 성 Lv 1~5가 다른 건물과 강화의 최대 단계를 정합니다.
  - 농장(식량)·제재소(목재)는 앱을 꺼 둔 동안에도 생산합니다(최대 120분치).
  - 영구 강화 3종: 영웅 공격, 탑 비용, 마을 체력. 다음 전투에 바로 반영됩니다.
  - 전투 보상은 방어한 웨이브 수에 비례하고, 같은 판은 한 번만 지급합니다.
  - 저장 키는 `arcana-rush:kingdom:v1`입니다.

- **영웅**: 도마뱀 궁수 GLB와 사격 동작. 영웅 모델은 캠페인 원본(`public/defense/models/`)의 러시 전용 meshopt 사본(`src/rush/models/`, `bash tools/rush-glb.sh`로 다시 만듦)을 씁니다(43회차). 체력 420, 3초간 전투가 없으면 회복, 쓰러지면 4초 뒤 마을 앞에서 복귀.
- **적**: 돌격병, 투척병(원거리 탄, 피할 수 있음), 거한(넉백에 강함), 보스(바닥 경고 0.9초 뒤 내려찍기). 영웅이 가까우면 영웅을 쫓고, 아니면 3개 길을 따라 마을로 갑니다.
- **탑**: 건설점 4곳. 마을에 가장 가까운 적을 노리는 유도탄. Lv1 60G, Lv2 100G, Lv3 160G.
- **조작**
  - 터치: 왼쪽 화면 끌기로 이동. 공격 버튼은 탭하면 자동 조준, 끌면 직접 조준, 가운데로 되돌리면 취소. 보라 버튼은 필살기.
  - PC: WASD 이동, 마우스 클릭 공격(커서 방향), Space 필살기(커서 지점), E 건설(Lv2는 화염), R 냉기 Lv2, Enter 웨이브 시작, Esc 일시정지.
- **피드백**: 조준 부채꼴과 필살기 착탄 원, 피해 숫자, 화면 흔들림(동작 줄이기 설정 시 끔), 기존 전투 효과음·진동 재사용. 피해 숫자는 같은 적·같은 공격자 종류면 0.35초 안에서 하나로 합치고, 몰린 곳에서는 위로 쌓습니다(22회차).
- **이펙트 문법 (05회차)**: 외곽선 있는 단색 조각, 연기, 반짝임, 잉크 충격파를 인스턴스 메시 2개로 그립니다. 섬 가장자리에 장식이 있습니다.
- **히트스톱 (04회차)**: 보스 처치, 영웅 쓰러짐, 필살기 명중, 거한 처치 때 0.045~0.11초 멈춥니다. 결과는 바뀌지 않고, 동작 줄이기 설정에서는 꺼집니다.
- **렌더 톤 1차**: 툰 셰이딩 3단계와 림 라이트, 잉크 외곽선, 부품을 하나로 구운 적·지형·마을, 섬 지형, 외곽선 있는 굵은 UI 글꼴. 휴대폰 짧은 화면은 카메라를 당깁니다.

## 한계 (정직하게)

- **실기기 성능 미측정.** 컨테이너 브라우저는 소프트웨어 렌더링이라 FPS 숫자에 의미가 없습니다. 드로콜은 06회차 인스턴싱 뒤 웨이브3 51, 보스전 56입니다(적 수와 무관). 실기기 게이트는 루프 백로그에 있습니다.
- 마을 비용·생산·보상 수치는 사람 플레이로 검증하지 않았습니다.
- 적은 도형을 구워 만든 임시 모델이고, 사운드는 기존 합성음을 재사용합니다. 세로 화면은 동작하지만 가로 화면 기준으로 설계했습니다.
- 사람 대상 재미 검증은 아직입니다.
