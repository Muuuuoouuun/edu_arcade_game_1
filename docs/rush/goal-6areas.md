### 정직하게 적는 것

- **자체 평가다.** 일곱 점수 모두 81~85로 여유가 크지 않다. 처음 매겼을 때 영웅 모델은 18(목표 19), 디펜스는 80에 딱 걸쳤다. 그래서 영웅 키를 올리고 탑 철거를 더한 뒤 다시 매겼다(영웅 19, 디펜스 82).
- **게임이 쉬워지고 짧아졌다.** 바리케이드가 웨이브를 탑 앞에 붙잡아서 7·8·10스테이지 권장 전투력이 내려갔고, 캠페인이 16판에서 13판으로 줄었다. 권장 전투력은 다시 잰 값으로 바꿨다.
- **마지막 스테이지의 단차가 작았다.** 97회차에는 10스테이지 권장 전투력이 9스테이지보다 한 단계(50)만 높았다. 99회차에 서리군주의 포효를 ‘영웅 3초 얼리기’로 바꿔, 이제 10스테이지는 성장 단계 하나를 더 요구한다(같은 단계에서 9스테이지 8판 8승, 10스테이지 8판 3승). 전투력 숫자로는 2,450 → 2,550이다.
- **그리기 비용이 크게 늘었다.** 높음 품질의 드로콜이 64에서 109로 늘었다(그림자 패스). 주 스레드 시간은 예산 안이지만 GPU 비용은 소프트웨어 렌더라 재지 못했다. 실제 기기에서 느리면 자동으로 낮음으로 내려간다.
- **봇은 새 요소 일부를 쓰지 않는다.** 전초 자리, 시냇물, 빙판, 보물 상자는 사람만 쓴다. 그래서 사람에게는 측정보다 쉬울 수 있다.
- **계정 사용 한도에 두 번 걸렸다.** 하위 에이전트 다섯을 동시에 돌린 탓이다. 두 번째부터는 메인 세션이 남은 갈래를 직접 마무리해 합쳤다.

## 계획 (80점까지)

일을 다섯 갈래로 나눠 하위 에이전트가 각자 작업 트리에서 하고, 메인 세션이 합치고 균형을 다시 잰다. D·E는 사용자 추가 요청으로 더했다.
