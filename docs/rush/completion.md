# 아르카나 러시 1.0 완성 기준 (2026-11-13 사용자 목표)

사용자 목표: “최신 방향성과 지침대로 게임 완성. Fable·Opus를 최우선으로 쓰고, 필요하면 OpenAI API로 이미지·참고 시트를 만든다. API 한도 400달러.”

방향과 경계는 [loop.md](loop.md)를 그대로 따른다. 지켜야 하는 것은 다음과 같다.
- 킹샷식 마을 성장 + PvE이고, 브롤스타즈풍 렌더다.
- 범위 파일만 바꾼다.
- 공유 설정(`package.json`, `vite.config.ts`, `capacitor.config.ts`)은 바꾸지 않는다.
- 모든 변경은 시험·스크린샷으로 확인한다.
- #107의 ‘전투 HUD·알림 글 숨김’과 ‘체력 HUD 없음’을 지킨다.

### 사용자 결정 (2026-11-13, 1.0 범위 확정)

- **배포 형태: 웹 설치판으로 완성.** 1.0은 홈 화면에 설치하는 웹 앱이다(C2).
  - Android APK는 1.0 범위에 넣지 않는다.
  - 독립 앱 껍데기(`tools/rush-app`, C14)는 준비되어 있다. 사용자가 Android SDK 라이선스에 동의한 뒤 `build.sh`를 한 번 돌리면 APK가 나온다.
  - 이 세션에서 SDK 라이선스 자동 동의를 시도했으나 권한 검사에서 막혔다(사용자 이름의 법적 동의). 그래서 사용자에게 물었다.
- **실기기 확인: 1.0 완성 기준에서 우선 뺀다.** 음악·효과음 크기를 귀로, 진동을 손으로, 실제 프레임을 기기로 확인하는 일은 출시 전 권장 점검으로 남긴다. 1.0은 측정 근거(C11~C13)로 완성으로 본다.

**범위 밖**(사용자 결정 또는 실기기 필요): Android SDK 라이선스 동의와 그 뒤 APK 빌드 한 번(`./gradlew assembleDebug`), 스토어 출시, 실기기에서 마지막으로 듣고 만져 보기(백로그 9). 1.0 기록에 ‘사용자 결정 대기’로 남긴다.
