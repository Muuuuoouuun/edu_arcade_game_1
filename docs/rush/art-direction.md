# 아르카나 러시 · 렌더 톤 기준 (아트 디렉션 v1)

**2026-11-13 사용자 확정:** [승인 스틸컷 기반 제작 기준](../arcana-approved-visual-standard.md)을 최우선 시각 기준으로 적용합니다. 전투 4장과 생산·타워 2장의 캐릭터·입체 지형·재질·조명·UI 형태를 이후 제작에 유지합니다. 기존 런타임의 단순한 모델이나 거친 외곽선은 목표 품질 기준이 아닙니다.

**방향(2026-11-10 사용자 결정): 디자인·그래픽·렌더 톤은 브롤스타즈풍, 플레이는 킹샷식(마을 성장 + PvE).**

**2026-11-12 적용 범위 확정:** 이 시각 방향은 아르카나 전체 모드가 공유한다. 마을 수비·원정·군단·훈련장에서도 캐릭터 비율, 모델링, 재질·텍스처, 색감과 3D 표현을 유지한다. [전체 모드 공통 기준](../arcana-character-art-standard.md)이 우선하며, 아래 수치는 Rush의 구현 기록이다. 다른 모드의 동일 수치 적용이나 현재 자산의 최종 품질 달성을 의미하지 않는다.

“브롤스타즈풍”은 **원칙**이다. 그 게임의 캐릭터·아트·UI 레이아웃·아이콘·폰트·맵을 복제하지 않는다. 캐릭터와 세계는 아르카나 IP(사용자 소유)를 쓴다.

## 기술 규칙 (모바일 비용)

- **부품을 하나로 굽는다(bake).** 여러 도형을 정점 색이 있는 지오메트리 하나로 합친다. 적 1마리는 본체 1 + 외곽선 1 드로콜이다. 지오메트리는 종류별로 한 번 만들어 모든 개체가 공유한다.
- **외곽선용 지오메트리는 법선을 평균낸다**(`toCreasedNormals`, π). 상자 모서리에서 외곽선이 갈라지지 않는다.
- **피격 반짝임은 머티리얼 교체로 한다.** 개체별 머티리얼 복제를 금지한다.
- **GLB 모델은 `toonify()`로 툰 재질로 바꾼다.** 노드 축척과 관계없이 외곽선 두께가 같아지도록 월드 축척으로 나눈다.
- 1차 적용 측정(같은 시드·틱, 1280×720): 웨이브3 드로콜 108→101, 보스전 180→147. 삼각형 1.0만→2.5만, 1.5만→4.0만. 성능 주장은 하지 않는다. 개수만 보고한다.

## 이펙트 문법 (05회차)

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| 조각 | 단색 이십면체 + 굵은 잉크 외곽선(×1.35). 중력과 튕김 | 명중(영웅 청록, 탑 노랑), 처치(적 색), 필살기(보라), 영웅 쓰러짐 |
| 연기 | 작은 크림·흙색 덩어리 + 가는 외곽선(×1.1). 금방 커졌다 사라짐 | 처치, 보스 내려찍기, 건설, 사격 총구 |
| 반짝임 | 흰색·금색, 빠르고 짧음 | 명중, 벽에 맞은 탄, 코인 줍기 |
| 충격파 | 색 고리 아래에 잉크 고리 | 필살기, 보스 내려찍기, 보스 처치, 영웅 쓰러짐 |
| 얼음 껍질 | 몸 모양을 ×1.08로 덮는 반투명 하늘색(0.4), 끝나기 직전 깜빡임 | 냉기탑에 느려진 적(16회차) |

- 파티클은 인스턴스 메시 2개(본체 + 외곽선)로 그린다. 개수와 관계없이 드로콜은 2다.
- 동작 줄이기 설정에서는 파티클 수가 절반 정도로 준다.
- 연기는 작게 유지한다. 크고 하얀 연기는 바위처럼 보이고 적을 가린다(05회차 검토).
- **단단해 보이는 것은 단단해야 한다.** 장식(덤불·바위·상자)은 울타리 밖에만 둔다.
- **지나갈 수 있는 것은 그렇게 보여야 한다**(10회차). 전장 안 덤불은 상자 모양이 아니라 얇은 바닥에 잎 날을 세운 키 큰 풀로 그린다. 영웅이 숨은 덤불만 반투명해진다.
