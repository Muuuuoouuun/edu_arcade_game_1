## 문제

123회차 기준표에서 막을 두른 서리늑대가 눈에서 73~81%로, 얼지 않은 늑대(89~94%)보다 낮았다. 늑대는 껍질을 입지 않으므로(90회차) 이상하다.

## 원인(먼저 봄)

123회차 프레임에서 늑대의 측정 창(이웃과의 중간까지)을 잘라 보니, 창 오른쪽에 **이웃 보스의 망토**가 들어와 있다. 보스는 커서 중간선을 넘는다. 얼지 않은 장면에서는 짙은 붉은 망토가 바닥과 잘 갈려 늑대 값을 올리고, 막 장면에서는 보스의 반투명 자홍 껍질이 망토를 덮어 늑대 값을 내린다. 늑대 자신은 두 장면에서 같다. **측정 결함이다.**

## 범위

- 마스크 프레임(`__rush.maskMode`)이 적을 **종마다 다른 단색**으로 그린다(`MASK_COLOR`: 돌격병 빨강, 투척병 초록, 거인 파랑, 방패병 노랑, 주술사 자홍, 서리늑대 청록, 보스 주황). 이 프레임에서는 모든 종을 함께 그리는 multi-draw 묶음 대신 종별 묶음을 쓴다.
- `tools/rush-contrast.py`: 적의 몸 = 측정 창 안에서 **그 종의 색**인 화소. 창은 넓게 잡는다(색이 종을 가르므로 보스처럼 중간선을 넘는 몸도 다 든다).
- 26장면을 다시 찍어 기준표 `docs/rush/contrast.md`를 고친다.

**먼저 해 보고 되돌린 것**(분석만 바꿔 123회차 프레임으로 잼)
1. 자홍 마스크를 이어진 덩어리로 나눠 가장 가까운 적에게 주기: 막 껍질끼리 붙으면 세 적이 한 덩어리가 되어 투척병·방패병 막 값이 비었다(n/a).
2. 덩어리 + ‘내 덩어리가 창의 40% 넘을 때만’: 막 늑대는 여전히 보스 막 껍질과 붙어 그대로였다.
3. 창 경계를 이웃 크기 비례로: 막 장면에서는 이웃마다 1.16배 껍질이 있어 양쪽에서 들어와, 막 늑대 값이 그대로(72%·70%)였다.
→ 창으로 가르는 방식으로는 막 장면을 풀 수 없어, 종마다 색을 다르게 그리는 쪽으로 갔다.

## 결과

**마스크**(직접 봄, 눈 8 가운데 막 장면): 돌격병 빨강, 투척병 초록, 거인 파랑, 방패병 노랑, 주술사 자홍, 늑대 청록, 보스 주황의 평평한 실루엣. 막 껍질끼리 닿아도 색으로 갈린다.

**처음 분석에서 한 번 더 틀렸다**: 색만으로 고르니 빈 장면의 모래 길이 보스 주황, 물이 늑대 청록과 비슷해 바닥이 몸으로 잡혔다(5스테이지 보스 장면 빈 프레임에서 주황 21,203·청록 12,217 화소). 마스크 색이면서 **빈 프레임과 다른 화소**만 세도록 고쳤다. 그 뒤 고목왕 88%(123회차와 같음).

**가설은 맞았다.** 서리늑대는 이제 세 상태가 같다.

| 장면 | 123회차 늑대(얼지 않음 / 얼림 / 막) | 126회차 |
| --- | --- | --- |
| 눈 7 길 | 94 / 86 / 74 | **89 / 89 / 89** |
| 눈 8 풀밭 | 91 / 88 / 81 | **86 / 86 / 86** |
| 눈 7 가운데 | 90 / 76 / 80 | **84 / 84 / 84** |
| 눈 8 가운데 | 89 / 78 / 73 | **81 / 81 / 81** |

늑대 옆 보스의 몸·망토·껍질이 늑대 값에 섞여 있었다(얼지 않음은 짙은 망토 때문에 높게, 얼림·막은 옅은 껍질 때문에 낮게).

**다른 종도 바뀌었다**: 큰 거인 옆의 투척병·방패병 값이 거인 몸·껍질이 빠지며 내려갔다(예: 숲 3 가운데 얼린 투척병 69 → **55**, 눈 7·8 가운데 방패병 70·69 → **65·65**, 눈 8 풀밭 투척병 79 → 70). 종·장면 56칸 가운데 40칸에서 세 값 중 하나 이상이 2 넘게 바뀌었다. 바뀐 표와 70% 아래 목록은 `docs/rush/contrast.md`에 있다.

**바꾼 것**
- `render.ts`: 디버그 마스크 모드가 종마다 다른 단색(`MASK_COLOR`)으로, 종별 묶음으로 그린다(그 프레임에서는 multi-draw 묶음을 비움). 게임 화면은 그대로.
- `tools/rush-contrast.py`: `SHAPE` = 그 종의 마스크 색이면서 빈 프레임과 다른 화소. 창은 넓게(보스처럼 큰 몸도 다 든다).
- `docs/rush/contrast.md`: 표와 방법·살펴볼 목록을 새 값으로.
