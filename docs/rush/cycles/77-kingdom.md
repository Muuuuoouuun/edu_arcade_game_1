## 문제

71회차 전투력은 상단 막대 제목(`h1`) 안에 있다. 그런데 폭 760 이하 가로 화면(예: 667×375)에서는 58회차 규칙이 막대를 한 줄로 지키려고 제목 전체를 숨긴다. 그래서 전투력도 함께 사라진다. 작은 휴대폰 가로에서는 성장 숫자가 안 보인다.

## 범위

- 좁은 가로에서는 제목 **글자만** 숨기고 전투력 줄은 남긴다. 제목 글자를 `<span class="town-title">`으로 감싸고, 그 범위만 숨긴다.
- 막대가 한 줄을 유지하는지(접힘·잘림 0, 막대 아래 끝 그대로) 58회차 측정 스크립트로 잰다. 넘치면 전투력 줄을 더 줄인다(숫자만).
- 바꾸는 파일: `rush.html`, `src/rush/rush.css`.

## 가설

전투력 줄(약 100px)을 더해도 667폭 막대(자원 셋 + 영웅 + 수확 약 531px)에 들어간다. 막대 아래 끝은 52 그대로다.

## 수용 기준

- [x] 667×375·740×360에서 전투력이 보이고, 6개 화면 접힘·잘림 0, 막대 높이 그대로
- [x] 스크린샷 직접 확인
- [x] `test:rush`, `tsc`, `build`, `smoke:rush` 통과

## 결과

가설이 맞았다. 좁은 가로에서도 ‘전투력 280’이 왼쪽에 보이고, 막대는 한 줄 그대로다.

- 제목 글자를 `.town-title`로 감쌌다. 폭 760 이하 가로에서는 그것만 숨긴다. 제목 칸은 내용 폭(`flex: 0 1 auto`)이고, 오른쪽 자원·영웅·수확은 `margin-right: auto`로 오른쪽에 붙는다.
- 측정(58회차 스크립트, 7개 화면): 접힌 글자·잘린 단추 0이다. 막대 아래 끝도 전과 같다.

| 화면 | 막대 아래 끝 | 전투력 위치(CSS px) | 자원 칸 시작 |
| --- | ---: | --- | ---: |
| 작은 가로 667×375 | 52 | 10~67 | 232 |
| 가로 740×360 | 52 | 10~67 | 305 |
| 가로 863×360 | 52 | 10~67(제목 아래) | 428 |
| 세로 360·412, 태블릿, 데스크톱 | 156·156·105·59 | 그대로 | — |

- 스크린샷 직접 확인: 좁은 가로에서는 제목 없이 전투력만 왼쪽에 있고, 863에서는 제목 아래 그대로다.
