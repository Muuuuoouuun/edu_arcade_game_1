## 문제

마을에서 강화·훈련·특기·별을 모으면 각 줄의 레벨 숫자는 오른다. 하지만 ‘내 왕국이 얼마나 컸나’를 한눈에 보여주는 하나의 숫자는 없다. 킹샷류는 화면 위의 전투력 하나가 모든 성장을 모아 보여주고, 오를 때마다 ‘+N’으로 반응한다. 그것이 다음 강화를 부르는 고리다.

## 범위

- **규칙**(`kingdom.ts`): `kingdomPower(k)` 순수 함수다. 아래를 더한다.

  | 항목 | 단위당 |
  | --- | ---: |
  | 성 레벨 | 100 |
  | 농장·목재소 레벨 | 30 |
  | 강화 다섯 종(공격·탑 할인·성벽·대장간·금고) 레벨 | 60 |
  | 영웅 셋 레벨 합 | 40 |
  | 특기 레벨 합 | 80 |
  | 별 합 | 25 |
  | 끝없는 도전 최고 웨이브 | 10 |

  새 왕국은 0이 아니라 시작 값이 있다.
- **화면**(`town.ts`, `rush.html`, `rush.css`): 상단 막대 제목 아래에 작게 ‘전투력 1,234’를 둔다. 값이 오르면 그 옆에 금색 ‘+N’이 떠오르고 숫자가 살짝 커진다(동작 줄이기에서는 끔).
- 바꾸는 파일: `kingdom.ts`, `kingdom.test.ts`, `town.ts`, `rush.html`, `rush.css`.

## 가설

강화 한 번마다 전투력이 오르는 것이 보이면 성장이 하나의 고리로 읽힌다. 상단 막대는 58회차 배치를 깨지 않는다(세로 줄 수 그대로, 접힘·잘림 0).

## 수용 기준

- [x] 시험: 새 왕국 값, 강화·훈련·특기·별·기록마다 정확히 그만큼 오름, 저장값에 따로 저장하지 않음(늘 계산)
- [x] 휴대폰 가로·세로·데스크톱 스크린샷: 전투력 표시와 ‘+N’ 확인, 상단 막대 접힘·잘림 0(58회차 측정 스크립트)
- [x] `test:rush`, `tsc`, `build`, `smoke:rush` 통과

## 결과

**전투력**

- 새 왕국은 280이다(성 100 + 농장·목재소 60 + 영웅 셋 Lv1 120).
- 측정용 왕국(성 3, 별 12, 궁수 Lv3)은 980이다. 농장을 강화하면 1,010(+30)이 된다.
- 시험은 다음을 확인한다.
  - 성·농장·강화·훈련·별·끝없는 기록·특기가 각 무게만큼 정확히 오른다.
  - 저장 JSON에는 들어가지 않는다(늘 계산).

**화면**

- 상단 막대 제목 아래에 ‘전투력 1,010’이 작게 뜬다. 숫자에는 천 단위 쉼표가 붙는다.
- 값이 오르면 바로 옆에 금색 ‘+30’이 떠올랐다 사라진다(1.4초). 전투에서 별·기록을 얻고 마을로 돌아올 때도 같은 반응이 나온다.
- 처음 판에서는 ‘+N’이 막대 오른쪽 끝(자원 칸 옆)에 떴다. 전투력 줄이 제목 폭만큼 넓은 블록이었기 때문이다. 내용 폭으로 줄여(`display: table`) 숫자 바로 뒤에 붙였다.
- ‘전투력’과 숫자 사이 간격이 붙어 4px를 띄웠다.
- 상단 막대(58회차 측정 스크립트, 6개 화면): 접힌 글자·잘린 단추 0이다.
