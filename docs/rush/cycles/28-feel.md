## 문제

공격 버튼을 탭하면 자동 조준이 **가장 가까운 적**을 노린다. 방패병(27회차)이 정면으로 다가오면 가장 가까운 적이 그것이다. 탭할 때마다 화살이 방패에 막혀 25%만 들어가고, 옆에 맞힐 수 있는 적이 있어도 그쪽을 쏘지 않는다. 손으로 조준하면 피할 수 있지만, 탭(자동 조준)이 기본 조작이다.

## 범위

- **자동 조준 점수**: 거리에 **방패 벌점 3m**를 더한다. 벌점은 궁수의 화살이 그 적의 방패 정면에 맞을 때(적이 영웅 쪽을 바라볼 때)만 붙는다. 그래서 비슷한 거리에 다른 적이 있으면 그쪽을 쏜다. 방패병만 있으면 그대로 방패병을 쏜다.
- 브론의 휘두르기 자동 조준은 지금처럼 가장 가까운 적이다(휘두르기는 막히지 않음).
- **막힘 소리**: `block` 이벤트에 기존 효과음 중 금속성인 것을 붙인다(공용 `src/lib/sound.ts`는 바꾸지 않음).
- 이것은 규칙(`sim.ts`의 자동 조준) 변경이다. 봇도 자동 조준을 쓰므로 밸런스 테스트를 다시 확인한다.

## 수용 기준

- [x] 규칙 테스트
  - 정면을 보인 방패병(3m)과 돌격병(4.5m)이 있으면 돌격병을 쏜다.
  - 방패병만 있으면 방패병을 쏜다.
  - 등을 보인 방패병은 벌점이 없다.
- [x] 봇 기준 스테이지 6~8에서 막힌 화살 수 전후. 설계 기둥·스테이지·영웅 훈련 테스트 통과
- [x] `test:rush`, `tsc`, `build`, `smoke:rush` 통과

## 바꾼 것

- **`sim.ts`**
  - `shieldFaces(e, from)`: `from`에서 온 화살이 방패 정면에 맞는가. 27회차의 막기 판정도 이 함수를 쓰도록 합쳤다.
  - `autoTarget(s, from, range)`: 사거리 안에서 ‘거리 + (방패 정면이면 3m)’가 가장 작은 적을 고른다. 궁수 자동 조준이 쓴다. 브론은 지금처럼 `nearestEnemy`다.
- **`main.ts`**: `block` 이벤트에 기존 효과음 `cannon`(둔탁한 금속성)을 붙였다. 공용 `src/lib/sound.ts`는 바꾸지 않았다.
- **테스트 1개 추가**(51 → 52): 정면 방패병보다 옆 돌격병, 방패병만 있으면 방패병, 등을 보이면 벌점 없음.

## 결과

**궁수 봇, 스테이지 6~8 × 시드 1~4 (12판)**

| | 전 | 후 |
| --- | --- | --- |
| 막힌 화살 / 영웅 명중 | 64 / 2,317 (2.8%) | **37 / 2,342 (1.6%)** (−42%) |
| 승리 | 0/12 | 0/12 |

- 남은 막힘은 방패병만 사거리에 있을 때와, 3갈래 화살 중 옆 화살이 방패에 맞을 때다.
- 방패병이 웨이브에 1~2마리뿐이라, 승패를 바꿀 만큼은 아니다. 탭 조작에서 화살이 방패에 낭비되는 일이 준다.

## 테스트 기준 변경 (기록)

**‘강화 최대 마을은 스테이지 10을 이긴다’**는 궁수 시드 1·2가 각각 이겨야 했는데, 시드 2가 졌다. 시드 1~8로 넓혀 보면 다음과 같다.

| 자동 조준 | 궁수 시드 1~8 | 브론 시드 1~8 |
| --- | --- | --- |
| 전(가장 가까운 적) | 승 승 패 승 패 승 승 승 (6/8) | 8/8 |
| 후(방패 벌점 3m) | 승 패 패 승 승 승 승 승 (6/8) | 8/8 |
| 벌점 1.5·2·4m | 6/8 (같은 시드에서 짐) | 8/8 |

- 이긴 판 수는 같고, 지는 시드만 바뀌었다. 봇 판은 작은 규칙 변화에도 시드마다 결과가 뒤집힌다(14회차에서도 봤다).
- 그래서 이 확인을 **시드 1~8 중 6판 이상 승리**로 바꿨다(궁수). 강화 없는 스테이지 10 패배와 스테이지 1~3 승리는 지금처럼 시드별로 확인한다. 브론 확인은 바꾸지 않았다.
