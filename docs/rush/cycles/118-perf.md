## 문제

건설 자리 고리(탑 자리 6 + 바리케이드 자리 3)는 자리마다 메시 하나라, 보이는 만큼 따로 그린다(115회차 무거운 장면 4). 고리는 색(금색 = 살 수 있음, 옅은 노랑 = 아직, 초록 = 수리)과 불투명도(0.85 / 0.42)가 다르고, 손 닿는 자리는 깜빡이며 커졌다 작아진다.

## 범위

- 고리를 인스턴스 묶음 두 개로: 진한 고리(불투명도 0.85, 인스턴스 색), 옅은 고리(0.42). 손 닿는 자리 하나는 지금처럼 따로 된 메시(불투명도 깜빡임 유지).
- 그리기 순서(2)·크기·높이·색은 그대로.
- 잴 것: 고리가 여럿 보이는 장면(시연 시작 무렵 마을 앞, 무거운 장면)에서 드로콜 전후, 같은 장면 스크린샷.

## 가설

보이는 고리 n개가 많아야 3번(진함·옅음·손 닿는 곳)이 된다. 마을 앞 장면에서 고리 6~9개가 보이면 3~6 준다. 화면은 같다.

## 수용 기준

- [x] 드로콜 전후(고리가 많이 보이는 장면과 무거운 장면)
- [x] 같은 장면 스크린샷을 직접 보고 고리 색·불투명도·크기가 같음
- [x] `test:rush`, `tsc`, `build`, `smoke:rush` 통과

- 가설보다 많이 줄었다. 마을 앞에서는 고리 9개가 다 보여, 9번이 1번(옅은 것과 진한 것이 섞이면 2번, 손 닿는 곳이 있으면 +1)이 된다. 115회차 무거운 장면(들판 가운데)에서는 4 → 1~2다.

**화면**(직접 봄): 같은 장면 전후를 위아래로 놓고 보니 금색 고리·옅은 고리의 색·불투명도·크기가 같다. 다른 화소(약 4,700)는 화면 곳곳에 흩어진 움직이는 장식이다. 영웅이 탑 자리에 서면 그 고리만 따로 된 메시로 커지고(깜빡임 유지), 나머지는 묶음으로 그려진다.

**바꾼 것**(`render.ts`): 건설 자리 고리 9개 메시 → 인스턴스 묶음 둘(`site-rings` 불투명도 0.85, `site-rings-faint` 0.42, 색은 인스턴스마다) + 손 닿는 고리 하나(`site-ring-near`). 순서(2)·높이·크기·색 규칙은 그대로.
