## 문제

81회차에서 `tools/rush-glb.sh`를 다시 돌렸더니 숲 마을 웹 사본이 71,732 B로 나왔다. 커밋된 66회차 사본은 51,508 B다. 도구는 ‘quantize: TEXCOORD_0이 0~1 밖이라 건너뜀’ 경고도 냈다. 원본(`forest-town.glb`)은 11월 11일 뒤로 바뀌지 않았다.

**먼저 찾은 단서**: #111의 `a505183`(질감 영웅 적용)이 이 도구의 `prune --keep-attributes false`를 **두 곳 모두** `true`로 바꿨다. 영웅은 질감 아틀라스 UV가 필요해서 맞는 변경이다. 마을은 질감이 없다(이미지 0, 재질 1개, 정점색으로 그림, `townScene.ts` 191행). 그래서 마을 쪽은 같이 바뀐 것으로 보인다.

## 범위

- 마을 단계만 `--keep-attributes false`로 돌려 다시 만든다. 커밋된 사본과 **바이트가 같은지**(`cmp`) 확인한다. 같으면 원인이 확정된다. 다르면 npx 의존 판(meshoptimizer 등)을 비교한다.
- 도구 고치기
  - 마을 단계는 `false`로 하고 이유를 주석으로 적는다. 영웅 단계는 `true`로 둔다.
  - 인자로 `heroes` / `town`을 받아 한쪽만 다시 만들 수 있게 한다. 인자가 없으면 지금처럼 둘 다 만든다. 81회차처럼 영웅만 고칠 때 마을 사본을 건드리지 않게 하려는 것이다.
- 사본 파일은 바이트가 같으면 커밋하지 않는다(변경 없음).
- 바꾸는 파일: `tools/rush-glb.sh`, 기록.

## 가설

`--keep-attributes false`로 다시 만들면 커밋된 51,508 B와 바이트까지 같다. 늘어난 20 KB는 쓰지 않는 UV 자료다. UV 범위가 0~1 밖이라 양자화도 안 되고 원래 크기로 남는다.

- [x] 도구 인자(`heroes`, `town`, 없음) 각각 실행해 바뀌는 파일 확인. 영웅 사본은 81회차 커밋과 바이트가 같다
- [x] `test:rush`, `tsc`, `build`, `smoke:rush` 통과

## 결과

가설이 맞았다. 마을 단계를 `--keep-attributes false`로 돌리면 커밋된 66회차 사본과 **바이트까지 같다**(`cmp` 차이 없음, 51,508 B).

**원인**

- #111 `a505183`이 이 도구의 `prune --keep-attributes false`를 영웅·마을 두 곳 모두 `true`로 바꿨다.
- 영웅에게는 맞는 변경이다. 질감 아틀라스 UV를 지켜야 한다.
- 마을에는 질감이 없다(이미지 0, 정점색으로 그림). 그래서 쓰지 않는 UV가 사본에 남았다.
- 그 UV는 0~1 밖이라 meshopt가 양자화하지 못하고(‘TEXCOORD_0 건너뜀’ 경고), Float32 그대로 남는다.

| 마을 사본 | 정점 | UV(압축 전) | 파일 |
| --- | ---: | ---: | ---: |
| `keep-attributes false` (66회차, 커밋된 것) | 8,520 | 없음 | **51,508 B** |
| `keep-attributes true` (`a505183` 뒤 도구) | 8,520 | 68,160 B (Float32 2개 × 8,520) | 71,732 B (+20,224) |

위치(Int16)·법선(Int8)·정점색(Uint8)은 두 사본이 같다. 다른 것은 UV 하나다.

**도구 고침** (`tools/rush-glb.sh`)

- 마을 단계는 `--keep-attributes false`로 돌리고, 이유를 주석으로 적었다. 영웅 단계는 `true`로 둔다.
- 인자를 받는다.

| 실행 | 다시 만드는 것 | 결과 |
| --- | --- | --- |
| `bash tools/rush-glb.sh heroes` | 영웅 셋 | 81회차 커밋과 바이트 같음, 마을 사본 안 건드림 |
| `bash tools/rush-glb.sh town` | 마을 웹 사본 | 66회차 커밋과 바이트 같음 |
| `bash tools/rush-glb.sh` | 둘 다 | 네 파일 모두 커밋과 바이트 같음(`git status` 변경 없음) |
| 다른 인자 | 없음 | 사용법을 보이고 종료 코드 2 |

- 이제 도구를 다시 돌리면 커밋된 사본 네 개가 그대로 나온다. 사본 파일은 바뀌지 않아 커밋하지 않는다.
