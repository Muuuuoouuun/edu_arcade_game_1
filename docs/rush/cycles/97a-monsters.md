# 97-A회차: 몬스터·적 모델 (6분야 목표 A갈래)

목표: [goal-6areas.md](../goal-6areas.md)의 몬스터(62)와 적 모델(9/20)을 근거로 올린다.

## 바꾼 것

- **적 6종 모델**(`render.ts` `enemyKit`): 구운 정점 색 도형 + 종류별 인스턴스 배치 구조는 그대로다. 종류마다 큰 눈·눈썹·입(송곳니), 고유 무기·소품, 갑옷·천 조각을 넣었다.
  - 돌격병: 뿔·귀·아래턱 송곳니, 못 박힌 뼈 몽둥이, 허리띠, 어깨 가시.
  - 투척병: 뒤로 젖힌 모자(높은 카메라에서 얼굴이 보이게), 복면 위 노란 눈, 당긴 활과 화살, 빨간 깃털, 화살통.
  - 거한: 뿔 투구, 내민 턱과 엄니, 가시 어깨 갑옷, 쇠 띠 두른 주먹.
  - 방패병: 볏 달린 투구, 창과 깃발, 눈 아래에서 끝나는 방패(얼굴이 방패 위로 보임).
  - 주술사: 뿔 달린 뼈 가면, 초록 불빛 눈, 목걸이, 발톱 달린 지팡이.
  - 보스: 눈썹·턱·송곳니·허리띠·팔찌. 이름 없는 보스는 금 어깨 갑옷.
- **화면 속 크기**: 시각 배율 `ENEMY_SCALE`(돌격병 1.3, 투척병·방패병·주술사 1.25, 거한 1.2, 보스 1.1, 늑대 1.3). 시뮬레이션 반지름·충돌·사거리는 그대로다. 모델 시트에서 돌격병 높이 25.5 → 38.9 CSS px, 투척병 46.1 → 57.9, 거한 53.0 → 68.6 (Pixel 7 가로).
- **지역 옷**: 눈 지역(6~10)에서는 다섯 종이 크림색 털 깃·장화·모자 테·방패 위 눈을 걸친다. 지오메트리를 전투마다 바꿔 끼운다(`restyle`).
- **이름 있는 보스 모양**: 1-5 고목왕은 가지 뿔·나무껍질 왕관·이끼 수염·잎 어깨·뿌리, 2-5 서리군주는 얼음 가시 왕관과 큰 수정·어깨 수정·고드름 수염·털 망토·주먹 얼음 가시. 색(`BOSS_LOOK`)과 함께 바뀐다.
- **서리늑대**(`EnemyKind` `wolf`): 네발 실루엣(몸·머리·주둥이·귀·꼬리·다리 넷), 서리 파랑 털에 흰 갈기, 등 얼음 조각, 빨간 눈과 빨간 목걸이. 스테이지 7~9(2-2 ‘늑대 무리의 습격’부터)에 웨이브 2·4·5에서 3마리씩(스테이지 배율 적용) 나오고, 그만큼 돌격병 무리가 1마리씩 준다(`less`). 체력 22, 속도 4.0(돌격병의 1.6배), 피해 6, 골드 6.
- **덮치기 예고**: 목표가 3.2 m 안에 들어오면 0.4초 웅크리고(멈춤, 흰 깜빡임, 발밑 빨간 고리) 0.35초 동안 2.6배 속도로 뛴다. 3초에 한 번. 글자는 없다(#107).
- **걷기·치기 동작**: 걸을 때 좌우로 뒤뚱(늑대는 앞뒤 질주), 근접 공격 직후 0.16초 앞으로 찌르기. 동작 줄이기에서는 뒤뚱거림을 끈다.
- 모델 시트(`?sheet=1`)에 늑대를 넣고, `?stage=N`으로 눈 옷·이름 있는 보스를 볼 수 있다.

- 스테이지 9는 L6에서 4/8로 문턱에 딱 걸린다(전 7/8). 합친 뒤 다시 잴 때 먼저 볼 곳이다.

## 남은 것

- 스테이지 10과 끝없는 도전의 늑대. 늑대가 왜 최대 성장 왕국(영웅 Lv1, 탑 위주)에 유독 비싼지는 밝히지 못했다.
- 늑대 우두머리(2-2 이야기의 보스 이름)는 만들지 않았다. 스테이지 7 보스는 이름 없는 보스 모양이다.
- 빽빽한 무리에서는 거한이 뒤의 작은 적을 가린다(크기를 키운 대가). 실기기 확인이 필요하다.
