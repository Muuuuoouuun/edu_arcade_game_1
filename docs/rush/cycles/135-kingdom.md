# 135회차: 킹덤 메타, 결과 화면의 ‘할 일’을 마을에서 바로 이어 하기

| 항목 | 값 |
| --- | --- |
| 시각 | 2026-11-16 07:41 ~ 07:50 KST (예약 회차) |
| 기준 | `60e416c` (134회차 뒤) |
| 레인 | 킹덤 메타 (129회차 이어서) |
| 상태 | 완료 (‘마을로’가 권한 건물을 골라 둔 채 열고 ‘추천’ 띠를 단다) |
| 다음 레인 | PvE 콘텐츠 |

## 문제

129회차에 결과 화면이 ‘할 일: **성 올리기** → 전투력 +100’처럼 다음 판 준비를 알려 주게 했다. 그런데 ‘마을로’를 누르면 마을은 늘 마지막으로 고른 건물(처음엔 성)을 연 채로 시작한다. 결과 화면이 ‘금고 올리기’를 권했으면, 마을에서 금고 표지를 다시 찾아 눌러야 한다. 권한 것과 마을이 이어지지 않는다.

## 범위

- `main.ts`: 결과 화면이 고른 할 일(`nextStep`의 `action`)을 기억했다가 ‘마을로’에서 마을에 넘긴다.
- `town.ts`: `show(rewardText, suggest)`가 그 건물(영웅 훈련·특기면 영웅 칸)을 골라 둔다. 그 표지에 ‘추천’ 작은 띠를 단다. 그것을 올리면(레벨이 오르면) 띠가 사라진다. 다른 건물을 눌러도 띠는 남는다(무엇을 권했는지 잊지 않게).
- 결과 화면을 거치지 않고 마을에 들어올 때(타이틀 → 마을, 끝없는 도전 결과)는 바뀌지 않는다.

## 가설

진 판 → ‘마을로’ → (이미 골라진) 올리기 버튼 한 번 → 출전으로, 권한 행동까지 탭 수가 하나 준다(표지 찾기·누르기가 빠짐). 다른 마을 동작은 그대로다.

## 수용 기준

- [x] 진 판 결과에서 ‘마을로’를 누르면 권한 건물이 골라진 채 열리고 ‘추천’ 띠가 보인다(스크린샷 직접 확인, 폰 가로)
- [x] 그 건물을 올리면 띠가 사라진다
- [x] 타이틀에서 들어온 마을은 전과 같다(띠 없음)
- [x] `test:rush`, `tsc`, `build`, `smoke:rush` 통과

## 결과

폰 가로(Pixel 7), 6스테이지를 열어 둔 저장(전투력 925, 식량 90·목재 40)으로 확인했다. 새 왕국은 권하는 것이 처음 골라지는 성과 같아 차이가 보이지 않기 때문이다.

| 순서 | 골라진 건물(카드) | ‘추천’ 띠 |
| --- | --- | --- |
| 타이틀 → 마을 | 성 | 없음 (전과 같음) |
| 2-1 패배 결과: ‘할 일: 금고 올리기 → 전투력 +60’ | — | — |
| ‘마을로’ | **금고** (카드에 금고와 올리기 버튼) | **금고** |
| 그 카드의 올리기 버튼 한 번 | 금고 | 없음 |

- 권한 행동까지: 전에는 ‘마을로’ → 금고 표지 찾아 누르기 → 올리기, 이제는 ‘마을로’ → 올리기. 탭 하나가 줄고, 무엇을 누를지 찾지 않아도 된다.
- 띠는 그것을 올릴 때까지 남는다(다른 건물을 눌러도). 영웅 훈련·특기를 권하면 영웅 칸이 골라지고 영웅 단추에 띠가 달린다. 이 경우는 코드 경로만 확인했고 브라우저에서 따로 재현하지 않았다.
- 결과 화면을 거치지 않은 진입(타이틀 → 마을), 끝없는 도전 결과, ‘다시 하기’는 바뀌지 않는다.
- ‘추천’ 두 글자가 글꼴 부분 집합에 더해졌다(513 → 514자, 81,580 → 81,676바이트).
