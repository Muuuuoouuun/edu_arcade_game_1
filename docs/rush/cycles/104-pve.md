## 문제

눈 지역(6~10스테이지) 길목에는 빙판이 있다. 영웅은 빙판에서 1.2배 빨리 달리고, 밀려난 적은 1.6배 더 미끄러진다. 그런데 적이 빙판을 걷는 배수(`ZONE.iceSpeed`)는 1이다. 예전 원정 캠페인은 1.25였다. 맵 작업 때 ‘봇 밸런스 시험이 칼날 위라 1.0001만 바꿔도 시드 몇 개가 뒤집힌다’며 다음 밸런스 점검으로 미뤄 두었다. 그래서 지금 빙판은 적에게는 장식이다.

백로그의 나머지 절반(10스테이지·끝없는 도전의 서리늑대, 기둥 시험의 ‘다 키운 왕국’ 정의 바꾸기)은 기둥 시험 자체를 바꾸는 일이라 사용자 결정으로 남긴다. 이번에는 기둥 시험을 그대로 둔 채 할 수 있는 빙판만 본다.

## 범위

- **측정 먼저**: `tools/rush-ice-sweep.ts`. 빙판 배수 후보(1, 1.1, 1.15, 1.25)마다 기둥 시험이 보는 값을 그대로 잰다.
  - 다 키운 왕국의 10스테이지 승수(궁수, 시드 1~8, 6 이상)
  - 브론 다 키운 왕국 10스테이지(시드 1·2 승)
  - 영웅 훈련(세 영웅, 7·8스테이지 Lv1 대 Lv10 승수 차 3 이상, Lv10 혼자 10스테이지 시드 1~4 모두 짐)
- 기둥을 모두 지키는 가장 큰 값을 고르고, 눈 스테이지(6~10) 권장 전투력을 다시 재 `STAGE_POWER`에 반영한다. 캠페인 도구로 멈춤이 없는지 본다.
- 어느 후보도 기둥을 지키지 못하면 바꾸지 않고 표와 이유를 남긴다.

## 가설

빙판은 길목 몇 칸뿐이라, 1.1~1.15는 적이 마을에 닿는 시간을 1초 안팎 당길 뿐이다. 다 키운 왕국 승수는 6/8 근처에서 흔들리겠지만 1.1은 지킬 것이다. 1.25는 깨질 수 있다.

## 결과

**가설은 틀렸다. 어떤 후보도 기둥을 다 지키지 못했고, 빙판 효과는 시드 흔들림에 묻혔다.**

**기둥 시험 값**(`tools/rush-ice-sweep.ts`, 기둥 시험과 같은 시드)

| 빙판 배수 | 다 키운 궁수 10스테이지 (≥ 6/8) | 다 키운 브론 (2/2) | 영웅 훈련 Lv1 → Lv10 (궁수·브론·눈곰), Lv10 혼자 10스테이지 | 기둥 |
| ---: | --- | --- | --- | --- |
| 1 (지금) | 6/8 | 2/2 | 0→4, 1→5, 1→12, 혼자 0 | 지킴 |
| 1.05 | **3/8** | **1/2** | 1→7, 1→6, 1→12, 눈곰 혼자 **1** | 깨짐 |
| 1.1 | 6/8 | **0/2** | 0→4, 2→7, 1→8, 혼자 0 | 깨짐 |
| 1.15 | **5/8** | 2/2 | 0→5, **4→5**, 1→11, 혼자 0 | 깨짐 |
| 1.25 | 6/8 | **0/2** | 0→6, 2→6, 2→11, 눈곰 혼자 **1** | 깨짐 |

값이 한 방향으로 움직이지 않는다(1.05가 1.1·1.25보다 나쁘다). 그래서 표본을 넓혔다.

**시드 40개로 넓혀 잰 10스테이지 승률**(`--wide=40`)

| 빙판 배수 | 다 키운 궁수 | 다 키운 브론 |
| ---: | ---: | ---: |
| 1 | 18/40 (45%) | 18/40 (45%) |
| 1.1 | 25/40 (63%) | 13/40 (33%) |
| 1.25 | 19/40 (48%) | 15/40 (38%) |

시드 40개에서 승률의 흔들림은 ±15%p쯤이다. 빙판 배수는 그 안에서 오르내린다. **빙판 배수가 마지막 스테이지를 어렵게 한다는 증거는 없다.** 기둥 시험이 시드 8개(브론은 2개)만 보니 어떤 규칙 변경이든 시드 몇 개가 뒤집혀 깨진다. 맵 작업 때 적은 ‘칼날 위’는 이것이다.

**대신 찾은 것: 기둥 시험의 시드 1~8이 운 좋은 표본이다.** 지금 규칙(빙판 1, 포효가 영웅을 3초 얼림)에서 시드 40개로 재면

| 왕국 (궁수) | 9스테이지 | 10스테이지 |
| --- | ---: | ---: |
| 성장 단계 L6 | 39/40 (98%) | 12/40 (30%) |
| 성장 단계 L7 (지금 10스테이지 권장 전투력 2,550) | — | 18/40 (45%) |
| 성장 단계 L8 | — | 34/40 (85%) |
| 다 키운 왕국 (영웅 Lv1) | — | 18/40 (45%) |

- 기둥 시험은 ‘다 키운 왕국이 10스테이지를 대부분 이긴다’를 시드 1~8의 6승(75%)으로 확인한다. 넓은 표본에서는 45%다.
- 권장 전투력은 ‘봇이 절반 넘게 이기는 단계’인데(89회차), 10스테이지 L7은 넓은 표본에서 45%로 절반에 못 미친다. L8은 85%다.
- 포효의 영웅 얼리기(99회차)를 바꾸면 (다 키운 왕국 / L6 / L7): 0초 63% / 68% / 73%, 2초 45% / 45% / 50%, 3초(지금) 45% / 30% / 45%. 3초 얼리기는 L6을 크게 떨어뜨려 마지막 스테이지에 성장 단계 하나를 더 요구하는 구실을 한다(99회차 의도대로). 다 키운 왕국(영웅 Lv1)은 얼리기가 없어도 63%라 원래부터 ‘대부분’에 못 미쳤다.

**바꾸지 않은 이유**: 빙판은 효과가 보이지 않는다. 마지막 스테이지 난이도와 기둥 시험의 표본·정의는 이 레인 혼자 정할 일이 아니라 사용자 결정으로 올린다(아래 백로그 1).

**도구**(저장소)
```
node --experimental-strip-types tools/rush-ice-sweep.ts 1 1.1 1.25            # 기둥 시험 값 (후보마다 약 35초)
node --experimental-strip-types tools/rush-ice-sweep.ts --wide=40 1 [--freeze=S]  # 시드 40개 승률 (후보마다 약 1분 30초)
```
