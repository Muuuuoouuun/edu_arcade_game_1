## 문제

영웅이 탑 자리·방벽 자리에서 1.8 m(`PAD_REACH`) 안에 들면 왼쪽 위에 짓기 알약이 뜨고, 벗어나면 사라진다. 143회차에 가장자리 깜빡임 가능성을 적었다. 막대는 아날로그라(데드존 6 px) 서 있으면 깜빡이지 않지만, 싸우며 자리 가장자리를 스치면 알약이 잠깐씩 뜬다.

측정(가드 봇, 스테이지 1·4·7 × 시드 1~6, 18판 46.7분, 스크래치패드 `reach.ts`): 알약 바뀜 분당 30.6번, 닿음 712번 중 **0.15초 미만 364번(51%)**, 0.15~0.3초 22번, 0.3~1초 164번, 1~3초 32번, 3초 이상 130번. 절반이 몇 프레임짜리 번쩍임이다. 봇은 사람보다 자리 근처를 많이 돌지만, 지나가며 스치는 일은 사람도 같다.

## 범위

- 화면에서만: 같은 자리에 0.2초 머물러야 알약을 보인다(`src/rush/reachGate.ts`, 게임 시간 기준). 자리가 바뀌거나 벗어나면 곧바로 숨긴다(누를 수 없는 알약을 남기지 않음).
- 시뮬레이션·짓기 규칙·E 키는 그대로(E는 닿자마자 짓는다). 봇·기둥 시험·밸런스 영향 없음.

## 가설

0.2초 미만 닿음(위 측정의 약 52%)이 화면에서 사라지고, 자리에 멈춰 짓는 흐름은 0.2초 늦게 알약이 뜨는 것 말고는 같다.

## 수용 기준

- [x] 시험: 0.2초 전에는 숨김, 뒤에는 보임, 자리가 바뀌면 다시 0.2초, 벗어나면 곧바로 숨김
- [x] 같은 봇 측정으로 화면에 뜨는 알약 횟수 전후
- [x] 스모크(짓기 알약 검사 포함), `test:rush`, `tsc`, `build` 통과

## 결과

같은 봇 18판(46.7분, 스크래치패드 `reach2.ts`):

| | 전 | 후(0.2초 문턱) |
| --- | ---: | ---: |
| 알약이 뜬 횟수 | 717 (분당 15.3) | **344 (분당 7.4)** |
| 그중 0.3초 안에 사라진 것 | (0.3초 미만 닿음 386) | 63 |

- **가설대로다.** 몇 프레임짜리 번쩍임이 화면에서 사라지고 알약이 뜨는 횟수가 절반 아래로 줄었다. 남은 0.3초 미만 63번은 0.2~0.5초 머문 닿음이다(지나가며 조금 오래 걸친 경우).
- `src/rush/reachGate.ts`(`ReachGate`, `REACH_SHOW = 0.2`): 게임 시간으로 같은 자리를 0.2초 지켜야 보인다. 일시정지·히트스톱 동안은 시간이 멈추므로 기다림도 멈춘다. 자리가 바뀌거나 벗어나면 곧바로 숨겨, 화면에 있는 알약은 늘 누를 수 있다.
- 시뮬레이션의 닿음 규칙과 E 키는 그대로라 봇·기둥 시험·밸런스는 바뀌지 않는다. 자리에 멈춰 짓는 사람에게는 알약이 0.2초 늦게 뜬다.
- 알약 모양은 그대로라 새 스크린샷 비교는 하지 않았다. 스모크의 ‘탑 자리에서 짓기 단추가 뜸’·‘E로 짓기’·‘갈래 고르기’ 검사가 통과했다.
