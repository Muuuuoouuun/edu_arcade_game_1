# 적 대 바닥 대비 기준표

적이 바닥에서 얼마나 튀어 보이는지 잰 값. 마지막으로 잰 때: **123회차(2026-11-15)**, 커밋 `4a9e25f` 뒤 빌드.

## 무엇을 재나

- **튀는 몫**: 적 몸 화소 가운데 바로 아래 바닥 색과 CIELAB ΔE 30 이상 다른 화소의 비율. 외곽선(L < 20)은 뺀다.
- **몸 영역**: 적을 빛 없는 자홍으로 그린 마스크 프레임(`__rush.maskMode`)의 자홍 화소(114회차). 바닥과 같은 색인 부위도 몸에 든다.
- **몸 색**: 적 그림자·발밑 얼룩·바닥 고리를 끈 프레임(`__rush.bodyOnly`, 109회차).
- **같은 프레임 맞춤**: 세계 자세 멈춤(`__rush.holdPose`)과 카메라 붙임(`__rush.snapCamera`)(120회차). 같은 장면을 두 번 찍은 차이는 1 이하다. **2 넘게 달라지면 색 변화로 읽는다.**
- 높음 품질, 휴대폰 가로(Pixel 7), 소프트웨어 GL, 움직임 줄이기.

## 쓰는 법

```
npx vite --port 3150 --strictPort      # 따로 띄워 둔다
node tools/rush-contrast.cjs <outDir>  # ONLY=s7mid,s8mid 처럼 장면을 줄일 수 있다(전체 26장면, 둘로 나눠 병렬로 약 10분)
python3 tools/rush-contrast.py <outDir> s2 s3 s7 s8 s2mid s3mid s7mid s8mid
```
`SHAPE` 줄이 이 표의 값이다(`stands out` = 얼지 않음, `frosted` = 얼림, `warded` = 막).

## 판단선

- **70% 아래**는 살펴본다(굵게). 바닥과 같은 색인 부위가 몸의 3할을 넘는다는 뜻이다.
- 겨울 차림의 흰 털처럼 일부러 밝은 부위가 있으면, 섞이는 화소 그림(117회차 방법)으로 원인을 본 뒤 정한다.

## 장면

- **길 줄**: 마을 앞 길(z 1.5). **풀밭 줄**: 마을 앞 풀밭(z −0.6). 영웅이 마을 앞에 있어 카메라가 마을 쪽으로 당겨진 시점이라 적이 화면 위쪽이다.
- **가운데 줄**: 들판 가운데(z −8), 영웅은 3.5 m 남쪽(106회차). 실제로 싸우는 자리.
- 적 7종을 2.5 m 간격으로 한 줄에 세운다. 보스(기본 모양)는 줄 끝.
