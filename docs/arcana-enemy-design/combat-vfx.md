# Arcana 적·보스 전투 연출 설계 검토

검토 기준: `edu_arcade_game_1` main `6569da1`, 2026-11-09. **아래 제안은 설계이며 런타임 변경·성능 실측이 아니다.** 현재 기능, 표현 개선, 새 규칙을 구분한다.

## 1. 현재 구현의 경계

- 영웅·용병·펫·타워에는 HP가 없다. `CombatAttack`의 공격자는 이 네 종류뿐이다. 적은 경로를 따라 마을로 이동하고 끝에 도달하면 제거되며 일반 적은 마을 HP 1, 보스는 8을 깎는다. 적의 칼·주먹·발톱은 **마을 돌파 연출**로 해석해야 한다. 영웅 피격, 타워 파괴, 적의 원거리 탄환은 새 시스템 없이는 구현된 기능처럼 표현하지 않는다.
- 고목왕은 HP가 절반 미만이면 즉시 이동속도 ×1.55. 별도 시전 시간·근접 공격·돌진 충돌 피해는 없다.
- 서리군주는 경로 진행 220 이후 주기 조건을 만족하면 **2.5초 정지 충전 → 타워 2초 동결**. 충전 중 어떤 영웅의 필살기를 써도 거리와 무관하게 차단하고 다음 주기를 9초로 재설정한다. 동결 중 영웅·용병·펫과 이미 발사된 투사체는 계속 작동한다.
- 보스 돌파 즉시 패배는 새 게임 규칙의 **결정/제안**이다. 현재 엔진은 보스가 돌파해도 마을 HP가 남으면 웨이브를 완료할 수 있다.
- 일반 적 6종은 Blender 렌더 3프레임(`walk-a`, `walk-b`, `hit`)을 사용한다. 새싹 도적은 기본 아틀라스 단일 이미지 변형이다. **일반 적 사망은 hit 포즈 재사용**이다. 두 보스는 기본·charge·hit·death의 전용 4포즈가 있다. 현재 적의 독립적인 공격 클립은 없다.

근거: `src/games/defense/{data.ts,engine.ts,art.ts,DefenseBoard.tsx,DefenseEffects.tsx}`. 특히 engine의 `elementMultiplier`, `reapEnemies`, `useHeroSkill`, 충전/동결 갱신 및 경로 끝 처리, art의 `monsterSpriteAsset` 포즈 매핑.

## 2. 기본 7종 + 보스 2종

HP/속도는 데이터의 기본값이며 실전에서는 스테이지·웨이브·난이도 보정이 붙는다. 아래 실루엣과 움직임은 제작 방향이다.

전기 연쇄는 금속 또는 젖은 비절연 대상에서 가까운 다음 대상으로 이어지고 후속 피해는 0.85배다. 최소한의 속성 이해는 적 도감의 한 줄과 전투 반응으로 전달한다. 퀴즈·계산 입력을 끼워 넣지 않는다.

## 3. 행동과 시각 신호의 계약

**시간과 판정의 주인은 엔진이다.** 새 프레임 수, 애니메이션 길이, 화면 크기, 저사양 모드 때문에 이동·피해·보상·동결 시간이 달라지면 안 된다.

| 행동 | 예고 → 모션 → 판정 순간 → 회복 | 대응과 구현 구분 |
|---|---|---|
| 일반 이동 | 경로 방향을 향함 → 진행 거리에 맞춰 보행 → 위치는 엔진 경로 계산 → 반복 | 기존 기능. 보행 시각 단계가 이동을 밀거나 멈추지 않음 |
| 피격 | 별도 예고 없음 → 0.10~0.18초 국소 기울기·재질 섬광 → 피해는 기존 타격 이벤트 순간 → 보행 복귀 | 시간 범위는 표현 제안. 추가 경직 없음. 실제 넉백만 기존 질량/힘/감쇠 사용 |
| 일반 적 돌파 | 출구/방어선이 상시 표시됨 → 도달 시 칼 휘두름·몸통 박치기 잔상 → **도달 그 프레임에 HP−1/제거** → 0.20~0.35초 잔상 소멸 | 공격 자세는 새 표현. 공격 대상을 마을 문/방어선으로 고정. 살아 있는 적을 도착 뒤 붙잡아 두거나 피해를 애니메이션 끝으로 늦추지 않음 |
| 보스 돌파 | 보스 경로·출구 위험을 명확히 표시 → 큰 문 충격/실루엣 잔상 → 현재 HP−8/제거 → 결과 UI | 현재와 새 ‘보스 돌파 패배’ 규칙을 혼용하지 않음. 새 패배 규칙 적용 때 판정·문구·재시도까지 함께 변경 |
| 고목왕 분노 | HP 절반 경계가 힌트 → 상체를 낮추고 나무껍질 균열/앞 방향 화살표 → **절반 미만 즉시 가속** → 계속 분노 보행 | 0.25초 자세 전환은 표현 제안이며 이동 중 수행. 가상의 시전 대기나 돌진 충돌 피해를 넣지 않음. 대응: 남은 경로와 감속·불 화력 활용 |
| 서리군주 충전 | 0.00초 지면 문양+상단 문구·2.5초 게이지 → 0~0.6초 들어 올림, 0.6~2.1초 응집, 2.1~2.5초 수축 → **2.5초에 타워 동결 2초** → 약 0.35초 자세 회복 | 구간별 자세는 표현 제안. 충전 전체 정지는 기존 기능. 마지막 순간까지 필살기 차단 가능해야 함. 판정 프레임의 입력 우선순위는 기존 엔진을 따름 |
| 서리군주 차단 | 필살기 입력 → 기존 interrupt 사건에서 문양 파쇄 → **즉시 충전 취소·주기 9초 재설정** → 보행 복귀 | 모든 영웅 필살기로 글로벌 차단. 영웅과 보스 사이 거리를 조건처럼 그리지 않음. 효과 범위를 암시하는 공격 원을 추가하지 않음 |
| 동결 | 충전 성공 → 각 타워에 얼음 고리·눈송이·남은 시간 → 타워 발사만 2초 차단 → 녹는 외곽선 | 기존 기능. 움직이는 영웅/펫과 날아가는 탄환을 얼리지 않음 |
| 사망 | HP 0 → 즉시 대상 제거·보상 확정 → 기존 0.7초 사망 표현 → 소멸 | 일반 적 전용 death 포즈를 추가하는 것이 제작 우선순위. 사망 애니메이션이 끝나야 보상 지급되도록 바꾸지 않음 |

공격 자세의 종별 어휘: 새싹은 어깨 들이받기, 나무는 가지 내려치기, 얼음은 방패 밀기, 돌은 주먹 내리찍기, 금속은 팔뚝 밀기, 슬라임은 눌렸다 튀는 충돌, 늑대는 짧은 도약. **전부 출구 돌파 표현이며 영웅과의 근접 전투를 새로 만들지 않는다.**

## 4. 이펙트 우선순위와 모바일 예산

현재: 엔진 effects 최대 100, 장식 파편 렌더 최대 64, 최근 20개 효과만 상세 장식, 투사체 최근 24개만 상세 장식. 일반 hit 기본 0.4초, death 0.7초, breach 0.6초. 효과는 시뮬레이션 시간에 종속된다. 보스 충전 문구/지속 링은 일회성 effects 목록과 분리되어 있다.

권장 순서:
1. **필수:** 보스 충전/차단·동결, 출구 위험, HP/상태 정보. 장식 제한에 의해 제거하지 않는다.
2. **전투 판독:** 실제 타격 코어·투사체 경로·연쇄 연결·젖음/연소/감속 표시.
3. **장식:** 먼지·작은 파편·잔상·코인 반짝임. 과밀 시 먼저 줄인다.

예산 제안(실측 전 목표): 저사양 장식 파편 24~32개, 기본 64개 유지, 큰 국소 타격 섬광 동시 1개(전체 화면 섬광은 추가하지 않음). 보스 충전 중 다른 장식의 불투명도를 낮춰 필수 신호를 보존한다. 이것은 최적화 제안이지 측정된 보장값이 아니다. 엔진의 총 100개 효과 제한은 오래된 필수 이벤트도 밀어낼 수 있으므로 새 이벤트가 많아질 경우 중요도별 보존 또는 별도 지속 상태로 분리할 필요가 있다.

색만으로 구분하지 않는다: 불=주황 불꽃, 물/젖음=청록 물방울, 전기=황백 지그재그, 충격=황토 쐐기/돌 파편, 서리 동결=옅은 파랑 육각 결정, 차단=끊어진 육각 고리. 적의 빨강 경고는 적색 외곽선+날카로운 문양을 함께 사용한다. 고목왕 분노는 전방 화살표와 낮은 자세로도 보이게 한다. 청록 물과 파란 동결을 도형·아이콘으로 분리한다.

화면 흔들림은 선택적이며 터치 좌표·카메라 판정에 영향을 주지 않는다. reduced-motion은 보행 흔들림·회전·파편을 줄여도 타이머, 상태 아이콘, 공격 판정 코어를 남긴다. 전역 동결을 좁은 원형 범위 공격처럼 표현하지 않는다.

## 5. 차기 엘리트 2종: 우선 외형 변형으로만

- **고목 근위병:** wood 기반, 넓은 가지 어깨·금이 간 목재 방패. 현재 wood의 보행/상성/판정을 재사용하는 외형 시안. 실제 방패 흡수·투사체 반사는 미정 새 기능이다.
- **빙관 추적자:** frostwolf 기반, 비대칭 등 결정·흰 꼬리 끝. 현재 wolf의 보행/상성/판정을 재사용하는 외형 시안. 추가 소환·점멸·영웅 물기는 넣지 않는다.

별도 적 ID, 엘리트 능력, 보상 배율이 필요하면 출현 웨이브·체력·속도·보상·예고 시간을 먼저 확정하고 별도 구현 범위로 다룬다.

## 6. 제작·검증 순서

1. 현재 9종 실루엣/바닥 접점/그림자와 세로 모바일 48~64px 축소 판독을 먼저 맞춘다.
2. 일반 6종 death 포즈와 새싹 walk/hit/death를 보강한다. 보스 4포즈는 무기·손·왕관이 잘리지 않고 동일 월드 스케일을 유지한다.
3. 돌파 잔상, 고목왕 가속 상태, 서리군주 충전 타이밍을 실제 사건에 연결한다. 영웅 피격을 암시하는 시연은 제외한다.
4. 일시정지·1배/2배속·reduced-motion·세로 좁은 화면에서 보스 2.5초/동결 2초 의미와 상태 표시를 확인한다.
5. 여러 타격이 같은 적을 처치해도 사망·보상 중복이 없어야 하며 죽은 적의 잔상은 타격 대상이 아니어야 한다. 빙결 타워의 발사 대기와 이미 비행 중인 탄환을 따로 검증한다.
6. 적 밀집·연쇄·연소·보스 충전이 겹치는 장면을 실제 Android 기기에서 측정한 뒤 파편 예산을 조정한다. 이번 문서는 측정 결과를 포함하지 않는다.
