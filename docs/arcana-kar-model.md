## 컨셉과 선택

실제로 연 `public/defense/snow-atlas.png`의 첫 인물과 `art-source/defense/atlases/melee-motion.png` 첫 줄, PC/모바일 전투 화면을 비교했다. 카르는 붉은 머리·땋은 수염·흰 털망토·붉은 앞치마·커다란 전투 망치를 가진 전사다. 기존 공격은 삽화 세 장과 좌우 반전을 사용해 자세마다 몸 크기가 달라지고, 위아래 표적에 같은 방향의 몸을 보였다. 다른 다섯 영웅과 서리늑대의 완료된 모델을 반복하지 않고 **카르의 첫 실제 모델과 방향별 동작**을 선택했다.

투구·방패·청록 강철 갑옷의 브론과 구분되도록 열린 얼굴, 솟은 붉은 머리, 흰 털 덩어리와 길게 벌어진 망토, 붉은 앞치마, 태양 문양의 철/황동 망치를 제작했다. 작은 화면에서 머리·망토·무기를 먼저 읽도록 원본의 촘촘한 장식을 단순화했다. 이미지 평면·색만 바꾼 기존 영웅 모델을 사용하지 않았다.

## 실제 움직임과 전투 연결

11개 변환 노드가 몸·머리·수염·망토·망치·두 발·팔 분절을 움직인다. 손은 망치 손잡이의 두 그립에 붙어 있고 팔 분절이 어깨에서 그립까지 연결된다. 강체 관절과 계산한 연결점이며, 고정 길이 뼈대/스킨 IK는 아니다.

- **공격:** 0.56초. 중립→몸 낮추기→들어 올리기→정점→0.28초 타격→반동→회수→정리. 발은 고정하고 몸이 무게를 받으며 수염·망토가 뒤따른다. 8방향×8포즈를 같은 카메라·배율로 렌더한다.
- **보행:** 0.8초, 8방향×8포즈. 두 손의 그립을 유지하고 두 발을 번갈아 내딛는다. 실제 누적 이동 거리로 진행하며 정지는 같은 몸의 중립 자세로 돌아간다.
- **전투:** 영웅·용병, 대시·필살기 표시에서도 같은 모델을 유지한다. 필살기 피해 규칙이나 대시 물리는 변경하지 않았으며 필살기 전용 새 클립을 제작한 것은 아니다. 캠프 초상화는 기존 컨셉을 유지한다.
- **타격 궤적:** 실제 망치 중심을 정점부터 타격까지 7회 투영해 짧은 잔상을 표시한다. 모델이 준비되면 기존 큰 삽화용 곡선을 숨기고, 실제 표적 위치의 충격 효과는 유지한다. 이동·승급·모바일 배율에도 궤적이 표시된 망치와 같은 크기를 따른다.
- **접근성/실패:** 동작 줄이기는 중립/타격 포즈를 사용한다. 공격·보행 16장 중 하나라도 실패하면 카르 전체가 기존 삽화로 돌아간다. 다른 영웅이나 동료의 준비 상태에는 영향을 주지 않는다.

Claude 47회차의 화면 게시 주기 분석과 같은 조건으로 새 동작을 검사했다. 브론의 표시 구간을 그대로 사용하면 2배속/30Hz의 일부 시작 위상에서 타격 프레임을 건너뛰었다. 실패를 재현한 뒤 카르의 접촉 표시를 **0.28~0.35초, 0.07초**로 확보했다. 피해는 기존 0.28초에 발생한다. 벽시계 정지나 판정 지연을 추가하지 않았고 모든 포즈가 모든 저속 기기에서 보인다고 보장하지 않는다.

## 원본과 재생성

```sh
npm run models:barbarian
npm run models:barbarian -- --check
npm run models:barbarian -- --preview --samples 24
```

Blender 4.3.2·ffmpeg를 사용하며 기본은 Cycles CPU 64 samples다. `--check`는 출력물을 바꾸지 않고 8방향 포즈 경계를 검사한다. `--preview`는 앞쪽 두 방향을 `/tmp/arcana-kar-preview-*.png`에 렌더하고 전체 경계를 검사한다.

| 산출물 | 경로/규격 |
| --- | --- |
| 생성 코드 | `tools/blender/build_barbarian.py` |
| 편집 원본 | `art-source/defense/kar-barbarian.blend`, `kar-barbarian-walk.blend` |
| 실제 클립 | `public/defense/models/kar-barbarian.glb`의 `kar-slam`(0.56초), `kar-barbarian-walk.glb`의 `kar-walk`(0.8초) |
| 공통 카메라 렌더 | `art-source/defense/kar-barbarian/`, 128 PNG, 384×384 |
| 전투 베이크 | `public/defense/models/kar-{slam,walk}-{0..7}-atlas.webp`, 16장, 각각 2048×256 |
| 미리보기·규격 | 같은 폴더의 `kar-barbarian*.png`, `kar-barbarian.json` |
| 생성된 궤적 | `src/games/defense/karHammerTrail.ts` |

기존 영웅과 같은 카메라 `(7,10,7)`, 목표 `(0,0,1.7)`, 정사영 크기 6.8을 사용한다. 원본 지면 `(192,330)`, 배포 지면 `(128,220)`과 포즈별 공통 배율을 유지한다. 메타데이터에 기준 이미지 해시·클립·방향·경계·망치 중심/궤적·출력 해시를 기록한다. 초기 미리보기에서 남쪽으로 향한 망치가 잘려, 카메라나 포즈별 크기를 바꾸지 않고 타격 도달 거리를 조정했다.

각 GLB는 **20,432 삼각형·41메시·13재질**이다. 공격 1,273,268바이트, 보행 1,281,724바이트이며 편집 원본은 각각 2,828,664 / 2,999,736바이트다. 전투 WebP 합계는 **795,234바이트**, 추가 RGBA 디코딩 규모는 약 **32MiB**다. 실제 Android GPU 메모리 측정값은 아니다. 전투는 베이크 기반 2.5D를 유지하고 GLB를 요청하지 않는다. 작업실은 기존 단일 3D 장면에서 모델을 교체한다.

- 동일 조건의 전후 화면과 실제 모바일 기본 확대 화면을 열어 비교했다. 작업실 PC/모바일에서 GLB 공격·보행 재생/정지, 회전·와이어프레임·동작 줄이기·다운로드 및 GLB 실패 시 PNG 대체를 확인했다. 예상 밖 페이지 오류·가로 넘침·전투 GLB 요청이 없었다. 22개 산출물 해시와 128개 WebP 프레임의 알파/경계도 통과했다.
