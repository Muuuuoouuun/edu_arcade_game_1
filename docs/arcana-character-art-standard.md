# 아르카나 전체 모드의 캐릭터·3D 스타일 기준

**2026-11-13 사용자 확정:** [승인 스틸컷 기반 제작 기준](arcana-approved-visual-standard.md)을 최우선 시각 기준으로 적용합니다. 전투 4장과 생산·타워 2장의 캐릭터·입체 지형·재질·조명·UI 형태를 이후 제작에 유지합니다. 기존 런타임의 단순한 모델이나 거친 외곽선은 목표 품질 기준이 아닙니다.

**최신 사용자 결정(2026-11-12): 게임 모드가 바뀌어도 전체 캐릭터 스타일과 3D 표현은, 확인한 Rush 계열의 브롤스타즈풍 캐릭터·입체 전장과 킹샷 느낌의 마을 형식을 공통으로 유지한다.** 마을 수비·원정·군단·훈련장에 모두 적용한다. 모드는 조작과 규칙을 구분하며, 미술 방향은 공유한다.

시각 기준은 **귀여운 3D 캐릭터, 두툼한 형태, 선명한 색면, 툰 명암과 읽기 쉬운 질감 텍스처**다. 이 결정은 과거 반실사 방향과 기존 원정 아틀라스를 최우선으로 삼았던 지침보다 우선한다. 현재 Rush의 단순한 임시 적·건물이나 미완성 텍스처를 최종 품질 기준으로 고정하는 뜻은 아니다.

## 참조 우선순위

1. [Rush 렌더 톤 기준](rush/art-direction.md)과 실제 도마뱀 궁수·드워프·눈곰 모델: 두툼한 비율, 큰 머리·손·무기, 색면·명암·외곽선과 실제 게임 크기의 가독성을 우선한다.
2. Rush의 입체 전장·마을과 Frontier의 높낮이·절벽·강·다리: 공간 구성과 실제 3D 형태를 참고한다. Frontier 자산도 공통 색감·재질·조명에 맞춰 사용한다.
3. [기본 아틀라스](../public/defense/atlas.png), [키아트](../public/defense/arcana-keyart.webp), 기존 카르·영웅 모델: 인물·문화권·무기 정체성과 제작 원본을 보존한다. 기존 비율·재질·카메라가 새 공통 스타일과 다르면 조정한다.
4. [테마별 시안](../art-source/defense/concepts/2026-11-12-characters/README.md)과 보정판: 종족·복식·무기 아이디어를 참고하며, 새 모델은 공통 3D 기준으로 검수한다.

## 모드 전체에서 공유할 기준

| 영역 | 공통으로 유지 | 모드에 맞춰 조정 가능 |
| --- | --- | --- |
| 캐릭터 | 같은 인물의 모델·비율·실루엣·의상·무기·색·재질 | 편성 수, 행동과 스킬, 화면 크기에 따른 LOD |
| 환경 | 실제 입체 지형, 건축 비율, 두툼한 모서리, 높낮이와 접지 | 맵 구조, 경로, 건설점, 지역별 기후·소품 |
| 재질·텍스처 | 툰 명암, 재료별 표면 구분, 무늬의 크기와 대비 | 지역별 색과 재료, 손상·상태 표현 |
| 조명·렌더 | 명암 단계, 외곽선 인상, 그림자·색감·효과의 표현 방식 | 가독성을 유지하는 지역 조명과 성능 단계 |
| 3D 크기·카메라 | 인물·무기·건물의 상대 크기, 전방 축·발 기준점, 읽기 쉬운 입체감 | 전투 범위에 따른 줌·추적·화면 배치 |

좌표 단위가 다른 엔진은 변환 계수로 상대 크기와 접지를 맞춘다. FOV·카메라 거리·외곽선의 원시 수치를 모든 모드에 그대로 복사하는 대신, 같은 캐릭터를 같은 화면 크기로 비교해 같은 인상을 유지한다. 구체적인 공통 수치는 비교 검증 후 확정하며, 기존 렌더러의 값이 이미 통일되어 있다는 뜻은 아니다.

기존 자산도 교체·개선 시 이 기준에 맞춘다. 통합 검수에는 동일 캐릭터의 마을·원정·군단·훈련장 비교를 포함한다. 모드별 저장·재화·승패 규칙의 통합 여부는 이 미술 결정과 별개다.

## 제작 목표

아래 수치는 원본 메시의 실측값이 아닌 시안 제작 가이드다. 실제 모델의 체형·종족에 맞춰 조정하고 기본 영웅과 나란히 비교한다.

| 요소 | 공통 기준 | 테마에 따른 변화 |
| --- | --- | --- |
| 비율 | 모자·뿔·무기를 제외한 정수리부터 발바닥까지 약 2.5~3등신. 큰 머리, 짧은 목·몸통·팔다리, 넓은 손·발 | 체격·귀·주둥이·꼬리·등껍질 등 종족 특징 |
| 얼굴 | 작은 화면에서 읽히는 눈·눈썹·코·입, 큰 머리 형태. 성인 인물의 성격 유지 | 표정·머리 모양·종족 특징 |
| 실루엣 | 얼굴, 몸통, 손과 무기를 분리해 읽을 수 있는 큰 형태. 무기 끝·발이 잘리지 않는 전신 | 주무기·망토·방패·배낭 형태 |
| 금속 | 둥근 모서리와 넓고 절제된 밝은 면, 큰 판과 결합부 | 청동·강철·칠한 금속·상징 문양 |
| 천·가죽 | 천은 큰 무광 주름, 가죽은 굵은 봉제와 넓은 접힘. 작은 무늬 반복을 줄임 | 색·복식·큰 테두리 문양 |
| 목재·털·석재 | 굵은 나뭇결, 덩어리로 묶인 털, 적은 수의 큰 석재 면과 균열 | 지역의 재료·종족 표면 |
| 색·효과 | 선명한 주색과 보조색, 소량의 속성 강조색. 얼굴·손·무기 경계 보존 | 숲의 녹색, 동방의 먹청·주홍, 설산의 청백, 군도의 청록, 황혼의 자주 |

사진 같은 피부·촘촘한 섬유·미세 자수·작은 장식의 과밀을 줄이고, 입체적인 손그림 판타지 재질로 통일한다. 기본 캐릭터의 표면 구분을 유지하면서 플라스틱처럼 균일한 광택도 피한다.

## 질감 텍스처와 게임 환경의 통합 기준

- 귀여움은 큰 머리·둥근 윤곽·읽기 쉬운 표정으로 전달한다. 전투 역할은 무기·체형·색 배치로 구분하고, 얼굴과 무기보다 표면 무늬가 먼저 보이지 않게 한다.
- 천·가죽·목재·금속·석재는 색뿐 아니라 거칠기와 넓은 명암으로 구분한다. 천은 무광의 큰 주름, 가죽은 봉제선, 목재는 굵은 결, 금속은 제한된 가장자리 반사, 석재는 큰 면과 얕은 균열을 사용한다.
- 캐릭터·포탑·성문·마을 건물에 같은 손그림 질감의 크기와 조명을 적용한다. 전장 바닥은 캐릭터보다 대비를 낮춰 이동 경로와 공격 예고가 보이게 한다.
- 실제 GLB 전달에는 UV와 base-color 텍스처를 확인하고, 필요한 roughness/normal 맵을 연결한다. 색 텍스처는 sRGB, 거칠기·법선 맵은 데이터 색 공간으로 처리한다. Blender 절차형 재질은 GLB 내보내기 전에 필요한 맵으로 베이크한다.
- 모바일 제작의 시작 예산은 캐릭터당 공유 재질 2~4개와 1024² base-color 한 장이다. 실제 전장 크기에서 결·얼굴·무기가 읽히는지 확인한 뒤 조정하며, 이는 현재 모든 모델의 달성 수치가 아니다.
- 새 텍스처 적용 후에는 같은 카메라·조명의 기본 영웅과 비교하고, 숲·설산 및 모바일 가로 화면에서 무늬 깜박임·UV 이음새·검은 재질·과도한 광택을 점검한다. 모델이나 텍스처 로딩 실패 시 기존 대체 표시도 유지한다.

최초 브랜치 통합은 기존 3D 모델·재질·컨셉을 연결했다. 이후 [공통 캐릭터 제작본 01](arcana-character-production-20261112.md)에서 도마뱀 궁수·브론·눈곰 포포의 새 텍스처와 호흡·보행·공격을 Rush와 작업실에 적용했다. 모든 캐릭터·모드의 교체가 끝난 것은 아니며, 컨셉 이미지 보존과 런타임 적용 범위를 구분한다.

## 비교 자료와 다음 검증

[기본 테마 보정판 5장](../art-source/defense/concepts/2026-11-12-characters/base-theme-v2/README.md)은 최초 시안과 동일한 `1-A`~`5-D` 후보를 다시 표현한 이미지다. 새 이름·전투 역할·지역 해금의 확정이나 실제 3D 제작 완료를 의미하지 않는다.

선택 이후 같은 카메라와 바닥선에서 기본 영웅 옆에 배치하고, 실제 전장 표시 크기의 얼굴·속성·무기 가독성을 확인한다. 모델링 단계에서는 측면·후면, 손과 손잡이의 분리, 공격 중 장비 간섭, 발 접지, 기본 영웅과의 체급을 확인한다. 현재 이미지는 이 실기 검증을 대체하지 않는다.
