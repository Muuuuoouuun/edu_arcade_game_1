# 아르카나 캐릭터 비율·질감 기준

2026-11-12 사용자 요청: “캐릭터 비율, 질감은 기본 캐릭터 기본테마에 맞게”. 신규 캐릭터의 문화권·종족·의상·무기는 다양하게 제안하되, 기존 영웅과 같은 게임에 속하는 비율과 재질 표현을 사용한다.

후속 통합 요청의 시각 기준은 **“아르카나 수비대, 디펜스 — 3D 귀여운 그림체의 캐릭터들 그리고 질감 텍스처”**다. 원정·마을·군단·훈련장의 새 자산은 아래 비율과 재질 기준을 공유한다. 과거 문서의 반실사 방향보다 이 기준을 우선하며, 기존 모델·컨셉 원본은 제작 참고로 보존한다.

## 참조 우선순위

1. [기본 아틀라스](../public/defense/atlas.png)의 맨 위 영웅 4명: 얼굴 크기, 몸통·팔다리 비율, 손·발·무기의 강조, 색면과 재질 표현의 우선 기준이다. 아틀라스를 미술 참고로 사용하는 것이며 2D 전장으로 되돌리는 뜻은 아니다.
2. [기본 키아트](../public/defense/arcana-keyart.webp): 청록·녹색·아이보리·따뜻한 금속색, 판타지 세계의 재질과 분위기를 참고한다. 키아트의 구도와 인체 비율보다 전투용 아틀라스 비율을 우선한다.
3. 기존 드워프·카르 모델: 큰 손·발과 무기의 입체 덩어리, 관절과 손잡이 공간을 참고한다. 기존 모델은 보존한다.
4. [테마별 최초 시안](../art-source/defense/concepts/2026-11-12-characters/README.md): 종족·문화권·복식·무기 아이디어를 보존한다. 새 제작의 비율·질감 기준은 아래 보정판을 사용한다.

## 제작 목표

아래 수치는 원본 메시의 실측값이 아닌 시안 제작 가이드다. 실제 모델의 체형·종족에 맞춰 조정하고 기본 영웅과 나란히 비교한다.

| 요소 | 공통 기준 | 테마에 따른 변화 |
| --- | --- | --- |
| 비율 | 모자·뿔·무기를 제외한 정수리부터 발바닥까지 약 2.5~3등신. 큰 머리, 짧은 목·몸통·팔다리, 넓은 손·발 | 체격·귀·주둥이·꼬리·등껍질 등 종족 특징 |
| 얼굴 | 작은 화면에서 읽히는 눈·눈썹·코·입, 큰 머리 형태. 성인 인물의 성격 유지 | 표정·머리 모양·종족 특징 |
| 실루엣 | 얼굴, 몸통, 손과 무기를 분리해 읽을 수 있는 큰 형태. 무기 끝·발이 잘리지 않는 전신 | 주무기·망토·방패·배낭 형태 |
| 금속 | 둥근 모서리와 넓고 절제된 밝은 면, 큰 판과 결합부 | 청동·강철·칠한 금속·상징 문양 |
| 천·가죽 | 천은 큰 무광 주름, 가죽은 굵은 봉제와 넓은 접힘. 작은 무늬 반복을 줄임 | 색·복식·큰 테두리 문양 |
| 목재·털·석재 | 굵은 나뭇결, 덩어리로 묶인 털, 적은 수의 큰 석재 면과 균열 | 지역의 재료·종족 표면 |
| 색·효과 | 선명한 주색과 보조색, 소량의 속성 강조색. 얼굴·손·무기 경계 보존 | 숲의 녹색, 동방의 먹청·주홍, 설산의 청백, 군도의 청록, 황혼의 자주 |

사진 같은 피부·촘촘한 섬유·미세 자수·작은 장식의 과밀을 줄이고, 입체적인 손그림 판타지 재질로 통일한다. 기본 캐릭터의 표면 구분을 유지하면서 플라스틱처럼 균일한 광택도 피한다.

## 질감 텍스처와 게임 환경의 통합 기준

- 귀여움은 큰 머리·둥근 윤곽·읽기 쉬운 표정으로 전달한다. 전투 역할은 무기·체형·색 배치로 구분하고, 얼굴과 무기보다 표면 무늬가 먼저 보이지 않게 한다.
- 천·가죽·목재·금속·석재는 색뿐 아니라 거칠기와 넓은 명암으로 구분한다. 천은 무광의 큰 주름, 가죽은 봉제선, 목재는 굵은 결, 금속은 제한된 가장자리 반사, 석재는 큰 면과 얕은 균열을 사용한다.
- 캐릭터·포탑·성문·마을 건물에 같은 손그림 질감의 크기와 조명을 적용한다. 전장 바닥은 캐릭터보다 대비를 낮춰 이동 경로와 공격 예고가 보이게 한다.
- 실제 GLB 전달에는 UV와 base-color 텍스처를 확인하고, 필요한 roughness/normal 맵을 연결한다. 색 텍스처는 sRGB, 거칠기·법선 맵은 데이터 색 공간으로 처리한다. Blender 절차형 재질은 GLB 내보내기 전에 필요한 맵으로 베이크한다.
- 모바일 제작의 시작 예산은 캐릭터당 공유 재질 2~4개와 1024² base-color 한 장이다. 실제 전장 크기에서 결·얼굴·무기가 읽히는지 확인한 뒤 조정하며, 이는 현재 모든 모델의 달성 수치가 아니다.
- 새 텍스처 적용 후에는 같은 카메라·조명의 기본 영웅과 비교하고, 숲·설산 및 모바일 가로 화면에서 무늬 깜박임·UV 이음새·검은 재질·과도한 광택을 점검한다. 모델이나 텍스처 로딩 실패 시 기존 대체 표시도 유지한다.

이번 브랜치 통합은 기존 3D 모델·재질·컨셉을 연결한다. 새 텍스처를 모든 캐릭터에 제작·적용한 작업은 아니며, 컨셉 이미지 보존과 런타임 UV/텍스처 적용 완료를 구분한다.

## 비교 자료와 다음 검증

[기본 테마 보정판 5장](../art-source/defense/concepts/2026-11-12-characters/base-theme-v2/README.md)은 최초 시안과 동일한 `1-A`~`5-D` 후보를 다시 표현한 이미지다. 새 이름·전투 역할·지역 해금의 확정이나 실제 3D 제작 완료를 의미하지 않는다.

선택 이후 같은 카메라와 바닥선에서 기본 영웅 옆에 배치하고, 실제 전장 표시 크기의 얼굴·속성·무기 가독성을 확인한다. 모델링 단계에서는 측면·후면, 손과 손잡이의 분리, 공격 중 장비 간섭, 발 접지, 기본 영웅과의 체급을 확인한다. 현재 이미지는 이 실기 검증을 대체하지 않는다.
