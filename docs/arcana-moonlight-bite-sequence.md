## 컨셉과 이번 차이

실제로 연 `public/defense/snow-atlas.png`의 동료는 큰 귀·초록 눈·목장식을 가진 작은 은빛 늑대다. 기존 실제 모델의 이 특징은 유지했다. PC/모바일 전투의 기존 4포즈에서는 공격 시작부터 입을 크게 벌린 자세가 나오고, 같은 타격 자세를 유지한 뒤 복귀로 바로 넘어갔다. 이번에는 **몸을 낮춰 힘을 모으는 준비와 물기 이후의 반동·회수**를 실제 관절과 8단계 베이크로 확장했다.

새 몸통을 다시 만들거나 기본 보행을 반복한 작업이 아니다. 몸통·머리·턱·귀·꼬리·목장식의 실제 변환 곡선을 바꿨다. 몸을 최대 0.15 모델 단위 낮추고 준비 중 뒤로 0.14, 타격에서 앞으로 0.25 이동한다. 머리 기울기와 작은 비틀림, 최대 0.44rad의 턱 열림을 연결하고 꼬리·귀·목장식은 타격 뒤에도 반대쪽으로 움직였다가 회수한다. 주요 자세 사이에는 완만하게 시작하고 멈추는 보간을 사용한다. 네 발의 원본 좌표는 고정하고 다리 분절은 움직이는 몸통과 발을 연결한다.

`petBiteFrame`은 타격 전과 후의 구간을 공격 계약에 맞춰 정규화한다. 내부 단계 경계에는 작은 부동소수점 허용치를 두되 타격 전/후를 나누는 비교는 정확히 유지한다. 타격 이미지를 피해 시점보다 먼저 보여주지 않는다.

입의 접촉 표시는 타격 후 0.12초 동안만 존재한다. 이 구간 안에서도 타격과 반동의 입 위치가 다르므로 **현재 표시 포즈의 실제 입 소켓**을 사용한다. 동작 줄이기는 중립/타격만 표시하며 소켓도 같은 타격 포즈를 따른다. 물기 또는 보행 아틀라스가 하나라도 실패하면 기존 삽화 전체와 공통 궤적으로 돌아간다.

## 제작물과 재생성

```sh
npm run models:pet-wolf
npm run models:pet-wolf -- --check
npm run models:pet-wolf -- --preview
```

Blender 4.3.2, ffmpeg를 사용한다. 기본 렌더는 Cycles CPU 64 samples다. 실제 형태·움직임은 `.blend`/GLB, 전투는 같은 카메라에서 렌더한 2.5D다. 이미지 평면을 모델로 사용하거나 전투에 유닛별 WebGL 렌더러를 추가하지 않았다.

- 생성 코드: `tools/blender/build_pet_wolf.py`.
- 편집 원본: `art-source/defense/moonlight-wolf.blend`, `moonlight-wolf-walk.blend`.
- 실제 클립: `public/defense/models/moonlight-wolf.glb`의 `moonlight-bite`(0.41초), 보행 GLB의 `moonlight-walk`(0.8초).
- 공통 카메라 PNG: `art-source/defense/moonlight-wolf/`, 물기 64장+보행 64장, 384×384.
- 전투: `moonlight-bite-{0..7}-atlas.webp`, `moonlight-walk-{0..7}-atlas.webp`, 각각 2048×256의 8포즈.
- 규격·소켓·해시: `public/defense/models/moonlight-wolf.json`, 생성된 `src/games/defense/petWolfSockets.ts`.

공통 정사영 크기 6.8, 원본 지면 `(192,330)`, 배포 프레임 지면 `(128,220)`, 기존 표시 배율과 체형을 유지했다. 보행 WebP 8장의 해시가 기준과 같음을 확인했다. 픽셀이 같은 PNG 73장은 렌더 시각 메타데이터만 바뀌지 않도록 기준 바이트를 보존했다.

삼각형 20,712개·39메시·10재질은 동일하다. 물기 GLB는 1,351,196바이트다. 전투 WebP 16장 합계는 524,784바이트(종전 397,750)이며 전부 디코딩하면 RGBA 약 32MiB로 종전보다 8MiB 늘어난다. 실제 Android GPU 메모리 측정값은 아니다.

## 검증

저장소 밖 `/tmp/arcana-hourly-20261107-1040/`에 기준·소유권·범위·미완료 상태부터 구현·검증·전달을 기록했다. 임시 증거는 새 환경에서 사라질 수 있으므로 제작 원본·코드·규격은 저장소에 남긴다.

- 전체 테스트 **218개 중 217개 통과**, 기존 수학 `(3×7)÷5` 기대 4.2/실제 4 실패만 남았다. TypeScript/Vite 빌드 통과. 새 테스트는 기본/변형 공격 시간, 정확한 타격 경계, 중립 복귀, 일시정지 시 동일 입력, 동작 줄이기와 잘못된 시간 입력을 검사한다.
- 최초 단계 경계 테스트가 0.06초에서 부동소수점 오차를 발견했다. 내부 포즈 경계만 보정해 통과했으며 최초 실패 로그도 보존했다.

- 실제 Board 920조합(8방향×공격 시점 15개/보행 8단계×PC·모바일·동작 줄이기·물기 실패·보행 실패)을 확인했다. 입 표시의 화면 오차 최대 약 `0.00000833px`, 타격 전 표시나 전투 GLB 요청, 예상 밖 페이지 오류가 없었다.
