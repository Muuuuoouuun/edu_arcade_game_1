# 파쇄포 Lv.2 — 고정 기초와 쌍 완충 피스톤

2026-11-07 KST. 기준 `9375fd7f3322f1097bbe8bcc5163cc15600f67e4`, 브랜치 `codex/arcana-stage-experience-20261106`.

원격 main `2eabc76`, Claude `bf7c1c6`와 새 `97ef02c`(49회차)를 확인했다. Claude의 새 기획은 피격 반응을 필터 없이 변형으로 표현하자는 제안이며 이번 모델 범위와 충돌하지 않는다. PR #81의 번개 표적·연쇄 로직은 별도 작업이다. 서리늑대·여섯 영웅의 기본 방향별 동작과 완료된 포탑을 보존하고, 아직 정지 모델인 파쇄포 Lv.2를 선택했다. 임의 보행 위상에서 공격으로 이어지는 영웅 자세 보간은 별도 후속 단위다.

## 컨셉과 구현

[모듈 컨셉](../art-source/defense/concepts/2026-10-29/props/six-tower-modules.png)의 넓고 무거운 포신·금속 띠·고정 기초를 기준으로 검토했다. 기존 파쇄포의 현무암 포신, 붉은 문양, 돌 포탄 적재대를 유지한다. 전후 실제 화면에서 확인한 문제는 **포신은 고정된 채 기초 전체가 흔들리고, 포탄이 실제 포구에서 벗어나 출발한다는 점**이었다.

양옆에 고정 강철 완충통·황동 끝 고리·움직이는 피스톤·포신 연결대·갑판 받침을 실제 메시로 만들었다. 상부 포대와 적재대가 함께 8방향으로 조준하고, 발사 후에는 포신과 피스톤만 포신 축을 따라 후퇴·복귀한다. 석재/목재 기초와 붉은 문양은 고정된다. 반동 경로를 확보하기 위해 적재대를 뒤로 0.38 모델 단위 옮기고 틈에 있던 느슨한 돌 포탄 3개를 정리했다. 기본 `towers.blend`와 기존 정적 산출물은 덮어쓰지 않는다.

전투는 같은 모델의 준비·반동·복귀·정착 4포즈를 사용한다. 기존 발사 시점 0.28초, 이후 반동 0.24초와 피해 판정을 유지한다. 실제 GLB는 0.28초까지 준비 자세를 고정하고 0.29초에 최대 반동, 0.52초에 중립으로 돌아오는 0.52초 클립이다. 전투 베이크는 발사 직후 최대 반동 자세를 보여주며 각 후속 자세를 80ms 유지한다.

발사 섬광과 포탄 출발점은 **발사 순간 완전히 뻗은 포신의 포구**에 고정한다. 그 뒤로 포신만 밀리므로 섬광이 총신과 함께 뒤로 끌려가지 않는다. 충격 포탄의 발사 당시 방향·등급을 보존해 목표 이동·강화·판매 이후에도 출발점이 바뀌지 않는다. 화면상의 포구 오프셋은 착탄 때 0이 되며 충돌 좌표는 바꾸지 않는다.

기획·게임성에서는 기존 파쇄 분기의 범위 피해와 느린 포격 간격을 유지했다. 디자인·모델링의 주 작업은 무거운 포신과 장전대 사이의 분리, 실제 완충 구조다. 구조는 기존 2.5D 전투와 단일 3D 작업실을 유지하고 모바일에서는 전체/확대 화면의 실루엣과 반동을 검토한다. 필터나 유닛별 WebGL 렌더러는 추가하지 않는다.

## 산출물과 재생성

- 편집 원본: [crush-cannon-action.blend](../art-source/defense/crush-cannon-action.blend), 개별 메시·재질·베벨·실제 포신 관절.
- 실제 3D: [crush-cannon-action.glb](../public/defense/models/crush-cannon-action.glb), `crush-cannon-fire` 0.52초·1채널 클립, 1,124,892 bytes. 26,698 삼각형·25 메시/프리미티브·13 재질.
- 공통 카메라: [640×640 PNG](../public/defense/models/crush-cannon-action.png), [8방향×4포즈 원본 PNG](../art-source/defense/crush-cannon-action/). 정사영 배율 7.5·전투 배율 1.16·기존 지면 기준 유지.
- 전투: `crush-action-{0..7}-atlas.webp`, 각 1024×256 RGBA. 파일 합계 265,148 bytes. 8장 디코드 픽셀 합은 8 MiB이며 실제 기기 GPU 측정값은 아니다.
- [메타데이터](../public/defense/models/crush-cannon-action.json): 렌더 설정·소켓·포즈 경계·기초 고정·반동 거리·53개 키프레임 시점의 포신/적재대 표면 간섭·파일/생성기/원본 SHA-256.
- [생성기](../tools/blender/build_crush_cannon_action.py): `npm run models:crush-action` (Blender 4.3+, ffmpeg).

렌더 전 네 자세 검사는 `npm run models:crush-action -- -- --check`다. `--reuse-renders`는 원본·렌더 설정·포즈 경계/소켓을 확인하며 **클립만 바꿨을 때** 재포장하는 보조 옵션이다. 재질·형상 수정은 전체 재생성을 사용한다. 작업실은 `/model-lab.html?model=crush-cannon`에서 실제 GLB를 재생한다.

- 최종 `npm run build` 통과. 전체 242개 중 241개 테스트 통과. 기존 수학 문제의 `4 !== 4.2` 실패는 기준 커밋에서도 재현했다. 디펜스 엔진은 60/60 통과한다.

## 남은 범위와 다음 후보

Lv.3의 조준·반동은 후속 [최종 강화 파쇄포](arcana-crush-cannon-lv3-action.md)에서 구현했다. 4포즈와 8방향 사이의 연속 보간, 실제 Android 메모리/프레임 성능, 적재대에서 포신으로 포탄을 공급하는 동작은 미구현이다. 완충 장치는 시각적 반동 기구이며 실제 유체·기계 시뮬레이션은 아니다.
