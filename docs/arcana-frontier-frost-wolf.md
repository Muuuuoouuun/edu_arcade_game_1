# 서리 협곡의 서리늑대 보행

기존 [은서리 늑대 컨셉](../art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png)과 가로 3D 전장을 비교했다. 설산에서도 녹음 협곡과 같은 직립 통나무 병사가 나타나 지역의 체형과 움직임이 구분되지 않았다. 이번에는 기존 회백색 갈기·짙은 발의 실제 사족 모델과 접지 보행을 서리 협곡 적에 연결했다. 눈밭에서 형태가 사라지지 않도록 전장용 털 색을 약간 낮췄다. 녹음 협곡은 기존 통나무 병사를 사용한다.

이동한 거리로 네 발의 기존 0.8초 보행을 샘플링하고, 정지하면 보행 자세를 중립으로 거둔다. 각 발의 바닥을 지형·다리와 보이는 수면에 맞춘다. 기존 공격 예고와 0.28초 피해 시점은 그대로이며, 입을 벌리고 앞으로 무는 절차적 자세가 그 시점에 닿는다. 피격 반동과 지면에 닿는 시각적 쓰러짐도 같은 시뮬레이션 시간을 따른다. 동작 줄이기에서는 고정 자세와 타격 표시를 사용한다. 이것은 별도 제작된 물기 GLB나 물리 충돌 시뮬레이션이 아니다.

원본 66개 메시를 불러온 뒤 **움직이는 관절별 17개 표면**으로 묶어 공유 인스턴스로 그린다. 지형·적·영웅은 기존 단일 Three.js 장면을 쓴다. 모델 로딩이나 필수 관절 검사에 실패하면 기존 통나무 병사 및 그 대체 모형으로 계속한다. 모바일 오프라인 패키지에도 늑대 GLB를 포함한다. 기존 캠페인 전투는 2.5D이며 이번 변경 대상이 아니다.

모델을 새로 제작하지 않았다. 편집 가능한 `.blend`, 공통 카메라 렌더, 원본 GLB와 전투 WebP·메타데이터는 [기존 보행 제작 기록](arcana-frost-wolf-grounded-stride.md)에 있으며 `npm run models:wolf-stride`로 재생성한다. 새 장면 연결의 검사는 `src/games/frontier/wolfView.test.ts`와 `npm run models:wolf-stride:check`로 실행한다.

## 검증과 한계

- 늑대 8방향·8걸음과 평지·경사·다리·다리 가장자리의 네 발을 확인하고, 반복 렌더에서 자세가 누적되지 않는지 검사했다. 공격 전 체력 100, 타격 후 92와 일시정지 중 고정 자세를 실제 3D 장면에서 확인했다.
- 전체 테스트 553개와 웹·모바일 빌드가 통과했다. PC와 가로 모바일에서 설산 전장을 조작해 이동·일시정지·배속·동작 줄이기·스킬과 늑대 GLB 실패 대체를 확인했다. 브라우저 뷰포트 에뮬레이션이며 실제 기기 시험은 아니다.
- 844×390 소프트웨어 WebGL의 3초 표본에서 적 30마리 시 전후 모두 캔버스 하나였고 렌더 호출은 38→47, 삼각형은 60,626→98,906, 평균 프레임 간격은 137.7→143.6ms였다. 실제 모바일 GPU의 성능이나 발열을 뜻하지 않는다.
- 보행의 급회전 발 고정, 별도의 물기·착지 애니메이션 제작, 개별 적 타입에 따른 공격 규칙과 실제 Android/iOS GPU 검증은 남아 있다. 현재 서리늑대의 피해·범위·보상은 기존 적 규칙을 공유한다.
