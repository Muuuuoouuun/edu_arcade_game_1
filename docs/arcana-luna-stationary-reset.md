# 루나의 제자리 시전 회수

2026-11-08 · 컨셉 개발 51회차. 기준 `37bedd8456ceefdc1bdb4baef8b7c514f259aea0`, 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉 대비 차이

`art-source/defense/atlases/ranged-motion.png`의 발사 후 손과 옷자락이 안정되는 흐름을 현재 PC/모바일 전장과 비교했다. 이동 중 회수는 앞 회차에 연결했지만, 제자리 시전은 여전히 뻗은 팔 이미지에서 대기로 바로 바뀌었다. 이번에는 두 발을 고정하고 몸의 반동을 정리한 뒤 지팡이 손이 작은 호로 접히고 망토·머리카락이 뒤따라 멈추도록 실제 관절 동작을 제작했다. 체형·재질은 기존 모델을 보존한다.

main `2eabc76`, Claude `nice-meitner` `bf7c1c6`, `wizardly-shannon` `0ac6ac5`는 지난 확인 이후 그대로다. 이전 회차에 읽은 Claude 57회차의 약점 명중 소리 제안과 PR81의 번개탑 표적 선택은 이번 동작과 별개다. 서리늑대·영웅 방향별 공격·포탑·지형·성문의 완료 계보를 보존하며 아직 남은 루나의 제자리 회수에 집중했다. 작업 트리는 깨끗했고 다른 편집 작업은 없었다. 프로세스 목록에는 Vite가 보이지 않았지만 실행 시도에서 3100 포트 점유를 확인했고 응답 중인 기존 서버를 그대로 사용했다.

## 구현

- 실제 `luna-reset-0` GLB 1클립, 0.12초·100fps·17개 애니메이션 노드다. 기존 0.15초 발사 자세에서 시작해 기존 대기 자세로 끝난다.
- 몸은 0.085초 안에 기울기를 정리한다. 양손과 가지 지팡이는 0.015초, 망토·머리카락·귀·옷자락은 0.025초 늦게 따라온다. 지팡이 손이 바깥·위로 각각 0.045 모델 단위의 작은 호를 그리며 돌아오고 빈 손도 조금 들어 회수한다.
- 양쪽 위팔·아래팔을 공통 어깨·팔꿈치·손 끝점에서 계산해 소매의 연결을 유지한다. 두 다리의 변환은 전체 클립과 보간 시점에서 고정한다.
- 전투 0.21~0.33초의 정지 회수에만 사용한다. 기존 발사 이미지 → 새 회수 이미지 → 새 안정 이미지 → 기존 대기 이미지를 선택하며 경계는 0.225/0.27/0.32초다. 새 이미지는 실제 클립 0.04/0.10초에서 베이크했다.
- **0.15초 발사·0.33초 공격·이동·피해·투사체 소켓·엔진 상태는 유지한다.** 앞 회차의 이동 중 복귀와 보행 진입은 그대로 사용한다. 필살기·돌진·동작 줄이기 우선순위를 보존한다.
- 새 회수 이미지 하나라도 실패하면 기존 제자리 회수를 사용한다. 이동 복귀/진입 이미지의 실패는 새 제자리 회수를 끄지 않으며 기존 시전/보행 실패 대체 규칙도 유지한다.

전투는 WebP 기반 2.5D이고 모델 작업실은 단일 장면의 실시간 GLB다. 유닛마다 WebGL 렌더러를 추가하지 않았다.

- 타입 검사·프로덕션 빌드 통과. PNG 16장·WebP 16셀의 해상도·투명 경계, 최소 여백 17px, 빌드 파일 11개의 원본 일치를 확인했다.

- 원본 컨셉, 동일 조건의 전후 전장, 실제 모바일 전투·3D 작업실 화면을 직접 확인했다. 모바일은 Chromium 터치 에뮬레이션이다. Browser 실행용 `js`가 제공되지 않아 워크스페이스 Playwright를 사용했다. 페이지 식별·유의미한 화면·오류 오버레이·페이지 오류·조작 후 상태를 확인했다.
- 실제 `DefenseBoard`에서 영웅/용병×8방향×기본/승급 크기×12시점, 1440/390/320px, 동작 줄이기와 새 제자리 회수·기존 이동 복귀·진입·시전·보행 이미지 실패 **3,456조합**을 검사했다. 페이지 오류·가로 넘침·전투 GLB 요청이 없고 이동 복귀/필살기/돌진 우선순위도 유지됐다.
