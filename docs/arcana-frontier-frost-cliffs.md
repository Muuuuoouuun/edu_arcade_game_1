# 서리 협곡의 층진 절벽

2026-11-09, Asia/Seoul. 기준 `5f5dd1c5360d7f74ca51b508b97a425193fc7d46`, 소유 브랜치 `codex/arcana-stage-experience-20261106`.

기존 극지 컨셉과 실제 가로 전장을 비교했을 때 반복된 뾰족한 빙하가 컨셉의 넓은 암면·눈 처마·깊은 틈을 충분히 표현하지 못했다. 기존 늑대·영웅·포탑 완료 작업을 다시 만들지 않고, 최신 배경·모델링 요청에 맞춰 서리 지형의 바깥 절벽 한 단위를 개선했다. 캠페인의 2.5D 전투와 별도 실시간 3D 변경 전장을 구분하며 이번 연결은 변경 전장과 모델 작업실이다.

## 실제 구현

- 33개 암체의 층진 단면·오목한 틈·불규칙한 암면·두꺼운 눈 덮개를 실제 메시 66개로 제작했다. 컨셉의 큰 형태를 단순화한 모델이며 회화 디테일과 동일한 품질을 주장하지 않는다.
- 원본 지형·성문 파일은 보존했다. 파생 `.blend`에는 편집 가능한 메시 428개, 전장 GLB에는 버텍스 컬러 1표면·16,946삼각형이 있다. 이미지 평면을 3D로 표시하지 않는다.
- 절벽의 모든 새 꼭짓점은 이동 영역 `abs(x/z)<28` 밖에 있다. 기존 지면·다리·성문 피격 동작을 유지한다. 전장의 기존 단일 Three.js 장면에 연결한다.
- 새 GLB 실패 시 이전 서리 지형 GLB, 그것도 실패하면 기본 입체 지형을 사용한다. 작업실에는 별도 모델 항목을 추가했다.

## 시안·원본·재생성

연결된 OpenAI 이미지 생성 도구로 기존 `polar-battlefield.png`를 참고한 절벽 시안 1건을 실제 생성했다. 원본은 `art-source/defense/concepts/2026-11-09-openai/frost-cliffs-reference.png`, 호출 출처·요약은 같은 폴더 JSON에 있다. 직접 OpenAI REST·Claude API 호출은 없으며 90% 사용률이나 사용 한도 소진을 주장하지 않는다. 생성 시안을 보고 Blender Python으로 메시를 제작한 것으로 자동 이미지→3D 변환이 아니다.

- 편집 원본: `art-source/defense/frontier-frost-cliffs.blend`
- 배포: `public/defense/models/frontier-frost-cliffs.glb`
- 16:9 공통 카메라 렌더·정적 WebP: 같은 경로 `.png`, `.webp`
- 절벽 근접 렌더: `frontier-frost-cliffs-detail.png`
- 카메라·8개 파일 해시·재생성 정보: `frontier-frost-cliffs.json`
- 생성: `npm run models:frontier-frost-cliffs` (Blender 4.3.2, ffmpeg)
- 검사: `npm run models:frontier-frost-cliffs:check`

WebP는 정적 베이크 산출물이며 이번 실시간 전장은 GLB를 사용한다. 신규 동작 클립이나 캠페인 스프라이트 교체로 집계하지 않는다.

## 검증

모델 검사와 production build 통과. 변경 전장 `terrainView`, `camera`, `engine` 관련 테스트 22개 통과. 전체 저장소 테스트를 이번 회차에 다시 실행한 것은 아니다.

- 지면 990개 샘플의 이전 모델 대비 최대 높이 오차 0, 다리 통행면 0.36 유지. 수평 광선으로 외곽 절벽의 실제 깊이 가림 확인.
- PC 1440×900, 모바일 터치 844×390에서 실제 시작·포탑 건설·적 보행·2배속·일시정지·재개·동작 줄이기 조작 통과. 일시정지 전후 전장 픽셀 동일, 단일 캔버스, 페이지 오류 없음.
- 새 지형 실패→이전 GLB, 양쪽 실패→기본 지형에서도 시작·건설 가능.
- 작업실 PC 1440×900 / 모바일 390×844에서 GLB 로딩·회전·메시 보기·시점 초기화·동작 줄이기 확인. GLB 실패→PNG, PNG까지 실패→미리보기 없음 확인.
- 작업실 첫 검사는 숨겨진 정적 동작 버튼을 접근성 역할로 찾은 검사 스크립트 오류로 중단됐다. 버튼 ID로 검사기를 수정한 재실행은 모두 통과했다. 제품 회귀로 집계하지 않는다.

증거 폴더: `/tmp/arcana-cliffs-openai-20261109-1422/`. 실제 전후 화면·UI 스크립트·로그·성능 기록을 보관한다. 전후 전투 시점/성문 체력은 동일하지 않아 환경 형태의 비교 근거로만 사용한다.

## 성능과 남은 범위

동일 현재 코드에서 이전 지형 GLB와 새 GLB만 바꾼 Chromium SwiftShader 모바일 크기 측정이다. 각 3초 단일 표본이며 실기기 FPS의 증거가 아니다.

드로콜은 양쪽 모두 20~22, 지오메트리 192·텍스처 3·캔버스 1로 동일하다. 지형 삼각형은 11,864→16,946으로 5,082개 증가했다. 소프트웨어 렌더의 평균 비용이 늘었으므로 성능 개선이나 모바일 60fps 달성으로 보고하지 않는다. 다음 후보는 보이지 않는 절벽 내부 면 제거·거리별 단순화와 실제 Android GPU 검증이다. 신규 미션·보상·확장 맵·동작 전환·경사 발 IK는 이번 범위가 아니다.

원격 main `4f10e7c`와 Claude `6924533`/`bf7c1c6`을 확인했으며 자동 main 병합·배포·예약 등록/변경은 하지 않았다. 이번 개발 회차의 결과와 스케줄러 실행 상태는 별개다.
