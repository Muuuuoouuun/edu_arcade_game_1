# 빙결 기사 · 검을 든 행군

원본 컨셉 `public/defense/monster-models.webp`의 얼음 투구·어깨 가시·검을 유지한다. 기존 전투에서는 두 정적 자세를 교대했으므로, 기존 편집 모델의 발목 관절과 양팔을 이용해 **디디기 → 무게 이동 → 다음 발 회수**가 반복되는 1초 보행을 만들었다. 검은 기존 팔의 자식으로 고정하고 검팔은 반대 팔보다 작게 흔들린다. 원본 정강이가 발 아래로 관통하던 부분은 보행용 원본에서 정강이를 위로 옮겼다. 피격·붕괴 원본과 피해·이동 속도는 변경하지 않는다.

- 재생성: `npm run models:ice-walk`, 검사: `npm run models:ice-walk:check`.
- 편집 원본 `art-source/defense/ice-knight-walk.blend`, 실제 3D `public/defense/models/ice-knight-walk.glb`, 공통 카메라 384px PNG 8장, 전투용 256px × 8 WebP와 해시·좌표 메타데이터를 보관한다. 모델 작업실에서 GLB를 재생하고 전투는 베이크 이미지를 사용한다.
- 3D 기준 지면 투영은 원본의 y=317.61이다. 기존 피격·붕괴 전투 이미지의 기준 y=340과 이어지도록 전투용 아틀라스만 22px 아래로 옮긴 뒤 256px로 축소한다. 원본 PNG는 카메라 그대로이며, 전달 이미지의 지면 기준 y=339.61은 기존과 0.39px 차이다.
- 크기 68 기준 한 주기의 투영 보폭은 24.8373 보드 단위이며 모바일 확대 시 크기에 비례한다. 이동한 거리만으로 걸음이 진행되고, 넉백·일시정지에서 걸음은 되감기지 않는다. 이미지가 불완전하면 기존 피격/보행 그림으로 돌아간다.
- GLB의 129개 보간 표본에서 최저 바닥 관통은 약 0.00089 모델 단위이며 두 발 중 적어도 하나가 지면을 지킨다. 검의 부모·손과의 고정과 루프를 검사했다. 화면에 8포즈를 유지하는 동안 가로 지지 발 흔들림은 약 5.9 보드 단위이며 완전한 발 고정은 아니다.
- 전투용 WebP는 약 76.6KB, RGBA 디코딩 크기는 약 2MiB다. 작업실 GLB는 약 154KB·37메시·1,352삼각형이다. 세로·대각선에서의 방향별 발 고정과 Android 실기기 성능은 검증하지 않았다.
