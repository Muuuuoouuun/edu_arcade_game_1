# 브론의 마지막 걸음에서 발 디디며 멈추기

2026-11-08 · 컨셉 개발 44회차. 기준 `7450a61`, 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉과 선택

`art-source/defense/atlases/melee-motion.png` 둘째 행의 낮은 체중·벌린 발·큰 망치를 실제 PC·모바일 전장과 비교했다. 기존 브론의 공격 진입·강타·보행 복귀는 완료됐지만, 이동 종료에서는 마지막 걸음이 곧바로 대기 자세로 바뀌었다. 이번에는 한 발씩 짚어 체중을 정리하고 망치가 몸보다 늦게 안정되는 동작을 만든다. 기존 강철·청동·가죽 체형과 공격은 유지한 실제 관절 애니메이션 작업이다.

시작 시 작업트리는 깨끗했고 다른 활성 개발 작업은 없었다. 기존 지형·성문·브론·통나무 병사를 포함한 통합 계보와 Vite 서버를 보존했다. main `2eabc76`, Claude nice `bf7c1c6`, 최신 wizard `6b33852`를 확인했다. 새 Claude 55회차는 표적이 없는 포탄의 재사용 대기를 되돌리지 않기로 한 비교 기록이며, 이번 시각 작업에 쿨다운 변경을 넣지 않았다. 세계관 제작 명세의 “이동 종료는 마지막 발을 짚되 목표 위치를 지나치지 않는다”를 따른다.

## 실제 동작과 전투 연결

- `dwarf-stop-0`~`dwarf-stop-7`: 여덟 걸음 각각에서 시작하는 **0.24초·100fps·8관절** 실제 GLB 클립.
- 먼저 옮길 발을 출발 높이·보행 위치로 고른다. 첫 0.12초는 반대 발을 고정하고, 이후 0.12초는 먼저 내려놓은 발을 고정한다. 발을 낮게 들고 몸통은 지지 발 쪽으로 체중을 옮긴다.
- 몸통 회전은 0.16초에 정리하고, 망치팔·팔꿈치·망치는 0.035초 늦게 회수를 시작한다. 작은 관성 회전을 더해 마지막 0.08초에도 무기가 뒤따른다. 0.24초에는 기존 방향별 대기 자세와 일치한다.
- 영웅·용병 브론의 정지 정보를 기존 시뮬레이션 시간 기반 `settle` 경로에 연결했다. 용병이 주인을 따라잡는 틱에서도 실제로 이동했으면 보행을 유지한다. 준비 화면에서 정지를 끝낼 때 전투 시간을 진행하지 않는다.
- 0~0.08초는 저장한 마지막 보행, 0.08~0.16초와 0.16~0.24초는 두 중간 베이크, 이후 기존 대기를 표시한다. 1·2배속 게시 간격의 모든 시작 오프셋에서 두 중간 자세가 관측된다.
- 재이동·돌진·공격·필살기를 우선한다. 동작 줄이기나 새 정지 이미지 하나의 실패는 기존 방향별 대기로 돌아간다. 정지 이미지 실패가 공격·이동 복귀·보행을 막지 않는다.

발 고정은 **모델 평면 기준**이며 지형 IK가 아니다. 전장 위치·속도 규칙·0.24초 강타 시점·0.52초 공격 길이·피해·보상은 유지한다. 용병의 시각 보행 속도를 고치면서 기존 공격 진입에 저장되는 `walkEntry`도 실제 걸음에 맞아진다. 전투는 베이크 2.5D이고, 작업실은 단일 실시간 3D 장면에서 관절을 보간한다.

## 검증과 한계

외부 증거 폴더 `/tmp/arcana-hourly-20261108-1236/`에 편집 전 기준 SHA·소유 브랜치·범위·수용 기준·미완료 상태부터 기록했다.

- 전체 **302개 중 301개 통과**, 타입 검사·프로덕션 빌드 통과. 기존 수학 게임 `(3×7)/5`의 4/4.2 실패는 기준 커밋에서도 재현했다. 새 정지 세트가 몬스터 요청 개수 검사에 포함되던 테스트 분류를 수정한 후 새 실패는 없다.
- GLB 저작 200시점·보간 검사 776시점: 시작 오차 최대 `3.98e-7`, 대기 끝 `5.96e-8`, 지지 발 이동 `4.77e-8`, 모델 최저 높이 약 `0.005`. 142개 해시 통과.
- 0.16초에 몸통 회전은 대기와 일치하지만 망치팔은 약 0.016~0.064라디안 남아 실제 시간차가 있다. 모든 클립 끝에서 원본 대기와 일치한다.
- `.blend` 재열기에서 157개 메시×8개 시작/끝의 원본 대비 최대 월드 변환 오차 약 `1.10e-17`. PNG 128장·WebP 128셀 경계 통과, 최소 투명 여백 13px. 빌드 파일 11개가 원본과 동일하다.
- 스테이지 1·4·5·8×영웅/용병 8게임·14,400스텝에서 시각용 `settle`, 용병 보행 속도·`walkEntry`를 제외한 상태가 기준 엔진과 동일하다. 위치·피해·체력·보상·공격 시점·배속·일시정지·돌진·필살기·강화를 포함했다.
- 실제 PC 1440×900·390×844 터치 UI로 이동·도착·1배속/2배속 정지·일시정지·동작 줄이기·복원·재개·재이동·웨이브·자연 강타를 조작했다. 여덟 보행 프레임과 정지 세 단계, 공격 우선순위, 페이지 오류/가로 넘침 없음을 확인했다.
