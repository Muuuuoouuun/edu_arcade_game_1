# 서리 협곡의 눈 덮인 숲 경계

2026-11-10. 기준 `52a63d315d63e6c52cafac08f03ba8ac8a2cf138`. [은서리 고개 컨셉](../art-source/defense/concepts/2026-11-06/silverfrost-pass.png)과 PC·가로 모바일 변경 전장을 비교하면, 기존 절벽은 입체적이지만 컨셉의 짙은 침엽수와 눈의 높이층이 없어 전장 경계가 단순하게 보였다. 서리늑대의 기본 보행, 영웅 방향 공격과 포탑 조준은 이미 구현되어 있어 다시 만들지 않았다.

기존 서리 절벽의 실제 눈·암석 표면에 11그루의 침엽수를 얹었다. 각 나무는 어두운 줄기, 3층 청록 잎과 별도의 불규칙한 눈 덩어리로 구성한 7개 편집 메시다. 가로 카메라의 전경에 놓였던 동쪽 나무는 영웅을 가려 제거하고 서쪽·북쪽 배경에 배치했다. 이동 가능 영역, 적 경로, 다리와 강의 입력·높이 및 게임 판정은 유지한다. 기존 3D 단일 장면의 한 표면에 결합했으며 별도의 이미지 평면이나 유닛별 렌더러는 없다. 캠페인 전투는 기존대로 2.5D다.

## 원본과 재생성

- 편집 원본 `art-source/defense/frontier-frost-forest.blend`: 기존 절벽에서 이어진 지형과 77개의 개별 나무 파트.
- 실시간 전장 `public/defense/models/frontier-frost-forest.glb`: 한 표면, 18,398삼각형. 이전 절벽은 17,342삼각형이다.
- 공통 16:9 카메라 PNG, 상세 PNG, 메뉴용 WebP와 출처·좌표·해시 메타데이터: `public/defense/models/frontier-frost-forest.*` 및 `frontier-frost-forest-detail.png`. WebP는 메뉴 미리보기이며 실시간 3D 모델이 아니다.
- 재생성 `npm run models:frontier-frost-forest`; 검사 `npm run models:frontier-frost-forest:check`. 모델 작업실에서 해당 GLB를 회전해 볼 수 있다.

새 GLB가 실패하면 기존 절벽 → 기존 서리 지형 → 기본 입체 지형 순으로 대체한다. 메뉴 WebP가 실패하면 기존 절벽 미리보기를 사용하고, 그것도 실패하면 이미지만 숨긴 채 선택 버튼을 유지한다. 모바일 패키지에도 새 GLB와 기존 대체 자산을 포함한다.

## 검증과 한계

- 990개 이동 지면 표본에서 이전 GLB와 높이 오차 0, 교량 통행면 0.36을 확인했다. PC·가로 모바일, 지휘·솔로, 세 확대 단계와 전체보기의 1,944개 영웅 중심 시선 표본에서 신규 가림 0건이었다. 기존 지형의 가림 52건은 유지된다. 모든 위치의 가림이 해결된 것은 아니다.
- PC 1440×900과 가로 모바일 844×390 실제 전장에서 포탑 발사, 교량 클릭/터치와 횡단, 강 선택 차단, 일시정지·재개·2배속·동작 줄이기를 확인했다. 메뉴 이미지 2단계, 전장 GLB 3단계, 작업실 GLB/PNG 실패 대체를 확인했다.
- 전체 게임 테스트, 웹·모바일 빌드와 모델 검사를 실행했다. 모바일 빌드만 제공하는 브라우저에서 타이틀→마을→새 3D 전장→건설·일시정지를 확인했고, Capacitor에 복사된 GLB와 원본의 SHA-256이 일치했다. 메뉴 이미지 회귀는 Vite와 Playwright 환경에서 `BASE_URL=http://127.0.0.1:3100/frontier.html node tools/tests/frontier-preview-browser.cjs`로 재현한다.
- Chromium SwiftShader 844×242, 12적·8볼트를 인위적으로 유지한 2초 단일 표본에서 이전/변경 평균은 71.40/74.17ms, p95는 각각 83.4ms, 호출은 29회로 같았다. 전체 렌더 삼각형은 35,314→36,370이었다. 짧은 소프트웨어 측정이며 실제 휴대기기 성능을 보장하지 않는다.

전후 화면과 로그는 `/workspace/arcana-loop-evidence-20261110-1333/`에 있다. 실제 Android/iOS GPU·발열, 이동 영역 확장과 모든 카메라 위치의 시야 검증은 후속이다. 다른 Claude 세션의 2.5D 캠페인 맵 생성기는 별도 진행 작업이며 이번 지형에 합치지 않았다. 기존 컨셉을 참고했으며 이번 회차에 API 생성은 하지 않았다.
