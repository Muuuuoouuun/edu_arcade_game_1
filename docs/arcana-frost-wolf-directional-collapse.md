## 컨셉과 전투 화면에서 선택한 차이

[은서리 늑대 컨셉](../art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png)의 회백색 갈기·긴 주둥이·짙은 발을 기존 모델과 비교했다. 일반 피격은 전 회차에서 방향을 유지하게 됐지만, **처치 순간에는 위/아래를 향한 늑대가 다시 고정 옆모습으로 바뀌고 발 디딤도 초기화됐다.** PC와 모바일의 같은 위치·방향으로 전후 화면을 기록하고 이 연결을 선택했다.

기존 여덟 보행 자세 각각에서 출발하는 실제 0.6초 클립을 만들었다. 먼저 들린 발을 내려놓고, 네 발이 지면에 닿은 뒤 몸과 무릎이 낮아진다. 발은 접힌 다리를 받치는 위치로 지면을 따라 조금 미끄러지며 평평함을 유지한다. 목·머리가 숙여지고 눈이 감기며 꼬리가 늦게 정리된다. 정강이가 접힐 때 발목 털도 위로 눌려 바닥을 뚫지 않는다. 0.48초 이후에는 끝 자세를 유지한다.

네 발의 수평 위치를 끝까지 고정하는 초안은 접힌 정강이/털이 지면을 뚫었다. 몸의 하강을 0.55 모델 단위로 조정하고, **발 내려놓기 → 지면을 따른 발 정리 → 몸 낮추기**로 나눴다. 전장 좌표의 발 고정이나 지형 IK라고 표현하지 않는다. 끝 자세의 코끝이 WebP 크롭에 1픽셀 걸리는 문제도 확인해 머리 숙임을 다듬었다.

## 전투 연결

적을 제거하기 직전 `Effect.targetWalk`에 마지막 방향·누적 보행 주기·거리를 복사한다. 개체별 위상 차이를 포함하며 방향 객체를 적과 공유하지 않는다. 모바일 확대 크기는 화면에서 걸음을 선택할 때 반영한다. 죽은 뒤 살아 있는 다른 적의 걸음이나 시간으로 다시 계산하지 않는다.

| 처치 효과의 시뮬레이션 나이 | 표시 |
| --- | --- |
| 0–0.06초 미만 | 사망 시점 걸음의 기존 방향 보행 이미지 |
| 0.06–0.24초 미만 | 발 내려놓기: GLB 0.14초 베이크 |
| 0.24–0.42초 미만 | 무릎·몸 낮추기: GLB 0.30초 베이크 |
| 0.42–0.70초 | 쓰러진 자세: GLB 0.48초 베이크, 기존 페이드 |

8방향 렌더를 그대로 사용하며 좌우 반전·전체 이미지 회전·크기 축소를 더하지 않는다. 보행과 같은 카메라·지면·표시 배율로 위치와 몸 크기를 유지한다. 동작 줄이기는 같은 방향의 끝 자세만 표시한다. 새 이미지가 실패하거나 과거 효과에 `targetWalk`가 없으면 기존 쓰러짐으로, 기본 모델까지 실패하면 기존 삽화로 대체한다.

처치 효과의 0.7초 수명·일시정지·배속·피해·보상·승패 규칙은 유지한다. 전투는 베이크 2.5D이며 새 WebGL 렌더러나 GLB 요청을 만들지 않는다.

## 산출물과 재생성

- [편집 원본](../art-source/defense/frost-wolf-fall.blend): 기존 66메시·재질, 17개 관절과 4개 눈/눈 테두리·4개 발목 털을 합친 25개 애니메이션 노드. 각 노드에 같은 N의 `Frost wolf fall N / 노드 이름` 액션을 지정한다. N=0–7, 기본 0이며 모든 액션을 fake user로 보존한다.
- [실제 GLB](../public/defense/models/frost-wolf-fall.glb): 하나의 메시 집합을 공유하는 `frost-wolf-fall-0`…`frost-wolf-fall-7`, 각각 0.6초·100fps·61키 시점. 66메시·2,300삼각형·6재질, 558,880바이트. 정지 이미지 평면 모델이 아니다.
- [공통 카메라 미리보기](../public/defense/models/frost-wolf-fall.png), [192개 원본 PNG](../art-source/defense/wolf-fall/): 8방향×8출발 걸음×3중간/종료 포즈, 384×384. 기존 접지 보행과 같은 카메라·조명·크롭을 사용한다.
- `frost-fall-{0..7}-atlas.webp`: 방향마다 8열×3행·1536×576. 가로는 출발 걸음, 세로는 동작 단계다. 셀 192×192, 크롭 (4,20,184,152). 압축 이미지 합 551,412바이트, 전체 추가 RGBA 픽셀 합 27MiB이며 실기기 GPU 메모리 측정값은 아니다.
- [메타데이터](../public/defense/models/frost-wolf-fall.json): 488개 제작 시점의 발 목표/바닥 높이·클립·카메라·지면·방향별 경계·원본/생성기/산출물 해시.
- 작업실 `/model-lab.html?model=frost-wolf-fall`: **서리늑대 · 걸음에서 쓰러짐**, 출발 걸음 1–8·재생·끝 자세 유지. 기존 단일 WebGL 장면과 GLB 실패 시 PNG 대체를 사용한다.

## 남은 범위와 다음 후보

전투는 기존 시작 자세와 세 베이크 자세이므로 연속 관절 보간은 아니다. 넉백 상태에서 죽을 때 기존 넉백 옆모습과 새 쓰러짐의 전환은 아직 완전히 이어지지 않는다. 경사면 접지·월드 좌표 발 고정·추가 디코드 비용의 실제 Android 측정도 남아 있다.

다음 후보는 서리늑대의 방향별 넉백 준비/회복, 리엘·브론의 방향 전환을 동반한 공격 복귀, 성문 앞 유닛 가림 개선이다. 이번 회차에서 예약 조회/변경·Claude API 호출·main 병합·서비스 배포는 수행하지 않았다.
