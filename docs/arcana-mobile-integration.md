# 아르카나 모바일 통합 현황

기준 확인: 2026-11-09. 이 문서는 구현 완료와 기획 제안을 구분하기 위한 통합 작업 기록이다.

## 제품 방향

- 기존 영웅·용병 캠페인을 중심으로 Android 설치판을 우선한다. 게임 엔진 전면 교체는 범위에 없다.
- 고유한 판타지 세계관을 유지하고 작은 화면의 캐릭터 식별, 조작 가독성, 동작과 타격감을 개선한다. 3D 모델과 전장 실험은 캠페인에 적합성을 검증한 뒤 단계적으로 연결한다.
- 카드·퀴즈는 독립 교육 실험이다. 별도 3D 변경 전장은 캠페인 성장·저장과 아직 연결되지 않은 훈련판이다. 이 기록을 통합했다고 두 게임의 진행도나 규칙이 합쳐진 것은 아니다.
- 화면 방향은 기존 지원과 기획 기록이 다르므로 확정 전까지 기존 세로·가로 지원을 보존한다. Android 빌드 성공과 실제 기기 검증은 별도다.

## 다음 검증

1. 3D 전장의 입력·카메라·성능·에셋 의존성과 캠페인 충돌을 기능 단위로 검토한다. 캠페인 저장·성장 연결은 별도 설계와 회귀 검증이 필요하다.
2. 열려 있는 캠페인 PR과 통합 브랜치의 최신 기준을 다시 대조한다. 최종 커밋에서 자동 테스트와 빌드를 실행하고 독립 검토를 받는다.
3. Android 설치 빌드 후 실제 기기에서 터치, 화면 방향, 성능, 백그라운드 복귀와 저장을 확인한다. 기기 확인 전에는 모바일 완성으로 표시하지 않는다.
4. 화면 방향, 3D 요소를 캠페인에 적용할 범위, 조작 방식과 성능 목표를 확인한다. 각 기획 회차는 당시의 기록으로 보존하며 현재 결정과 구분한다.

## 빌드 재현성

기존 `src/games/engine.ts`의 저장소 밖 `math_speed/functions/src/mathEngine.ts` 참조는 독립 체크아웃에서 빌드를 막았다. 수학 엔진을 이 저장소에 고정한 사본으로 사용하며, 출처와 갱신 방법은 [수학 엔진 안내](../src/games/math/README.md)에 기록한다. 두 프로젝트의 사본은 자동 동기화되지 않는다.
