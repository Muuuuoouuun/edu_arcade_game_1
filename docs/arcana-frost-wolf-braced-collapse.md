## 컨셉과 화면에서 고른 차이

[은서리 늑대 원본](../art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png)의 긴 주둥이·회백색 갈기·짙은 발을 실제 PC/390px 전장과 비교했다. 체형·방향 보행·일반 피격·넉백·일반 쓰러짐은 이미 구현돼 있다. 이번 범위는 **넉백으로 낮아진 몸이 사망 첫 순간에 원래 보행 자세로 다시 올라갔다가 쓰러지는 연결 오류**다.

강한 버티기·중간 버티기·걸음 복귀 중의 세 자세 각각에서 여덟 걸음을 받아, 몸을 다시 세우지 않고 발을 내려놓고 무릎·몸·머리가 낮아지는 실제 0.6초 관절 동작 24개를 제작했다. 기존 메시·재질·실루엣은 공유하며, 발바닥 방향을 평평하게 유지하고 발목 털은 다리가 접힐 때 위로 압축한다. 끝 자세는 기존 방향별 쓰러짐과 일치한다.

## 전투 연결

치명타 직전 `knockVelocity`를 `deathBraceVelocity`에 기록하고, 삭제 직전 사망 효과의 `targetWalk.braceVelocity`로 복사한다. 치명타가 새로 만든 밀림 힘을 출발 자세로 잘못 사용하지 않는다. 처음부터 걷고 있던 늑대의 사망은 기존 보행→쓰러짐이며, 화상처럼 추가 타격 없이 죽는 경우는 현재 밀림 자세를 사용한다. 방향·걸음·위상·피해·사망 시간·보상·넉백 물리는 유지한다.

| 사망 효과 나이 | 표시 |
| --- | --- |
| 0–0.06초 미만 | 사망 직전의 기존 버티기 이미지 그대로 |
| 0.06–0.24초 미만 | 해당 버티기에서 발을 내려놓은 자세, GLB 0.14초 |
| 0.24–0.42초 미만 | 무릎·몸·머리가 낮아지는 자세, GLB 0.30초 |
| 0.42초 이후 | 기존 방향별 쓰러짐의 최종 자세 |

출발 세기는 기존 속도 구간 `>65`, `>22`, `>7`을 따른다. 7 이하에서는 새 전환을 적용하지 않는다. 동작 줄이기는 기존과 동일하게 같은 방향의 최종 자세를 유지한다. 이미지 묶음이 불완전하면 기존 방향별 쓰러짐으로 돌아가며, 기존 보행/기본 모델까지 실패하는 경우도 기존 단계별 대체를 유지한다.

전투는 2.5D 베이크다. 유닛별 WebGL이나 전투 GLB 로딩을 추가하지 않았다. 모델 작업실에서만 단일 실시간 3D 장면으로 연속 관절 동작을 재생한다. 접지는 모델의 평면 기준이며 전장 지형 IK나 월드 좌표 발 고정은 아니다.
