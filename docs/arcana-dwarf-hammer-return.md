## 컨셉 대비 개선

[동작 컨셉](../art-source/defense/atlases/melee-motion.png)의 넓은 발과 무거운 망치 동작을 현재 PC/모바일 전투와 비교했다. 기존 낮은 몸·강철/청동·청록 천·방패·수염은 유지하고, **강타 회수 중 고정된 발이 다음 보행 자세로 바로 바뀌던 구간**을 선택했다.

기존 회수 자세에서 여덟 걸음으로 각각 이어지는 실제 0.14초 클립을 만들었다. 몸통·머리·방패팔이 정리되고 망치 상완·팔꿈치·손목이 0.015초 늦게 따라온다. 돌아오는 발에 작은 들어 올림을 더하고 반대 밑창은 지면을 지지한다. 손과 손잡이는 같은 손목 관절에 결합되어 있다. 시작은 원본 회수 포즈(원본 클립 0.39초), 끝은 각 원본 보행 자세와 일치한다.

전투는 **타격 이후 회복 구간의 뒤쪽 절반**에만 적용한다. 현재 이동 방향이 공격 생성 당시 조준 방향과 같은 8방향 구간이고 이동 중일 때 현재 보행 거리로 목표 걸음을 선택한다. 공격 시작의 `walkEntry`에 걸음을 고정하지 않는다. 방향이 다르거나 정지·필살기·돌파·동작 줄이기·이미지 실패인 경우 기존 표시를 따른다.

기본 공격의 표시 구간은 아래와 같다. 실제 `hitAt`과 `duration`에 비례하므로 시뮬레이션 일시정지·배속을 따른다.

| 공격 경과 시간 | 표시 |
| --- | --- |
| 0–0.38초 | 기존 진입·타격·반동 |
| 0.38–0.40초 | 기존 회수 포즈 6 |
| 0.40–0.45초 | 첫 복귀 베이크: 클립 0.04초 |
| 0.45–0.50초 | 늦은 복귀 베이크: 클립 0.12초 |
| 0.50–0.52초 | 현재 걸음의 기존 보행 이미지 |

**타격 0.24초·전체 공격 0.52초·접촉 잔상·피해·이동 규칙은 변경하지 않았다.** 접지는 모델 내부 좌표 기준이다. 전장 좌표의 발 고정이나 연속 방향 전환을 구현한 것은 아니다.

## 산출물과 재생성

- [편집 원본](../art-source/defense/dwarf-return.blend): 기존 157개 메시·재질·베벨과 8관절×8액션 세트. 각 관절에 같은 N의 `Bron return N / 관절 이름`을 지정한다. N=0–7, 기본 0이며 fake user로 모두 보존한다. 기존 `dwarf-hammer-sequence.blend`와 `dwarf-locomotion.blend`는 변경하지 않았다.
- [실제 GLB](../public/defense/models/dwarf-return.glb): `dwarf-return-0`…`dwarf-return-7`, 각 0.14초·100fps·15키 시점. 55개 묶음 메시·23,190삼각형·18재질, 1,387,636바이트. 작업실의 56메시는 다중 재질 primitive 분리 집계다. 8클립은 하나의 메시 집합을 공유하며 텍스처 이미지나 이미지 평면 모델이 아니다.
- [공통 카메라 PNG](../public/defense/models/dwarf-return.png), [128개 PNG](../art-source/defense/dwarf-return-frames/): 8방향×8목표 걸음×2중간 포즈. 384×384, 정사영 6.8, 지면 (192,330).
- `dwarf-return-{0..7}-atlas.webp`: 방향마다 16셀·3072×192, 셀 192×192, 지면 (96,165), 배율 `1.2×6.8/5.8`. 합계 501,272바이트, 추가 RGBA 디코드 픽셀 합 18MiB. 실기기 GPU 메모리 측정값은 아니다.
- [메타데이터](../public/defense/models/dwarf-return.json): 원본·컨셉·생성기/산출물 해시, 클립·카메라·지면·방향별 경계·시작/끝 오차·밑창 높이.
- [생성기](../tools/blender/build_dwarf_return.py): `npm run models:dwarf-return` — Blender 4.3+, ffmpeg. 렌더 없는 검사: `npm run models:dwarf-return -- --check`. 납품 GLB/해시 검사: `npm run models:dwarf-return:check`.
- 작업실 **브론 · 강타에서 걸음으로**에서 복귀 걸음 1–8을 선택해 재생하고 끝 자세를 유지한다. 기존 단일 WebGL 장면을 사용하며 GLB 실패 시 PNG임을 표시한다. 전투는 GLB를 요청하지 않는 베이크 2.5D다.
