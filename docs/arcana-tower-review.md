# 아르카나 타워 시각·자산 점검

2026-11-09. 전투용 `tower-models.png`의 9개 실루엣 중 화염 수정탑·관통 발리스타·물폭탄포와 작업실의 해당 3D 모델을 비교하고, 기존 서리 시안 2종까지 파일과 작업실 로드를 점검했다.

## 기존 자산

| 자산 | 관찰과 조정 우선순위 |
|---|---|
| 화염 수정탑 | 3D 모델은 둥근 몸체·붉은 깃발·수정을 유지한다. 아틀라스에는 더 거친 짙은 석재, 큰 금색 발톱, 불꽃과 명암 대비가 있다. 석재·수정의 명도 대비를 먼저 조정한다. |
| 관통 발리스타 | 긴 볼트·목재 구조·활대·청록 문장으로 역할이 구분된다. 3D의 목재와 금속은 아틀라스보다 매끈하고 밝다. 나뭇결, 금속 마모와 그림자를 보강하되 활줄과 볼트의 움직임은 유지한다. |
| 물폭탄포 | 청록 탱크·포신·배관·물결 문장으로 구분된다. 3D는 물과 유리의 구분 및 배관 대비가 약하다. 유리·물 표면과 포구의 어두운 깊이를 우선 검토한다. |
| 서리 수정탑·수호탑 | 독립적인 설산 타워 시안이다. 서리 수호탑은 돌 블록과 짙은 틈, 금속·눈꽃 문장이 더 명확하며 색 변화 이미지 맵을 포함한다. 이 둘은 기존 전투의 9개 타워에 연결되어 있지 않다. |

Claude는 물폭탄포 아틀라스에 복수 출구가 있다고 해석했지만, 확인 가능한 주 포신은 하나이므로 그 주장은 판단 근거에서 제외했다. 이미지 판독 결과는 실제 자산과 대조해야 한다.

## Higgsfield 비교 시안

Claude Haiku 4.5에 아틀라스와 3D 렌더 4개를 보내 디자인을 검토하고, 원본과 대조하여 지시문을 조정했다. Claude 사용량은 입력 3,888토큰·출력 466토큰이다. Higgsfield `gpt_image_2_6` 세 장의 사전 견적은 합계 0.75크레딧이었다. 실제 청구 달러는 확인하지 못했다. Higgsfield에는 원본 이미지를 직접 넘기지 않고 텍스트를 전달했다.

- 화염: 돌·불꽃·황동·붉은 문장의 대비가 강하다. 기존 아틀라스보다 훨씬 높은 구조이고, 수정 꼭대기가 이미지 상단에 가깝다.
- 발리스타: 목재와 금속이 읽히고 볼트·활대가 뚜렷하다. 문양과 높은 기단은 기존 아틀라스와 다르므로 그대로 대체할 수 없다.
- 물폭탄포: 물탱크·배관·포신과 물결 문장의 구분이 명확하다. 기단이 높고 포신의 방향과 외형이 기존 자산 및 3D 모델과 달라 실제 포구·발사 경로에 맞춘 수정이 필요하다.

세 장 모두 불투명한 단색 배경의 정지 콘셉트이며, 투명 스프라이트·회전 가능한 모델·게임용 발사 애니메이션이 아니다. 시각 검토를 위한 별도 결과이고 전투 아틀라스와 코드는 교체하지 않았다.

## 기술 확인

- 기존 5개 GLB는 모두 외부 파일 참조 없이 내부 자산을 사용한다. 화염 모델의 `fire-core`, 발리스타의 `turret`·`bolt`, 물폭탄포의 `turret`·`barrel` 노드가 있다. 기존 세 모델에는 이미지 텍스처가 없고, 서리 수호탑에는 이미지 6개가 포함되어 있다.
- Chromium 1440×900과 390×844에서 5개 모델을 순서대로 로드하고 발사/발광 미리보기 완료, 페이지 오류·요청 실패·가로 넘침 없음을 확인했다. 실제 모바일 GPU 성능이나 애니메이션의 예술적 품질을 보장하는 검사는 아니다.
