컨셉의 입체 지형과 실제 가로 화면을 비교했다. 변경 전장 카르의 충격파는 하나의 평면을 중심 지형의 접선에 맞추므로 반경 8의 넓은 범위가 경사·다리·강을 가로지를 때 공중에 뜨거나 지면에 가려질 수 있었다. 2.5D 캠페인은 바꾸지 않는다.

기존 충격파를 64개 구간으로 나누고 각 구간의 안쪽·바깥쪽 꼭짓점을 지면·다리 상판·수면 높이에 맞춘다. 급격한 높이 단차나 전장 밖에서는 해당 구간을 생략해 강을 가로지르는 수직 면을 피한다. 따라서 경계에서는 고리에 짧은 빈틈이 생길 수 있다. 이것은 판정의 벽이나 장애물이 아니다. 원래 0.28초의 타격 접촉, 반경 8, 피해·입력·이동 규칙과 0.18초 이펙트 시간을 보존한다. 동작 줄이기는 기존처럼 고정 크기와 파편 생략을 유지한다.

하나의 Three.js 장면과 기존 이펙트 슬롯을 사용한다. 투영용 지오메트리는 슬롯마다 처음 필요할 때 만들고 재사용·종료 시 폐기한다. 프레임마다 모델이나 렌더러를 새로 만들지 않는다. 기존 `.blend`, GLB와 베이크 이미지는 변경하지 않았으며 새로운 모델 제작으로 집계하지 않는다.
