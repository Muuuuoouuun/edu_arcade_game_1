# 변경 전장 · 카르의 돌진 버팀 자세

녹음의 망치 영웅 컨셉과 직전 OpenAI 돌진 시안, 같은 카메라의 실제 전장을 비교했다. 시간 기반 돌진은 구현됐지만 중간에도 보행 동작을 계속 반복해 체중을 낮추고 망치를 지지하는 실루엣이 약했다.

기존 `frontier-kar.blend`에서 생성한 카르 GLB의 보행과 망치 대기 자세를 실제 돌진 진행도에 따라 혼합한다. 중간에 몸을 낮추고 양발을 앞뒤로 벌려 버틴 뒤 착지할 때 거리 기반 보행으로 돌아간다. 서서 출발할 때는 선 자세에서, 걸으며 출발할 때는 마지막 걸음에서 시작하도록 출발 이동 여부를 시각 상태에 저장한다. 발 보정은 지형 높이를 따르고 매 프레임 이전 보정을 되돌려 일시정지에서 누적되지 않는다. 양손과 망치는 기존 관절·클립을 사용한다.

돌진 속도·경계·피해·공격 취소·재사용 시간은 바꾸지 않는다. 진행도는 시뮬레이션 시간을 따르므로 정지·배속과 함께 멈추고 움직인다. 동작 줄이기는 새 버팀 자세를 생략하고 기존 자세를 사용한다. 카르 GLB를 읽지 못할 때 기본 영웅과 기존 이동이 남는다. 새 모델·Blender 애니메이션 클립이나 캠페인 2.5D 베이크는 제작하지 않았다. 기존 편집 원본 및 재생성 명령은 [카르 모델](arcana-frontier-kar-model.md)을 따른다.

## 확인 범위

- 실제 돌진 명령의 서기/보행 출발, 8방향·16걸음 위상·7진행 단계의 망치 양손 연결과 시작·끝 접합, 반복 정지 프레임, 동작 줄이기를 검사했다. 평지·경사·다리에서 8방향과 4걸음 위상·5진행 단계를 검사해 발 관통이 없고 최소 한 발이 지형에 닿음을 확인했다.
- PC 1024×576과 가로 모바일 844×390 Chromium에서 실제 보행→스킬 준비→돌진 취소→일시정지·동작 줄이기·2배속→착지 후 공격을 조작했다. 두 카르 GLB 요청 실패의 기본 영웅도 확인했다. 모바일은 에뮬레이션이다.
- 전체 테스트 535개, 웹·모바일 오프라인 빌드, 기존 카르 편집 원본과 GLB 검사에 통과했다. 모바일 패키지의 메뉴 진입과 같은 조작도 확인했다. 단일 SwiftShader 장면의 짧은 전후 표본은 드로콜 38개·삼각형 46,210개로 같았으며, 실제 기기 성능을 의미하지 않는다. 기존 Three.js 그림자 설정 경고가 남아 있다.

보행·대기 클립의 절차적 혼합이며 새로 손으로 만든 관절 돌진 클립이나 완전한 발 IK가 아니다. 공격 취소 순간의 임의 포즈와 모든 지형에서의 발 미끄러짐, 실제 Android/iOS GPU와 사용자 플레이는 후속 검증이 필요하다.
