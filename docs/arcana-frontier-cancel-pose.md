# 변경 전장 · 카르의 공격 취소에서 돌진으로

녹음 컨셉의 무게 있는 양손 망치 자세와 실제 3D 전장을 대조했다. 직전 돌진 버팀 개선 이후에도 공격 준비·접촉·회수 중 돌진을 누르면 공격 클립이 즉시 사라져 망치와 팔이 기본 자세로 튀었다.

돌진이 실제 시작되면 취소된 공격의 **시각용** 시간과 이전 걸음 위상만 기록한다. 공격 상태와 판정은 이전처럼 즉시 취소한다. 기존 공격/회수 관절 포즈를 실제 돌진 진행의 첫 25% 동안 버팀 자세와 혼합하므로, 최대 5단위 돌진에서는 0.05초이며 경계에서 짧아진 돌진에서는 더 빨리 끝난다. 혼합 중 어깨→팔꿈치→손잡이를 기존 3D 관절에서 다시 연결하고, 이전 보정을 복원해 같은 시뮬레이션 프레임을 반복해도 누적되지 않게 했다.

공격의 타격 시점·피해·미발동 환급, 돌진의 거리·경계·재사용 시간은 바꾸지 않는다. 이미 발생한 타격은 되돌리지 않고, 취소된 공격은 추가 피해를 내지 않는다. 일시정지와 배속은 시뮬레이션 진행을 따르며 동작 줄이기는 새 혼합을 생략한다. 기존 3D 카르와 관절·클립을 재사용하며 새 Blender 모델·GLB·2.5D 전투 베이크는 제작하지 않았다. 편집 원본과 재생성 명령은 [카르 모델](arcana-frontier-kar-model.md)을 따른다.

## 확인 범위

- 제자리/보행 진입, 공격 준비→0.28초 접촉→회수의 10개 시점, 8방향과 평지·경사·다리에서 취소 직전과 직후 관절 자세를 비교했다. 혼합 6개 시점의 손잡이·팔꿈치 연결, 발 비관통, 반복 정지 프레임의 안정성을 검사했다.
- 같은 0.19초 준비 자세에서 돌진 입력 전후 망치 타격점의 순간 이동은 1.0335→0 전장 단위였다. 이후 자세는 진행도에 맞춰 바뀐다.
- 취소 직전·직후 피해와 쿨다운, 정지·2배속, 동작 줄이기 및 선택 클립 누락을 자동 검사했다. PC 1024×576과 가로 모바일 844×390 Chromium에서 실제 보행·스킬·돌진 취소·일시정지·2배속·후속 공격을 조작했고 두 GLB 로딩 실패 폴백과 모바일 패키지도 확인했다. 모바일은 에뮬레이션이다.
- 전체 테스트 540개, 웹·모바일 빌드와 기존 카르 Blender/GLB 검사가 통과했다. 844×242 SwiftShader의 짧은 단독 표본에서 드로콜 38개와 삼각형 46,210개는 전후 동일했다. 실기기 성능을 뜻하지 않으며 기존 Three.js 그림자 설정 경고가 남아 있다.

완전히 막혀 돌진 이동이 0인 경우는 기존처럼 즉시 취소하며 이번 시각 혼합을 적용하지 않는다. 완전한 발 IK, 모든 지형의 미끄러짐과 실제 Android/iOS GPU·사용자 플레이는 미검증이다.
