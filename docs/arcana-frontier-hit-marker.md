# 변경 전장 피격 대상 표시

2026-11-09 KST. 기준 `5c82b4b02c88ce4cacec475655d99bb6570bb2c4`, 브랜치 `codex/arcana-stage-experience-20261106`.

통나무 병사 시안과 모바일 실제 전장을 비교했다. 이전 회차에서 피격 시 몸이 기울도록 했으나 영웅과 적이 겹치면 맞은 대상을 알아보기 어려웠다. 피해가 실제로 적용된 생존 병사의 머리 위에 짙은 테두리의 금색 표식을 시뮬레이션 0.32초 동안 표시한다. 적마다 명중 시각을 사용하며 피해 전·시간 종료·적 제거 뒤에는 표시하지 않는다. 일시정지·배속을 따르고, 동작 줄이기에서는 표식 크기를 고정해 정보를 유지한다. 피해·타격 타이밍·대상 선택은 바뀌지 않는다.

표식은 기존 Three.js 전장 안에서 카메라를 바라보는 공유 인스턴스 메시 하나로 그린다. 깊이 검사를 사용하고 불투명 지형 다음에 그려, 뒤쪽 벽은 표식을 가리지 않고 앞쪽 벽은 가린다. 화면 밖 적은 기존 시야 검사로 제외한다. GLB를 못 불러온 기본 입체 병사에도 적용한다. 새 Blender 모델·GLB·이미지나 캠페인 2.5D 스프라이트를 제작한 것은 아니다.

## 검증 및 한계

- 관련 엔진·피격·3D 병사 테스트 33개와 production build 통과. 명중 전/후·복수 대상·화면 밖·적 제거·정지 시각·동작 줄이기·깊이 검사 설정을 확인했다.
- Chromium WebGL 실제 렌더에서 표식 앞 벽과 뒤 벽을 바꾸어 각 픽셀을 검사했다. 앞 벽이 있으면 벽 색, 벽이 뒤면 표식 색이 보인다. 다만 장면 전체의 모든 가림 상황과 실기기 GPU를 대체하지 않는다.
- PC 1440×900 및 모바일 터치 844×390에서 실제 공격 준비·타격 시점·표식·일시정지·배속·동작 줄이기·돌진 취소를 확인했다. 통나무 GLB를 차단한 모바일 경로에서도 대체 모형의 명중 표식·일시정지·배속·동작 줄이기를 확인했다. 이전 화면은 동일 기준 커밋의 실제 전투 기록이다. 자료: `/tmp/arcana-hit-marker-20261109-1847/`.

- 30명이 동시에 피격 표시를 유지하는 인위적 부하, Chromium SwiftShader의 844×242 장면·6초 단일 표본: 평균 117.69→121.43ms, p95 150.1→150.0ms. 드로콜 37→38, 삼각형 59,612→60,332, 지오메트리 214→215였다. 순서를 바꿔 실행한 짧은 비교이며 실제 기기의 FPS나 성능 합격을 뜻하지 않는다. 초기 투명 양면 표시가 두 번 그려지는 문제를 발견하고 단일 패스로 수정한 뒤 재측정했다.
