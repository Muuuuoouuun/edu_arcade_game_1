## 컨셉과 실제 화면에서 선택한 차이

[원본 원거리 동작 시트의 리엘](../art-source/defense/atlases/ranged-motion.png)은 넓게 디딘 발, 몸을 감싸는 망토와 긴 활의 균형이 특징이다. 실제 PC/390px 전장에서 보행과 사격 연결은 이미 있지만, **이동 종료 순간에는 마지막 걸음의 발과 망토가 즉시 대기로 바뀌는 차이**를 확인했다. 완료된 서리늑대 보행·피격·넉백·쓰러짐과 기존 영웅 사격을 반복 제작하지 않고 리엘의 보행→정지 한 단위를 선택했다.

기존 여덟 보행 자세 각각에서 시작해 같은 대기 자세로 끝나는 실제 0.24초 관절 클립 8개를 제작했다. 들린 발을 먼저 내려놓고 그 발로 체중을 받은 뒤 반대 발을 정리한다. 지지하는 발은 위치를 유지하며 몸을 지지 발 쪽으로 약간 옮긴다. 활과 몸을 안정시키고 머리카락·망토는 0.035초 늦게 정리를 시작한다. 기존 130개 편집 메시와 재질·후드·귀·활 실루엣을 공유한다.

## 전투 연결과 수정한 회귀 조건

기존 정지 시각 상태 `locomotion.settle`을 리엘 영웅/용병에도 연결했다. 이동 거리에서 마지막 걸음과 방향을 한 번 저장하며, 멈춘 위치에서 시뮬레이션 시간으로 0.24초만 진행한다. 이안의 정지용 시계 함수를 재사용하고 이안의 자산·동작은 변경하지 않는다.

| 정지 후 시간 | 전투 표시 |
| --- | --- |
| 0–0.08초 미만 | 저장한 방향·걸음의 기존 보행 이미지 |
| 0.08–0.16초 미만 | 첫 발을 내려놓는 베이크, GLB 0.08초 |
| 0.16–0.24초 미만 | 두 번째 발·몸·망토 정리, GLB 0.20초 |
| 0.24초 이후 | 기존 방향별 대기 |

정지 중 재이동하면 전환을 즉시 취소한다. 공격·필살기·돌진이 우선하며 정지 베이크가 사격 준비/발사/회수 위에 덮이지 않는다. 동작 줄이기는 정지 베이크를 생략하고 기존 대기를 사용한다. 새 8방향 묶음이 불완전하면 기존 대기로 돌아간다. 기존 사격·보행 이미지가 실패하는 경우에도 기존 삽화 대체를 유지한다.

검증 중 리엘 용병이 주인의 이동 목표를 매 틱 따라잡으면 이동 중에도 보행 속도 0으로 기록되는 기존 문제를 확인했다. 리엘 용병은 **실제 위치 변화**가 있을 때 보행을 기록하도록 수정했다. 준비 화면에서도 마지막 이동 다음 틱에 정지를 시작·완료하고 다시 유휴 상태가 되도록 연결했다. 이 변경에 따라 용병이 움직이며 사격할 때 기존 `walkEntry`도 정확한 마지막 걸음을 받는다. 공격/투사체의 이 필드는 시각 전환용이다. 실제 위치·속도 제한·공격 시점·피해·보상·해금은 바꾸지 않았다.

## 납품과 재생성

- [편집 가능한 Blender 원본](../art-source/defense/riel-stop.blend): 130개 메시·24개 애니메이션 노드. 각 노드에 같은 N의 `Riel stop N / 노드 이름` 액션을 지정한다. N=0–7, 모두 fake user로 보존한다.
- [실제 GLB](../public/defense/models/riel-stop.glb): `riel-stop-0`…`riel-stop-7`, 각각 0.24초·100fps·25키 시점. 재질별로 묶은 55메시·16,734삼각형·14재질, 1,325,416바이트. 정지 이미지 평면이 아니다.
- [공통 카메라 PNG](../public/defense/models/riel-stop.png), [128개 원본 렌더](../art-source/defense/riel-stop-frames/): 8방향×8출발 걸음×2중간 자세, 384×384. 기존 카메라·지면 `(192,330)`과 표시 배율을 공유한다.
- `riel-stop-{0..7}-atlas.webp`: 방향마다 16열·3072×192. 열은 `출발 걸음×2+중간 자세`, 셀 192×192, 지면 `(96,165)`. 합 443,162바이트, 디코드 RGBA 픽셀 합 18MiB. 실제 GPU/Android 메모리 측정치는 아니다.
- [메타데이터](../public/defense/models/riel-stop.json): 클립·카메라·방향별 경계·지지 발 검사·생성기/원본/컨셉/산출물 해시.
- 작업실 `/model-lab.html?model=riel-stop`: **리엘 · 발 디디며 멈추기**. 여덟 출발 걸음 선택·재생·끝 자세 유지·메시 보기·회전·시점 복귀. 기존 단일 장면을 사용하며 GLB 실패는 PNG 렌더로 표시한다.

```bash
npm run models:riel-stop             # Blender 4.3+, ffmpeg; 전체 재생성
npm run models:riel-stop:pose-check  # 렌더 없이 관절/접지 검사
npm run models:riel-stop:check       # 납품 GLB 보간·끝점·지지 발·활 연결·해시 검사
```
