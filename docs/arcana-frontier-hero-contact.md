# 변경 전장 카르의 방향·강타 접촉

2026-11-09 KST, 컨셉 개발 60회차. 기준 `57b389be8d812d48bc7abf8550e275bb20a8756a`, 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉과 실제 차이

`art-source/defense/atlases/melee-motion.png` 첫 줄, 기존 카르 GLB, 실제 PC1440×900·가로 터치844×390 화면을 비교했다. 양손 망치를 들어 체중을 싣는 컨셉과 달리 3D 훈련에서는 공격 버튼을 누르자마자 멀리 있는 적에게 직선 효과와 피해가 발생했다. 모델의 원래 앞쪽은 glTF -Z인데 전장은 +Z 진행각을 그대로 적용해 몸과 망치도 반대로 향했다.

이번 단위는 **기존 실제 3D 동작을 올바른 방향·접촉 위치·피해 시점에 연결하는 것**이다. 이미 완료된 서리늑대·2.5D 영웅·포탑·통나무 병사 동작과 지형 계보는 유지했다. 새 메시나 애니메이션 원본을 제작했다고 표시하지 않는다.

## 구현과 플레이 변화

- 기존 카르 모델에 Y축 180도 보정을 적용한다. 여덟 방향의 실제 `hammer-contact` 소켓과 판정 위치가 일치한다.
- 기존 `kar-entry-0..7`을 같은 몸에 적용한다. 실제 이동 거리로 보행 시간을 진행하고 공격 진입은 가장 가까운 8개 걸음 중 하나를 선택한다. 이동 중인 몸은 공격이 시작되면 위치·방향을 고정한다.
- 기본 강타·충격파는 0.56초 동안 준비→접촉→회수한다. **0.28초 이전 무피해**, 그 경계를 넘을 때 한 번만 피해와 효과가 발생한다. 긴 프레임과 2배속에서도 중복 판정하지 않는다.
- 기본 강타는 가까운 적 하나를 선택하며 대상을 바꾸지 않는다. 기존 즉시 사거리9를 근접 선택 거리2.6으로 바꿨다. 접촉점 중심 반경1.4 안에 대상이 여전히 있어야 명중한다. 피해는 시작할 때의 `22 + 레벨×3`, 재공격 간격은0.62초다. 적이 떠나거나 죽으면 빗나가며 보상을 다시 주지 않는다.
- 충격파는 기존 영웅 중심 반경8·피해 `45 + 레벨×5`·대기6초를 유지하되 접촉 시점에 발생한다. 준비 중 다른 공격으로 덮어쓰지 않는다. 준비/회수 중에는 공격·충격파 버튼도 비활성화해 현재 사용할 수 없는 입력을 알린다.
- 이동 명령/방향 입력은 강타 중 발을 미끄러뜨리지 않으며 회수가 끝나면 이동한다. 돌진은 즉시 강타를 취소한다. 아직 접촉하지 않은 기본 공격/충격파의 대기시간만 환급하고, 접촉 이후에는 지출한 대기시간을 유지한다. 돌진 자체의3초 대기와 기존 강/섬 경계 규칙은 그대로다.
- 준비 중 망치 접촉 범위 또는 충격파 범위를 표시한다. 기본 명중의 먼지 고리는 원본에서 추출한 소켓 아래에서, 충격파는 영웅 중심에서 시작한다. 표시와 효과는 지역 지형의 기울기를 따른다.
- 일시정지·배속은 시뮬레이션을 따른다. 동작 줄이기에서는 준비/접촉 고정 자세와 범위 정보를 유지한다. 기존 한 장면·한 WebGL 렌더러를 사용한다.

독립 3D 훈련의 사거리·공격 지연·이동 제한·취소 규칙이 달라지므로 이전 전투 결과와 같다고 주장하지 않는다. 2.5D 캠페인의 공격·돌진 판정은 변경하지 않았다. 분대원의 별도 지원 사격도 유지한다.

## 기존 제작물 재사용과 재생성

편집 가능한 `kar-barbarian.blend`, `kar-barbarian-walk.blend`, `kar-entry.blend`와 그 GLB·공통 카메라 PNG·방향별 WebP·메타데이터를 그대로 보존한다. 자세와 재질·지오메트리를 다시 만들지 않았다. 전체 제작 규격은 [카르 보행→강타](arcana-kar-hammer-entry.md)에 있다.

| 전달물 | 역할 |
| --- | --- |
| `tools/build-frontier-hero-contract.mjs` | 기존 보행 크기와 강타0.28초 소켓을 읽어 전장 규격 추출 |
| `public/defense/models/frontier-hero.json` | 원본/GLB/메타데이터8개 해시, 배율·지면·방향·접촉 규격 |
| `src/games/frontier/heroModel.ts` | 위 규격에서 생성한 런타임 상수 |
| `heroAttack.ts`, `heroView.ts`, `heroEffects.ts` | 판정·클립 재생·지형 기울기의 범위 표시 |

```bash

npm run models:barbarian

npm run models:frontier-hero
# 이번 런타임 연결과 기존 산출물 검증
npm run models:frontier-hero:check
npm run models:kar-entry:check
node --experimental-strip-types --test src/games/frontier/heroAttack.test.ts src/games/frontier/heroView.test.ts
npm test
npm run build
```
