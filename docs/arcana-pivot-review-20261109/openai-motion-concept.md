## 프로젝트 Arcana 전환 제작 스펙

### 1) 런치 키아트(정지 생성물)
- 용도: 스토어/타이틀 공용 세로형 키비주얼.
- 구성: 상단 25%는 어두운 틸 네거티브 스페이스, 로고/타이틀 배치용. 하단 18%는 Start 버튼 전용 안전 영역.
- 중심: 숲/설원 전선 위 영웅 6인, 전면 Bron 배치. Bron: 주황 수염, 틸 스틸 해머, 드워프 엔지니어 실루엣 명확.
- 톤: 교육 앱 느낌 제거, 독립형 판타지 히어로 타워디펜스. 캠프 테마는 “전투 전 야영지”로 재해석.
- 결과물: 2D/2.5D 레이어 분리 PSD. 배경/안개/영웅/무기광/전경 파편/버튼영역 분리.

### 2) 3초 오프닝 모션 프로토타입
※ 런타임 애니메이션 검증용. 생성 정지화와 별도 관리.

**Beat 1 / 0.0–0.8s**
- 배경 숲/설원 레이어 Y -8px, 전경 안개 X +18px 이동.
- 영웅 실루엣 알파 0→100%.
- 카메라 흔들림 금지. 레이어 패럴랙스만 사용.

**Beat 2 / 0.8–2.0s**
- Bron 해머 룬광 0→100→35%, 스케일 1.00→1.025.
- 주변 영웅 무기 하이라이트 순차 점등, 각 0.15s.
- 파편 레이어 Y -10px, 알파 0→60%.

**Beat 3 / 2.0–3.0s**
- 전체 영웅 레이어 1.025→1.0 정착.
- 타이틀 페이드인 0.35s, Start 버튼 2.55s부터 알파 0→100%, Y +12px→0.
- 루프 시 마지막 프레임 유지.

### 3) 선택 영웅 0.6초 모션
- 선택 카드 확대 1.00→1.06→1.03.
- 캐릭터 상체/무기 레이어 Y -6px 후 복귀.
- 외곽광 0→80→35%.
- Bron은 해머가 6도 들렸다가 복귀. 신규 공격/스킬처럼 보이지 않게 연출.

### 4) Reduced Motion Mode
- 오프닝: 페이드만 사용, 이동량 0, 광량 50% 제한.
- 영웅 선택: 스케일 1.00→1.02, 무기 회전 없음.
- 자동/수동 옵션 제공. 기기 OS 설정 감지 가능하면 반영.

### 5) 라이트 GPU 비용 규칙
- 런타임 파티클 최대 20개, 블렌드 레이어 3개 이하.
- 풀스크린 블러/왜곡 금지.
- 2048 텍스처 1장 또는 1024 아틀라스 2장 기준.
- Spine/스프라이트 본 12개 이하. 30fps 기준, 저사양은 24fps 허용.

### 6) 모바일 UI 계층
1. Splash  
2. Title: 상단 로고, 중앙 키아트, 하단 Start  
3. Hero Select: 6영웅 카드 그리드, 선택 하이라이트, 하단 Confirm  
4. Hero Detail Confirm: 대형 영웅, 역할/무기/짧은 소재 팁, Confirm / Back  
5. Stage Map: 기존 8스테이지 숲/설원  
6. Battle: 2.5D 스프라이트 전투 HUD

### 7) 소재 팁 카피
- Wood + Fire: “마른 나무는 불이 붙기 쉽습니다. 습기와 두께에 따라 달라집니다.”
- Ice Impact: “얼음은 강한 충격에 금이 가거나 깨질 수 있습니다.”
- Metal Conduction: “금속은 열과 전기를 잘 전달하는 편입니다.”
- Insulators: “고무, 마른 천, 나무 등은 조건에 따라 전달을 줄이는 데 쓰입니다.”
