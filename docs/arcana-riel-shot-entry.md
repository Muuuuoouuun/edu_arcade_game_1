## 컨셉 대비 개선

[원본 컨셉](../art-source/defense/atlases/ranged-motion.png)의 큰 후드·금발·긴 귀·곡선 활과 실제 PC/모바일 전투를 비교했다. 기존 몸과 재질을 유지하면서 **걸음에서 곧바로 발을 벌리고 활을 끝까지 당긴 자세로 바뀌던 부분**을 선택했다.

기존 8개 보행 자세에서 각각 출발하는 실제 관절 클립을 만들었다. 떠 있는 장화(양발 접지 시 뒤쪽 발)를 먼저 옮기고, 그 발을 지지한 채 반대 장화를 옮긴다. 몸통의 작은 체중 이동·숙임과 머리·망토·양팔을 함께 정리하며 활을 당긴다. 시작은 해당 보행 자세와 같고 0.08초부터는 기존 사격의 모든 관절·화살 상태와 같다. **발사 0.10초, 전체 공격 0.28초와 기존 회수·화살촉 소켓은 유지한다.** 활대·시위는 공통 끝점에서 다시 계산해 연결한다.

전투에서는 움직이던 영웅/용병의 공격을 만들 때 보행 위상을 한 번 기록한다. 0–25ms는 그 보행, 25–55ms는 첫 발, 55–80ms는 둘째 발 자세를 표시한 뒤 기존 사격으로 이어진다. 시뮬레이션 시간에 연결되어 일시정지·배속에 따른다. 정지 사격·필살기·돌파·동작 줄이기는 기존 표시를 사용한다. 진입 이미지 하나라도 실패하면 기존 모델 사격/보행을 유지하고, 기존 모델 세트가 실패하면 원래 삽화 대체를 따른다.

**접지는 모델 내부 좌표 기준이다.** 이동 명령에 따른 전장 좌표 이동을 잠그지 않으며, 새 이동 명령이 발사 전 공격을 취소하는 기존 규칙도 유지한다. 계속 이동하며 쏠 때의 월드 좌표 발 고정과 방향 회전 보간은 구현 범위가 아니다.
