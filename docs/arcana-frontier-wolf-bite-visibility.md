# 서리 협곡 근접 물기의 가독성

[은서리 늑대 컨셉](../art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png)은 머리와 주둥이가 방향을 분명히 드러낸다. 기존 실시간 전장에서는 [접지된 물기](arcana-frontier-wolf-bite.md)가 영웅에게 겹치면 목과 턱이 가려졌다. 영웅의 몸을 잘라내는 시안은 몸통에 빈 구멍이 보여 폐기했다.

서리 협곡에서 영웅을 향한 물기 중 주둥이가 영웅 뒤에 있는 경우, 기존 GLB의 움직이는 머리와 턱 메시를 같은 3D 장면에서 옅은 서리색으로 한 번 더 그린다. 깊이 검사로 이미 가려진 조각만 표시하고 영웅의 재질과 깊이 버퍼는 바꾸지 않는다. 영웅에게 실제로 가려지는지 광선으로 먼저 검사하며, 여러 공격 중 피해 전의 가장 진행된 물기를 우선해 한 마리만 표시한다. 걷기, 성문 공격, 쓰러진 적에는 표시하지 않는다. 절벽·성문 가림이 활성화된 곳과 서리 성문 중심 4단위 안에서는 표시를 끈다. 기존 공격 예고, 발 접지, 피해와 조작은 유지된다.

이는 완전한 픽셀 단위 영웅 마스크가 아니다. 머리 중심 광선이 영웅에 닿을 때 다른 물체의 깊이에 가려진 머리 조각도 옅어질 수 있고, 특히 성문에서 더 먼 위치나 여러 적이 밀집한 장면은 추가 검증이 필요하다. 가장 우선한 한 마리가 안 가려지면 다른 늑대를 대신 표시하지 않는다. 동작 줄이기에서는 기존 정적 물기 자세를 유지하되 가려진 주둥이를 표시한다. 새 모델이나 Blender 모션은 만들지 않았으며 기존 [편집 원본·공통 렌더·GLB·전투 WebP와 재생성 명령](arcana-frost-wolf-grounded-stride.md)을 사용한다. 캠페인 전투는 기존 2.5D다.

## 검증

- `npm test`에 선택 우선순위·깊이 설정·영웅 재질 보존·정리·모델 누락과 실제 GLB의 PC/가로 모바일 8방향 검사를 포함한다.
- 3D 전장의 실제 시뮬레이션에서 준비 100 HP, 접촉 후 92 HP, 일시정지, 1·2배속, 동작 줄이기, 성문 인접 및 성문 공격 시 표시 해제를 검사한다.
- PC와 가로 모바일 브라우저에서 실제 메뉴·이동·스킬·일시정지와 모델/이미지 실패 대체를 확인한다. 브라우저의 모바일 화면과 소프트웨어 렌더러 측정은 실제 휴대기기 GPU 검증을 대신하지 않는다.

- 844×390 Chromium SwiftShader에서 표시 중 드로우콜은 47→49, 삼각형은 1마리에서 31,724→32,456, 30마리에서 98,772→99,504였다. 3초 평균 프레임 간격은 각각 90.9→92.3ms, 140.2→130.6ms로 측정 잡음이 커 기기 성능 향상을 뜻하지 않는다.
