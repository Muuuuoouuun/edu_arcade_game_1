# 뇌전 수정탑 Lv.3 — 이중 고리 충전·방출

2026-11-07 KST. 기준 `ea9c1f2`, 브랜치 `codex/arcana-stage-experience-20261106`.

원격 main `2eabc76`, Claude `895335c`/`bf7c1c6`와 진행 중인 작업을 확인했다. 열린 PR #81은 번개 표적·연쇄 로직이며 이번 모델 변경과 별개다. 서리늑대·영웅·기존 포탑 작업을 보존하고, **최종 강화하면 Lv.2의 관절 동작이 사라지던 번개 Lv.3**를 선택했다.

## 컨셉과 구현

[모듈 컨셉](../art-source/defense/concepts/2026-10-29/props/six-tower-modules.png)의 푸른 수정·여러 금속 띠·석조 기초를 유지한다. 기존 Lv.3의 비스듬한 고리를 높이와 반경이 다른 두 고리로 재배치했다. 위쪽 강철 고리, 바깥 금빛 고리와 여섯 구슬, 양옆 전극이 실제 메시와 관절로 충전·방출·복귀한다. 큰 고리가 올라가며 모였다가 기울어지고, 전극이 펼쳐진 뒤 원위치로 돌아온다. 넓은 이중 고리와 네 첨탑으로 Lv.2와 구분한다.

초기 자세에서 발견한 금속 고리와 수정·첨탑의 관통을 수정했다. 안쪽 고리 중심은 모델 Z 3.18, 바깥 고리는 Z 2.65·반경 1.40으로 분리하고 전극 진폭을 조정했다. 중앙 수정·피뢰침·네 첨탑·기초는 고정한다. 재생성 과정에서 25쌍의 강체 표면을 6개 베이크 자세와 실제 키프레임 40개 시점에서 검사한다.

전투에서는 같은 모델의 6포즈 WebP를 사용한다. 발사 시점 0.15초와 이후 0.24초의 반동 시간을 따라가며, 각 주요 자세는 시뮬레이션 시간 75–80ms를 유지한다. 피뢰침 끝을 공통 카메라로 투영해 충전광·발사광·탄 출발점에 연결했다. Lv.3 크기와 Lv.2 크기를 구분하고 발사 당시 등급을 사용하므로 강화·판매 이후의 탄이 이동하지 않는다. 피해·표적·연쇄·보상 규칙은 변경하지 않았다.

## 검증

- 최종 `npm run build` 통과. 전체 테스트 234개 중 233개 통과. 기존 수학 문제 `(3 × 7) ÷ 5`의 `4 !== 4.2` 실패는 기준 커밋 파일로도 재현했다. 최종 art 테스트 62/62 통과.
- 원본·재수입 GLB의 40프레임: 움직이는 실제 메시·고리 구슬 확인, 기초/네 첨탑 이동 0, 중립 복귀 오차 0. 강체 간섭 0, 렌더 알파·크롭·파일 해시 검사 통과.
- 명목 30Hz 게시·1/2배속·100개 위상에서 두 등급의 모든 주요 자세 표시 및 발사 전 방출 금지 검사 통과. 전투 시간 입력만 사용하며 일시정지와 동작 줄이기를 따른다.
- Chromium PC 1440×900·터치 390×844 실제 진입→건설→뇌전 분기→최종 강화→웨이브→발사 중 일시정지/복귀→1/2배속·동작 줄이기 확인. 전체/확대 화면의 전후 캡처를 확인했다.
- 보드 6조건(PC/390px/320px/동작 줄이기/아틀라스 실패/기본 이미지 실패)×7상태 통과. 고리 동작 중에도 몸 전체 변형 없음, 소켓/효과 오차 <0.000062px, 투사체 출발 일치. 강화·판매 후 기존 탄 위치 유지. 등급별 실패 대체 독립, 전투 GLB 요청 0.
- 작업실 PC/모바일의 실제 클립 변화·중립 복귀·메시 보기·회전·동작 줄이기·GLB 실패 시 PNG 대체 통과. 유닛별 WebGL 렌더러는 추가하지 않았다.

증거는 저장소 밖 `/tmp/arcana-hourly-20261107-1636/`의 전후 PNG·로그·검사 스크립트·상태 기록에 있다. 임시 경로는 환경 보존 기간에 따라 사라질 수 있다. 모바일 검사는 브라우저 뷰포트·터치 에뮬레이션이며 실기기 성능 측정은 아니다.
