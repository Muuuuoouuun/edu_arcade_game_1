# 러시 성채 진입 경사와 높은 광장

2026-11-12. 원본 `verdant-heart.png`의 흙길·차분한 풀·석조 단차를 실제로 보고, 체크 평면을 연결된 지면 메시로 교체했다. 이번 범위는 북쪽 낮은 들판에서 성채 광장까지의 한 경사다. 전 맵의 산악 지형이나 독립적인 3D 물리 엔진을 완성한 것은 아니다.

## 지면 계약

- 기존 x/z 경기장·경로·충돌·피해 판정은 유지한다.
- z≤1의 지면은 y=0, 1<z<5는 y=.3×(z−1), z≥5는 y=1.2다. 성채와 네 탑 부지는 같은 높은 광장 위에 놓인다.
- `src/rush/terrainElevation.ts`가 높이·실제 정점·조준 ray 교차의 유일한 원본이다. Blender 생성기는 이 모듈을 Node로 실행해 동일 정점을 읽는다.
- 플레이 표면 2,340삼각형, 경계의 울타리를 받치는 1.1m 폭 비이동 가장자리와 바위 측면 552삼각형, 합계 **2,892삼각형**이다. 신규 렌더러를 만들지 않는다. 낮은 품질에서도 지면은 유지된다.
- 숲의 넓은 녹색 영역·실제 적 경로와 일치하는 흙길·성채 광장은 정점색이다. 평면 지도 이미지를 입체라고 표시하지 않는다.

## 런타임

영웅과 적의 몸 원점·발밑 그림자·동전·성채·탑·엄폐물·파티클 바닥·카메라 초점·조준 ray가 같은 높이를 사용한다. 경사를 걸치는 석조 엄폐는 중앙 높이에서 형태를 유지하고 낮은 쪽에 기초를 채운다. 조준 범위·타격 고리는 개별 메시의 정점을 지면에 맞춘다. 영웅의 발밑 원점은 지면에 맞추지만 **발별 IK를 추가한 것은 아니다**.

직선탄의 표현은 발사점과 도착점의 높이를 보간한다. 눈덩이·필살기는 높이를 보간한 뒤 기존 포물선 연출을 더한다. 경사에 따라 탄을 매 프레임 꺾는 방식은 사용하지 않는다. 포탑 유도탄은 기존 추적 규칙을 유지한다. 실제 명중·엄폐 판정은 기존 결정론적 x/z 시뮬레이션이며, 수직 축 충돌이 추가됐다고 주장하지 않는다.

피해 표현을 보존하며 새 전투에 파티클을 비워 이전 성채 연기가 남지 않도록 한다. 피해 연기는 작은 회갈색 덩어리로 제한해 캐릭터나 위험 표시를 가리지 않도록 했다.

## 제작물과 재생성

```sh
blender --background --python-exit-code 1 --python tools/blender/build_rush_approach.py
node --experimental-strip-types --test src/rush/terrainElevation.test.ts
```

- 편집 원본: `art-source/defense/rush-approach.blend` (지면·바위 측면 각각 편집 가능한 메시)
- GLB·공통 카메라 PNG·보관용 WebP: `public/defense/models/rush-approach.*`
- 카메라·개수·재생성·파일 해시: `public/defense/models/rush-approach.json`
- 런타임은 같은 정점 생성 함수를 사용한다. GLB는 실제 내보내기·검수용 동반 자산이며, 2.5D 원정에 이 WebP를 연결하지 않았다.

검증은 연속성, 성채/탑 높이, 표면 법선, 정확한 3평면 ray 교차와 Three.js 삼각형 교차의 일치, 경계 밖 입력 거부, 실제 GLB 재불러오기 5개 테스트다. 브라우저·조작·성능 결과는 통합 인수 기록에 별도로 남긴다.
