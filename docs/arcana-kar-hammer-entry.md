# 카르 · 걸음에서 양손 망치 강타로

2026-11-08, 컨셉 개발 53회차. 기준 `646b72132eae57f97ba9558faf28c6410a0528d8`, 소유 브랜치 `codex/arcana-stage-experience-20261106`.

원본 `art-source/defense/atlases/melee-motion.png` 첫 줄과 실제 PC/모바일 화면을 비교했다. 붉은 머리·흰 털망토·양손 망치의 기존 실루엣은 유지되지만, 걷다가 공격하면 발이 고정 준비 자세로 즉시 바뀌었다. 이번 단위는 여덟 걸음에서 체중을 받고 망치를 들어 올리는 연결이다. 서리늑대 체형·보폭, 다른 영웅의 완료 동작, 포탑과 지형·성문·브론·통나무 병사 계보를 보존한다.

원격 main `2eabc76`, Claude nice `bf7c1c6`, 새 wizard `67fc1c4`를 확인했다. Claude 58회차의 리엘 활 두께·방향 시험은 읽고 별도 후보로 남겼다. 이번 구현에 그 미완료 실험을 통합하지 않았다.

## 실제 구현

- `kar-entry-0`~`kar-entry-7`: 원래 여덟 보행에서 시작하는 **0.56초·100fps·11개 관절** 실제 GLB 클립이다. 0.18초 이후 모든 관절이 기존 강타와 일치한다.
- 발의 높이·전후 위치로 먼저 디딜 발을 선택한다. 첫 0.09초에는 반대 발, 다음 0.09초에는 먼저 내려놓은 발의 변환을 고정한다. 이동 발은 낮은 호를 그리고 몸은 지지 발 쪽으로 체중을 받는다.
- 두 손은 망치 그립에 붙어 있다. 준비 중 몸통의 어깨와 실제 그립 위치에서 팔꿈치를 구하고 상완·전완을 다시 연결해 손이 망치에서 떨어지지 않는다.
- 영웅·용병이 이동 중 공격할 때 마지막 걸음 `walkEntry`를 한 번 기록한다. 전투 준비는 저장된 보행→0.06초 베이크→0.14초 베이크→기존 정점으로 이어진다. 표시 구간은 0~0.04, 0.04~0.11, 0.11~0.182초이며 공격의 `hitAt` 비율을 따른다.
- **0.28초 타격·0.56초 공격·기존 망치 접촉 궤적을 보존**한다. 돌진·필살기를 우선하고 정지 공격에는 기존 준비를 쓴다. 동작 줄이기와 선택 세트 로딩 실패에는 기존 강타가 유지된다. 카르의 기본 강타/보행 세트 실패에는 기존 일러스트 대체가 유지된다.
- 전투는 실제 모델을 베이크한 2.5D이며 유닛별 WebGL을 추가하지 않았다. 작업실은 단일 실시간 3D 장면에서 출발 걸음 선택과 실제 클립 재생을 제공한다.

접지는 모델 평면 기준이다. 이동하는 캐릭터의 월드 좌표 발 고정이나 지형 IK를 구현한 것은 아니다. 전투의 세 준비 자세는 연속 관절 보간과 다르며, 작은 기본 모바일 전장에서는 발의 세부 움직임보다 전체 실루엣으로 읽힌다.
