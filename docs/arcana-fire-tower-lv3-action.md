## 컨셉 대비 개선

`art-source/defense/concepts/2026-10-29/props/six-tower-modules.png`의 수정탑은 큰 수정·금속 지지대·석조 기초가 구분된다. 기존 Lv.3의 주황 수정·금빛 고리·네 첨탑은 유지했다. 실제 PC/모바일 화면을 비교하니 Lv.2에서 최종 강화하면 독립된 코어 동작이 사라지고 전체 탑이 흔들리며, 불꽃도 수정 옆에서 출발했다.

이번에는 **Lv.3의 고리를 실제 관절로 분리**했다. 고리의 금속·발광 띠와 여섯 불씨 구슬이 함께 기울고 회전한다. 충전할 때는 코어를 감싸고, 방출할 때는 고리가 펼쳐지며 수정과 청동 지지대가 반응한다. 네 첨탑·기초 금장·벽체는 고정한다. 수정의 투영 위치에 광원·섬광·탄 출발점을 연결해 강화 후에도 출발 위치가 일치한다.

고리는 중심 `(0,0,2.68)`의 강체 관절이며, 충전 자세의 추가 기울기/회전은 `(0.10,-0.18)rad`, 방출은 `(-0.27,0.28)rad`다. 원본의 기초·첨탑 81메시는 움직이지 않는다. 기존 Lv.2 원본·GLB·PNG·WebP·소켓 파일은 바이트 단위로 그대로다.

## 표시 시점과 Claude 기획 반영

Claude 47회차는 약 30Hz 상태 게시와 2배속에서 짧은 포즈가 건너뛰어질 수 있음을 지적했다. 이 문제를 이번 Lv.3의 **자세 선택 구간**에 반영했다. 엔진의 발사 0.15초, 반동 0.24초, 공격력·표적·이동·피해 규칙은 유지한다. 히트스톱이나 벽시계 기반 지연은 추가하지 않았다.

| 자세 | 전투 표시 구간 | 실제 GLB 키 시각 |
| --- | --- | --- |
| 중립 | 공격 전/반동 종료 | 0초, 0.39초 |
| 모으기 | 0~0.075초, 경과 0은 중립 | 0.05초 |
| 충전 | 0.075~0.15초 | 0.13초 |
| 방출 | 0.15~0.23초 | 0.15초 |
| 반동 | 0.23~0.31초 | 0.23초 |
| 가라앉기 | 0.31~0.39초 | 0.31초 |

각 주요 자세는 75~80ms의 시뮬레이션 구간을 갖는다. 일정한 30Hz 게시의 2배속 간격 약 66.7ms보다 길다. 게시 시작 위상 100개씩, 1/2배속 총 200조건에서 다섯 주요 자세가 모두 관측되는지 테스트했다. 실제 Chromium PC·모바일에서도 2배속 공격을 각각 3회 관측해 매번 준비/충전/방출/반동/회수가 표시됨을 확인했다. 임의 프레임 저하에서도 모든 포즈를 보장한다는 의미는 아니다.

동작 줄이기는 중립 모델과 중립 소켓을 사용한다. 일시정지·배속은 기존 시뮬레이션 입력을 따른다. 발사된 탄은 기존 `sourceLevel`을 사용하므로 이후 강화·판매와 관계없이 발사 단계의 소켓을 유지한다. Lv.2/Lv.3는 각자의 전체 아틀라스와 대기 렌더가 준비돼야 사용하며, 한 등급의 실패가 다른 등급의 동작을 끄지 않는다.
