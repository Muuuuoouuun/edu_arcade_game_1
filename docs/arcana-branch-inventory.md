- 로컬의 미커밋·미추적 파일과 저장소 밖 이미지들은 이 원격 목록에 포함되지 않는다.

재조회: `git ls-remote --heads origin`, `gh pr list --state all --limit 300 --json number,headRefName,headRefOid,state,mergeCommit,url`. 원격 tip은 PR의 `headRefOid`와, 병합 커밋은 main 조상 여부와 대조한다.
