## 4. 진단과 정정

1. **01회차 결론은 실제 구매 경로에서도 성립한다.** 합류 644는 입구 쪽 배치를 무너뜨린다(1-3 기본 예산: W20 → 패배). 다른 배치는 그대로다. 전체 구매(15개)를 해도 입구 쪽은 W12/8이다. 다 사기 전인 앞 웨이브의 **짓는 순서**가 결과를 정한다.
2. **정정**: 01회차는 합류가 “같은 지형에서 정답 배치를 **바꾼다**”고 썼다. 실제로는 정답을 **좁힌다**. 다리 쪽 배치는 합류가 없어도 1-2·1-3·1-4의 모든 조건에서 가장 좋거나 같다(1-4 빠듯함: 다리 쪽만 승리). 합류는 이미 약한 입구 쪽 배치를 실패로 바꿀 뿐이고, 판마다 다른 배치가 최선이 되게 하지는 않는다.
3. 그래서 “스테이지마다 생각할 거리”라는 01회차의 목표에는 **반대 방향의 규칙**이 하나 더 필요하다. 입구 쪽이나 가운데가 더 좋은 판이 있어야 같은 지형 세 판의 답이 서로 달라진다. 지금 다리 쪽이 강한 이유는 두 가지로 보인다. 영웅의 시작 위치(440, 355)가 가운데에 있고, 다리 쪽이 마지막 방어선이다.
4. 합류 462는 644의 약한 버전이다. 여유 난이도 후보로 쓸 수 있다는 01회차 판단은 유지한다.
