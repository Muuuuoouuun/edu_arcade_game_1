## 3. 결과

> **14회차 정정**: 이 장의 ‘능력 끔’ 조건은 측정 오류였다. 충전값을 매 단계 뒤에 지우는 방식이라 보스가 제자리에 멈춰 있었고(판당 11~94초), 그래서 ‘끄면 보스 처치’가 나왔다. 올바른 조건(충전이 시작되지 않음)에서는 **켜든 끄든 승패와 보스 돌파가 같고**, 능력이 있을 때 보스의 남은 HP가 오히려 21~23%p 낮다. 아래 표의 ‘능력 끔’ 열과 4장 1번은 쓰지 않는다 → [14-monster](14-monster.md) 3장. 충전 주기·필살기 재사용·경고 문구에 관한 내용(4장 2~4번, 6장 P0)은 그대로 맞다.

| 예산 · 정책 | 능력 켬 | 능력 끔 | 충전 / 동결 / 차단 |
| --- | --- | --- | --- |
| 빠듯함 · 조작 없음 | 패배(보스 전) | 패배(보스 전) | 0 / 0 / 0 |
| 빠듯함 · 필살기만 | W8, **보스 돌파** | W16, 보스 처치 | 6 / 3 / 3 |
| 빠듯함 · 능동 | W12, **보스 돌파** | W20, 보스 처치 | 6 / 3 / 3 |
| 빠듯함 · 필살기 아끼기 | W8, **보스 돌파** | W11, 보스 처치 | 6 / 3 / 3 |
| 기본 · 네 정책 | W15~W20 | 같음 | 3~4 / 1~4 / 0~2 |
| 전체 · 네 정책 | W20 | 같음 | 1~2 / 0~2 / 0~1 |

## 4. 진단

1. **보스의 타워 공격은 빠듯한 판에서 결과를 가른다.** 필살기를 쓰는 세 정책 모두 능력을 켜면 보스가 빠져나가고, 끄면 잡는다. 05회차의 일반·정예 국지 방해(어떤 판에서도 결과 불변)와 다르다. 전체 타워에 걸리는 효과라서 결과에 닿는다. 05회차의 정리(“타워 공격은 보스의 전체 효과로”)가 측정으로 뒷받침된다.
2. **충전의 절반은 끊을 수 없다.** 빠듯한 판에서 차단은 충전 6번 중 3번, 기본 예산에서는 3~4번 중 0~2번이었다. 원인은 엔진 숫자에 있다.
   - 첫 충전은 등장 후 진행 220 이후 6초 뒤에 오고, 이후 충전은 차단·동결 뒤 9초 + 충전 2.5초 = **약 11.5초마다** 온다(`engine.ts:398·406·407`).
   - 필살기 재사용은 **20초**다.
   - 그래서 매 충전을 끊는 것은 불가능하고, 차단은 많아야 두 번에 한 번이다.
3. **아껴도 나아지지 않는다.** 필살기를 충전 차단에만 아낀 정책도 차단 수는 3번 그대로였다. 무리를 치지 못한 만큼 HP는 오히려 낮았다(W8 대 능동 W12). “아껴 두면 막을 수 있다”는 판단이 성립하지 않는다.
4. **화면은 불가능한 행동을 요구한다.** 충전 경고는 필살기가 재사용 중이어도 “눈보라 충전 · 필살기로 끊으세요”라고 쓴다(`DefenseBoard.tsx:254`). 등장 알림도 “충전할 때 필살기로 끊으세요”다. 플레이어는 절반의 충전에서 할 수 없는 지시를 받는다.

## 5. 설계서 — 지역 보스의 타워 공격 틀 (작업 가정)

| 항목 | 기준 |
| --- | --- |
| 범위 | **지역 보스마다 하나.** 일반·정예에게는 주지 않는다(05회차) |
| 효과 | 전체 타워에 걸리는 짧은 효과(멈춤·약화). 2초 이하. 영웅·용병·펫과 이미 날아간 투사체는 영향 없음(PR #104 계약) |
| 예고 | 2초 이상. 보스 자세 + 충전 막대 + 남은 초 |
| 대응 | 필살기 차단(지금처럼 거리 무관) |
| **응답 가능률** | 충전 주기와 필살기 재사용을 맞춘다. 원칙: **“끊으라고 말하는 충전은 끊을 수 있어야 한다.”** 아래 셋 중 하나 |
| 화면 | 경고 문구가 필살기 상태를 따른다. 준비됨 = “지금 필살기로 끊으세요”, 재사용 중 = “타워가 2초 멈춰요 · 영웅으로 버티세요” |

응답 가능률을 맞추는 세 방법:

| 안 | 내용 | 장점 | 확인할 것 |
| --- | --- | --- | --- |
| A. 문구만 | 엔진은 그대로, 경고만 필살기 상태에 맞춘다 | 균형이 그대로다. 결정이 필요 없다(P0 UI) | 절반은 ‘버티는 충전’이 된다. 그래도 플레이어가 속지 않는다 |
| B. 충전 주기 늘리기 | 다음 충전까지 9초 → 18초 | 충전마다 대응 가능 | 서리군주 위협이 줄어든다. 빠듯한 판 결과를 다시 잰다 |
| C. 충전이 필살기를 당김 | 충전이 시작되면 필살기 재사용 −8초 | “보스가 힘을 모으면 영웅도 결의” — 연출과 맞는다 | 필살기가 더 자주 터진다. 03회차 필살기 모양 결정과 함께 정한다 |

**권장**: A는 지금 바로 한다(문구가 사실과 맞게). B·C는 03회차 필살기 모양 결정(방향 루프 04 질문)과 06회차 P0 적용 뒤에 다시 잰다. 3장 보스를 설계할 때도 이 표를 그대로 쓴다.
