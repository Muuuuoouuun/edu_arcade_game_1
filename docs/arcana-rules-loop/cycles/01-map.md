## 2. 세 분야 짧은 점검 (기준선)

### 맵

- 8스테이지가 **지형 두 개**를 나눠 쓴다. 1-1·1-2·1-3은 경로·건설 지점이 완전히 같고, 1-4는 둘째 길과 지점 2개만 더한다. 2-1~2-3, 2-4도 같다 (`src/games/defense/data.ts:46-83`).
- 엔진이 아는 지형 차이는 셋뿐이다: 고지대 지점 사거리 +45, 숲 물길 구간(x 650~735) 적 −20%·젖음, 설산 빙판 구간(x 300~520) 적 +25% (`engine.ts:13`, `engine.ts:413-416`). 날씨는 ‘비’만 효과가 있다(모든 적 젖음). ‘눈’·‘눈보라’, 1-3의 ‘차가운 서리’는 **엔진 효과가 없다**.
- 지점 설명이 엔진과 다르다: 물가 지점 “물길 인접 · 전기 연계에 유리”, 빙판 지점 “빙판 인접 · 적 이동 가속 구간” (`DefenseBoard.tsx:18`, `DefenseBattle.tsx:21`). 엔진에서 물가·빙판 지점은 평지와 똑같다.

### 몬스터

- 9종 모두 같은 목적(길 끝 마을)과 같은 움직임(길 따라 걷기·넉백)만 있다. 서로 돕거나 막는 상호작용이 없다. 타워에 영향을 주는 적은 서리군주(타워 2초 동결)뿐이다.
- 서리늑대 설명 “빙판에서 가속”은 늑대만의 특징이 아니다. 빙판 +25%는 **모든 적**에 적용된다 (`engine.ts:413`).
- 2-3이 갑자기 어렵다: 4웨이브 24마리·HP 합 9,162로 2-2(6,463)보다 +42%. 같은 6지점 석궁 배치가 2-2는 돌파 0, 2-3은 돌파 13(HP 7). 2-3의 ‘눈보라’는 효과가 없으니 숫자만으로 생긴 급등이다.

### 규칙·스킬·스테이지 완료

- P0 “보스 필수 격파”는 미반영. 이번 측정에서도 1-4가 고목왕을 놓치고(HP 20→12, 돌파 1) **승리**했다.
- 필살기는 전장 전체의 모든 적에게 맞는다(115 피해 기준). 1-1 1웨이브 새싹 도적 HP는 65라서 한 번에 모두 쓰러진다. 쓸 **시점**은 고르지만 **위치**를 고를 일은 없다 → 03회차.
- 스테이지 완료 = 4웨이브 종료 + 본진 생존. 등급·별은 없고 추가 퀘스트 3유형(마을 체력·외곽 보호·60마리 처치)만 있다.

## 3. 맵 측정과 진단

### 3-1. 경로·구간·지점 (현재 엔진, `map-audit.json`)

| 지형 | 길 | 길이 | 특수 구간 비율 | 통과 시간(새싹/늑대 · 돌 갑옷병) |
| --- | --- | ---: | ---: | --- |
| 숲 1-1~1-3 | 본길 | 1,095 | 물길 8% | 새싹 23.3초 · 돌 48.6초 |
| 숲 1-4 | 본길 / 강 건너 | 1,095 / 754 | 8% / 12% | 둘째 길은 약 31% 짧다 |
| 설산 2-1~2-3 | 본길 | 1,175 | 빙판 19% | 늑대 19.8초 · 돌 49.1초 |
| 설산 2-4 | 본길 / 피난처 | 1,175 / 723 | 19% / **46%** | 둘째 길 늑대 11.5초 |

- **길에서 어느 곳도 비어 있지 않다.** Lv1 석궁 사거리(205, 고지대 250)로 보면 본길 모든 점이 지점 1개 이상의 사거리 안이고, 3개 이상 겹치는 곳이 36~50%다. 사거리가 넓어 “어디에 짓느냐”의 차이가 작다.
- 1-4의 지점 6(평지)은 본길의 1%만 닿고 강 건너 길의 68%를 닿는다. 2-4의 지점 6(빙판)은 본길 0%·피난처 길 65%. 확장 지점은 **둘째 길 전용**으로 이미 역할이 나뉘어 있다(좋은 점).

### 3-2. 모든 지점에 지으면 뒤쪽은 쉰다 (`map-audit.json` util)

6~8지점 모두에 석궁 Lv1을 둔 판에서, 각 타워가 쏜 시간 비율:

| 스테이지 | 앞쪽 지점 0·1·2 | 뒤쪽 지점 3·4·5 | 결과 |
| --- | --- | --- | --- |
| 1-1 | 100 / 72 / 55% | 5 / 0 / 0% | 승리, 돌파 0 |
| 1-2 | 97 / 80 / 75% | 32 / 0 / 0% | 승리, 돌파 0 |
| 2-1 | 92 / 76 / 83% | 47 / 8 / 7% | 승리, 돌파 0 |
| 2-3 | 73 / 66 / 74% | 66 / 43 / 44% | 승리, **돌파 13** |

다만 “앞쪽만 지으면 된다”는 뜻은 아니다. 지점 3개만 고르면 1-2에서 앞쪽 3지점(0·1·2)은 돌파 4, 뒤쪽 3지점(3·4·5)은 돌파 0이었다(영웅이 가운데 서 있어 뒤쪽과 겹침). **문제는 1-1·1-2·1-3의 정답 배치가 같다는 것**이다. 지형이 같으니 한 번 찾은 배치를 세 판 내내 쓴다.

### 3-3. 실험 A — 길 중간 합류 지점 (`map-experiment.jsonl`)

적 3명 중 1명(2번째)이 길 처음이 아니라 중간에서 나타나게 했다. 462 = (410, 285) 꺾이는 곳, 644 = (520, 430) 다리 서쪽 끝.

| 스테이지 | 배치 | 지금 | 합류 462 | 합류 644 |
| --- | --- | --- | --- | --- |
| 1-1 | 앞쪽 3 | 돌파 0 | 0 | **4** (HP 16) |
| 1-1 | 뒤쪽 3 | 0 | 0 | 0 |
| 1-2 | 앞쪽 3 | 4 (HP 16) | 2 | **17 (HP 3)** |
| 1-2 | 뒤쪽 3 | 0 | 0 | 0 |
| 1-2 | 모든 6 | 0 | 0 | 0, 뒤쪽 지점 3·4·5가 44·37·21% 쏨 (지금 32·0·0%) |

- 합류 지점 하나로 **같은 지형에서도 정답 배치가 바뀐다.** 앞쪽 3 배치는 크게 무너지고 뒤쪽·고른 배치는 그대로다. 실수해도 판 전체가 끝나지는 않는다(HP 3으로 승리).
- 462(앞쪽과 가까움)는 효과가 작고, 644(다리 앞)는 크다. 합류 위치가 곧 난이도 손잡이다.
- 1-3은 석궁만으로는 앞쪽 3이 모든 조건에서 패배했다(얼음 갑옷병 때문. 속성이 필요한 판이라 이 실험으로는 구분이 안 된다).

## 4. 설계 제안

### 제안 1 — 스테이지마다 새로운 것 하나 (지형 또는 날씨)

같은 배경 그림을 다시 쓰고, **스테이지마다 규칙 하나만 새로** 더한다. 지형 규칙(길의 모양·구간)과 날씨 규칙(전장 전체)을 나누어, 한 판에 새로 배우는 것이 하나를 넘지 않게 한다.

| 스테이지 | 지형 | 날씨 | 이 판에서 새로 배우는 것 | 상태 |
| --- | --- | --- | --- | --- |
| 1-1 숲 가장자리 | 기본 | 맑음 | 건설·속성 약점 | 지금과 같음 |
| 1-2 제재소 구조 작전 | 기본 | 비: 모든 적 젖음 | 연쇄 번개 | 지금과 같음 |
| 1-3 서리 낀 옛길 | **옛길 합류** — 3명 중 1명이 다리 앞(644)에서 나타남 | 맑음 (‘차가운 서리’ 문구는 효과 없음을 반영해 바꿈) | 두 번째 등장 지점 → 뒤쪽 지점 | **제안** |
| 1-4 강 건너의 불빛 | 두 진입로 + 외곽 (+ 옛길 합류 유지) | 비 | 두 거점, 보스 | 지금 + 합류 |
| 2-1 눈꽃 고갯길 | 빙판 구간 (+25%) | 눈 (효과 없음) | 빙판 | 지금과 같음 |
| 2-2 늑대 무리의 습격 | **눈더미 구간** — 아래쪽 길 ×0.8 | 눈 | 빠른 곳(빙판)과 느린 곳(눈더미) 중 어디서 칠까 | **제안**, 실제 구매 경로로 재측정 필요 |
| 2-3 영물의 발자국 | 기본 | 눈보라 → 새 규칙 필요 (사거리 −30은 기각) | (04회차에서 다시 설계) | **보류** |
| 2-4 서리 왕좌의 결전 | 두 진입로 + 외곽 | 눈보라 | 보스 충전 차단 | 지금과 같음 |

**1-3에 합류를 두는 이유**: 이야기가 이미 “얼음 갑옷을 입은 적들이 **내려와요**”다. 옛길(북쪽 산길)에서 내려오는 적이 다리 앞에 합류하면 이야기와 규칙이 같다. 1-2(비·연쇄)와 겹치지 않고, 1-4의 둘째 길을 배우기 전 단계가 된다.

세 축 판단:

| 축 | 판단 |
| --- | --- |
| 게임성 | 통과. 같은 지형에서 정답 배치가 달라진다(측정은 1-3과 경로가 같은 1-2에서: 앞쪽 3 배치 돌파 4→17, 뒤쪽·고른 배치 0 그대로. 1-3 적 구성으로는 실제 구매 경로로 재측정 필요). 졌을 때 “합류 지점 옆에 지었어야 했다”가 화면에 보인다 |
| 오락성 | 통과. 같은 지형이라도 판마다 새 판단이 생긴다. 숲 세 판의 반복감이 줄어든다 |
| 정체성 | 보통. 합류·감속 구간은 장르 공통 문법이다. 아르카나다움은 **이야기와 묶을 때** 생긴다(옛길에서 내려옴, 눈더미 = 늑대가 파 놓은 굴?) |
| 비용 | 낮음. 새 배경 없음. 합류 표지(화살표·바위틈) 그림 1개, 눈더미 구간 덧칠 1개, `StageDef`에 규칙 칸 |

수용 기준(구현할 때):

1. 규칙은 **전투 전 예보**(웨이브 예보 창)와 **맵 위 표시**(합류 화살표·구간 덧칠)가 모두 있다. 예보에 “3명 중 1명은 다리 앞에서 나타나요” 한 줄.
2. 합류는 웨이브 계획에서 정해진다(무작위 없음). 예보와 실제 등장이 같다는 기존 테스트 규칙(`difficulty.ts` 주석)을 그대로 지킨다.
3. 보스는 합류하지 않는다(언제나 길 처음에서).
4. 기본 난이도에서 앞쪽 3 배치로도 패배하지 않는다(측정: HP 3 승리 → 경계선이므로 여유 난이도에서 합류 위치를 462로 당기는 것도 후보).
5. 엔진 테스트: 합류한 적의 첫 위치가 합류 지점과 같다, 합류 적의 진행 거리는 합류 지점부터 센다(돌파 판정 변화 없음).

### 제안 2 — 지점 설명을 엔진과 맞춘다 (P0, 결정 불필요한 쪽)

지금 설명은 플레이어에게 없는 효과를 약속한다. 결정 전에 할 수 있는 최소안은 **문구 정정**이다.

| 지점 | 지금 문구 | 최소안 (문구만) | 정식안 (사용자 결정 후) |
| --- | --- | --- | --- |
| 물가 | 물길 인접 · 전기 연계에 유리 | 물길 옆 · 물길을 지나는 적은 젖어요 | **물가 타워의 공격은 적을 젖게 함(2초)** → 옆의 뇌전탑이 연쇄 |
| 빙판 | 빙판 인접 · 적 이동 가속 구간 | 빙판 옆 · 이 구간의 적은 빨라요 | 그대로(경고 표시로 충분) |
| 고지대 | 고지대 · 사거리 증가 | 고지대 · 사거리 +45 | 그대로 |

정식안(물가 = 적을 적심)의 이유: 비 오는 판(1-2·1-4)이 아니면 연쇄 번개를 쓸 기회가 물길 8% 구간뿐이다. 물가 지점에 석궁을 두고 옆에 뇌전탑을 두는 **조합**이 생긴다. 비 오는 판에서는 효과가 겹쳐 의미가 없으므로, 맑은 판의 선택지가 된다. 측정은 결정 후(04회차) 사본에서 한다.

### 제안 3 — 몬스터 설명 정정 (P0, 문구만)

서리늑대 “불 약점 · 빙판에서 가속” → 빙판 가속은 모든 적에게 같다. 둘 중 하나:

- 최소안: “불 약점 · 가장 빠른 적” (늑대 속도 57, 가장 빠름).
- 정식안(02회차에서 다룸): 늑대만 빙판 +50%, 다른 적 +15%처럼 **늑대의 특징으로 만든다**.
