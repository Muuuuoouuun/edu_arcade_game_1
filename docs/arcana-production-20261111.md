# 2026-11-11 모델링·전투·운영 작업

이 문서는 11월 11일 시점의 기록이다. **11월 12일 후속 작업**에서 카르·브론·관통 석궁 Lv2·나무 병사의 GLB를 캠페인에 연결하고 인간 창방패병 시제품을 제작했다. [최신 구현 범위와 검증](arcana-battle-models-20261112.md)을 현재 상태의 기준으로 사용한다.

## 제작과 검토

카르의 기존 Frontier 원본에서 망치 자루와 머리 양끝을 조정한 Blender·GLB 사본, 전후 이미지, 생성·검증 도구를 만들었다. [작업 기록과 제한](../art-source/defense/kar-detail-20261111/README.md). 런타임 메시와 편집용 개별 메시의 변형은 완전히 동일하지 않아 최종 채택 전 정렬이 필요하다. 작은 화면과 모든 방향의 관통, 물리적 접지 및 기기 성능은 확인하지 않았다.

원본 카르·발리스타·나무 병사 및 카르 디테일 시안은 `/model-lab.html`에서 GLB 회전 및 각 공격 클립 재생으로 비교할 수 있다. 이들은 개발용 작업실 자료며 현재 캠페인과 모바일 APK의 실시간 전투에 연결하지 않았다. 기존 3D 지형 위 캐릭터와 타워의 표현은 스프라이트다.

[발리스타·나무 병사 이미지 검토](arcana-model-reviews-20261111/README.md)는 실제 Frontier 정지 렌더를 각각 Claude Fable 5.2 `high`에 제공한 의견이다. 두 요청 모두 본문 반환·정상 종료, 입력 합계 888 / 출력 합계 3,521토큰. 제안은 실물 시안을 보는 참고 사항이며 화면 가독성이나 동작 검증을 대신하지 않는다.

## 전투 로직

[`sampleAttackAnimation`](../src/games/defense/animationTiming.ts)은 엔진 공격의 `elapsed`·`hitAt`·`duration`을 실측한 3D 클립 접촉 시각에 맞춘다. 피해·명중 이벤트는 만들지 않는다. 엔진 기반 테스트는 일시정지·히트스톱·이동 취소·타워 동결·재조준·공격 중첩을 확인한다. GLB별 접촉 시각 실측과 Three.js 전장 렌더러 연결은 아직 하지 않았다.

## 운영

[단일 이미지 검토 도구와 운영 안내](arcana-fable-review-operations.md)는 키를 환경에서 읽고 모델·effort를 명시하며 요청 해시로 동일 호출 중복을 막고 응답·사용량을 기록한다. 자동 재시도는 없다. 타임아웃은 과금과 처리 결과 미확인으로 남긴다. 중복 원장은 이 작업 공간에만 적용되며 계정 전체의 한도나 비용을 강제하지 않는다. API 사용량과 실제 금액은 계정에서 확인한다.
