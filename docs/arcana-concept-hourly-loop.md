# 컨셉 기반 모델·움직임 반복 개발

2026-11-06 사용자 지시: “계속 디벨롭, 컨셉 아트 기반, 1시간 단위 루프”. 이전 개발 루프의 일반적인 여섯 분야 순환보다 **컨셉을 실제 3D·2.5D 게임으로 구현하는 작업**을 우선한다.

## 예약과 개발 결과

호스팅 자동화 **아르카나 컨셉 개발 루프**를 등록했다. 등록 당시 설정은 Asia/Seoul, 2026-11-06 18:37:23 시작, `FREQ=HOURLY;INTERVAL=1`, 활성화다. 현재 대화의 실행 환경을 상속하는 설정이며 미래 실행 성공을 미리 보증하지 않는다. 실제 활성 상태·실행 결과는 자동화 도구로 다시 확인한다.

이전 `tools/arcana_loop.py`는 환경 안의 별도 Claude 실행기다. 이번 등록에서는 이를 시작하지 않았다. 다른 개발 세션의 소유권과 변경 파일을 확인하고 겹치는 편집을 시작하지 않는다. 이전 회차가 진행 중이면 중복 작업 대신 상태를 확인하고 인계한다. 한 회차는 40~45분에 마무리하고 최대 50분에 중간 결과를 인계한다.

## 한 회차의 순서

1. 원격 main·Claude 브랜치와 미커밋 작업을 확인한다. `codex/arcana-stage-experience-20261106`의 모델·성문·지형·보행 개선이 main에 들어갔는지 확인한 뒤 통합 개발 계보를 이어간다. fetch refspec이 제한됐을 수 있으므로 `git ls-remote`로 실제 브랜치 SHA를 비교하고, 필요한 Claude 브랜치는 명시적으로 fetch한다.
2. 실제 컨셉 이미지를 열고 같은 대상의 모델과 게임 화면을 본다. 실루엣·재료·자세·발 접지·공격 시점 중 줄일 차이를 한 문장으로 정한다.
3. 검증 가능한 한 단위를 구현한다. 모델링이면 형태·구조를 바꾸고, 움직임이면 관절·접지·준비/타격/복귀와 시뮬레이션 연결을 다룬다. 문서나 작은 색 변경만으로 모델 제작을 대신하지 않는다.
4. 편집 원본, 재생성 명령, 공통 카메라·지면 기준, 배포 파일과 해시를 남긴다. 3D 원본·실시간 3D·2.5D 렌더·생성 삽화를 구분한다.
5. 관련 자동 검사와 PC/모바일 실제 조작을 검증한다. 일시정지·배속·동작 줄이기·로딩 실패를 변경 범위에 맞게 확인한다. 같은 조건의 전후 화면, 개선점과 남은 차이를 기록한다.
6. 검증된 변경을 개발 브랜치에 커밋·푸시하고 원격 SHA를 확인한다. 자동 main 병합·서비스 배포는 포함하지 않는다. 실패·미완료·무변경을 성공으로 표시하지 않는다.

일시적 화면·로그·회차 상태는 저장소 밖 증거 폴더에 두고, 반복 제작에 필요한 설계·규격만 저장소에 남긴다. 새 실행 환경에서는 임시 파일이 없어도 원격 커밋과 제작 문서에서 이어갈 수 있어야 한다. 통과 후 변경이나 새로운 우려 없이 같은 검사를 반복하지 않는다.

## 제작 판단

- 참고작: 브롤스타즈의 동작 가독성과 무게감, 클래시 오브 클랜의 축소 화면 실루엣·건축 재료 구분, 사용자가 지정한 기존 디펜스의 경로·포탑·전선 판단.
- 컨셉: `art-source/defense/concepts/2026-10-29/`, 최신 `2026-11-06/`, [컨셉 갤러리](arcana-world-planning/concept-gallery.md), [지역 확장](arcana-world-planning/concept-expansion-2026-11-06.md).
- 제작 기준: [모델 제작 과정](arcana-asset-pipeline.md), [모델·보행 개선](arcana-model-motion-development.md), [지형·액션](arcana-terrain-action.md).
- 원본의 성격은 보존하되 작은 게임 크기에 필요한 단순화를 명시한다. 펫·몬스터·수인은 장구·체형·자세로 구별한다.
- 현재 전투는 베이크 기반 2.5D다. 실시간 3D 전장으로 확장할 때는 단일 장면의 지형 가림·좌표 입력·유닛 수별 성능부터 검증한다.
- Blender와 필요한 라이브러리는 사용 가능하다. Claude API는 연결된 인증과 실제 모델 가용성을 확인한 경우만 사용한다. 없는 키·호출·검토 성과를 만들어내지 않는다.
