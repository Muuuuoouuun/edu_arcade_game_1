# 서리늑대의 접지된 처치 동작

2026-11-06 여섯 번째 컨셉 개발 회차. 완료된 은서리 체형·8단계 보행은 보존하고, 피격 자세를 축소해 지우던 처치 표시를 별도 관절 동작으로 바꿨다.

## 컨셉과 형태

원본은 `art-source/defense/concepts/2026-10-29/beasts/silverfrost-wolf.png`다. 회백색 몸·짙은 발·긴 다리를 유지하면서, 무릎이 접히고 몸통이 낮아지는 무게를 추가했다. 네 발 중심은 고정하고 몸통을 0.7 모델 단위 낮춘다. 목·턱·꼬리가 뒤따라 멈추고 눈이 가늘어진다. 최종 자세는 무릎을 접고 주저앉은 형태이며, 옆으로 완전히 눕는 동작이나 래그돌은 아니다.

기존 `frost-wolf.blend`, 보행 GLB와 베이크는 변경하지 않았다. 복사한 원본에 무릎·발 피벗을 만들고 상·하박 메시를 관절 사이에 맞췄다. 생성 시 평면 IK로 발 접지를 계산한 뒤 키프레임을 저장한다. 전투와 작업실에는 IK 계산기가 필요하지 않다.

동일한 384px 카메라·배율에서 불투명 실루엣 높이는 181px에서 141px로 약 22% 낮아졌다. 기존 피격 포즈와 최종 포즈의 고정 좌표 알파 마스크 IoU는 0.30이다. 이는 자세 차이의 자동 측정이며 사용자 인지 실험은 아니다.

## 산출물과 재생성

```bash
npm run models:wolf-collapse
# 렌더 없이 19개 시점의 접지·메시 지면·카메라 경계 확인
blender --python-exit-code 1 -b --python tools/blender/build_wolf_collapse.py -- --check
```

- 편집 원본: `art-source/defense/frost-wolf-collapse.blend`
- 공통 카메라 PNG 4장: `art-source/defense/wolf-collapse/`
- 실시간 3D: `public/defense/models/frost-wolf-collapse.glb`, 0.6초 단일 클립, 약 272KB
- 전투: `frost-wolf-collapse-atlas.webp`, 1536×384, 약 33KB
- 정지 미리보기: `frost-wolf-collapse.png`
- 카메라·접지 좌표·프레임·원본 및 산출물 해시: `frost-wolf-collapse.json`

기존 늑대와 같은 정사영 카메라, 프레임 crop `(8,100,368,228)`, 지면 Y `284.49`, 표시 배율 `368/315`를 쓴다. 프레임 1·6·11·16을 베이크하며 클립은 19프레임까지 끝 자세를 유지한다. 모델 작업실은 `/model-lab.html?model=frost-wolf-collapse`에서 실제 GLB를 재생한다. 끝 자세를 유지하고 재생 버튼으로 다시 시작한다. GLB 실패 시 PNG임을 명시한다.

## 전투 연결

처치 판정·보상·효과 수명 0.7초는 유지한다. `Effect.age`의 진행률 0·0.24·0.48·0.72에 맞춰 포즈를 고르고, 마지막 0.21초 동안 투명도를 낮춘다. 추가적인 전체 몸 축소·낙하·회전과 파편을 적용하지 않는다. 살아 있는 늑대와 같은 모바일 유닛 확대율과 발 기준점을 사용한다. 좌우 방향은 마지막 처치 효과의 방향을 따른다.

일시정지는 같은 포즈를 유지하고 배속은 시뮬레이션 시간을 따른다. 동작 줄이기에서는 마지막 포즈를 고정한다. 기본 모델 또는 처치 아틀라스가 실패하면 기존 피격/삽화 대체 경로를 유지한다. 전투 로더는 GLB를 요청하지 않는다.

## 확인 결과

- Blender 원본 재열기와 GLB 재가져오기: 19개 시점의 최대 발 중심 이동 약 `3e-7`, 최저 메시 높이 `0.0066`으로 지면 관통 없음. 기존 보행 원본 해시 일치.
- 에셋/전투 관련 76개 검사 통과. 전체 176개 중 175개 통과. 기존 수학 엔진의 `(3 × 7) ÷ 5` 기대값 4/4.2 불일치 1건은 이번 범위 밖이다. 프로덕션 빌드 통과.
- 설치된 Playwright·Chromium의 1440×900 / 390×844 실제 UI: 설산 입장·마법탑 건설·영웅 이동·웨이브·8단계 늑대 보행·처치 4포즈·일시정지/재개·배속 확인. 처치 표시 수명은 PC 1배 694ms / 2배 341ms, 모바일 691ms / 357ms였다.
- 같은 전투 컴포넌트의 고정 상태 검토: 양방향 4포즈, 일정 크기·접지, 동작 줄이기, 처치/기본 아틀라스 실패 대체 확인. 작업실의 끝 자세 유지·재생·메시 표시·동작 줄이기·GLB 실패 표시 확인. 예상 밖 페이지 오류 없음.
- 작업실 GLB는 2,300 삼각형이다. 이는 모바일 실기기 성능 검증을 대신하지 않는다. 실제 Android 기기 측정은 남아 있다.

다음 우선 후보는 성문 진입부의 구조·크기·조명·유닛 가림이다. 늑대의 도약과 착지는 피해 판정까지 별도로 설계할 때 다룬다. 이번 회차는 예약을 새로 등록하거나 변경하지 않았다.
