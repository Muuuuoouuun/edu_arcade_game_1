# 변경 전장 발리스타 착탄 파편

2026-11-09 KST. 기준 `459031cd08ae9323f131d8a9d26215009f04a2e7`, 브랜치 `codex/arcana-stage-experience-20261106`.

기존 발리스타 컨셉과 실제 가로 전장을 확인했다. 원래 3D 발리스타는 소켓에서 볼트를 내보내 표적을 추적하고 실제 도착 시 피해를 주지만, 착탄은 일반 섬광이었다. 이번에는 실제 볼트의 마지막 이동 방향과 접촉점에서 목재 파편 여덟 개가 진행 방향으로 퍼지고 아래로 떨어지게 했다. 시작 높이는 기존 적 몸통 착탄 높이 1.1, 0.46초 동안 수평 속도·초기 상승 속도와 일정한 중력으로 궤적을 계산하며 지면·다리·수면 아래로 내려가지 않는다. 파편별 속도와 회전을 다르게 해 재현 가능하게 만든다.

게임 좌표를 쓰는 연출용 근사다. 파편은 충돌 피해, 반사나 강체 시뮬레이션을 만들지 않으며 지면에서 미끄러질 수 있다. 볼트의 기존 유도·타격 시점·피해·대상·강화 규칙은 유지한다. 시뮬레이션 시간, 일시정지, 2배속을 따르고 동작 줄이기에서는 파편을 생략하고 짧은 명중 섬광을 유지한다. 기존 접촉 파편의 인스턴스 풀과 단일 Three.js 장면을 재사용한다. 새 모델이나 Blender 동작 클립, 캠페인 2.5D 스프라이트를 제작한 것은 아니다.

## OpenAI 시안

사용자가 지정한 연결된 OpenAI 이미지 생성 도구 `image_gen.imagegen`으로 기존 6종 포탑 컨셉을 참조한 발리스타 착탄 시안 한 건을 생성·확인했다. [원본 시안](../art-source/defense/concepts/2026-11-09-openai/ballista-impact-reference.png)과 같은 폴더의 출처 JSON을 보존한다. 시안은 게임 화면이나 3D 모델이 아니며, 파편은 별도의 절차적 3D 메시다. 직접 OpenAI REST 및 Claude API는 호출하지 않았고 API 사용 비율을 주장하지 않는다.

## 검증

- 관련 발리스타·효과·엔진 테스트 22개와 `npm run build` 통과. 착탄 전 무피해·무파편, 진행 방향, 상하 궤적과 지면, 0길이 방향, 일시정지·2배속·동작 줄이기와 피해 중복 방지를 확인했다. 전체 테스트를 이번에 재실행한 것은 아니다.
- 실제 PC 1440×900 / 모바일 844×390에서 같은 타워 건설·발사·착탄·일시정지·2배속·동작 줄이기를 전후 비교했다. 발리스타 GLB 로딩 차단 후 기본 입체 포탑에서도 발사와 파편을 확인했다. 착탄 직후와 파편이 퍼진 시점도 실제 모바일 화면에서 확인했다. 전장 전체 보기에서는 파편이 작고 적과 겹쳐 잘 구분되지 않는 한계가 남는다. 증거는 `/tmp/arcana-ballista-impact-20261109-1904/`에 있다.
- 844×242 Chromium SwiftShader 장면에서 지속 착탄 효과를 인위적으로 유지한 3초 단일 표본: 적 1개 평균/p95 72.86/83.4→72.12/83.4ms, 적 30개 115.94/133.4→116.22/133.4ms. 드로콜 40→41, 삼각형 64개 증가. 장치·표본 한계상 실제 Android 성능이나 개선을 주장하지 않는다.
