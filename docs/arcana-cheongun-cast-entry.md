# 청운의 걸음에서 부적 시전으로

2026-11-08 · 컨셉 개발 45회차. 기준 `40e075624674565935d0095cdc1c258361fee13b`, 개발 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉 대비 개선

원본 `art-source/defense/concepts/2026-10-29/motion/talisman-cast-keyposes.png`의 넓은 흰 소매·청록 도포·들어 올린 부적 손과 기존 게임 화면을 직접 비교했다. 기존에는 걷던 청운이 즉시 준비 자세로 바뀌었다. 이제 마지막 걸음에서 한 발씩 디디고 몸의 무게를 정리하며 부적을 들어 올린다. 기존 체형·재질을 유지한 실제 관절 동작 개선이다.

서리늑대의 보행·피격·쓰러짐, 주요 포탑 조준·반동, 지형·성문은 앞 회차 완료 범위다. 원격 main `2eabc76`, Claude `nice-meitner` `bf7c1c6` / `wizardly-shannon` `6b33852`와 최근 기록을 확인했다. Claude 55회차의 포탑 표적·쿨다운 검토는 이번 동작과 별개다. 통합 계보의 완료 작업과 기존 Vite 프로세스를 보존했다.

## 실제 구현

- 여덟 보행 자세를 출발점으로 하는 `cheongun-entry-0`~`7`, 각각 0.33초·100fps·16개 애니메이션 노드다.
- 처음 0.05초에 들린 발을 내려놓고 다음 0.05초에 다른 발을 정리한다. 지지 발은 모델 평면에서 고정한다. 몸통의 작은 체중 이동과 부적·붓 손의 준비를 연결한다.
- 진입 구간의 양쪽 위팔·아래팔을 공통 어깨·팔꿈치·손 끝점으로 다시 계산해 소매가 관절 사이에서 벌어지지 않도록 했다. GLB 보간 중 최대 연결 오차는 공통 카메라 약 0.242px다.
- **0.10초 이후 기존 시전, 0.15초 발사, 전체 0.33초 공격과 피해·이동 판정을 유지한다.**
- 전투에서는 기존 출발 보행 → 0.04초 첫 디딤 → 0.08초 두 번째 디딤 → 기존 시전을 사용한다. 표시 경계는 0.025/0.065/0.10초다. 준비 광원은 8방향×8걸음×3시점의 실제 부적 끝 소켓 192개를 따른다.
- 영웅·용병 공격에 기존 시각 필드 `walkEntry`를 기록한다. 동료 청운이 이동하며 매 틱 주인을 따라잡을 때 보행 표시가 사라지는 문제는 실제 이동량으로 판정한다. 준비 화면에서 멈추면 표시 속도만 0으로 정리하며 새 정지 애니메이션이나 시계 진행은 추가하지 않는다.
- 필살기·돌진이 우선한다. 제자리 시전·동작 줄이기는 기존 시전을 유지한다. 새 이미지 하나라도 실패하면 새 진입만 끄고 기존 세트를 사용한다.

전투는 베이크 WebP 기반 2.5D이고 작업실은 단일 장면의 실제 GLB다. 유닛별 WebGL 렌더러는 추가하지 않았다.

## 산출물과 재생성

## 검증과 증거

증거 폴더 `/tmp/arcana-hourly-20261108-1341/`에 시작 시 기준·소유 브랜치·범위·수용 기준·미완료 상태를 기록하고 갱신했다.

- 전체 테스트 **307개 중 306개 통과**, 타입 검사·프로덕션 빌드 통과. 실패 1건은 기준에서도 재현한 기존 수학 게임 `(3×7)/5`의 4/4.2 불일치다. 새 베이크를 추가하며 달라진 사전 로딩 수의 기존 테스트는 원래 시전/보행 16개를 명확히 세도록 수정했다.
- 납품 GLB의 저작 시점 272개·보간 시점 1,064개를 검사했다. 기존 보행 시작 오차 최대 `1.84e-7`, 0.10초 이후 시전 오차 `1.28e-7`, 소켓 오차 `1.40e-7`, 지지 발 이동 `1.12e-16` 미만이며 발바닥 최저 높이 약 0.005다. 원본·생성기·산출물 해시 144개 통과.
- `.blend` 재열기에서 159개 메시×8세트 시작/끝 변환 오차 0. PNG 128장·WebP 128셀의 해상도·알파 경계, 최소 투명 여백 14px, 배포 파일 11개의 원본 일치를 확인했다.
- 스테이지 1·4·5·8의 영웅/용병 8게임·14,400스텝을 기준과 비교했다. 청운 공격/투사체의 `walkEntry`와 동료 청운의 표시용 속도만 제외하고 게임 상태가 일치했다.
- 실제 `DefenseBoard` 마운트에서 영웅/용병×8방향×8걸음·시전 시점, 1440/390/320px, 동작 줄이기, 새 진입/기존 시전/보행 이미지 실패 및 별개 이안 정지 이미지 실패의 **3,072조합**을 확인했다. 부적 끝 광원 좌표·우선순위·페이지 오류·가로 넘침·전투 GLB 요청도 검사했다.
- 실제 PC·390px 터치 UI로 입장·이동·웨이브·자연 시전, 1·2배속, 시전 중 일시정지·동작 줄이기·복원·재개를 조작했다. 보행 8프레임, 준비·발사·회수, 진입 자세를 관측했다. 모바일 전장 확대 버튼도 조작하고 확대 화면을 확인했다. 최초 자동화는 저장 데이터의 해금 정규화로 이안이 선택되어 실패했다. 3스테이지 클리어와 실제 `data-actor=tao` 확인을 넣은 뒤 PC/모바일 모두 통과했고 초기 로그도 보존했다.

## 남은 문제와 다음 후보
