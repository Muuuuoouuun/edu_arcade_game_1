# 컨셉 아트와 전투 화면 연결

2026-11-06. 이번 작업은 기존 8개 스테이지의 표현 개선이며, 게임은 2.5D SVG 방식을 유지한다.

## 성문

녹음 성채·청강 요새·운령 산성·황혼성의 준비 화면 컨셉을 참고해 전투용 투명 성문 4종을 제작했다. 석재, 기와, 목재, 금속, 깃발과 등불을 포함한다. 이는 생성된 **2D 일러스트 에셋**이며 신규 3D 건축 모델은 아니다.

본진과 외곽 거점은 같은 테마의 성문을 공유한다. 실루엣의 최대 폭 128·높이 145 논리 단위 안에서 종횡비를 보존하고, 원본의 투명 여백을 고려해 바닥을 맞춘다. 로딩 중·실패 시 기존 SVG 성문으로 대체하며, 장식은 클릭·충돌·피해 판정에 관여하지 않는다. 원본은 `art-source/defense/gates/`, 배포 파일과 해시는 `public/defense/gates/`에 있다.

```bash
npm run art:gates
```

## Blender 지형

숲·설산의 단일/확장 지형 4종에 월드 좌표 기반 표면 색 변화와 범프를 적용했다. 돌의 마모된 모서리, 불규칙한 길 경계석과 이끼/서리, 목재의 방향성 있는 결, 따뜻한 광원과 차가운 환경광을 사용한다. 지형은 실제 Blender 메시에서 베이크한 이미지다.

급한 굽이에서 폭이 있는 길의 안쪽 면이 겹치던 문제는 Shapely의 버퍼 합집합과 제약 삼각분할로 수정했다. 삼각형 면적 합을 검사하고 기존 경로 좌표 투영 검사를 유지한다. 설산 얼음 재질은 x=300과 x=520에서 정확히 나눠 기존 가속 구간과 맞춘다. 추가 라이브러리는 제작 과정에만 필요하며 브라우저에 포함되지 않는다.

Blender가 사용하는 Python에 `tools/blender/requirements.txt`를 설치한 뒤 재생성한다. 이 환경의 Blender Python은 `/usr/bin/python3.13`이다. 다른 환경에서는 Blender의 `sys.executable`을 먼저 확인한다.

```bash
python -m pip --python /usr/bin/python3.13 install --user --break-system-packages -r tools/blender/requirements.txt
npm run models:terrain
```

회화 배경은 화면에서 채도·밝기를 소폭 낮추고, 건설 버튼은 어두운 청록/청회색과 황동 테두리로 조정했다. 원본 배경 이미지는 보존하며 버튼의 48px 입력 영역, 선택 표시와 준비 안내는 유지한다.

## 확인 범위

Chromium에서 네 테마, 데스크톱·모바일 건설, 지형/성문 로딩 실패 시 대체 표시, 이동·돌진·일시정지와 동작 줄이기를 확인했다. 1440×900 데스크톱과 390×844 터치 화면에서 검사했으며 모바일 건설은 ‘전체 보기’ 전환 후 직접 터치했다. 건설 입력 영역은 48×48px 이상이고 가로 넘침·예상하지 않은 콘솔 오류가 없었다.

빌드 통과. 전체 테스트 156개 중 155개 통과, 기존 수학 엔진의 `(3 × 7) ÷ 5` 정답 4/4.2 불일치 1개는 남아 있다. 마지막 지형 재생성 후 지형·테마·아트 관련 26개 테스트도 통과했다. 실제 Android 기기 GPU 측정과 새 지역 전체를 컨셉 아트 수준으로 제작하는 작업은 포함하지 않는다.

Claude API 사용은 허용되었지만 이 실행 환경에 인증 정보가 연결되어 있지 않아 호출하지 않았다. 이번 제작에는 네이티브 이미지 생성, Blender 4.3.2, Shapely 2.1.2, FFmpeg를 사용했다.
