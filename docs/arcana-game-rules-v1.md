# 아르카나 기본 게임 규칙 v1

2026-11-09 · 기준 구현 `355e573` · **규칙 점검과 설계 결정 문서**

이 문서는 이번 검토에서 채택한 개발 기준이다. 이미 동작하는 규칙과 변경하기로 정한 규칙을 구분한다. **이번 커밋은 문서와 재현용 분석 도구만 추가하며, 앱의 승패·보상·전투 수치를 변경하지 않는다.** 사용자 승인 이력을 대신하는 문서도 아니다.

## 1. 게임의 중심

**영웅을 움직여 빈틈을 메우고, 타워와 동료의 조합으로 마을을 지키는 모바일 판타지 디펜스.**

플레이의 중심 질문은 “어디를 지키고, 무엇에 투자하고, 언제 필살기를 쓸까?”다. 배치·속성·위치·타이밍을 선택하는 재미를 우선한다. 짧은 캠페인 v1은 숲4개와 설산4개, 총8스테이지다. 한 판의 목표는 초반 약1~2분, 이후 약2~4분의 전투 시간이며 준비·메뉴를 읽는 시간은 별도다. 강제 제한 시간이나 대기 타이머를 추가하지 않는다.

마을에서 요청 확인 → 영웅 편성 → 타워 배치 → 4웨이브 방어 → 자동 보상·동료 합류 → 마을 성장 → 다음 요청.

본진HP20, 외곽HP12를 유지한다. 일반 적 돌파는 해당 마을HP−1이다. 변경 후의 지역 보스 돌파는 즉시 실패이므로 “보스는8HP만 깎고 지나간다”는 현재 예외를 남기지 않는다. 보스를 놓친 패배에서도 기존 처치 기반 소액 보상은 받을 수 있지만, 첫 클리어·지역 해금·추가 퀘스트 보상은 지급하지 않는다.

외곽 목표는 “추가 구조 성공”으로 표시한다. 첫 성공의80G와 결과 상태를 명확히 보여 주고, 목표 실패를 본진 패배와 혼용하지 않는다. 재도전 시 외곽을 지키는 가치는 완벽 방어와 개인 도전이다. 반복 구조의 별도 영구 보상·랭킹은 아직 없다.

## 3. 전투 규칙과 수치 기준

### 영웅·용병·펫

- 해금된 영웅 선택·변경은 마을에서 무료. 상세 미리보기는 편성을 바꾸지 않고 출전 확정에서만 저장한다.
- 용병은 출전 영웅과 다른 해금 동료1명, 비용120전투코인. 기본 공격력은 해당 영웅의80%. 원정이 끝나면 다시 고용한다.
- 루나를 영웅 또는 용병으로 편성하면 늑대1마리가 함께한다. 현재 독립 펫 수집·펫 장비 시스템은 없다.
- 돌진 재사용5초, 최대 이동200(전장 좌표). 적에게 피해를 주는 기술이나 탱킹·회피 행동으로 설명하지 않는다.
- 필살기는 **전장 전체의 현재 적**에게 적용한다. 화면에 보이는 작은 원은 피해 범위가 아니다. 재사용20초, 웨이브 종료마다 재충전. 서리군주 충전 중 쓰면 끊을 수 있다.
- 2웨이브 뒤 강화형 또는 제어형 전직. 강화형은 기본 공격·필살기+40%, 제어형은 사거리+65와 필살기 둔화. 영웅별 기존 둔화/펫 적용 차이는 현재 엔진을 따른다. 전직은 해당 원정에만 유지한다.

### 타워와 선택의 비용

| 기본 타워 | 설치 비용 | Lv2 갈래 |
| --- | ---: | --- |
| 석궁탑 | 70 | 관통 / 연발 |
| 마법탑 | 90 | 화염 / 뇌전 |
| 포격탑 | 110 | 파쇄 / 물폭탄 |

고정 건설점에 설치한다. Lv2는80코인과 갈래 선택, Lv3는120코인이다. 갈래를 바꾸려면 판매 후 재건한다. 판매 환급은 투자액75%, 소수점 버림이며 확인을 요구한다. 타워 체력·파괴·수리는 v1에 넣지 않는다. 고지대 사거리+45 등 지형 특성은 유지한다.

### 속성은 짧고 일관되게

| 상대·상태 | 게임에서의 선택 |
| --- | --- |
| 나무·식물 | 불 약점, 물 내성 |
| 얼음 갑옷 | 불·충격 약점 |
| 돌 갑옷 | 충격 약점, 불 내성 |
| 금속·젖은 적 | 연쇄 번개 연결점. 금속에 번개 직접 피해가 추가되는 것은 아님 |
| 절연 슬라임 | 번개 피해 감소, 젖어도 연쇄 차단 |

약점1.5배·내성0.6배·보통1배를 기준으로 유지한다. 물은 둔화·젖음, 불은 연소, 충격은 무게에 따른 넉백이다. 연쇄는 가까운 적1명에게85% 피해, 절연체가 차단한다. 연소는 현재 고정4/초에 속성 배율을 적용하며 영구 공격력 강화와 별도다. 불의 모든 피해가 같은 비율로 성장한다고 안내하지 않는다.

비·물길·빙판은 전술을 바꾸는 환경이다. 이것들은 단순화된 게임 규칙이며 현실의 모든 재료·생물에 그대로 적용하는 과학 법칙처럼 설명하지 않는다.

## 4. 성장·보상 규칙

### 유지할 가격과 보상

| 항목 | 기준 |
| --- | --- |
| 시작 전투 코인 | 숲240 / 설산280, 여유 난이도+70 |
| 웨이브 기본 보급 | 종료 시45전투코인 |
| 완벽 방어 | 해당 웨이브 돌파0이면 추가25코인. **밸런스 실험값으로 유지**, 실수 후 복구 가능성 재검증 |
| 첫 클리어 기본 골드 | 100 + 전체 스테이지 번호×40. 변경 후 난이도 공통 |
| 재클리어 기본 골드 | 30 + 전체 스테이지 번호×10. 정예×1.4 유지 |
| 추가 퀘스트 | 승리와 조건 달성 시80G, 스테이지당 최초1회 자동 지급 |
| 패배 보상 | 처치당2G, 최대40G, 난이도 배율 없음. 패배 파밍 효율은 미검증 |
| 영구 강화 | Lv0→5, 단계당+8%, 최대+40% |
| 영구 강화 비용 | 100 / 180 / 260 / 340 / 420G, 총1300G |

첫 클리어 보상을 공통으로 정하는 이유는 “쉬운 모드부터 배우면 나중에 받을 일회성 보너스를 잃는다”는 압박을 없애기 위해서다. 이미 저장된 골드를 회수하지 않는다. 추가 최고 난이도 이력·차액 지급 스키마보다 단순한 공통 첫 보상 규칙을 채택한다. 기존 정예 도전의 보상 문구와 테스트도 함께 바꿔야 하므로 현재 앱에는 아직 적용하지 않았다.

현재 가격은 올리지 않는다. 첫 강화 때문에 재도전을 반복하도록 만들지 않는다. 기존 계산상 퀘스트 없이도1-2완료 직후Lv2를 살 수 있다. 모든 퀘스트 달성 시 기본난도2-1완료 후Lv5에 도달하고,8개 첫 클리어 후1580G가 남는다.

**v1은 끝이 있는8스테이지 캠페인이다.** 최대 강화 이후 골드는 보관하며 현재 다른 소비처가 없다는 한계를 인정한다. 이를 감추려고 새 재화·확률 강화·유료 수리·입장 에너지를 넣지 않는다. 다음 확장의 소비처는 마을 외형·기념물·선택형 장비로 검토하되, 없는 기능을 현재 보상 가치로 홍보하지 않는다.

마지막 웨이브 종료 코인은 이후 쓸 수 없으며 성장 골드에 포함되지 않는다. 결과 화면에서는 실제 영구 보상과 섞어 강조하지 않는다. 완벽 방어+25와 웨이브2·3후반 증원 가속은 구현된 실험값이며 재미가 최종 검증되었다는 뜻은 아니다.

## 5. 난이도와 능동 조작의 역할

여유롭게는 편하게 배치와 상성을 익히는 모드, 기본은 타워 조합으로 완주하는 모드, 정예는 더 높은 방어 완성도를 요구하는 도전으로 정한다. 낮은 난이도를 선택해도 콘텐츠를 잃지 않는다.

현재 난이도 수치는 여유 적HP×0.8·속도×0.9·출현간격×1.15, 정예HP×1.3·속도×1.12·출현간격×0.78와 추가 적이다. 이 수치를 이번에 무작정 올리지는 않는다.

이동·돌진·필살기의 효익은 더 빠른 처리, 새는 적 수 감소, 외곽 구조, 보스 충전 차단이다. 기본 모드에서 모든 입력을 빠르게 하지 않아도 배치로 완주할 수 있어야 한다. 정예는 정답 빌드 하나를 외우는 시험이 되지 않도록 최소2개 조합을 검증한다.

새로 추가한 합법 진행 시뮬레이션은 해금된 용병만 사용하고, 실제 보상으로 살 수 있는 강화만 구매한다. 기본 자동 정책은8개를1001전투초, 능동 정책은891초에 끝냈다(합계11.0% 단축). 정예 최종전은 자동HP15/177초, 능동HP20/148초였다. 이는 플레이어가 필요한 선택을 즉시 하는 결정론적 비교이며 사람 승률·재미·평균 한 판 길이가 아니다.

48실행 중47회 본진 무피해,48회 외곽 무피해였다. **정해진 혼합 배치 한 가지로 목표가 너무 쉽게 달성되는 신호**다. 전체 난이도가 무의미하다고 단정하지는 않지만, 조합 다양성·늦은 구매·실수 복구를 포함한 후속 평가가 필요하다.

## 7. 점검 근거와 제한

- 현재 구현: `src/games/defense/engine.ts`, `campaign.ts`, `difficulty.ts`, `tactics.ts`, `data.ts`; 기존 엔진·캠페인 테스트와 전술 UI.
- [합법 진행48실행](arcana-rules-20261109/legal-progression.json): `node --experimental-strip-types tools/audit-defense-rules.ts`로 재현. 이안 유지, 정해진 타워 구매 순서, 해금 용병만 고용, 가능한 영구 강화 즉시 구매. 모든 정책은2웨이브 뒤 강화형 전직을 고른다.
- [기존36조건 비교](arcana-rules-20261109/existing-benchmark.json): `tools/balance-defense.ts`. 스테이지4·8은 카르/훈련1과 진행 외 용병이 들어가는 재도전용 가정이므로 최초 진행 밸런스의 증거로 사용하지 않는다.
- 보스 통과 승리: 실제 엔진에 마지막 보스를 경로 끝에 둔 격리 반례에서4·8 모두HP20→12, 처치0, 승리. 실제 플레이 녹화가 아닌 규칙 반례다.
- [Claude Opus 검토](arcana-rules-20261109/claude-rules-review.md)는 제공된 자료를 검토한 의견이다. 원문의 “기본6/정예5에서 강화 상한”은 진입 레벨과 완료 후 레벨을 혼동한 값이며, 실제는 모든 목표 달성 시 **기본5완료/정예4완료**다. “실패 보상 최소40”도 잘못된 표현이며 **최대40**이다. “정예가 의미 없음”이라는 과도한 일반화는 채택하지 않았다.
- 반복 파밍 악용, 사람 승률, 실제 모바일 피로도와 장시간 재미는 이번 자료만으로 확정하지 않는다. 원래 장비·회복·성 능력·랭킹 기획은 [확장 후보](arcana-world-planning/combat-and-growth.md)로 보존한다.
