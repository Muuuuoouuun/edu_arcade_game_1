# 아르카나 수비대 — 01. 코어 메카닉 & 수치 설계 (v0.1)

> 기준: `00_brief.md` v0.1. 브리프 4절은 "프로토타입 기준값이며 밸런싱 문서가 조정할 수 있다"고 정합니다.
> 이 문서는 코디네이터가 확정해 전달한 조정값 4개를 반영합니다.
> - 자동 회복 **1마나/10초**(브리프 1마나/5초의 절반)
> - 오답 후 입력 잠금 **2초에서 시작해 연속 오답마다 +1초, 최대 5초**
> - 카드 **Lv4 추가**(강화 비용 8)
> - 웨이브별 적 HP 배수 **×1 / 1.6 / 2.4 / 3.4 / 5.0**
>
> 모든 수치는 계산식으로 근거를 붙였습니다. 검증에는 아래 두 가지를 썼습니다.
> - 0.1초 틱 시뮬레이터(규칙은 8절 의사코드와 같음)
> - 결정론 "평균 플레이어" 모델(8초마다 1문제, 10문제 중 7문제 정답 패턴 `OOXOOXOOOX`)
>
> 무작위 플레이어(풀이 간격 4~12초 균등분포, 정답률 70%)는 몬테카를로(MC)로 돌렸습니다.

## 1. 전투 모델

### 1.1 시간
| 항목 | 값 | 근거 |
|---|---|---|
| 틱 | **10틱/초 (0.1초)** | 공격 주기를 모두 0.1초 단위(0.3~1.5초)로 설계해 반올림 오차가 0입니다. 모바일 웹에서 rAF(60fps) 6프레임마다 1틱을 처리하면 됩니다. |
| 시작 준비 시간 | 5초 | 웨이브 간 휴식(5초)과 같은 규칙입니다. 이 시간에도 문제를 풀 수 있습니다. |
| 웨이브 종료 | 그 웨이브의 적이 전부 처치되거나 탑에 도달한 시점 | 이후 5초 휴식 |
| 1판 길이 | 결정론 284초, MC 평균 272초 (4.5~4.7분) | 0.1초 틱 시뮬 측정값. 브리프 목표 3~5분 안에 들어옵니다. |

### 1.2 맵 (세로 모바일)
- 격자는 **9열 × 12행** 타일입니다. 폭 390pt 기기라면 1타일 = 390/9 ≈ 43pt이고, 전장 높이는 12×43 = 516pt(화면의 약 61%)입니다. 나머지 약 330pt에는 HUD와 문제 카드가 들어갑니다.
- 길은 **S자 3굴곡**으로, 가로 4줄을 3번 U턴으로 잇습니다. 꼭짓점 좌표는 (x, y)입니다.
  `(0,1)→(7,1)→(7,4)→(1,4)→(1,7)→(7,7)→(7,10)→(4,10)→(4,11)=탑`
  - 길이 L = 7+3+6+3+6+3+3+1 = **32타일**
- 소환 슬롯은 **9개**입니다(브리프 범위 8~10). 길 사이 빈 줄(y=2~3, 5~6, 8~9)의 중앙에 두어 위아래 두 줄을 동시에 덮습니다.

| 슬롯 | 좌표 | 사거리 2.0 커버 | 2.5 커버 | 3.0 커버 |
|---|---|---|---|---|
| S1 | (2, 2.5) | 5.2 | 7.8 | 9.5 |
| S2 | (4, 2.5) | 5.3 | 8.0 | 10.4 |
| S3 | (6, 2.5) | 7.7 | 9.0 | 10.2 |
| S4 | (2, 5.5) | 7.7 | 9.0 | 10.2 |
| S5 | (4, 5.5) | 5.3 | 8.0 | 10.4 |
| S6 | (6, 5.5) | 5.1 | 7.6 | 9.8 |
| S7 | (5, 11) 탑 옆 | 3.7 | 4.5 | 5.2 |
| S8 | (4, 8.5) | 4.5 | 7.0 | 8.8 |
| S9 | (6, 8.5) | 7.7 | 9.0 | 10.3 |

- **커버**는 길 32타일 가운데 사거리 원 안에 들어가는 길이(타일 수)입니다. 0.01타일 단위로 수치적분해 구했습니다.
- 적이 한 카드의 사거리 안에 머무는 시간은 `커버 / 적 속도`입니다. 예를 들어 S3의 완드(사거리 2.5)는 안개 조각(1.2타일/초)을 9.0/1.2 = 7.5초 동안 때릴 수 있습니다.
- 설계 의도: 깊은 슬롯(S4~S9)에서는 적이 늦게 도착합니다. 그래서 나중에 산 카드도 전투에 끝까지 참여할 수 있고, "어디에 둘까"가 의미 있는 선택이 됩니다. 시뮬에서도 깊은 슬롯을 먼저 채우는 빌드가 앞쪽 슬롯을 먼저 채우는 빌드보다 확실히 강했습니다.

### 1.3 공격 규칙
- 적중 판정은 즉시 판정(히트스캔)입니다. 투사체는 연출만 합니다.
- 카드는 쿨다운이 0이고 사거리 안에 적이 있을 때 발사합니다. 적이 없으면 쿨다운이 0인 상태로 대기했다가 적이 들어오는 즉시 발사합니다.
- 타겟팅은 **가장 앞선 적**(경로 진행거리 d가 최대인 적)이 우선입니다. 소드는 앞선 순서로 N마리를 칩니다.

## 2. 마이너 아르카나 4속성 카드

소환 비용은 5, 강화 비용은 Lv2 4 / Lv3 6 / Lv4 8입니다(고정). 따라서 누적 비용은 **5 / 9 / 15 / 23**입니다.

| 카드 | Lv | 공격력 | 주기(초/틱) | 사거리 | 단일 DPS | 최대 DPS | 특수효과 |
|---|---|---|---|---|---|---|---|
| **완드**(불, 단일 고화력) | 1 | 12 | 1.2 / 12 | 2.5 | 10.0 | 10.0 | 정예·보스에게 피해 ×1.5 |
| | 2 | 18 | 1.2 / 12 | 2.5 | 15.0 | 15.0 | 〃 |
| | 3 | 26 | 1.2 / 12 | 2.5 | 21.7 | 21.7 | 〃 |
| | 4 | 36 | 1.0 / 10 | 3.0 | 36.0 | 36.0 | 〃, 사거리 +0.5 |
| **컵**(물, 둔화) | 1 | 3 | 1.0 / 10 | 2.0 | 3.0 | 3.0 | 맞은 적 기준 반경 0.8타일 안의 적 둔화 30%, 2초 |
| | 2 | 4 | 1.0 / 10 | 2.0 | 4.0 | 4.0 | 둔화 35%, 반경 0.8 |
| | 3 | 5 | 1.0 / 10 | 2.5 | 5.0 | 5.0 | 둔화 40%, 반경 1.0 |
| | 4 | 6 | 1.0 / 10 | 2.5 | 6.0 | 6.0 | 둔화 45%, 반경 1.2 |
| **소드**(바람, 연타·다수) | 1 | 3 | 0.5 / 5 | 2.0 | 6.0 | 12.0 | 동시 타격 2 |
| | 2 | 4 | 0.5 / 5 | 2.0 | 8.0 | 16.0 | 동시 타격 2 |
| | 3 | 5 | 0.4 / 4 | 2.5 | 12.5 | 37.5 | 동시 타격 3 |
| | 4 | 6 | 0.4 / 4 | 2.5 | 15.0 | 45.0 | 동시 타격 3 |
| **펜타클**(땅, 방어) | 1 | 4 | 1.5 / 15 | 2.0 | 2.7 | 2.7 | 보호막 +1을 45초마다 생성 |
| | 2 | 5 | 1.5 / 15 | 2.0 | 3.3 | 3.3 | 보호막 생성 40초 |
| | 3 | 6 | 1.5 / 15 | 2.0 | 4.0 | 4.0 | 보호막 생성 35초 |
| | 4 | 8 | 1.5 / 15 | 2.0 | 5.3 | 5.3 | 보호막 생성 30초, 웨이브 클리어 시 탑 HP +1 |

**표의 규칙과 근거**
- DPS = 공격력 / 주기. 최대 DPS는 단일 DPS × 동시 타격 수입니다.
- 둔화는 중첩되지 않고 가장 큰 값 하나만 적용됩니다. 둔화된 적은 사거리 안에 `1/(1−s)`배 오래 머뭅니다. 둔화 30%면 1.43배, 45%면 1.82배입니다. 컵의 가치는 자기 DPS가 아니라 이 체류시간 증폭입니다.
- 보호막은 탑 피해 1점을 흡수합니다. 생성 시간은 웨이브 중에만 흐릅니다. 보호막 보유 상한은 **전체 합산 2**입니다. 상한이 없으면 펜타클 1장(5마나)이 판당 HP 5~6점의 가치를 내서 탑 HP 10의 의미가 사라집니다(이전 시뮬 측정).
- 마나당 효율(완드, DPS/누적비용): Lv1 2.00, Lv2 1.67, Lv3 1.44, Lv4 1.57.
  - 슬롯이 비어 있으면 새 소환(2.0)이 강화보다 효율적이고, 슬롯 9개가 차는 W3 무렵부터 강화가 주력이 됩니다.
  - Lv3→4 한계효율은 +14.3 DPS / 8 = 1.79로 Lv2(1.25)나 Lv3(1.11) 강화보다 높습니다. 그래서 Lv4가 "완성 보상"처럼 느껴집니다.
- 판 전체 예산과 비교하면 이렇습니다. 평균 플레이어의 판당 총 마나는 0.45/초 × 약 280초 ≈ 126(+콤보 할인 약 8)입니다. 반면 9슬롯 전부를 Lv4로 만들려면 9 × 23 = 207이 듭니다. 예산의 약 65%만 쓸 수 있으므로 무엇을 키울지 선택해야 합니다.

### 3.3 역산: 마나 수입 곡선과 필요 DPS

**1단계: 마나 수입.** 평균 플레이어의 정답 마나는 보통 난이도 +4로 둡니다.
- 정답 마나 = 0.7 × 4 / 8초 = 0.35/초
- 자동 회복 = 1/10초 = 0.10/초
- **합계 0.45마나/초**, 시작 마나 0. 따라서 `M(t) = 0.45·t`이고, 여기에 콤보 3 할인이 판당 약 4회 × 2 = +8 마나 상당으로 더해집니다.
- 8초 안에는 평균 입력 잠금 0.72초가 포함됩니다. 계산은 6절 끝을 참고하세요.

**2단계: 마나 → DPS 변환.** 결정론 시뮬에서 측정한 보유 공칭 DPS / 누적 마나는 1.75, 1.55, 1.51, 1.60입니다. 그래서 **η ≈ 1.55 DPS/마나**로 둡니다.

**3단계: 웨이브 창 T.** 적을 하나도 처치하지 못해도 모든 적이 사라지는 시간입니다. `T = 마지막 스폰 시각 + 가장 느린 적의 통과 시간`.

**4단계: 부하율 ρ = H / (D̄ · T).** D̄는 웨이브 중 평균 공칭 DPS로, 그 웨이브 시작과 다음 웨이브 시작 값의 평균입니다.
- 카드가 실제로 쏘는 비율인 **가동률 u**는 같은 시뮬에서 0.53~0.69로 측정됐습니다.
- **ρ가 u를 넘는 만큼 누수**가 납니다.
- 설계 목표는 W1~W2는 ρ ≤ u(학습 구간), W3~W5는 ρ ≈ u 상한(압박 구간)입니다.

| 웨이브 | 시작 t(초) | 누적 마나 M (0.45t / 측정) | 공칭 DPS 시작 → D̄ | 창 T(초) | 총 HP H | 필요 평균 DPS H/T | 부하율 ρ | 측정 가동률 u | 결정론 누수 |
|---|---|---|---|---|---|---|---|---|---|
| W1 | 5.0 | 2 / 0 | 0 → 17.5 | 13.0+26.7 = 39.7 | 360 | 9.1 | 0.52 | 0.59 | 0 |
| W2 | 44.7 | 20.1 / 20 | 35 → 48.5 | 15.4+26.7 = 42.1 | 1008 | 23.9 | 0.49 | 0.53 | 0 |
| W3 | 89.2 | 40.1 / 40 | 62 → 84.5 | 14+45.7 = 59.7 | 3168 | 53.1 | 0.63 | 0.58 | **3** |
| W4 | 154.6 | 69.6 / 71 | 107 → 132 | 16+45.7 = 61.7 | 5814 | 94.2 | 0.71 | 0.67 | **4** |
| W5 | 221.9 | 99.9 / 98 | 157 → 약165 | 18+45.7 = 63.7 | 7150 | 112.2 | 0.68 | 0.69 | 0 (왕 처치) |

- 결과: 누수 합계 7, 펜타클 보호막 흡수 2. 따라서 **최종 탑 HP = 10 − 7 + 2 = 5**로 목표 3~5를 충족합니다. 판 길이는 284.3초입니다.
- 결정론 평균 플레이어의 최종 빌드: S2 완드 Lv2, S3 소드 Lv3, S4·S5·S8 완드 Lv4, S6 소드 Lv4, S7 펜타클 Lv1, S9 컵 Lv3.

**보스 HP 역산.** 위 빌드가 왕(0.7타일/초) 한 마리에게 넣을 수 있는 최대 피해는 `Σ 단일 DPS × 커버 / 속도`입니다.
- 완드: 1.5 × (15×8.0 + 36×(10.2+10.4+8.8)) / 0.7 = **2525**
- 소드: (12.5×9.0 + 15×7.6) / 0.7 = **324**
- 컵 + 펜타클: 64 + 14
- 합계 **약 2930**(컵 둔화로 늘어나는 체류시간은 제외)

호위가 공격을 대신 맞는 몫을 감안해 왕 HP를 **1600(상한의 55%)**으로 정했습니다. 결정론 시뮬에서 왕은 경로 **93% 지점**에서 처치됩니다(탑 직전). 처음에 넣었던 HP 3000·2000은 조정 배수에서 왕이 탑에 도달했습니다(2000일 때 결정론 최종 HP 2).

- 승률 70%를 원하면 레버 1(W3·W4 배수 −5%)을 쓰면 됩니다. 이 −5% 효과는 직전 구성에서 결정론 HP +3으로 측정했고, 이번 구성에서는 **재측정 TODO**입니다.

|---|---|---|
| `streak` | int | 진짜 연속 정답 수. 표시("N연속")와 별점(콤보 최대치)에 씁니다. 오답 시 **0**. |
| `maxStreak` | int | 판 최대값. 별점에 씁니다. |
| `gauge` | int 0~7 | 보상 게이지입니다. 정답 시 +1. **오답 시 `floor(gauge/2)`(절반 리셋)**. 8에 도달하면 0으로 순환합니다. |
| `discountReady` | bool | 콤보3 보상. 다음 소환 1회 비용 −2(5→3). 이미 켜져 있으면 중첩되지 않습니다. |
| `buffUntil` | 틱 | 콤보5 보상. 모든 카드 공격력 +25%, 10초. 재발동하면 시간이 갱신됩니다. |
| `ultTicket` | int 0~1 | 콤보8 보상. 이미 1장이 있으면 대신 마나 +5를 줍니다. |
| `lastResult` | enum | 정답 / 오답 / 회피. 게이지 애니메이션(절반으로 줄어드는 연출)에 씁니다. |
| `wrongRun` | int | 연속 오답 수. 입력 잠금 길이를 정합니다. |
| `lockUntil` | 틱 | 오답 후 입력 잠금이 풀리는 시각. 잠금 중에는 정답과 해설을 보여 줍니다. |

규칙
- 보상은 gauge가 **올라가면서 3, 5, 8에 닿는 순간** 발동합니다. 절반 리셋 뒤 다시 올라가면 3, 5 보상을 다시 받을 수 있습니다.
- 8에 닿으면 gauge가 0이 되므로 궁극기를 연속으로 받으려면 최소 8정답이 필요합니다. 이 순환 규칙이 없으면 8→4→8 반복(4정답마다 1장)으로 궁극기를 쌓을 수 있습니다.
- **회피**(10초 방치로 문제 자동 교체): gauge와 streak는 그대로 두고 마나는 없습니다. 10초를 잃는 것 자체가 페널티(0.45×10 = 4.5마나 상당)입니다. "모르면 찍지 말고 넘기기"가 무작위로 찍는 것보다 손해가 작도록 한 설계입니다.
- **절반 리셋을 채택한 근거**(MC 100판): 절반 리셋은 승률 57%·궁극기 0.72회/판, 완전 리셋은 43%·0.37회입니다. 정답률 70%인 아이가 판당 궁극기를 한 번은 볼 확률을 높이면서, 승률 변화(+14%p)는 레버로 흡수할 수 있는 크기입니다.
- **입력 잠금(확정값)**: 오답 1회 2초, 연속 오답마다 +1초, 최대 5초. 즉 2/3/4/5초입니다.
  - 기준 플레이어의 평균 잠금 = 0.21×2 + 0.063×3 + 0.019×4 + 0.008×5 = 0.72초/문제(8초 안에 포함).
  - 각 항은 그 문제 직전 연속 오답 수의 확률입니다. 예: 0.21 = 0.3×0.7, 0.063 = 0.09×0.7.

## 6. "문제를 안 풀고 버티기"는 불가능함 (해석적 증명)

조건은 자동 회복 1마나/10초, 시작 마나 0입니다. 그러면 문제를 풀지 않는 플레이어의 마나는 `M_idle(t) = floor(t/10)`입니다. 첫 카드(5마나)는 **t=50초**, 두 번째 카드는 **t=100초**에 생깁니다.

1. **W1(t=5~최대 44.7초)**: 50초 전에는 카드가 0장이라 피해가 0입니다. 안개 6마리가 전부 도달하므로 **누수 6, HP 4**입니다.
2. **W2 시작**은 늦어도 5 + 39.7 + 5 = 49.7초입니다. W2 창은 42.1초(웨이브 시각 0~42.1)입니다.
   - 첫 카드는 웨이브 시각 0.3초에 설치됩니다. 두 번째 카드는 t=100(웨이브 시각 50.3)이라 창 밖입니다. 즉 **W2 내내 Lv1 카드 1장**입니다.
   - 그 1장의 피해 상한을 가장 관대하게 잡습니다.
     - 최대 DPS: 소드 Lv1, 2타겟 상시 명중 가정 = 12
     - 적 체류시간: 처치가 없다고 가정한 W2 적의 슬롯별 사거리 체류 합집합 중 최댓값 = S1 기준 29.4초(사거리 2.5로 넉넉하게)
     - 따라서 피해 ≤ 12 × 29.4 = **353**
   - 탑 HP 4로 W2를 버티려면 누수가 3 이하, 즉 13마리 중 **10마리 이상 처치**해야 합니다. 가장 싼 10마리(속삭임 5×48 + 안개 5×96)만 골라도 **720 > 353**입니다.
   - 353으로 처치할 수 있는 최대는 속삭임 5(240) + 안개 1(96) = 6마리입니다. 따라서 **누수 ≥ 7 > 3**이고, W2에서 탑이 무너집니다. ∎
   - 펜타클로 막는 경로도 닫혀 있습니다. 첫 보호막이 웨이브 시각 45초에야 생기는데 창이 42.1초라 보호막 0개입니다.
3. 시뮬레이션 확인
   - 대표 빌드 8종: 모두 누수 [6, 4]로 W2에서 탈락
   - 무작위 빌드 3,644개: 모두 W2에서 탈락
   - 언덕오르기 최적화: 최선도 W2에서 탈락

부록: 무작위로 찍기(4지선다, 1.0~1.5초에 1번)
- 잠금이 없으면 승률 100%입니다(이전 구성 측정). 확정 잠금 2/3/4/5초를 적용하면 무작위 찍기 MC 승률은 **15%(1.0초) / 7.5%(1.5초)**로 떨어집니다.
- 해석: 찍기 플레이어의 수입은 문제당 평균 3.80초(1 + 2×0.1875 + 3×0.1406 + 4×0.1055 + 5×0.3164)에 0.25×4 = 1마나입니다. 즉 0.263/초이고, 자동 회복을 더하면 0.363/초입니다. 기준 플레이어(0.45/초)의 81%라 완전히 막지는 못합니다. 아래 "변경 제안" 1번을 참고하세요.

## 8. 프로토타입용 의사코드 (100줄 이내)

```text
const TICK = 0.1                                   // 10 tick/s
state: t, mana=0, hp=10, shield=0, wave=0, enemies=[], towers{slot:{type,lv,cd,shT}}
       streak=0, maxStreak=0, gauge=0, discount=false, buffUntil=-1, ultTicket=0, ultReadyAt=0
       regenAcc=0, wrongRun=0, lockUntil=0, qShownAt=0, phase='prep', phaseEnd=5

loop every TICK:
  regenAcc += TICK
  if regenAcc >= 10: regenAcc = 0; mana += 1        // 자동 회복 1/10s
  if t - qShownAt >= 10 and t >= lockUntil: nextQuestion(); log('회피')   // 콤보 불변
  if phase == 'prep' or phase == 'rest':
     if t >= phaseEnd: startWave(++wave)
  else:
     spawnDue(waveSchedule[wave], tWave)
     updateTowers(); moveEnemies()
     if schedule empty and enemies empty: endWave()
  t += TICK

onAnswer(correct):                                  // UI가 호출
  if t < lockUntil: return                          // 잠금 중 입력 무시
  if correct:
     mana += manaFor(question.difficulty)           // 3/4/5
     streak++; maxStreak = max(maxStreak, streak); wrongRun = 0
     gauge++
     if gauge == 3: discount = true
     if gauge == 5: buffUntil = t + 10
     if gauge >= 8:
        gauge = 0
        if ultTicket == 0: ultTicket = 1 else mana += 5
  else:
     sealCard(question)                             // 복습 큐
     streak = 0; gauge = floor(gauge / 2); wrongRun++
     lockUntil = t + min(2 + (wrongRun - 1), 5)     // 2,3,4,5s, 정답/해설 표시
  nextQuestion(); qShownAt = max(t, lockUntil)

summon(slot, type):
  cost = discount ? 3 : 5
  if slot empty and mana >= cost: mana -= cost; discount = false; towers[slot] = {type, lv:1, cd:0, shT:0}
upgrade(slot):
  c = [4, 6, 8][towers[slot].lv - 1]
  if towers[slot].lv < 4 and mana >= c: mana -= c; towers[slot].lv++

updateTowers():
  mul = (t < buffUntil) ? 1.25 : 1.0
  for tw in towers:
     S = STATS[tw.type][tw.lv]
     if tw.type == PENTACLE:
        tw.shT += TICK
        if tw.shT >= S.shieldPeriod: tw.shT = 0; shield = min(2, shield + 1)
     tw.cd -= TICK
     if tw.cd > 0: continue
     inRange = enemies.filter(e => e.hp > 0 and dist(pos(e.d), tw.pos) <= S.range)
     if inRange empty: tw.cd = 0; continue          // 대기, 다음 틱 즉시 발사 가능
     targets = sortDesc(inRange, e => e.d).take(S.targets)   // 가장 앞선 적 우선
     for e in targets:
        dmg = S.dmg * mul * ((tw.type == WAND and e.elite) ? 1.5 : 1)
        e.hp -= dmg
        if tw.type == CUP:
           for o in enemies within S.slowRadius of pos(e.d): o.slow = max(o.slow, S.slow); o.slowT = 2.0
     tw.cd = S.period

moveEnemies():
  for e in enemies:
     if e.hp <= 0: remove(e); fx('흩어짐'); continue
     m = (e.slowT > 0 ? 1 - e.slow : 1) * (t < moonUntil ? 0.4 : 1)
     e.d += e.speed * max(0.3, m) * TICK; e.slowT -= TICK
     if e.d >= PATH_LEN:
        a = min(shield, e.towerDmg); shield -= a; hp -= e.towerDmg - a; remove(e)
        if hp <= 0: gameOver()

useUlt(kind):
  if ultTicket == 0 or t < ultReadyAt: return
  if kind != STAR and enemies empty: return
  ultTicket = 0; ultReadyAt = t + 20
  if kind == SUN:  for e in enemies: e.hp -= 300
  if kind == MOON: moonUntil = t + 10
  if kind == STAR: hp = min(10, hp + 2); shield = min(2, shield + 1)

endWave():
  if any tower is PENTACLE lv4 and hp < 10: hp += 1
  if wave == 5: finish(stars(hp, accuracy, maxStreak)) else phase = 'rest'; phaseEnd = t + 5
```

## 변경 제안
1. **무엇**: 오답 잠금 상한을 5초에서 10초로 올립니다(첫 잠금 2초는 유지).
   **왜**: 확정 잠금(최대 5초)에서는 4지선다 무작위 찍기 승률이 7.5~15%로, 정직한 기준 플레이어 승률 57%의 4분의 1 수준이 남습니다. 상한 10초 구성에서는 1~3%로 측정됐습니다.
   **영향 범위**: 입력 잠금 UI·해설 표시 시간, 프로토타입 `lockUntil` 식 하나. 기준 플레이어 평균 잠금은 +0.3초 이내로만 늡니다.
2. **무엇**: 웨이브 HP 배수의 W3·W4 값을 2.4/3.4에서 약 2.3/3.2(−5%)로 내리는 안을 검토합니다.
   **왜**: 확정 배수에서 결정론 평균 플레이어는 HP 5로 목표를 충족합니다. 하지만 풀이 간격이 들쭉날쭉한 실제 아이에 해당하는 MC 승률이 57%로 11~14세 대상에게는 낮습니다.
   **영향 범위**: 적 HP 표(3.1)와 역산표(3.3) 재계산. 무풀이 불가 증명(6절)은 W1·W2만 쓰므로 영향이 없습니다.
