## 1. 핵심 문제 정의와 설계안 비교

### 1.1 문제

세로 모바일(360×740)에서 한 손 엄지로 **① 문제 풀기(하단 2×2 선택지) ② 타워 배치(슬롯 탭) ③ 캐릭터 조작**을 한꺼번에 하라고 하면 손과 시선이 다툰다.
- 05의 엄지 도달 영역은 화면 하단 60%(y ≥ 약 296)다. 선택지·하단 바가 이미 거기를 쓴다. 맵은 상단(y 56–396)이라 조작이 늘수록 엄지가 위아래로 오간다.
- 07의 R1(문제 풀이와 전투의 상호 방해)이 이미 "상·상" 위험이다. 조작 대상이 하나 더 늘면 R1이 커진다.
- 그러므로 RTS 모드의 설계 목표는 "**캐릭터 조작을 늘리지 않으면서 캐릭터가 중요해지는 것**"이다. 조작이 풍부해서가 아니라, **결정이 적고 값진** 구조여야 한다.

### 1.2 세 가지 설계안

- **안 A "명령형"**: 정답을 맞히면 캐릭터가 명령 1개를 수행한다(지정 지점 이동 / 돌진 / 스킬). 직접 조작 없음.
- **안 B "반자동"**: 캐릭터는 자동 전투. 플레이어는 맵을 탭해 위치만 지정(이동 명령). 스킬은 정답으로 충전.
- **안 C "직접 조작"**: 가상 조이스틱 + 스킬 버튼. 문제 카드는 웨이브 사이와 "집중 구간"에만 등장.

### 1.3 비교표

별은 5점 만점의 설계자 추정(높을수록 좋음)이며 4차 플레이테스트로 검증한다. 문항 수는 03의 8초/문항(7.5문항/분)을 일반 기준으로 한 계산값이다.

### 1.4 추천: 안 B (반자동) + 정답 충전

**추천 이유**
1. **핵심 루프를 건드리지 않는다.** 문제 카드·선택지·방치 10초 규칙이 일반 모드와 똑같다. 브리프 11절의 "문제 풀이가 캐릭터에게 명령을 내리는 방식 등 핵심 루프를 해치지 않는 설계"에 부합한다(스킬이 곧 정답의 보상).
2. **한 손으로 끝까지 갈 수 있다.** 캐릭터는 가만히 둬도 쓸모 있게 싸운다(자동 순찰, 2.7절). 탭은 "더 잘하기 위한" 입력이다. 조작을 못 해도 클리어가 막히지 않는다.
3. **학습 밀도를 80% 이상 지킬 수 있다.** 조작 빈도에 상한을 두면(분당 명령 4회·스킬 2회가 설계 기준) 시간 예산이 계산된다(6절). 안 C는 구조상 불가능하다.
4. **안 A의 장점을 가져온다.** 스킬 에너지가 정답에서만 나오고, 호위·점령 목표는 정답 수에 연동된다(3절). "풀수록 캐릭터가 강해진다"는 브리프 원칙이 RTS에서도 유지된다.
5. **구현을 줄일 수 있다.** 조이스틱·충돌·연속 입력이 없다. 입력은 `{move(칸)}`, `{focus(적)}`, `{skill(1|2)}` 세 가지로 06의 틱 입력 큐와 헤드리스 봇에 그대로 들어간다.

안 C는 "직접 조작" 요구에 가장 가깝지만 이 게임의 존재 이유(학습 밀도)와 정면으로 부딪친다. 안 A는 안전하지만 4차 테스트에서 "재미가 없다"로 나올 가능성이 크다. 안 B는 그 중간에서 "조작하는 맛"을 최소 비용으로 준다. 4차에서 B가 R1 지표를 못 넘으면 A로 후퇴(탭 이동 제거, 자동 순찰 고정)하는 경로가 열려 있다.

## 2. 추천안 상세 규칙

### 2.1 원칙 5가지

1. **문제가 먼저다.** 캐릭터 조작은 문제 입력을 막지 않는다. 문제·선택지 영역과 입력 처리는 일반 모드와 같다.
2. **조작은 선택이다.** 아무것도 안 눌러도 캐릭터가 쓸모 있게 움직인다(자동 순찰). 눌러서 더 잘하는 구조다.
3. **정답이 힘이다.** 스킬은 "집중 구슬"이 있어야 쓴다. 구슬은 정답에서만 나온다.
4. **캐릭터는 타워가 못 하는 일을 한다.** 길 위 다수 처리는 타워가 주력이고, 캐릭터는 길 밖·보스 장막·호위·점령을 맡는다(2.6절).
5. **실패는 비싸지 않다.** 쓰러짐의 벌은 주로 시간이다. 폭력 표현 없이 "빛이 흐려졌다"로 표현한다.

### 2.2 빛지기 스탯 (가정값)

| 항목 | 값 | 근거 |
|---|---|---|

| 이동속도 | **3.0 타일/초** (오르막 ×0.85, 내리막·평지 ×1.0) | 03의 안개 조각이 약 2.8타일/초(경로 39칸/14초)이므로 약간 빠름. 맵 가로 10칸을 3.3초, 세로 18칸을 6초에 가로지른다 |
| 공격 방식 | 자동 공격 "빛줄기". 사거리 **2.0 타일** | 08의 기본 타워 사거리 2.5타일의 80% |

### 2.3 스킬 2개 (정답 구슬 + 쿨다운 + 콤보 연계)

| 항목 | **스킬 1 "빛의 걸음"** (이동 + 견제) | **스킬 2 "환한 등불"** (제압 + 해제) |
|---|---|---|
| 구슬 비용 | **2** | **4** |
| 쿨다운 | 8초 (콤보 3 이상이면 6초) | 20초 |
| 효과 | 표적 방향으로 4타일 돌진(0.25초, 돌진 중 접촉 피해 무시). 지나간 적 모두에게 40 피해 | 제자리 반경 2.5타일 파동. 즉시 60 피해 + 일반 적 **눈부심 2초(이동 정지)**. 보스 장막에는 피해 ×2 |
| 조준 | 자동. 지정 표적 > 가장 가까운 이탈 안개 > 가장 가까운 길 위 적 > 이동 방향 | 자동(제자리) |
| **콤보 연계** | 콤보 3 이상: 돌진 종점에 반경 1.5타일 빛 파문(+40 피해), 쿨다운 -2초 | 콤보 5 이상: 반경 3.2타일, 눈부심 4초 |
| 쓰는 때 | 도망치는 이탈 안개 따라잡기, 위험 지역 빠져나오기, 거점·수레 쪽으로 빠른 이동 | 이탈 안개 뭉침 정리, 보스 장막 깨기, 쓰러지기 직전 시간 벌기 |

- **콤보 8 궁극기(메이저 아르카나)는 따로 있다.** 캐릭터 스킬과 별개의 타워 측 궁극기이며, 05의 궁극기 버튼 규칙을 그대로 쓴다. 궁극기는 이탈 안개에 효과의 50%만 준다(캐릭터 역할 보존).
- 콤보가 끊겨도(오답) 이미 가진 구슬은 사라지지 않는다. 오답의 벌은 **구슬이 안 쌓이는 것**과 콤보 연계 효과 상실뿐이다. 05의 "색으로 벌을 주지 않는다" 방침과 같다.
- 스킬 수치는 가정값이다. 4차 봇 시뮬이 "스킬 평균 사용 횟수 판당 8~14회"가 되도록 쿨다운·비용을 조정한다.

### 2.4 집중 구슬 (스킬 자원)

| 규칙 | 값 |
|---|---|
| 획득 | 정답 1개당 **+1**. 난이도 "어려움" 문제 정답은 **+2** (마나 +5와 같은 축) |
| 상한 | 6개 |
| 소비 | 스킬 1이 2개, 스킬 2가 4개 |
| 오답·회피 | 획득 0. 가진 구슬은 유지 |
| 응답 속도 | 응답이 1.0초 미만인 정답은 구슬을 주지 않는다(07의 찍기 대응 제안 2와 정합. 정답 마나는 그대로 지급) |
| 쓰러짐 | 보유 구슬의 절반(내림)을 잃는다 |
| 기대 수입 | 정답률 70%, 6.4문항/분, 어려움 25% 가정: 약 **5.6개/분**. 스킬 1을 분당 약 1.5회 + 스킬 2를 약 0.6회 쓸 수 있는 양 |

"마나는 정답과 자동 회복이 유일한 원천"이라는 브리프 원칙은 그대로 유지된다. 집중 구슬은 마나가 아니라 **RTS 전용 2차 자원**이다(변경 제안 1에서 확정 요청).

| 탑 벌칙 | 판당 1~3회 쓰러짐은 시간 벌칙뿐. **4회째부터 쓰러질 때마다 탑 HP -1** (판당 최대 -3) |
| 구슬 | 보유 구슬 절반 상실 |
| 목표 영향 | 호위: 동행이 끊김(수레는 멈춘다). 점령: 서 있던 거점 진행도 -50%. 차단: 별도 없음 |
| 대기 중 | 문제·소환·강화·궁극기는 정상 동작. 구슬은 계속 쌓인다(대기 시간이 "문제 풀이 시간"이 되도록 의도) |
| 튜토리얼 | 첫 쓰러짐은 벌칙 없이 즉시 부활 |
| 별 | ★3은 쓰러짐 ≤ 2회 |

"탑 HP -1"을 매번 주면 초5가 연쇄 손실로 무너진다(쓰러짐 6회 = HP -6). 그래서 3회까지는 시간만 잃고 4회째부터 탑을 갉는 **완충 + 상한** 구조로 정했다.

### 2.6 타워와 캐릭터의 역할 분담

| 일 | 타워(카드) | 빛지기 |
|---|---|---|
| 길 위 다수 처리 | **주력** | 보조(×0.6) |
| 둔화·군중 제어·탑 방어·회복 | 컵 / 소드 / 펜타클 | 눈부심 2초 한 가지뿐 |
| **길 밖 이탈 안개** | **공격 불가**(엷어서 카드의 빛이 통과) | **전담** (궁극기는 50%) |
| **보스 장막**(방어막) | 피해 ×0.3 | **파괴 담당**(기본 공격·스킬 피해 ×1.0 / 스킬 2는 ×2) |
| **수레 호위** | 불가 | **전담**(동행 시 이동 가속, 접근한 이탈 안개 처리) |
| **거점 점령** | 불가 | **전담**(서 있어야 진행) |
| 한 곳에 오래 있기 | 슬롯 고정 | 이동 가능하지만 한 번에 한 곳 |

- 두 역할이 겹치지 않으므로 "캐릭터만 하면 되는" 상황이 생기지 않는다. 캐릭터의 단독 처리량 상한은 해당 스테이지 길 위 FM의 **40% 이하**로 설계하고 봇으로 검증한다(8절 S7).
- 펜타클 반경 2타일은 캐릭터의 회복소이자 호위·점령의 안전 지대가 된다. 배치 선택이 의미를 갖는 지점이다.

### 2.7 자동 순찰 (조작 없이도 쓸모 있게)

- **기본값 켜짐.** 이동 명령이 없을 때 빛지기는 "가장 가까운 위협(이탈 안개 > 장막 > 호위/점령 목표 근처)"으로 이동하고, 도착하면 자동 공격한다. 위협이 없으면 탑 앞에서 대기하며 회복한다.
- 이동 명령을 내리면 그 지점을 **8초 동안 고수**한다. 그동안 자동 순찰은 쉰다(플레이어 의도 우선). 명령이 없으면 순찰로 복귀.
- 설정의 "**빛지기 도우미**"를 켜면 스킬도 준비되는 즉시 자동 시전한다(구슬 소비는 동일, 학습 밀도 영향 없음). 이때 별은 최대 ★2. 조작 난도(초5, 운동 접근성)를 위한 안전망이다.

## 3. RTS 모드 전용 적과 스테이지 목표

### 3.1 새 적: 이탈 안개 ("길 잃은 안개", 가칭)

| 항목 | 값 |
|---|---|
| 정체 | 길 위의 안개 일부가 **이탈점(X)**에서 갈라져 나와 길 밖을 가로지르는 엷은 안개 |
| 내구 | HP 65 (= 0.5 FM) |
| 속도 | 안개 조각의 ×0.45 (03 기준 약 1.2타일/초). 빛지기(3.0)가 충분히 따라잡을 수 있다 |
| 이동 | 이탈점에서 목표(측문 G / 수레 / 거점)로 직선 이동, 장애물만 회피 |
| **타워 상호작용** | 카드의 빛이 통과해서 **타워 대상이 되지 않는다.** 궁극기는 효과 50% |
| 탑 피해 | 측문(G)에 닿으면 **탑 HP -1** (일반 안개 조각과 같음) |
| 빛지기에게 | 접촉 1.5초당 -1. 적극 추격은 하지 않음 |
| 외형(04 톤) | 안개 조각보다 옅고 반투명한 점선 윤곽, 꼬리 한 줄. 색을 빼도 "점선 + 꼬리"로 구별(05 8.4절). 머리 위에 작은 "카드 통과" 아이콘(✕ 모양) |
| 폭력 표현 | 없음. 처치 = 흩어짐 |

- 이탈 안개는 일반 안개 조각의 숫자를 **옮긴 것**이다. 스테이지 총 FM을 일반의 약 97% 수준으로 유지한다(4.2절 표). 새 적을 "추가"가 아니라 "재배분"으로 둔 것은 난이도 곡선(03의 r값)을 보존하기 위해서다.
- 측문 G는 탑 바로 옆의 샛문이다. 타워가 길 위에서만 막는 구조라, 이탈 안개를 못 막으면 탑 HP가 직접 깎인다.

### 3.2 목표 1: 차단전 (INTERCEPT) — "샛길을 막아요"

| 항목 | 내용 |
|---|---|
| 상황 | 웨이브마다 이탈점 X에서 안개가 갈라져 측문 G로 간다. 빛지기가 막는다 |
| **승리** | 모든 웨이브를 끝내고 탑 HP ≥ 1 (일반 스테이지와 같은 조건) |
| **패배** | 탑 HP 0 (측문 누수 포함) |
| 별 추가 | ★2: 측문 누수 ≤ 4 / ★3: 누수 ≤ 1, 쓰러짐 ≤ 2 |
| 정답과의 연동 | 스킬 구슬(2.4절). 구슬이 없으면 기본 공격만으로 이탈 안개를 잡아야 해 누수가 커진다 |
| 필수성 검산 | 1-3: 이탈 안개 12마리 > 탑 HP 10. **캐릭터가 아예 막지 않으면 누수만으로 패배**한다 |

### 3.3 목표 2: 호위 (ESCORT) — "지식의 조각을 탑까지"

| 항목 | 내용 |
|---|---|
| 상황 | 보관소(C)에서 **빛 수레**(빛 6칸)가 출발해 샛길 30타일을 지나 탑에 도착해야 한다. 수레는 스스로 움직이지 않는다 |
| **이동 규칙** | **정답 1개당 2타일 전진.** 빛지기가 수레 반경 2타일 안에 있으면(동행) **3타일**. 오답·회피는 정지(후퇴 없음) |
| 위협 | 이탈 안개가 수레를 노린다. 접촉 1.5초당 수레 빛 -1. 펜타클 반경 2타일 안에서는 수레도 회복 |
| 정답 요구량 | 동행 유지 시 10개, 동행 없이 15개. 정답률 70%의 판(응답 21개 중 약 15개)이면 여유 있음 |
| **승리** | 수레가 탑에 도착 + 모든 웨이브 클리어 + 탑 HP ≥ 1. 도착 시 탑 HP +1(최대 10) |
| 연장 | 웨이브 5 종료 시 수레가 미도착이면 **30초 연장**(적 스폰 없음, 문제는 계속). 연장 종료 시 미도착이면 패배 |
| **패배** | 수레 빛 0 ("조각이 흩어졌어요") / 탑 HP 0 / 연장 종료 시 미도착 |
| 별 추가 | ★2: 도착 시 수레 빛 ≥ 3 / ★3: 수레 빛 ≥ 5, 쓰러짐 ≤ 2 |
| 용어 주의 | 03의 "보스+호위"는 정예가 왕을 호위한다는 뜻이다. 이 문서의 호위는 **수레를 지키는 것**이다. 화면 문구는 "수레 호위"로 쓴다 |

### 3.4 목표 3: 거점 점령 (CAPTURE) — "기억의 봉화를 밝혀요"

| 항목 | 내용 |
|---|---|
| 상황 | 길 밖에 거점(봉화) 3곳(B). 빛지기가 반경 1.5타일 안에 서 있으면 점령 게이지가 오른다 |
| **게이지 규칙** | 서 있는 동안 **초당 +8%**(약 12초에 완성). **정답 1개당 +15%**(서 있을 때만 유효). 적이 반경 안에 있으면 정지. 다른 거점으로 가면 그 거점은 멈춘 채 유지 |
| 점등 효과 | 점등된 거점 반경 3타일 안 카드의 **공격 속도 +10%**, 빛지기 회복 ×2. 점등은 영구 |
| **승리** | 웨이브 5 종료 시 점등 **≥ 2곳** + 모든 웨이브 클리어 + 탑 HP ≥ 1. 점등이 2곳 미만이면 30초 연장 |
| **패배** | 탑 HP 0 / 연장 종료 시 점등 2곳 미만 |
| 별 추가 | ★2: 3곳 모두 점등 / ★3: 3곳 점등 + 쓰러짐 ≤ 2 |
| 거점 배치 규칙 | 길에서 2칸 이상 떨어진 길 밖. 탑에서 가장 먼 거점도 이동 6초 이내. 3장 이후 한 곳은 고도 2 |
| 수치 가드 | 점등 효과 +10%는 08의 지형 상한(T1 화력 환산 +20%) 안이다. 문제 풀이 정답률 10%p의 가치를 넘지 않는다 |

### 3.5 보스 견제: "망각의 장막" (목표와 별개의 보스 규칙)

- 장막 있는 스테이지(2-4, 3-5, 4-3, 4-5)에서 망각의 왕이 경로의 **40% 지점**을 지나면 장막이 펼쳐진다.
- 장막 중 타워 피해 **×0.3**. 장막 내구는 **360 × 챕터 왕 배수**(Ch2 ×1.25 / Ch3 ×1.6 / Ch4 ×2.0)이며 **빛지기의 피해만** 깎는다(기본 ×1.0, 스킬 2 ×2, 스킬 1 ×1.5).
- 장막은 최대 12초 뒤 스스로 옅어진다(소프트락 방지). 장막을 깨면 왕이 6초 동안 받는 피해 ×1.3.
- 느낌: 타워가 방해받는 시간에 빛지기가 "왕관 조각"을 흩어 주는 순간. 04의 "왕관 조각이 떨어질 때마다 주변이 잠시 흐려지지만 지식의 빛으로 다시 밝힐 수 있다"를 그대로 옮겼다.
- 선택 확장(변경 제안 8): 07의 제안 1처럼 장막 해제 시 **봉인 카드 1문제**를 출제해 정답이면 장막 내구 -50%. 복습이 전투 클라이맥스에 들어온다. 4차에서는 제외.

## 4. 스테이지 배치

### 4.1 배치 규칙과 24스테이지 표

| 규칙 | 내용 |
|---|---|
| 챕터당 | 1~2개 (Ch1은 1개로 시작해 부담을 줄임) |
| 제외 | **x-1**(새 지역 진입은 쉽게)과 **x-6**(보스전은 타워와 궁극기 중심) |
| 연속 금지 | RTS 스테이지 사이에 일반 스테이지 1개 이상 |
| 선행 | 튜토리얼 + 1-1 + 1-2는 RTS 요소 0. 핵심 루프를 먼저 익힌 뒤에 만난다 |
| 새 개념 | 03의 "새 개념은 한 번에 하나". RTS 목표는 한 스테이지에 한 가지 새것만 |
| 보상 | 일반 스테이지와 같음(RTS 선호·회피 유도 금지). 첫 클리어 시 도감에 "빛지기" 항목 |

```
Ch1  1-1   1-2  [1-3]  1-4   1-5   1-6
Ch2  2-1  [2-2]  2-3  [2-4]  2-5   2-6
Ch3  3-1  [3-2]  3-3   3-4  [3-5]  3-6
Ch4  4-1   4-2  [4-3]  4-4  [4-5]  4-6
     [ ] = RTS 스테이지 (7개 / 24)
```

### 4.2 RTS 스테이지 상세

일반 FM과 문항 수는 03 1.4절 표의 값이다. 길 위 FM은 **일반의 90%**(문제 시간이 빠져 마나 수입이 줄고 캐릭터가 일부 기여하므로 보정), 이탈 안개는 FM 0.5짜리를 별도로 추가한다. 합계는 일반의 약 96~97%다.

| 스테이지 | 목표 | 새로 배우는 것 | 일반 FM | 길 위 FM (×0.9) | 이탈 안개 (마리 / FM) | 합계 FM | 일반 문항 | **보장 응답** | ★1 정답 하한 |
|---|---|---|---:|---:|---|---:|---:|---:|---:|
| **1-3** | 차단 | 빛지기 이동·스킬, 이탈 안개 (**튜토리얼 포함**) | 82 | 74 | 12 / 6.0 | 80 | 24 | **20** | 10 |
| 2-2 | 호위 | 수레와 동행 | 84 | 76 | 10 / 5.0 | 81 | 24 | 20 | 10 |
| 2-4 | 차단 + 장막 | 보스 장막 | 99 | 89 | 14 / 7.0 | 96 | 26 | 21 | 10 |
| 3-2 | 점령 | 거점과 게이지 | 105 | 95 | 14 / 7.0 | 102 | 27 | 22 | 12 |
| 3-5 | 호위 + 장막 | 호위 중 장막 | 148 | 133 | 18 / 9.0 | 142 | 25 | 20 | 12 |
| 4-3 | 점령 + 차단 + 장막 | 점령과 차단 병행 | 156 | 140 | 20 / 10.0 | 150 | 33 | 27 | 12 |
| 4-5 | 호위 + 점령 (복합) | 목표 2개 | 182 | 164 | 24 / 12.0 | 176 | 28 | 23 | 12 |

- 보장 응답 = 일반 문항 수의 **80%**(올림, 최소 20). 6절의 6.0/분 목표와 같은 비율이다.
- 4-5는 두 목표를 모두 달성해야 클리어이므로 가장 어렵다. 4차 범위 밖이며 이후 밸런싱에서 길 위 FM 비율을 조정할 수 있다.
- RTS 스테이지는 웨이브 사이 휴식을 **5초 → 8초**로 늘린다(+12초). 휴식 중 빛지기는 자동으로 회복하며 이동 명령이 필요 없다. 문제 풀이를 선행 투자할 시간이다.

### 4.3 예시 맵: 스테이지 1-3 "은빛 씨앗 들판" (10×18)

08의 3.1절 1장 맵 위에 RTS 표시를 얹었다. 표기는 08과 같다: 한 칸 = 종류 1자 + 고도 1자, 좌표 `(열,행)`.

## 6. 학습 밀도 보장

### 6.1 기준

| 구분 | 일반 모드 | RTS 모드 |
|---|---|---|
| 응답 문항/분 | 7.3~7.6 (03의 23~25문항 / 3:00~3:20) | **목표 6.0 (일반의 80%)**, **하한 5.0 (67%)** |
| 판당 응답 | 23~33 | **일반의 80%, 최소 20** (4.2절 표) |
| ★1 정답 하한 | 8 | **10** (Ch3~4는 12) |
| 캠페인 평균 | — | 24스테이지 중 7개가 RTS → (17×7.5 + 7×6.0)/24 = **7.06/분** (일반 대비 -6%) |

"응답"은 정답 + 오답이다. 회피(10초 방치 교체)는 *제시*는 되지만 응답은 아니다. 하한 5.0/분 미달이 4차 테스트에서 확인되면 **설계 재검토**(안 A로 후퇴)를 건의한다.

### 6.2 시간 예산 계산

일반 모드의 문항 사이클은 8.0초다(읽기·선택 4~5초 + 피드백 1.0초 + 소환·전장 확인 2~3초). RTS는 이 위에 캐릭터 조작이 추가로 시선과 엄지를 쓴다.

| 항목 | 설계 기준 (분당) | 1회 비용 | 분당 합계 |
|---|---|---:|---:|
| 이동·표적 명령 | 4회 | 1.0초 (탭 0.4 + 시선 복귀 0.6) | 4.0초 |
| 스킬 | 2회 | 1.5초 (홀드 0.3 + 확인·복귀 1.2) | 3.0초 |
| 빛지기 상태 확인(빛 위기, 쓰러짐 대응) | 1회 | 2.0초 | 2.0초 |
| **추가 점유 합계** | | | **9.0초** |

- 가용 시간 60 - 9.0 = 51.0초 ÷ 8.0초 = **6.4문항/분** (일반의 85%) → 목표 6.0을 0.4 웃돈다.
- **산만한 플레이어**(명령 8 / 스킬 3 / 확인 2): 8.0 + 4.5 + 4.0 = 16.5초 → 43.5 ÷ 8.0 = **5.4/분**. 하한 5.0 위.
- **최악**(명령 12 / 스킬 4 / 확인 3): 12 + 6 + 6 = 24초 → 4.5/분. 하한 아래 → 아래 장치가 필요한 이유다.
- 이 표는 가정이다. 4차에서 실측해 "분당 명령 수"와 "응답/분"의 관계를 보정한다.
