# 아르카나 수비대 — 공통 기획 브리프 (v0.5, 모든 작업의 기준)

> v0.5 (2026-10-28): 교차 검토(`11_consistency_review.md`)의 권고를 반영해 3·4·5절을 개정했다. 사용자 결정이 필요한 항목은 13절에 모았고, 결정 전에는 거기 적힌 잠정값을 쓴다.

> 이 문서는 모든 세부 기획·프로토타입이 반드시 따라야 하는 고정 전제입니다.
> 바꾸고 싶은 전제가 있으면 바꾸지 말고 "변경 제안" 절에 따로 적으세요.

## 1. 한 줄 정의
**"문제를 풀어 마나를 모으고, 아르카나 카드(수호자)를 소환해 '망각의 안개'에서 지식의 탑을 지키는 3~5분 아케이드 타워 디펜스."**

## 2. 포지셔닝
- 플랫폼: 웹(브라우저), 모바일 세로/가로 모두 대응, PC 마우스·키보드 지원. `edu_arcade_game_1`(교육용 게임 허브)의 첫 게임.
- 대상: 초등 5학년 ~ 중학교 2학년(만 11~14세). 보호자/교사가 과목 팩을 고를 수 있음.
- 세션 길이: 1판 3~5분(아케이드). 하루 10~15분 플레이를 목표로 한 "짧게 자주".
- 과목: **콘텐츠 팩 교체형**. 1차 팩은 ① 수학 연산/분수 ② 영어 단어 ③ 과학 개념 ④ 한국사 연표. 게임 로직은 과목과 독립.
- 톤: 밝은 판타지 + 타로 '아르카나' 모티프(점술·오컬트 요소는 배제, "지식의 카드"로 재해석). 폭력 표현 없음(적은 안개/그림자가 "흩어짐").

## 3. 핵심 루프 (고정)
1. **웨이브 시작**: 망각의 안개(적)가 길을 따라 지식의 탑으로 진군.
2. **문제 카드**: 화면 하단에 문제 1개가 항상 떠 있음(4지선다 또는 짧은 입력). 정답 → **마나 +N**, 오답 → 마나 없음 + 문제 카드 **입력 잠금(2초, 연속 오답마다 +1초, 최대 5초)** + 해당 문제가 "봉인 카드"에 등록(복습 큐).
3. **소환/강화**: 마나로 아르카나 카드를 길 옆 슬롯에 소환하거나 강화.
4. **콤보**: 연속 정답 수에 따라 콤보 게이지 상승. 콤보 3/5/8에서 각각 다음 소환 1회 -2 → 전체 공격력 버프 10초 → "메이저 아르카나" 궁극기 사용권 1장(최대 1장, 콤보가 끊겨도 유지).
5. **웨이브 종료**: 탑 HP가 남아 있으면 클리어. 별 1~3개(탑 HP·정답률·콤보 최대치 기준). 보상으로 카드 조각/새 카드.
6. **복습 루프**: 판이 끝나면 봉인 카드(틀린 문제) 중 1~3개를 "해제 퀴즈"로 다시 품. 맞히면 다음 판 시작 마나 보너스.

핵심 원칙: **빠르고 정확하게 풀수록 강해진다**. 그러나 문제를 안 풀고 버티는 전략은 불가능해야 함. 마나의 원천은 정답과 소량의 자동 회복이 중심이며, 예외는 ① 해제 퀴즈 시작 보너스(최대 3) ② 특성이 주는 마나(판당 합계 상한 20, 처치형은 최근 문항 정답률 조건부)로 한정한다. 무풀이·찍기 플레이는 웨이브 2~4에서 반드시 탈락해야 하며, 이는 시뮬레이터(`sim/`, `prototype/tests/bal_sim.js`)로 매 차수 확인한다.

## 4. 고정 수치 (v0.5 — 프로토타입 기준값, 밸런싱 문서가 조정 가능)
- **탑 HP 10.** 일반 적(안개 조각·속삭임) 1마리가 탑에 도달하면 -1, **정예(침묵 덩어리) -2**, 보스(망각의 왕) -5. 펜타클 보호막이 먼저 흡수한다.
- **정답 마나** +3(쉬움) / +4(보통) / +5(어려움). 난이도는 문항 난이도다. 문항 유형별 가산(참/거짓·입력·순서)은 해당 문항형이 들어오는 차수에 적용하며, 한 판 평균은 3.6~4.4 안에 둔다.
- **자동 회복 1마나/10초.** **시작 마나 0**(판 시작 전 해제 퀴즈 보너스 포함 **최대 3**) [D1]. 튜토리얼은 시작 마나 10.
- **소환 비용 5**, 저지대 슬롯은 -1(하한 4). **강화 비용 4/6/8**(Lv2/3/4), **최대 Lv4**(슬롯당 누적 23). 판 안 강화는 판이 끝나면 초기화.
- **콤보**: 3 = 다음 소환 1회 -2(하한 3), 5 = 전체 공격력 버프 10초(25~30%, 3차 BALANCE에서 하나로), 8 = 궁극기 사용권 1장(최대 1장, 콤보가 끊겨도 유지, 8콤보마다 반복). 오답 시 콤보는 0으로 돌아간다 [D7]. 방치로 문제가 교체될 때(회피)는 웨이브당 1회까지 콤보를 보호한다.
- **오답**: 마나 없음, 봉인 카드 등록, 문제 카드 **입력 잠금 2초에서 시작해 연속 오답마다 +1초(최대 5초)**, 정답 시 리셋. 소환·강화는 잠금 중에도 가능. 문제가 뜬 뒤 **읽기 하한**(0.8초 + 글자 수 비례, 상한은 플레이테스트로) 이내에 낸 답은 정답이어도 콤보가 오르지 않는다(마나는 지급).
- **1판 = 웨이브 5개**(튜토리얼 3개). 첫 웨이브 전과 웨이브 사이에 **5초 휴식**(이때도 문제를 풀 수 있음). RTS 스테이지는 웨이브 사이 8초.
- **문제 제한 시간 없음.** 문제 영역 입력이 7초 없으면 테두리 경고, **10초면 자동 교체되고 "회피"로 기록**한다(봉인 카드가 아니다). 소환·강화·궁극기 조작은 방치 타이머를 리셋하지 않는다. 3연속 회피 시 일시정지 오버레이.
- **별**: ★1 = 탑 생존 + 정답 8개 이상 / ★2 = ★1 + 탑 HP 6 이상 + 정답률 60% 이상 / ★3 = ★2 + 탑 HP 9 이상 + 정답률 80% 이상 + 최대 콤보 5 이상. 정답률 = 정답 ÷ (정답 + 오답 + 회피).
- **해제 퀴즈**: 판이 끝나면 복습 기한이 된 봉인 카드 최대 3문항. 정답 1개당 다음 판 시작 마나 +1(합계 최대 +3).
- **맵·슬롯**: 10×18 그리드(세로), S자 3굴곡, 지역별 슬롯 10/9/9/9(08). 타일 고도 0/1/2.
- **적 이동속도 기준**: 타일/초 단위, 안개 조각 약 1.1~1.2. 적별 HP·속도의 수치 원본은 3차까지 프로토타입 `BALANCE`, 이후 01로 승격 [D5].
- **웨이브별 적 HP 배수** ×1 / 1.6 / 2.4 / 3.4 / 5.0(보스 웨이브는 수행 적 동반). 보통 플레이어(5초에 1문제, 정답률 75%)가 탑 HP 3~6을 남기고 클리어하는 것이 목표 밴드.

## 5. 카드(수호자) 체계 — 이름은 세계관 문서(04)가 확정
- **마이너 아르카나 4속성** = 4가지 기본 카드 역할. 속성 이름은 카드의 원소를 가리킨다(적에 대해서는 "적 종류"라고 쓴다).
  - 완드(불): 단일 고화력(정예·보스에게 추가 피해)
  - 컵(물): 둔화·군중 제어
  - 소드(바람): 빠른 연타, 다수 타격
  - 펜타클(땅): 방어. **탑 보호막**을 만들고, 상위 단계에서 탑 HP를 회복한다 [D4]
- 각 카드는 **Lv1~Lv4**이며 단계마다 04의 이름을 쓴다(예: 불씨 지킴이 → 횃불 수호병 → 붉은 봉화대 → 태양의 탑지기). 카드 Lv은 판 안 강화 단계이고, 판 안 성장(경험치)의 "수비 레벨"과 구별한다.
- **메이저 아르카나** = 궁극기(콤보 8 사용권). 1차 구현은 3장: 광역 폭발형 **태양**, 전체 둔화형 **고요한 등불**, 탑 회복형 **부드러운 힘**. 판 시작 전에 1장을 장착한다.
- **지형**: 타일 고도 0/1/2에 따라 고지대 사거리 보너스(최대 ×1.15), 저지대 소환 비용 -1, 오르막 적 속도 ×0.8·내리막 ×1.1. 지형 이득의 합은 정답률 10%p의 가치를 넘지 않는다(08). 지형 사거리와 특성 사거리는 가산 후 총 ×1.20에서 자른다(09).
- 카드 수집은 메타 진행(판 간 영구). 판 안 강화와 판 안 특성은 판이 끝나면 초기화.

## 10. 추가 요구 (v0.3, 2026-10-28) — 판 안 레벨업과 '특성'
- 판 안에서 경험치(처치 + 정답)가 쌓여 **레벨업**하면 **특성 3개 중 1개를 고른다**(로그라이트식 드래프트). 판이 끝나면 특성은 초기화(메타 진행 아님).
- 특성 계열(사용자 제시 + 학습 연계): ① 적 종류 대비 강화 ② 처치 보상(마나/탑 체력 회복, 판당 상한) ③ 주변 카드(인접 슬롯) 강화 오라 ④ 학습 연계(정답 마나, 잠금 단축, 봉인 해제 보너스). 수비 레벨 상한 Lv6(선택 최대 5회). 드래프트 중 월드 시간 ×0.3, 3초 제한.
- 원칙: 특성 선택이 문제 풀이 흐름을 끊지 않아야 하고(선택 3초 이내, 적은 계속 진군 혹은 아주 짧은 슬로우), 특성 총합 이득이 정답 마나 수입을 넘지 않아야 한다. 상세는 `09_traits_perks.md`.

## 11. 추가 요구 (v0.4, 2026-10-28) — 'RTS 모드' 스테이지
- 24스테이지 중 일부(가끔, 예: 챕터당 1~2개)는 **RTS 모드**: 타워(카드) 배치에 더해 **플레이어 캐릭터 1명을 직접 조작**(이동·기본 공격·스킬)한다.
- 캐릭터 조작은 문제 풀이와 손을 다투므로, 한 손으로 문제를 풀고 다른 손으로 캐릭터를 움직이는 구조가 아니라 **문제 풀이가 캐릭터에게 명령을 내리는** 방식 등 핵심 루프를 해치지 않는 설계가 필요하다. 상세는 `10_rts_mode.md`.
- 구현 우선순위: 기획·로직 확정이 먼저. 프로토타입 3차는 특성(09)까지만 넣고, RTS 모드는 설계 확정 후 별도 차수에서 다룬다.
