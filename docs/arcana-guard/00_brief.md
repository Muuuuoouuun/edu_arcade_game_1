# 아르카나 수비대 — 공통 기획 브리프 (v0.1, 모든 작업의 기준)

> 이 문서는 모든 세부 기획·프로토타입이 반드시 따라야 하는 고정 전제입니다.
> 바꾸고 싶은 전제가 있으면 바꾸지 말고 "변경 제안" 절에 따로 적으세요.

## 1. 한 줄 정의
**"문제를 풀어 마나를 모으고, 아르카나 카드(수호자)를 소환해 '망각의 안개'에서 지식의 탑을 지키는 3~5분 아케이드 타워 디펜스."**

## 2. 포지셔닝
- 플랫폼: 웹(브라우저), 모바일 세로/가로 모두 대응, PC 마우스·키보드 지원. `edu_arcade_game_1`(교육용 게임 허브)의 첫 게임.
- 대상: 초등 5학년 ~ 중학교 2학년(만 11~14세). 보호자/교사가 과목 팩을 고를 수 있음.
- 세션 길이: 1판 3~5분(아케이드). 하루 10~15분 플레이를 목표로 한 "짧게 자주".
- 과목: **콘텐츠 팩 교체형**. 1차 팩은 ① 수학 연산/분수 ② 영어 단어 ③ 과학 개념 ④ 한국사 연표. 게임 로직은 과목과 독립.
- 톤: 밝은 판타지 + 타로 '아르카나' 모티프(점술·오컬트 요소는 배제, "지식의 카드"로 재해석). 폭력 표현 없음(적은 안개/그림자가 "흩어짐").

## 3. 핵심 루프 (고정)
1. **웨이브 시작**: 망각의 안개(적)가 길을 따라 지식의 탑으로 진군.
2. **문제 카드**: 화면 하단에 문제 1개가 항상 떠 있음(4지선다 또는 짧은 입력). 정답 → **마나 +N**, 오답 → 마나 없음 + 해당 문제가 "봉인 카드"에 등록(복습 큐).
3. **소환/강화**: 마나로 아르카나 카드를 길 옆 슬롯에 소환하거나 강화.
4. **콤보**: 연속 정답 수에 따라 콤보 게이지 상승. 콤보 3/5/8에서 각각 소환 비용 할인 → 전체 공격력 버프 → "메이저 아르카나" 궁극기 1회 사용권.
5. **웨이브 종료**: 탑 HP가 남아 있으면 클리어. 별 1~3개(탑 HP·정답률·콤보 최대치 기준). 보상으로 카드 조각/새 카드.
6. **복습 루프**: 판이 끝나면 봉인 카드(틀린 문제) 중 1~3개를 "해제 퀴즈"로 다시 품. 맞히면 다음 판 시작 마나 보너스.

핵심 원칙: **빠르고 정확하게 풀수록 강해진다**. 그러나 문제를 안 풀고 버티는 전략은 불가능해야 함(마나의 유일한 원천은 정답 + 소량의 자동 회복).

## 4. 고정 수치(프로토타입 기준값, 밸런싱 문서가 조정 가능)
- 탑 HP 10. 일반 적 1마리가 탑 도달 시 -1, 정예 -2, 보스 -5.
- 정답 마나 +3(쉬움) / +4(보통) / +5(어려움). 자동 회복 1마나/5초.
- 기본 카드 소환 비용 5, 강화 비용 4/6/8 (Lv2/3/4).
- 1판 = 웨이브 5개(튜토리얼 스테이지는 3개). 웨이브 간 5초 휴식(이때도 문제는 풀 수 있음 = 선행 투자).
- 문제 제한 시간: 없음(아케이드 압박은 적의 진군이 대신함). 단, 10초 넘게 방치 시 문제가 자동 교체되고 "회피"로 기록.

## 5. 카드(수호자) 체계 — 이름은 세계관 문서가 확정
- **마이너 아르카나 4속성** = 4가지 기본 타워 역할
  - 완드(불): 단일 고화력
  - 컵(물): 둔화/군중 제어
  - 소드(바람): 빠른 연타, 다수 타격
  - 펜타클(땅): 방어/탑 HP 회복·보호막
- **메이저 아르카나** = 궁극기(콤보 보상). 1차 구현은 3장: 광역 폭발형, 전체 둔화형, 탑 회복형.
- 카드 수집은 메타 진행(판 간 영구 진행). 판 안에서의 강화는 판이 끝나면 초기화.

## 6. 적
- 일반 "안개 조각", 빠른 "속삭임", 단단한 "침묵 덩어리", 보스 "망각의 왕"(스테이지 마지막 웨이브). 세부 수치는 메카닉 문서.

## 9. 추가 요구 (v0.2, 2026-10-28)
- **배경 그래픽**: 지역(챕터 4개) × 과목 팩(4개) × 난이도(3단계)에 따라 달라지는 레이어형 배경. 상세는 `08_environment_terrain.md`.
- **지형 높낮이**: 타일 고도 0/1/2 세 단계. 고지대 슬롯 사거리 보너스, 오르막 구간 적 둔화 등 "약간의" 전술 변수. 지형 보너스는 문제 풀이 마나 수입보다 작아야 한다(핵심 루프 우선).
- 프로토타입 2차에서 지형 고도와 지역 배경을 통합한다.

## 10. 추가 요구 (v0.3, 2026-10-28) — 판 안 레벨업과 '특성'
- 판 안에서 경험치(처치 + 정답)가 쌓여 **레벨업**하면 **특성 3개 중 1개를 고른다**(로그라이트식 드래프트). 판이 끝나면 특성은 초기화(메타 진행 아님).
- 특성 계열 예시(사용자 제시): ① 특정 적 속성 대비 강화 ② 처치마다 마나/탑 체력 회복 ③ 주변 카드(인접 슬롯) 강화 오라.
- 원칙: 특성 선택이 문제 풀이 흐름을 끊지 않아야 하고(선택 3초 이내, 적은 계속 진군 혹은 아주 짧은 슬로우), 특성 총합 이득이 정답 마나 수입을 넘지 않아야 한다. 상세는 `09_traits_perks.md`.
