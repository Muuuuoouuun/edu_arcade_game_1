## 1. 배경 레이어 구조와 48조합 규칙

### 1.1 레이어 (뒤 → 앞)

| 층 | 이름 | 무엇이 바뀌나 | 바뀌는 기준 | 구현(1차 절차 생성) |
|---|---|---|---|---|
| L0 | 하늘 | 그라디언트 4색, 해/달/별 | **난이도** (+지역 색 편향 소량) | `createLinearGradient` + 원형 글로우 |
| L1 | 원경 | 언덕·수관·항구·구름 바다 실루엣 | **지역 고정** (난이도는 색만 변함) | 사인 합성 능선, 삼각형 수관, 다각형 |
| L2 | 중경 | 과목 소품 (스카이라인 띠 + 빈 칸 데코) | **과목** | 도형 조합 4세트 (아래 1.3) |
| L3 | 근경 | 지면 질감, 길, 슬롯, 고도 타일 | **지역**(팔레트·질감) + **스테이지 맵**(길·고도) | 타일 루프, 2.5D 고도 표현 (4절) |
| L4 | 날씨 | 흐르는 안개 1~3겹 | **난이도 × 지역** (항구 ×1.4, 정상 ×0.8) | 사전 렌더 안개 스프라이트를 가로 스크롤 |
| L5 | 마감 | 색 등급(틴트·밝기), 비네트 | **난이도** | 팔레트 단계에서 직접 계산 (후처리 패스 없음) |

화면 구성(기준 360×740): 위 100px = 하늘·원경·중경 띠 / 그 아래 10×18 그리드(칸 34px, 원점 (10,100)) / 맨 아래 28px = 마감 여백. 실제 게임에서 문제 카드는 DOM 오버레이(06 문서)이므로 그리드 아래 영역과 겹치지 않도록 캔버스 높이만 줄이면 됩니다(칸 크기·논리는 동일).

### 1.2 48조합을 만드는 규칙

조합 ID = `R{1-4}-S{1-4}-D{1-3}`. 화면은 이 식 하나로 만들어집니다.

```
bg(R,S,D) = sky(D, R.skyBias)            // L0
          + far[R]  (haze = D.horizon)    // L1  대기 원근: 원경색을 지평선 하늘색과 섞음
          + mid[S]  (accent = mix(S.accent, R.ground, 0.18))   // L2  지역 지면색과 18% 섞어 어울리게
          + near[R] + map[R]              // L3
          → 모든 색에 grade(D) 적용: mix(color, D.tint, D.amt) × D.bright, 그리고 채도 상한 0.48
          + fog(D.fog × R.fogMul, D.layers)  // L4 (동적)
```

**에셋·구현 수를 줄이는 핵심 3가지**
1. **난이도는 "색과 날씨"만 바꾼다.** 모양(소품 위치·질감·원경 실루엣)은 지역+과목 시드(`hash(R+S)`)로 고정하고, 난이도는 팔레트 등급·안개·별·글로우만 바꾼다. 그래서 난이도 3단계에 새 그림이 필요 없다.
2. **중경 소품은 지역 중립 도형 + 과목 색.** 소품은 4세트(과목별)만 만들고, 지역별로 다시 그리지 않는다. 지역 지면색을 18% 섞어 색만 맞춘다.
3. **원경·근경은 지역당 1세트.** 그래서 부품은 원경 4 + 중경 4 + 근경 4 + 난이도 파라미터 3 = **15개**로 48조합이 나온다 (곱셈이 아니라 덧셈).

**난이도 파라미터 (D)** — 난이도 1~3 = 쉬움/보통/어려움 (브리프 4절 마나 +3/+4/+5와 같은 축이라고 가정)

| D | 시간대 | 하늘(위→지평선) | 틴트·밝기 | 안개(알파×겹) | 별 | 비네트 | 그 외 |
|---|---|---|---|---|---|---|---|
| D1 | 이른 노을(밝고 따뜻) | `#7db9ee` → `#ffc890` | 노란빛 8%, ×1.00 | 0.10 × 1겹 | 0 | 0 | 해(우상단) |
| D2 | 황혼 | `#3c3f8f` → `#ffad7e` | 보라빛 20%, ×0.84 | 0.22 × 2겹 | 26 | 0.16 | 해가 언덕에 걸림, 슬롯 은은한 빛 |
| D3 | 밤 | `#0b1230` → `#5b73b4` | 푸른빛 34%, ×0.62 | 0.36 × 3겹 | 72 | 0.30 | 달, 슬롯 빛 강, 소품 조명 켜짐 |

**지역 파라미터 (R)** — 04 문서의 분위기를 색과 질감으로 번역

| R | 지면 A/B | 길(기본색) | 원경 | 질감 | 하늘 편향 | 안개 배수 |
|---|---|---|---|---|---|---|
| R1 은빛 씨앗 들판 | `#8fc788`/`#a3d39b` | `#54463a` 흙길 | 둥근 언덕 3겹 + 새싹 나무 + 떠다니는 씨앗 빛 | 풀잎 선, 은빛 작은 꽃 | 없음 | ×1.0 |
| R2 메아리 숲 | `#5f9c80`/`#6faa8c` | `#4e4034` 숲길 | 침엽 수관 3겹 + 빛줄기 + 메아리 고리(동심원) | 낙엽, 이끼 얼룩 | 숲 청록 14% | ×1.0 |

**과목 파라미터 (S)** — 중경 소품

| S | 소품(도형 조합) | 기본 색 | 비고 |
|---|---|---|---|

| S3 과학 | 실험 장치: 삼각 플라스크, 비커, 원자 궤도, 시험관 선반 | 청록 `#58c2b0` | 액체 색 = 포인트 색 |

**지역 × 난이도 예외(6개만 허용)**: ① R3 D2·D3 등대 빔 + 마을 창문 점등 ② R4 석재 밝기 보정(D2 +0.07, D3 +0.14, 스스로 빛남) + 계단선 발광 ③ R2 빛줄기 알파가 난이도가 오를수록 감소(0.16→0.12→0.08), 메아리 고리는 증가 ④ R3 안개 ×1.4, R4 ×0.8 ⑤ 모든 D2·D3 슬롯 후광(0.30/0.50) ⑥ S4 석등 점등. 이 6개 외의 조합별 특수 처리는 만들지 않습니다.

## 2. 지형 높낮이 시스템

### 2.1 규칙 (제안 수치)

고도는 **타일마다 0(저) / 1(중) / 2(고)** 세 단계. 인접한 두 칸의 고도 차는 **항상 1 이하**(절벽 없음, 경로 위 계단도 한 칸에 한 단계).

| 항목 | 저지대 e0 | 중지대 e1 | 고지대 e2 |
|---|---|---|---|
| 슬롯 **사거리** | ×1.00 | **×1.08** | **×1.15** |
| 슬롯 **소환 비용** | **-1 (5→4)** | 5 | 5 |
| 슬롯 공격력·공속·효과 | 변화 없음 (-0%) | 변화 없음 | 변화 없음 |
| 강화 비용(4/6/8) | 변화 없음 | 변화 없음 | 변화 없음 |

| 적 이동 (경로 칸 기준, 그 칸에 **들어설 때의 고도 변화**) | 속도 |
|---|---|
| 오르막 (이전 칸보다 높음) | **×0.80** |
| 평지 | ×1.00 |
| 내리막 (이전 칸보다 낮음) | **×1.10** |

- 사거리 환산: 기본 사거리 2.5타일, 슬롯이 직선 길에서 1칸 떨어진 경우 사거리 안에 머무는 길이는 4.58칸 → e1 **4.96칸(+8.3%)** → e2 **5.39칸(+17.6%)**. 즉 "사거리 +15%"는 화력으로는 약 +18%입니다. (사거리를 +1타일로 하면 +40%라 너무 큽니다. 비율 방식을 권장.)
- 소환 비용 -1은 **소환에만** 적용, 하한 4. 콤보 3 할인과 겹치면 합산 후 하한 3 (01 문서 확정 시 조정).
- 속도 배수는 컵(둔화)과 **곱셈**으로 합치되, 최종 속도는 기본의 **45% 미만으로 내려가지 않게** 하한(가정값).
- 보스·정예도 같은 배수를 쓴다(예외 없음, 규칙 단순화).

### 2.2 "문제 풀이 → 마나" 핵심 루프를 해치지 않는지 점검

가정: 1판 3~5분, 문제 1개 6~7초, 정답률 80%, 정답 +4마나 → **정답 수입 약 120~200마나**, 자동 회복 36~60마나. 한 판 소환 8~10회 + 강화.

| 점검 | 계산 | 결과 |
|---|---|---|
| 저지대 비용 절감 | 저지대 슬롯 2~5개 × 1마나 = 최대 5마나 | 수입의 약 3% (정답 1~1.3개분) |
| 고지대 사거리 이득 | 슬롯 평균 화력 이득 = (e2수×17.6% + e1수×8.3%) ÷ 슬롯수. R1 6.0% / R2 9.6% / R3 7.6% / R4 10.6% | 최대 약 10% |
| 풀이의 영향 | 정답률 10%p 하락(80→70%) = 마나 수입 -12.5% | **지형 최대 이득(약 10%)보다 큼** |
| 오르막/내리막 시간 | 맵별 길 통과시간 계수 ×0.999 ~ ×1.018 | 난이도 곡선 영향 ±2% |
| 슬롯 포화 | 슬롯 8~10개, 한 판 소환 8~10회 → 후반엔 대부분 채워짐 | 지형은 **초반 선택 순서와 강화 집중**에서만 갈림 |

결론: **지형 이득의 합 ≤ 정답률 10%p의 가치**로 묶어 두면 "문제를 안 풀고 배치만으로 버티는" 전략이 성립하지 않습니다.

### 2.3 상한(가드레일) — 밸런싱 문서가 바꿔도 이 선은 넘지 않기

| # | 상한 | 이유 |
|---|---|---|
| T1 | 지형 사거리 배율 ≤ ×1.15 (화력 환산 ≤ +20%) | 배치만으로 큰 화력 차가 나면 퍼즐이 됨 |
| T2 | 지형 비용 할인 ≤ 1마나(소환가의 20%), 강화비에는 적용 금지 | 수입의 3% 수준 유지 |
| T3 | 속도 배수 0.80 ~ 1.10, 둔화와 곱한 최종값 ≥ 기본의 45% | 길 한 곳에 적이 뭉쳐 정체되는 것 방지 |
| T4 | 맵당 오르막+내리막 칸 합 ≤ 12 (길의 약 1/3), 통과시간 계수 0.97~1.05 | 난이도 곡선 보호 (선택: `pathTimeNorm = 1/계수`로 속도 보정하면 총 시간 영향 0) |
| T5 | 슬롯 분포: 고 20~45%, 저 20~50%, 한 칸 이상의 중 포함 | 선택지가 분산되도록 |
| T6 | 지형 최적 배치와 최악 배치의 클리어 마나 효율 차 ≤ 12% (시뮬레이터로 검증) | 풀이 > 배치 |
| T7 | 소환 후 카드 이동·재배치 기능 없음 | 재배치를 넣으면 배치 퍼즐이 됨 |

챕터별로 지형 강도를 올려 학습 곡선을 만듭니다: **1장 완만**(고지대 슬롯 2개, 저지대 5개) → 2장 → 3장 → **4장 가파름**(고지대 4개, 길 위 오르막 2칸).

### 2.4 플레이어에게 보이는 방식 (색에만 의존 금지)
- 슬롯 판의 문양: 저지대 = 동그라미, 중지대 = ^ 1개, 고지대 = ^ 2개. 판 색도 다르지만 문양이 주 신호.
- 슬롯을 누르면(선택 시) 사거리 원을 지형 보너스 반영 크기로 미리 보여 주고, 문구 한 줄: "높은 곳이라 멀리 봐요 (사거리 +15%)", "낮은 곳이라 싸요 (마나 -1)".
- 오르막/내리막 칸에 계단선 3줄(계단선은 항상 표시). "지형 표시 강화" 옵션을 켜면 ▲(느려짐)/▼(빨라짐) 화살표와 숫자 표시.

## 3. 챕터별 길 모양·고도 맵 (10×18, 세로 모바일)

- 그리드: 가로 10 × 세로 18. 좌표 `(열,행)`, 왼쪽 위 (0,0). 한 칸 = 두 글자: **종류 1자 + 고도 1자**.
- 종류: `S` 적 출발(안개 문) / `T` 지식의 탑 / `=` 길 / `o` 슬롯 / `.` 장식 칸(소품 가능) 
- "S자 3굴곡" = 가로 왕복 구간 3개(꺾임 6회). 길 폭 1칸, 슬롯은 반드시 길과 상하좌우로 맞닿음.
- 모든 맵이 자동 검증을 통과: 인접 고도 차 ≤1, 슬롯·길 겹침 없음, 슬롯의 길 인접.

## 4. 렌더링 레시피 (Canvas 2D, 에셋 0)

### 4.1 원칙
- 배경 전체를 **오프스크린 캔버스 1장**(논리 360×740 × DPR ≤ 2)에 한 번만 그리고 `drawImage`로 쓴다 (06 문서 방침과 동일).
- 매 프레임 추가되는 것은 **안개 스프라이트 1~3장 가로 이동**과(켰을 때) **지형 오버레이 1장**뿐. 둘 다 사전 렌더.
- 난수는 `mulberry32(hash(R+S))` 시드 고정 → 같은 조합은 항상 같은 그림. 노이즈는 해시 격자 값 노이즈(스무스스텝 보간) 한 함수.
- `prefers-reduced-motion`이면 안개를 멈춘다. 번쩍임 없음, 안개 속도 5~8px/초.

### 4.2 그리는 순서
1. **하늘**: 세로 그라디언트(난이도 4색, 지역 편향 섞기) → 별(D2 26, D3 72, 크기 0.5~1.4px) → 해/달(원 + 방사형 글로우).
2. **원경**: 지역별 함수. 예) 언덕 능선 `y(x) = base - amp·(0.55·sin(fx+φ) + 0.3·sin(2.3fx+1.7φ) + 0.25) - 6·noise`, 겹마다 색을 지평선 하늘색과 섞어(haze 0.55 → 0.15) 대기 원근.
3. **지평선 안개**: 높이 36px 그라디언트(알파 0 → 0.42).
4. **중경 스카이라인**: 과목 소품 6~7개를 y=103 기준선에 일렬(크기 21~29px).
5. **지면 바탕 + 좌우 여백 장식**(지역별 덤불/나무/말뚝/구름 솜) + 좌우 가장자리 어둡게.
6. **타일 루프(행 위→아래, 페인터 알고리즘)** — 4.3 참조. 타일마다: 남쪽 절벽면 → 윗면 → 질감 → 길 → 측면 음영·립·등고선 → 경사 계단선 → 슬롯 → 데코 소품.
7. **시작 문(안개 소용돌이)·탑**, 하단 마감 그라디언트, 비네트.

### 4.3 고도 표현 (2.5D 느낌)

```
칸 윗면 좌표:   x = OX + c·T ,  y = OY + r·T − e·L      (T=34, L=4)
남쪽 절벽면:    (e − e남) > 0 일 때  높이 (e − e남)·L 의 세로 그라디언트
                (맨 아래 행은 e남 = 0) — 절벽색 = mix(지면색, R.cliff, 0.55), 어둡게 −10% → −24%
높은 이웃이 남쪽에 있으면 그 칸이 아래를 L px 덮음 (인접 고도차 ≤1 이라 최대 4px)
```
- **음영**: 윗면 그라디언트(위 밝게, 아래 어둡게), 고도 +1마다 윗면 밝기 +4%(HSL 명도). 높은 이웃이 북·서·동에 있으면 그 변에 6~7px 접촉 그림자(알파 0.24), 낮은 이웃 쪽 변에는 1.2px 밝은 립(알파 0.30).
- **등고선**: 낮은 이웃과 맞닿는 변을 3.2px 안쪽에서 1px 선(알파 0.30). 고도 2칸은 안쪽 사각 링 추가(알파 0.14). "지형 고도 표시"를 켜면 오버레이로 노란 두꺼운 선 + 칸 숫자 + 슬롯 배지(-1 / R+8% / R+15%) + 경사 ▲▼ + 고도 틴트(중 노랑 12%, 고 주황 20%).
- **길**: 칸 단위 사각형 + 바깥 모서리(양쪽 이웃이 길이 아닌 곳)만 반지름 9px 둥글게, 길이 아닌 쪽 변에 안쪽 그림자 6px.
- **경사 칸**: 이전 칸과 고도가 다른 길 칸에 진행 방향과 수직인 계단선 3줄(어두운 선 + 1px 밝은 선).
- **슬롯 판**: 반지름 12px 원, 어두운 외곽선(알파 0.9), 고도별 판 색(저 `#cde6f6` / 중 `#f6efd8` / 고 `#ffe19a`) + 문양(○, ^, ^^). 슬롯 판은 칸과 함께 들어올림(그림자 포함).
- **소품**: 길·슬롯과 상하좌우로 맞닿지 않는 장식 칸의 50%에만 17~25px 소품. 길 옆 1칸은 항상 비워 둠("깨끗한 차선").

## 6. 실제 아트로 교체할 때의 에셋 목록

절차 생성 코드는 그대로 두고 **층 단위로** 교체합니다(색 등급·안개·별은 계속 코드). 난이도별 그림은 필요 없고 런타임 등급으로 해결합니다 → **48조합 = 파일 16개**.

파일 규칙: `assets/bg/{층}/{id}@2x.webp`, 논리 크기 기준 @2x 저장, 팔레트 압축 WebP, 아틀라스는 JSON 좌표 파일 1개 동반.

| 파일 | 크기(@2x 픽셀) | 개수 | 내용 | 예상 용량 |
|---|---|---|---|---|
| `far/r{1-4}_far@2x.webp` | 720×200 | 4 | 지역 원경 (하늘 제외, 투명 하늘) | 각 ~20KB |
| `sky/celestial@2x.webp` | 512×256 | 1 | 해·달·별·구름 조각 6종 | ~10KB |
| `mid/s{1-4}_props@2x.webp` | 1024×512 | 4 | 과목당 스카이라인 6 + 데코 8 = 14스프라이트 (총 56) | 각 ~45KB |
| `near/r{1-4}_tiles@2x.webp` | 1024×1024 | 4 | 윗면 4변형, 절벽면 3(높이 1·2·밑단), 길 자동타일 16 + 계단선 2, 데코 8 (타일 68px) ≈ 37스프라이트 | 각 ~90KB |
| `shared/slots@2x.webp` | 512×256 | 1 | 슬롯 판 고도 3종 × (빈·선택·후광) | ~15KB |
| `near/fixtures@2x.webp` | 512×512 | 1 | 탑 4종(지역별 장식), 안개 문 4종 | ~35KB |
| `fx/fog@2x.webp` | 1440×260 | 1 | 안개 덩어리 3종(가로 타일 가능, 알파) | ~25KB |

- 합계: **파일 16개, 스프라이트 약 230개, 전체 약 680KB**. 06 문서 예산(아틀라스 합계 < 500KB, 스테이지별 지연 로드)에 맞춰 **스테이지 1개 로드분 = far 20 + celestial 10 + mid 45 + near 90 + slots 15 + fixtures 35 + fog 25 ≈ 240KB** 로 제한.
- 교체 순서 제안: ① 슬롯 판·탑(가장 자주 보임) → ② 근경 타일(길 자동타일) → ③ 중경 과목 소품 → ④ 원경.
