# 아르카나 수비대 — UI/UX 명세 (v0.1)

- 기준 문서: `docs/arcana-guard/00_brief.md` (v0.1). 브리프의 전제(핵심 루프, 고정 수치, 카드 체계, 적, 산출물 위치)를 그대로 따른다.
- 표기: 브리프 기준값은 그대로 쓰고, 밸런싱 문서가 조정할 값은 "(밸런싱 값)"으로 표시한다.
- 대상 뷰포트: 모바일 세로 **360×740**(기준, 좌우 여백 16px), PC 가로 **1280×720**(보조 레이아웃 1개).
- 범위: 화면 흐름, 전투 레이아웃, 인터랙션 타이밍, 콤보·궁극기 상태, 접근성, 입력, 방치 경고, 아트 디렉션.
  모바일 가로와 짧은 입력형 문제는 이번 명세 밖이며 변경 제안 7번에 적었다.
- 상태: 초안 (구현 전 검토용)

## 0. 설계 원칙

1. **엄지가 닿는 곳에 답이 있다.** 선택지 4개, 궁극기, 일시정지는 화면 하단 40% 안에 둔다.
2. **한 판은 한 화면에서.** 문제 → 마나 → 소환이 전투 화면 하나에서 끝난다. 화면 전환은 판 시작과 판 종료에서만 일어난다.
3. **소리 없이도 완결.** 모든 판정은 색, 모양, 아이콘, 글자 중 두 가지 이상으로 전달한다.
4. **틀리면 흩어질 뿐.** 오답은 "안개가 번졌다"로, 적은 "흩어져 사라짐"으로 표현한다. 피, 상처, 공포 연출은 쓰지 않는다.
5. **짧게 자주.** 허브의 "이어하기" 한 번으로 바로 전투에 들어간다.

## 1. 화면 목록과 전이도

### 1.1 화면 목록

| ID | 화면 | 목적 | 핵심 요소 |
|---|---|---|---|
| H | 허브 | 진입, 이어하기 | 이어하기(마지막 스테이지), 학습 시작, 도감, 설정, 복습 대기 수 배지 |
| P | 과목 팩 선택 | 팩 1개 고르기 (보호자·교사가 고를 수 있음) | 4개 팩 카드: 수학 연산·분수 / 영어 단어 / 과학 개념 / 한국사 연표. 팩별 진행률, 봉인 대기 수 |
| St | 스테이지 선택 | 팩 안의 스테이지 고르기 | 노드 경로 (첫 노드 = 튜토리얼 3웨이브), 별 0~3, 보스 스테이지 표시. 장착할 메이저 카드 선택 (변경 제안 4) |
| B | 전투 | 핵심 루프 | 2절 레이아웃 |
| B-P | 일시정지 오버레이 | 일시정지 중 조작 | 계속, 재시작, 설정, 나가기 (나가기는 확인 1회) |
| R | 결과 | 별, 보상, 요약 | 별 1~3과 기준 3줄(탑 HP, 정답률, 콤보 최대), 회피 수, 카드 조각·새 카드, 봉인 N개 |
| Q | 봉인 해제 퀴즈 | 복습 루프 | 봉인 카드 1~3문제. 전투와 같은 4지선다 컴포넌트 재사용. 맞히면 "해제" 스탬프와 다음 판 마나 보너스 (밸런싱 값) |
| C | 도감 | 메타 진행 확인 | 탭 4개: 카드(마이너 4속성, 메이저 3장) / 적 4종 / 봉인 기록 / 팩별 진척 |
| S | 설정 | 접근성, 표시 옵션 | 애니메이션 줄이기, 글자 크기, 효과음, 패턴 강화, 왼손 모드, 테마(시스템·라이트·다크) |

### 1.2 전이도

```
[H 허브]
  -> 학습 시작 ---------> [P 과목 팩] --팩 선택--> [St 스테이지] --스테이지 탭--> [B 전투]
  -> 이어하기 ---------------------------------------------------------------------^  (마지막 스테이지 바로 시작)
  -> 도감 -------------> [C 도감] --뒤로--> [H]
  -> 설정 -------------> [S 설정] --뒤로--> [H]

[B 전투]
  -> 일시정지 --------> [B-P 오버레이] --계속--> [B]
                              -> 나가기 (확인 1회) --> [St]
  -> 탑 HP 0 ---------> [R 결과: 실패]
  -> 웨이브 5 클리어 --> [R 결과: 클리어]

[R 결과]
  -> 카드 조각 / 새 카드 --> 해제 연출 --> (도감에서 NEW 배지)
  -> 봉인 카드 1개 이상 --> [Q 봉인 해제 퀴즈] --> [R] (보너스 표시)
  -> 다음 스테이지 (기본 버튼) --> [B]
  -> 재도전 --> [B]
  -> 홈 --> [H]

[공통] 뒤로 버튼은 직전 화면으로 돌아간다. 모든 화면에서 허브(H)로 가는 경로는 2탭 이내.
```

### 1.3 흐름 메모

- **첫 실행**: 허브에서 튜토리얼 스테이지(웨이브 3개)를 자동 추천한다. 전투 중 코치마크 3장(문제→마나, 슬롯 탭→소환, 콤보 3 할인)을 보여주며, 건너뛰기 가능하고 한 번만 뜬다.
- **결과 화면**: 기본 행동은 "다음 스테이지"다. 봉인 카드가 있으면 해제 퀴즈를 1회 권유하되 강제하지 않는다. 건너뛰면 다음 판 보너스만 없다.
- **실패 화면**: 탑 HP 0이어도 격려 문구를 쓴다. 예: "탑이 안개에 잠깐 덮였어요. 다시 지켜볼까요?" 주 버튼은 재도전이다.
- **일시정지**: 타이머와 적 이동이 모두 멈춘다. 나가기를 누르면 "지금 나가면 이번 판 기록은 사라져요" 확인 1회를 거친다.

## 3. 핵심 인터랙션

### 3.1 빈 슬롯 탭 → 카드 선택 팝업(4속성) → 소환

1. **슬롯 탭**: 슬롯이 0.95배로 눌린다. 팝업이 맵 하단 절반(y 240–392, 폭 328px)에 열린다. 제목은 "어떤 수호자를 세울까요?"다.
2. **4속성 버튼**: 1열에 76×72px 버튼 4개를 둔다. 각 버튼은 모양 아이콘, 이름, 역할 한 단어, 비용으로 구성한다.

   | 단축키 | 모양·색 | 이름 | 역할 한 단어 | 비용 |
   |---|---|---|---|---|
   | Q | ▲ 삼각 · 황금 | 완드 (불) | 단일 고화력 | 5 (할인 시 "5→4") |
   | W | ● 원 · 물빛 | 컵 (물) | 둔화 | 5 |
   | E | ◆ 마름모 · 쇠빛 | 소드 (바람) | 연타 | 5 |
   | R | ⬟ 오각형 · 흙갈 | 펜타클 (땅) | 방어 | 5 |

3. **마나 부족**: 해당 버튼은 흐려지고 "마나 2 더 필요"라고 적힌다. 탭하면 버튼이 1회 흔들리고 같은 안내가 한 번 더 보인다. 잠금 표시만 두지 않는다. 아이에게 이유를 알려주기 위해서다.
4. **확정**: 속성을 탭하면 마나 숫자가 150ms 동안 줄어든다. 선택한 슬롯에 카드가 나타난다(0.6배에서 1.0배, 200ms). 팝업은 100ms 동안 닫힌다. 카드는 Lv1로 시작한다.
5. **취소**: 팝업 바깥을 탭하거나 Esc를 누르면 닫힌다. 마나는 변하지 않는다.
6. **동시 조작**: 팝업이 열려 있어도 선택지와 궁극기를 누를 수 있다. 팝업이 문제 카드와 선택지를 가리지 않게 하기 위해서다.

### 3.2 채워진 슬롯 탭 → 강화·판매

- 슬롯을 탭하면 슬롯 바로 위(공간이 없으면 아래)에 작은 팝업이 뜬다. 카드명, 속성, 현재 레벨(●●○○ 4칸 표시)을 보여준다.
- 버튼은 세 개다.
  - **강화 Lv3 · 6마나**: 강화 비용은 브리프 고정값으로 Lv2 4, Lv3 6, Lv4 8이다. 마나가 부족하면 비활성화하고 사유를 적는다. Lv4에서는 "최고 레벨"로 바꾸고 버튼을 숨긴다.
  - **판매 · 환급 N**: 환급량은 변경 제안 2에서 정한다. 한 번 탭하면 "정말 팔까요?"로 바뀌고, 2초 안에 한 번 더 누르면 확정된다. 2초가 지나면 원래대로 돌아간다.
  - **닫기**: 바깥 탭, Esc와 같다.
- 팝업 하단에 고정 라벨 "이번 판에서만 강화돼요 (판 종료 시 초기화)"를 14px로 둔다. 브리프의 "판 안 강화는 판이 끝나면 초기화" 규칙을 알려주기 위해서다.

### 3.3 문제 선택지 탭 → 즉시 피드백 → 다음 문제

| 시점 (ms) | 화면에 보이는 것 | 입력 |
|---|---|---|
| 0 | 누른 선택지가 0.96배로 눌린다. 4개 선택지가 모두 잠긴다. | 잠김 (재탭 무시) |
| 0–100 | **정답**: 선택지가 숲녹으로 채워지고 ✓ 아이콘과 "정답!" 글자가 나온다. "+4" 숫자가 마나 쪽으로 떠오른다. **오답**: 선택지가 안개 보라로 채워지고 ✗ 아이콘과 "아쉬워요" 글자가 나온다. 정답 선택지에는 점선 테두리가 생긴다. | 잠김 |
| 100–400 | **정답**: 마나 숫자가 올라가고 콤보 게이지가 한 칸 찬다. 마커에 닿으면 400ms 빛 연출을 한다. **오답**: 선택지가 300ms 흔들린다(좌우 ±4px, 3회). 콤보는 0으로 리셋된다. "봉인 +1" 칩이 봉인 아이콘으로 날아간다. | 잠김 |
| 100–900 | 해설 한 줄(30자 이내)이 문제 카드 하단 띠에 0.8초 보인다. | 선택지 잠김. 소환·강화는 가능 |
| 900 | 문제 카드가 150ms 동안 교차 페이드되며 새 문제로 바뀐다. | — |
| 1000 | 새 문제의 선택지 입력이 가능해진다. | 입력 가능 |

- 정답 초록 플래시는 선택지 테두리가 200ms 동안 밝게 번쩍인 뒤 숲녹 채움으로 고정되는 방식이다.
- 해설 0.8초 동안은 선택지를 잠가 둔다. 해설을 읽기 전에 다음 답을 누르는 오입력을 막기 위해서다. 그 대신 소환·강화는 가능하게 둔다.

## 4. 콤보 게이지와 궁극기 버튼

### 4.1 콤보 게이지

게이지는 8칸이다. 칸 하나는 정답 한 번이다. 마커는 3, 5, 8에 있다.

| 콤보 | 효과 (브리프) | 표시 (모양 · 칩 글자) |
|---|---|---|
| 3 | 소환 비용 할인 | 아래 화살표 아이콘 · 칩 "할인" |
| 5 | 전체 공격력 버프 | 위 화살표 아이콘 · 칩 "공격↑" |
| 8 | 메이저 궁극기 사용권 1회 | 별 아이콘 · 칩 "궁극기!" |

- 표시 예: `콤보 [###.....] x5`. 채운 칸이 콤보 수, 마커 칸 위에 아이콘을 둔다.
- 효과 칩은 콤보가 임계값 아래로 떨어지면 200ms 페이드로 꺼진다.
- 오답이면 게이지가 오른쪽 칸부터 200ms 동안 비워진다. "끊김" 글자가 1회 뜬다. 색으로 벌을 주지 않는다.
- 궁극기 사용권은 콤보 8에서 한 번 얻는다. 콤보가 끊겨도 사용권은 남는다 (가정, 변경 제안 3).

### 4.2 궁극기 버튼 상태

버튼은 장착한 메이저 카드 1장을 보여준다. 장착은 판 전 스테이지 선택 화면에서 한다 (가정, 변경 제안 4). 메이저 3종은 광역 폭발형, 전체 둔화형, 탑 회복형이다. 명칭은 세계관 문서를 따른다.

| 상태 | 발생 조건 | 모양·색 | 글자 | 탭·Space 동작 |
|---|---|---|---|---|
| **잠김** | 해당 메이저 카드를 아직 해제하지 않음 (도감 기준) | 회색 점선 테두리, 자물쇠 아이콘, 채움 없음 | "잠김" / 작은 글씨 "도감에서 해제" | 1줄 안내 + [도감] 링크. 판 진행에는 영향 없음 |
| **충전중** | 장착 카드 보유, 사용권 0 | 잉크색 1.5px 테두리, 원형 진행 링이 콤보 n/8만큼 채워짐 | "충전 5/8" | "콤보 8이면 준비돼요" 1줄 안내. 효과 없음 |
| **사용가능** | 사용권 1 이상 | 황금 3px 테두리 (라이트 #8A5A00, 다크 #F2C14E), 1.2초 주기 펄스 (감소 모드는 정지), 우상단 사용권 수 뱃지 | "사용!" | 탭 또는 Space로 발동. 사용권 -1. 버튼은 "충전 0/8"로 바뀌고 다시 충전한다 |

- 준비 알림: 상태가 충전중에서 사용가능으로 바뀔 때 하단 바 위에 "궁극기 준비!" 글자를 1.5초 띄운다. 소리는 내지 않는다.
- 발동 연출: 맵 전체가 300ms 밝아지고 메이저 이름이 한 줄 뜬다.

## 6. 입력 방식

| 동작 | 모바일 터치 | PC 마우스 | 키보드 |
|---|---|---|---|
| 선택지 답하기 | 탭 | 클릭 | 1, 2, 3, 4 (숫자키 또는 숫자패드) |
| 빈 슬롯에 소환 | 슬롯 탭 → 속성 탭 | 슬롯 클릭 → 속성 클릭 | 슬롯 포커스 (Tab, 방향키) → Enter → Q(완드), W(컵), E(소드), R(펜타클) |
| 강화·판매 | 슬롯 탭 → 버튼 탭 | 슬롯 클릭 → 버튼 클릭 | 슬롯 포커스 → Enter → ↑↓ 이동 후 Enter |
| 궁극기 | 버튼 탭 | 버튼 클릭 | Space |
| 일시정지 | ⏸ 버튼 탭 | 클릭 | Esc |
| 팝업 닫기 | 바깥 탭 | 바깥 클릭 | Esc (팝업이 먼저 닫히고, 한 번 더 누르면 일시정지) |
| 설명 툴팁 | 길게 누르기 0.4초 | hover 300ms 후 | 포커스 즉시 |

- **오입력 방지 (모바일)**: 판정은 손을 뗄 때(pointerup)에 한다. 손가락이 버튼 밖으로 나가면 취소된다. 확대 제스처를 막기 위해 게임 영역에 `touch-action: manipulation`을 준다.
- **판매 2단계 확인**: 3.2절 규칙을 따른다. 모든 모드에 같이 적용한다.
- **hover 의존 금지**: hover는 PC 보조 표시일 뿐이며, 터치 사용자에게 필요한 정보는 hover에 두지 않는다.
- **포커스 표시**: 키보드 포커스는 3px 외곽선 (라이트는 잉크, 다크는 양피지)에 2px 간격을 준다.
- **단축키 충돌**: 1–4, Q W E R, Space, Enter, Esc, 방향키만 쓴다. 브라우저 단축키와 겹치지 않는다.

## 7. 10초 방치 자동 교체 경고

**타이머 규칙**

- 시작: 문제가 화면에 나타나는 순간.
- 리셋: 선택지 입력 때만. 소환, 강화, 궁극기 조작은 리셋하지 않는다 (변경 제안 5).
- 정지: 일시정지 중. 웨이브 사이 5초 휴식 중에도 계속 간다 (문제 풀이는 휴식 중에도 가능, 브리프).

**경고 타임라인**

| 경과 | 카드 표현 | 글자 | 햅틱 |
|---|---|---|---|
| 0.0s | 문제 표시. 카드 우상단에 "대기 0초" (14px 보조 글씨) | — | — |
| 0.0–6.9s | 평상시. 테두리는 정지 상태 (잉크 2px). 대기 초만 보인다 | — | — |
| 7.0s | 테두리 점멸 시작 (1Hz, 2px↔4px, 실선↔점선). 카드 상단 진행 띠가 3초 동안 줄어든다 | 황금 칩 "3초 뒤 바뀌어요" (시계 아이콘) | 없음 |
| 8.0s | 점멸 2Hz | 칩 "2초 뒤 바뀌어요" | 없음 |
| 9.0s | 점멸 3Hz, 진행 띠가 거의 0 | 칩 "1초 뒤 바뀌어요" | 지원 기기에서 1회 |
| 10.0s | 카드가 왼쪽으로 밀려 나가고(300ms) 새 문제가 들어온다 | 토스트 "문제가 바뀌었어요 · 회피 +1" (3초) | 없음 |

- 회피는 봉인 카드에 넣지 않는다. 결과 화면에 "회피 N"으로만 표시한다 (브리프의 "회피로 기록"). 변경 제안 6 참고.
- 감소 모드: 점멸 없이 테두리를 4px로 굵게 고정하고, 칩의 숫자만 바꾼다.
- 7초 전에는 아무 경고도 없다. 생각하는 시간을 빼앗지 않기 위해서다.
- 경고 색은 황금 하나만 쓰고, 글자와 아이콘을 항상 함께 쓴다.

### 8.2 폰트 성격

- **제목·메이저 이름**: Noto Serif KR (Bold, Black). 오래된 책과 "지식의 책" 느낌을 준다. 판타지 톤은 여기서만 낸다.
- **본문·선택지·HUD**: Noto Sans KR (Medium 500, Bold 700). 읽기 쉽고 정직한 산세리프. 한글 자간 +0.02em, 행간 1.5.
- **숫자 (HP, 마나, 비용)**: Noto Sans KR, 숫자 자리 고정(tabular-nums). 숫자가 바뀔 때 자리가 밀리지 않게 한다.
- **금지**: 필기체와 장식 서체 (난독이나 저학년에게 읽기 부담). 한 화면에 서체 2개를 넘기지 않는다 (세리프 제목 + 산세리프 본문).
- 두 서체 모두 Google Fonts로 받는다.

### 8.3 카드 프레임 스타일

- 비율 2:3(타로 비율), 모서리 반지름 10px. 둥근 모서리는 아이들에게 친근한 인상을 준다.
- 외곽은 이중 테두리다. 바깥 2px은 잉크, 안쪽 1px은 다크에서 황금, 라이트에서 황금 진한 색 (`#8A5A00`).
- 상단 중앙에 속성 엠블럼(모양 + 색, 28px)을 둔다. 하단에는 이름 띠를 양피지 색으로 둔다.
- 번호는 아라비아 숫자를 쓴다. 로마숫자는 쓰지 않는다. 학년에 따라 읽기가 달라지는 것을 피하기 위해서다.
- **메이저 카드**: 황금 프레임, 별 모티브, 두꺼운 외곽. 다크 테마에서만 약한 빛 번짐을 준다.
- **미보유 카드**: 실루엣, 물음표, 명도 40%. 카드 형태는 그대로 보여준다. 어떤 카드가 있는지 보고 모으고 싶게 만든다.

### 8.4 적의 실루엣 원칙

**원칙**

1. **색을 빼도 구별된다.** 모든 적을 검은 실루엣으로 만들었을 때 4종이 서로 구별되어야 한다.
2. **크기와 속도를 짝짓는다.** 작을수록 빠르고, 클수록 느리고 단단하다.
3. **사라짐은 흩어짐이다.** 적은 입자로 나뉘어 흩어지며 사라진다. 피, 상처, 고통 표정은 쓰지 않는다.
4. **앞이 열린 형태.** 적의 머리 쪽(진행 방향)은 열려 있고 뒤는 흐려진다. 이동 방향을 한눈에 읽게 한다.

| 적 | 실루엣 | 크기 | 속도 |
|---|---|---|---|
| 안개 조각 | 둥글고 흐물흐물한 구름 덩어리, 꼬리 없음 | 1.0배 | 보통 |
| 속삭임 | 얇고 긴 물결 꼬리 2줄, 뾰족한 머리 | 0.8배 | 빠름 |
| 침묵 덩어리 | 모서리가 각진 사각 덩어리, 넓은 바닥 | 1.2배 | 느림 |
| 망각의 왕 (보스) | 머리 위에 부서진 왕관 실루엣. 웨이브 마지막 | 2.5배 | 느림 |

- 정예는 기본 실루엣을 1.3배로 키우고 외곽을 이중선으로 그린다. 정예는 탑 피해가 -2다 (브리프).
- 적의 색은 안개 보라 한 계열로 통일한다. 라이트에서는 진하게, 다크에서는 밝게 쓴다.

### 8.5 맵 바닥과 슬롯

- 맵 바닥은 라이트에서 양피지, 다크에서 잉크 암색이다. 길은 한 톤 밝은 띠에 점선 가장자리를 준다.
- 안개가 나오는 입구 쪽은 빗금 패턴으로 흐리게 처리한다. 탑은 맵 오른쪽 아래에 실루엣으로 둔다.
- 빈 슬롯은 점선 원, 소환된 슬롯은 실선 원에 속성 색을 채운다. 강화 레벨은 슬롯 아래 pip 4칸으로 표시한다.

## 변경 제안

1. **제안 1 · 해설 시간 분리 (정답 0.8초, 오답 1.5초)**
   - 무엇을: 1줄 해설을 정답 0.8초, 오답 1.5초로 나누고, 해설 띠를 탭하면 고정되게 한다.
   - 왜: 0.8초는 초등 고학년에게도 짧다. 오답 해설이 복습 루프(봉인 → 해제 퀴즈)의 출발점인데 놓치면 복습 효과가 떨어진다.
   - 영향 범위: 3.3절 타임라인, 전투 템포(오답마다 +0.7초), 접근성 읽기 시간.

2. **제안 2 · 판매 환급률 확정**
   - 무엇을: 판매 시 환급량을 투입 마나의 50%로 정한다 (예시. 밸런싱 문서에서 확정).
   - 왜: 브리프에 판매 규칙이 없어서 판매 팝업의 환급 표시와 확인 문구를 확정할 수 없다.
   - 영향 범위: 3.2절 강화·판매 팝업, 밸런싱 문서.

3. **제안 3 · 궁극기 사용권 유지 여부 확정**
   - 무엇을: 콤보 8로 얻은 사용권이 콤보 리셋 뒤에도 남는다고 확정한다 (현재 명세의 가정).
   - 왜: 유지 여부에 따라 "사용가능" 상태 표현과 콤보 끊김 연출이 달라진다. 유지하면 긴 콤보를 쌓을 이유가 줄어든다.
   - 영향 범위: 4.1·4.2절 상태 규칙, 밸런싱 문서 (궁극기 가치).

4. **제안 4 · 메이저 카드 판 전 장착 1장**
   - 무엇을: 판 시작 전 스테이지 선택 화면에서 메이저 카드 1장을 장착하게 한다.
   - 왜: 궁극기 버튼 하나로 메이저 3종을 다루려면 장착 단위가 필요하다. 3종을 모두 동시에 두면 하단 바에 버튼이 3개 들어가 엄지 영역을 침범한다.
   - 영향 범위: 스테이지 선택 화면, 도감의 장착 표시, 하단 바 레이아웃.

5. **제안 5 · 방치 타이머는 문제 입력에서만 리셋**
   - 무엇을: 소환, 강화, 궁극기 조작은 방치 타이머를 리셋하지 않는다고 확정한다 (현재 명세).
   - 왜: 리셋하면 문제를 풀지 않고 소환만 반복해 버티는 전략이 가능해져, 브리프의 "문제를 안 풀고 버티는 전략은 불가능해야 한다" 원칙을 깨뜨린다.
   - 영향 범위: 7절 타이머 규칙, 자동 교체 연출, 튜토리얼 코치마크 문구.

6. **제안 6 · 회피는 봉인이 아닌 결과 기록으로만 표시**
   - 무엇을: 방치로 교체된 문제(회피)는 봉인 카드에 넣지 않고, 결과 화면과 봉인 기록 탭에 "회피 N"으로만 보여준다.
   - 왜: 브리프는 회피를 "기록"으로만 정했다. 회피도 봉인에 넣으면 복습 큐가 방치 횟수만큼 불어난다.
   - 영향 범위: 7절 토스트 문구, R 결과 화면, C 도감 봉인 기록 탭.

7. **제안 7 · 범위 분리: 모바일 가로와 짧은 입력형은 2차 명세로**
   - 무엇을: 모바일 가로(740×360)와 짧은 입력형 문제 UI를 이번 명세에서 빼고 2차 명세(별도 문서)로 분리한다.
   - 왜: 브리프는 둘 다 포함하지만, 이번 명세는 세로 360×740과 4지선다 검토에 집중해야 판단이 빨라진다.
   - 영향 범위: 2차 명세 작업량, 2절 레이아웃의 재사용 여부 확인.
