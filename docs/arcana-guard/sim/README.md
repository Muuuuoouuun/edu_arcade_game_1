# 메카닉 역산 시뮬레이터 (01_core_mechanics.md 근거 스크립트)

- `final.py`: 0.1초 틱 전투 시뮬레이터. 기본값은 **이전 설정**(회복 1/5초 등)이다.
- `coord.py`: `final.py`의 설정을 확정값(회복 1/10초, 잠금 2~5초, Lv4, HP 배수 ×1/1.6/2.4/3.4/5.0)으로 덮어써 실행하는 방식의 예.
- `coord2.py`: 확정값 기준 재현 스크립트. **문서 수치를 재현하려면 이 파일을 실행한다.**

```bash
python3 -I docs/arcana-guard/sim/coord2.py
```

프로토타입의 JS 봇 시뮬(`prototype/tests/bal_sim.js`)과는 모델이 달라 절대값이 다를 수 있다. 두 시뮬은 "무풀이·찍기 클리어 불가" 같은 불변식 확인에 함께 쓴다.
