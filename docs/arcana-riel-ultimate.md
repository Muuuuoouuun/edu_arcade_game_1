# 리엘의 별빛 화살비 동작

통합 브랜치의 기존 리엘 모델과 보행·일반 사격을 이어, 필살기에서 활을 들어 올려 발사한 뒤 대기 자세로 회수한다. 초록 후드·금발·곡선 활을 유지하고, 활·시위·장전 화살·활을 쥔 손을 실제 관절에 묶었다. 두 발은 고정되고 다른 손과 망토가 회수를 따른다. 화살비의 피해는 기존처럼 누르는 즉시 발생하며, 모델의 회수 동작은 피해를 추가하거나 지연하지 않는다.

## 재생성

```sh
npm run models:riel-ultimate
npm run models:riel-ultimate:check
```

편집 원본 `art-source/defense/riel-ultimate.blend`, 실제 0.5초 관절 동작 `public/defense/models/riel-ultimate.glb`, 공통 카메라 384px PNG 24장, 8방향×3포즈 192px WebP와 `riel-ultimate.json` 해시·카메라 정보가 한 세트다. 전투는 기존 2.5D 베이크를 사용하고 작업실에서는 GLB를 재생한다. 8개 아틀라스는 약 91KB, 디코딩 RGBA 합계는 약 3.375MiB다. 어느 방향 하나라도 로드하지 못하면 기존 리엘 사격 자세를 사용한다.

101개 GLB 보간 시점에서 손·팔 연결, 양쪽 시위 결합과 손의 활 접촉, 두 발 높이, 발사 후 화살 숨김과 재장전, 기존 대기 자세로 복귀를 검사한다. 공통 카메라의 8방향×51시점에서 화면 경계도 확인한다. 모바일은 브라우저 에뮬레이션이며 실제 Android 기기의 프레임 시간과 메모리는 측정하지 않았다. 이동 중 필살기는 기존처럼 이동을 허용하므로 발이 화면 지면을 미끄러질 수 있고, 동작은 활을 들어 올리는 발사·회수이지 탄도 시뮬레이션은 아니다.
