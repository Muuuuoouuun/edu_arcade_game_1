# 루나의 마지막 걸음에서 발 디디며 멈추기

2026-11-08 · 컨셉 개발 52회차. 기준 `4d609a86dbfa80659f4dd5ec1691c98131da76d3`, 브랜치 `codex/arcana-stage-experience-20261106`.

## 컨셉과 선택

`art-source/defense/atlases/ranged-motion.png`의 벌린 발, 몸보다 늦게 흐르는 망토·머리카락, 흰 소매와 가지 지팡이를 실제 PC·모바일 전장과 비교했다. 서리늑대의 보폭·피격·접지, 루나의 시전 진입·이동 복귀·제자리 회수는 이미 구현되어 있다. 남은 차이 중 **루나가 멈추는 순간 마지막 걸음에서 바로 대기로 튀는 현상**을 선택했다. 기존 체형·재질을 유지하고 실제 관절의 정지 동작을 제작했다.

시작 작업트리는 깨끗했고 다른 활성 편집은 없었다. 원격 main `2eabc76`, Claude nice `bf7c1c6`, wizard `0ac6ac5`와 최근 기록을 확인하고 fetch했다. 이전에 읽은 Claude 57회차 약점 명중 소리 제안과 열린 PR81의 번개 표적 로직은 별도 범위다. 서리늑대 기본 보행·접지, 주요 포탑 조준·반동, 지형·성문·브론·통나무 병사의 완료 계보를 보존한다. 세계관 제작 명세의 “이동 종료는 마지막 발을 짚되 목표 위치를 지나치지 않는다”를 적용했다.

## 실제 동작과 전투 연결

- `luna-stop-0`~`luna-stop-7`: 기존 여덟 걸음 각각에서 시작해 원래 대기로 끝나는 **0.24초·100fps·17노드** 실제 GLB 클립이다.
- 출발 발의 높이·전후 위치에 따라 먼저 옮길 발을 고른다. 첫 0.12초는 반대 발, 다음 0.12초는 먼저 내려놓은 발을 고정한다. 발은 낮은 호로 움직이고 몸은 지지 발 쪽으로 체중을 받는다.
- 몸과 머리는 0.16초에 정리하고 망토·머리카락·귀·옷자락·가지 지팡이는 0.035초 늦게 회수를 시작한다. 망토와 지팡이 끝의 작은 회전을 더해 몸이 멈춘 뒤에도 잔동작이 남는다.
- 양팔은 공통 어깨·팔꿈치·손 끝점으로 소매 연결을 유지한다. 모든 클립의 시작·끝은 기존 보행·대기 원본과 일치한다.
- 영웅·용병의 정지를 시뮬레이션 시간 기반 `settle`에 연결했다. 준비 화면의 정지 완료는 전투 시간을 진행하지 않는다. 실제 위치를 밀거나 목표점을 지나치게 만들지 않는다.
- 0~0.08초는 저장한 마지막 보행 자세, 0.08~0.16초는 0.08초 베이크, 0.16~0.24초는 0.20초 베이크, 이후 기존 대기를 표시한다. 연속 관절 보간은 작업실에서 제공하며 전투는 세 단계 베이크다.
- 재이동·돌진·공격·필살기를 우선한다. 동작 줄이기나 정지 세트 실패에는 기존 대기를 사용한다. 정지 세트의 실패가 기존 공격·보행·시전 복귀를 막지 않는다.

발 고정은 모델 평면 기준이며 지형 IK가 아니다. 기존 0.15초 발사·0.33초 공격 길이·피해·보상·위치·속도 규칙을 유지한다. 전투는 베이크 2.5D, 작업실은 단일 실시간 3D 장면이다.

## 산출물·재생성

```bash
npm run models:luna-stop
npm run models:luna-stop:pose-check
npm run models:luna-stop:check
```

## 검증과 한계

외부 증거 `/tmp/arcana-hourly-20261108-2037/`에 시작 기준·소유 브랜치·범위·수용 기준·미완료 상태와 각 검증 로그·화면을 남겼다.

- 전체 332개 중 331개 통과. 기존 수학 게임 `(3×7)/5`의 4/4.2 실패는 기준 커밋에서도 재현했다. 새 회귀는 없다. 타입 검사와 프로덕션 빌드 통과.
- GLB 저작 200시점·보간 776시점에서 원본 시작 오차 최대 `1.77e-7`, 끝 오차 `1.52e-7`, 지지 발 변환 오차 `6.95e-9`, 발바닥 높이 약 `0.005`, 양팔 연결 오차 `3.58e-6`을 확인했다.
- `.blend` 재열기에서 153메시×8개 시작/끝의 최대 월드 변환 오차 `3.07e-18`로 원본과 연결됨을 확인했다.
- 스테이지 1·4·5·8×영웅/용병 8게임·14,400스텝에서 시각용 `settle`만 제외한 모든 상태가 기준 엔진과 일치했다. 공격·피해·체력·보상·이동·배속·일시정지·돌진·필살기·강화를 포함했다.
- 실제 PC 1440×900·390×844 터치 UI로 이동·도착·1배속/2배속 정지·일시정지·동작 줄이기·복원·재개·재이동·웨이브·자연 시전을 조작했다. 여덟 보행 프레임과 정지 세 단계, 공격 우선순위를 확인했고 페이지 오류·가로 넘침은 없었다.

- 최종 재생성 후 원본·생성기·컨셉을 포함한 143개 해시가 일치한다. 몸은 0.16초에 대기와 일치하지만 망토·가지 지팡이 끝은 모든 클립에 잔동작이 남아 있다.
- PNG 128장·WebP 128셀에서 최소 투명 여백 14px을 확인했고 빌드 파일 11개가 원본과 동일하다. GLB는 1,762,916바이트다. 편집 원본은 17개 관절별 액션을 보존하며 작업실에서 여덟 출발 걸음을 선택한다.
- 작업실 PC 8클립, 390/320px 각각 3클립에서 실제 캔버스 변화·끝 자세·메시 보기·회전·시점 초기화·동작 줄이기·단일 캔버스를 확인했다. GLB 실패 시 PNG를 렌더 이미지로 표시하고 재생을 끈다. 기존 이안 정지 항목도 통과했다.
- 컨셉 원본·공통 카메라·동일 조건 PC/모바일 전후 화면·실제 모바일 전투·모바일 작업실을 직접 확인했다. 모바일은 Chromium 터치 에뮬레이션이다.

- 실제 `DefenseBoard`의 영웅/용병×8방향×8출발 걸음과 여러 시점을 PC·390/320px·동작 줄이기·정지/기본 시전/보행/이동 복귀 이미지 실패로 검사한 2,816조합이 최종 통과했다. 공격·필살기·돌진·재이동 우선순위와 오류·가로 넘침·전투 GLB 요청 없음을 확인했다.

공격/방향 전환/재이동 중간 자세의 연속 연결, 월드 좌표 발 고정·지형 IK, 실제 Android 메모리·프레임 측정은 남아 있다. 다음 후보는 카르의 보행→강타 준비 연결이다. 루나의 기존 시전 진입·이동 복귀·제자리 회수를 다시 만들지 않는다. 예약 설정 조회·변경 및 Claude API 호출은 하지 않았다.
