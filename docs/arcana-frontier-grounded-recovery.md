## 컨셉 대비 문제와 선택

`art-source/defense/atlases/melee-motion.png`의 카르와 실제 PC/모바일 변경 전장을 확인했다. 컨셉은 큰 양손 망치·넓은 지지 자세·몸 뒤를 따르는 모피가 무게를 만든다. 이전 전장은 정지에도 보행 첫 자세를 사용하고, 강타 후 그 자세로 바로 전환했다. 실제 동일 장면 검사에서 회수 종료→정지에 양발이 각각 0.18005 월드 단위씩 앞뒤로 튀었다.

완료된 늑대 체형/보행, 영웅 타격 방향/접촉, 발리스타 조준/반동, 지형/카메라/파편을 다시 만들지 않고 **카르의 정지·제자리 준비·접지 회수 연결**을 선택했다. 기획/게임성은 타격·회피 규칙 보존, 디자인/모델링은 기존 원본의 체중 이동 전달, 구조는 준비 출발 상태와 클립 선택, 모바일은 발/무기 자세·정지·배속·동작 줄이기를 점검한다.

원격 main `2cd0b9c`의 개별 영웅 준비만 취소되는 회귀 테스트 `c07dff5`를 `6d2f590`으로 통합했다. Claude `6c27660`/`bf7c1c6`과 기존 개발 계보를 보존했다.

## 구현

- 대기에는 원본 `kar-slam`의 0초 자세를 사용한다. 두 발을 내딛던 보행 첫 프레임을 대기 자세로 사용하지 않는다.
- 엔진은 공격 시작 당시 이동 여부를 `fromMoving`에 기록한다. 제자리 시작은 원본 강타 준비를, 이동 중 시작은 기존 8개 보행 진입을 사용한다. 피해·공격 가능 시점·사거리·이동 규칙은 바꾸지 않는다.
- 기존 `kar-reset-0`을 전장용 GLB에 추가하고, 모든 진입이 공유하는 반동 끝 0.43초부터 0.56초까지 재생한다. 원본 0.14초 회수를 0.13초 구간에 맞춰 기존 공격 종료 시점을 유지한다. 원본 시작이 강타 0.43초와 일치함을 관절 행렬로 검증했다.
- 몸이 먼저 일어서고 망치·털망토·수염이 뒤따르는 회수 동안 두 발은 고정된다. 회수 마지막 자세와 정지 자세의 관절 변환은 일치한다. 기존 0.28초 단일 타격·파편 시점은 보존한다.
- 일시정지와 배속은 기존 시뮬레이션 시간을 따른다. 동작 줄이기는 준비/접촉 자세를 유지하고 회수 중 추가 움직임을 생략한다.
- 회수 클립은 선택적이다. 구형 전장 GLB 또는 회수 로드 실패에서도 기존 강타로 계속한다. 전장 GLB 자체가 실패하면 원본 모델·회수 클립을 사용하고, 더 많은 실패에서는 기존 보행/기본 모형으로 복귀한다.
- 작업실에 `카르 · 변경 전장 회수` 항목을 추가했다. 같은 전장 GLB의 회수를 실시간 3D로 재생하며 기존 강타 항목을 유지한다.
