고정된 팔각 석조 받침·버팀돌·녹색 목재 기둥 위에 네 황동 잎 덮개와 신호 수정을 모델링했다. 지휘 모드의 기존 점령 진행에 맞춰 덮개가52도 벌어지고 수정이0.4월드 단위 올라온다. 기초는 움직이거나 커지지 않는다. 완료 시 수정과 지면 고리가 초록색으로 바뀐다.32구간 고리는 실제 반경4 안쪽에 놓이며 점령량을 표시한다. 새로운 영역 확장이나 기존2.5D 캠페인의 전환으로 집계하지 않는다.

- 점령 반경4·소요3초·보상120금화는 공유 상수로 추출하고 기존 판정을 유지한다. 밖으로 나가면 진행을 유지하고, 멈춤·배속은 시뮬레이션을 따른다. 중복 보상을 지급하지 않는다.
- 동작 줄이기는 완료 전 닫힌 자세, 완료 시 열린 자세로 표시한다. 지면 진행 고리는 계속 읽을 수 있으며 맥동·깜박임을 추가하지 않는다.
- ‘동쪽 봉화로 집결’은 기둥 중심 대신 서쪽3단위의 점령 범위 안에 도착한다. 일반 지형 클릭의 경로 찾기·건물 충돌 전체를 바꾼 것은 아니다. 수동 중심 클릭에 대한 건물 충돌은 후속이다.
- GLB를 못 불러오거나 필수 관절/클립이 없으면 기본 입체 봉화와 같은 진행 고리를 사용한다. 전투·점령을 막지 않는다. 모델 교체 시 이전 기본 모형 자원을 해제하고 장면 종료 시 모델·고리·믹서를 정리한다.
- 단일 Three.js 장면을 사용한다. 기초만 정적 그림자를 만들며 움직이는 덮개는 깊이 가림을 사용한다. 덮개의 실시간 그림자 갱신은 추가하지 않았다.
