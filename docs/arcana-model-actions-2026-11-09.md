# 모델 동작 제작 기록 — 2026-11-09

컨셉 이미지와 사용자가 공유한 모바일 게임 스크린샷의 큰 무기·단순한 색 덩어리를 기준으로 제작했다. 별도의 참고 영상은 제공되지 않았으며, 이번 시연 영상은 실제 모델 작업실을 녹화한 것이다.

## 실제 변경

- Astra: 북극곰의 손목 회전으로 타격 시 닻 망치가 몸통 밖으로 드러나도록 수정. 준비·타격 유지·복귀를 보강하고 64샘플로 네 포즈 재렌더. 기존 지오메트리와 카메라 유지.
- Astra: 잎 두건, 황금 눈, 긴 꼬리와 두 손 씨앗 쇠뇌를 가진 도마뱀 궁수 제작. 편집 가능한 Blender 원본, 실제 GLB, 1초 발사 반동 클립, 투명 네 포즈 렌더 제공.
- 작업실: 기존 네 모델과 함께 두 제작 시안을 선택·회전·공격 재생·메시 보기. 공격 포즈 슬라이더는 시간을 진행하지 않고 단일 자세를 평가하므로 동작 줄이기 설정에서도 사용 가능. 자동 회전과 공격 재생은 해당 설정에서 비활성화.
- 모바일: 모델 목록을 가로 스크롤로 줄이고 선택 모델을 노출. 제어 버튼 최소 높이 44 CSS px. GLB 로딩 실패 시 같은 영역에 PNG 표시.

| 모델 | 삼각형 | GLB 메시 | 재질 | GLB 바이트 | 클립 |
| --- | ---: | ---: | ---: | ---: | --- |
| 북극곰 | 9,176 | 31 | 9 | 426,268 | polar-bear-attack / 0.8초 |
| 도마뱀 궁수 | 7,804 | 24 | 9 | 261,840 | gecko-seed-shot / 1초 |

새 모델은 제작 작업실 시안이다. 캠페인 영웅, 충돌체, 걷기 동작, 투사체 또는 APK 반영이 완료된 것으로 표시하지 않는다. 도마뱀 쇠뇌의 씨앗은 장전된 시각 소품이며 발사체 시뮬레이션은 없다. 북극곰의 48px 무기 분리는 개선됐지만 세부 닻 모양·손가락 가독성에는 한계가 있다. 브라우저 소프트웨어 WebGL 검증은 실제 Android 기기 성능 측정이 아니다.

## 재현과 역할

- `/model-lab.html?model=polar-bear`, `/model-lab.html?model=gecko-ranger`
- `npm run models:bear`, `npm run models:gecko`: Blender 재생성 후 두 모델의 런타임 미리보기 동기화.
- `npm run models:prototypes`: 저장된 GLB와 idle PNG만 public에 복사. 편집 .blend는 앱 번들에 포함하지 않는다.
- 두 원본 디렉터리의 README와 `validate_reimport.py`에서 새 Blender 세션으로 재불러오기 검증을 재현한다.
- Fable 5.1 공식 API로 구체적인 가독성·동작·모바일 기준 검토. 44px 버튼과 수동 포즈 검토를 반영했다. 전투 팀 색 교체와 실제 전투 통합은 다음 단계다.
- Astra 작업자 두 명이 각각 북극곰 동작과 도마뱀 모델을 제작했다. Opus 5.5 공식 API는 통합 소스·검증 기록·실제 브라우저 렌더를 최종 검토한다. API 키와 이미지 요청 본문은 저장소에 저장하지 않는다.

브라우저 검증 범위는 데스크톱 1440×1100 및 모바일 390×844의 여섯 모델 로딩·공격 복귀, 새 두 모델 포즈·회전·메시 전환, 동작 줄이기, 가로 넘침, PNG 실패 대응이다. 검증 로그·API 영수증·시연 영상은 작업 환경의 별도 evidence/artifacts 디렉터리에 보존한다.
