# Arcana 기본 규칙 검토 (규칙 문서 전용, 런타임 변경은 모두 보류)

**근거 범위:** 아래 판단은 제공된 6개 결정론적 진행 정책(48개 스테이지 실행) 결과에 기반합니다. 이 결과는 즉시 선택과 이상적 이동을 가정하므로 사람의 승률이 아닙니다. 확인된 사실과 가설은 구분해 표시했습니다.

## 가장 큰 설계 위험 3가지

**1. [High / 전체 난이도] 긴장감이 없고 베테랑 난이도가 의미 없음**
- **확인:** 48개 실행 모두 승리했습니다. 본진 HP는 47회가 20/20이었고, 예외는 베테랑 자동 8스테이지(HP15) 1회뿐입니다. 전초기지는 48회 모두 12/12였습니다.
- **확인:** 베테랑 자동(배치만, 대시 0·스킬 0)도 1~7스테이지를 무피해로 클리어했습니다. "베테랑 완벽 클리어는 더 어려워야 한다"는 목표와 충돌합니다.
- **가설:** 사람은 배치가 서툴러 실제로는 더 어려울 수 있습니다. 하지만 상한선 자체가 너무 낮습니다.

**2. [High / 핵심 루프] 능동 입력의 보상이 시간 단축뿐임**
- **확인:** 자동과 능동을 비교하면 골드와 퀘스트 보상이 완전히 같습니다. HP도 이미 최대치라 차이가 날 수 없습니다.
- **확인:** 차이는 클리어 시간 약 5~23% 단축뿐입니다(예: 표준 1스테이지 88초 → 68초).
- 영웅이 무적이라 실패 압박도 없습니다. 그래서 "능동 입력 → 체력/시간/보너스 개선"이라는 목표 중 체력과 보너스 축이 작동하지 않습니다.

**3. [Med-High / 경제] 중반 이후 골드 사용처가 없고 추가 퀘스트가 사실상 자동 지급**
- **확인:** 훈련 상한 도달 시점은 표준 6스테이지, 베테랑 5스테이지입니다(nextTraining 5 기준). 이후 잔여 골드가 1580(표준), 2476(베테랑)까지 쌓입니다.
- **확인:** 전초기지가 한 번도 손실되지 않아 80G 구출 보상이 매번 그냥 들어옵니다. 선택의 의미가 없습니다.
- **보류:** 실패 보상(최소 40G)은 현재 데이터로 판단할 수 없습니다. 측정 후 결정하자는 방침에 동의합니다.

**참고 [Med / 규칙 정합성]:** 보스 이탈 피해 8HP와 "보스 이탈 = 패배" 규칙이 공존하고 있습니다. 4/8스테이지에서 HP 20→12, 처치 0으로 승리한 반례가 확인됐습니다. 문서에는 "보스 이탈 즉시 패배, 이탈 피해 수치는 폐기"로 단일화해 적어야 합니다.

## 후보 결정에 대한 입장

**동의**
- 무적 영웅과 "회피가 아닌 재배치" UI 표기
- 메뉴 일시정지, 수동 웨이브 시작
- 본진 HP20 필수, 전초기지는 선택 사항
- 보스 처치 + 본진 HP>0을 승리 조건으로
- 가격 유지, 반복 플레이·에너지·가챠 없음, 코스메틱은 스탯 중립
- 팁은 옵트인으로 짧게, 퀴즈 없음
- 난이도별 최고 보상 차액 지급안. 단, 세이브 계약 테스트 전에는 출시하지 않는다는 조건에 동의합니다.

**조건부 동의**
- **2~4분 목표:** 현재 1~3, 5스테이지가 120초 미만입니다(최저 68초). 목표가 하드 타이머가 아니라면 "초반 스테이지는 1.5분 허용"을 명시하거나, 초반 웨이브 구성을 재검토해야 합니다.
- **베테랑 보상 1.4배:** 난이도 차이가 거의 없는데 보상만 많으면, 베테랑이 그냥 "더 이득인 기본값"이 됩니다.

**반대 / 재검토 필요**
- **"배치만으로 승리 가능"을 베테랑에도 그대로 적용하는 것:** 자동으로 무피해 클리어가 되는 현재 상태를 기준선으로 고정하면 안 됩니다.
- **화상 DOT 고정 4/s를 필수 정책 없이 방치하는 것:** 훈련 스케일링과 분리돼 있습니다. 문서에 "의도된 고정값인지" 명시가 필요합니다.

## 최소 측정 가능 수용 기준 (문서 확정용, 미실행)

1. **보스 규칙:** 보스가 이탈하면 남은 HP와 무관하게 패배합니다. 4/8스테이지 반례는 "패배"로 판정되어야 합니다.
2. **난이도 분리:** 동일 정책에서 베테랑 자동의 평균 잔여 HP 또는 전초기지 생존율이 표준보다 확실히 낮아야 합니다. 구체적 임계치는 설계자가 결정합니다. 동시에 표준 자동 클리어는 유지되어야 합니다.
3. **능동 입력 가치:** 능동 정책이 자동 대비 시간 외에 HP·전초기지·보너스 중 최소 1개 지표에서 차이를 보여야 합니다.
4. **경제:** 5스테이지 이후 잔여 골드의 사용처(또는 의도적 미사용 선언)를 문서에 명시합니다. 실패 보상 G/분은 클리어 보상 G/분보다 낮아야 하며, 이는 측정 후 판정합니다.
5. **사람 데이터 분리:** 위 기준은 모두 결정론적 정책 지표입니다. 사람 승률 목표는 별도 플레이테스트 지표로 분리해 기록합니다.
