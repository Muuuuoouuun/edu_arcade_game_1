# Fable 5.2 max 모델링 분할 호출

2026-11-10. `claude-fable-5-2`, adaptive thinking, effort `max`로 카르·발리스타·나무 병사의 제작 과제를 세 호출로 나눴다. 각 호출은 출력 한도 10,000토큰이며, 기존 캠페인의 `elapsed`·`duration`·`hitAt`·`fired`와 기존 투사체·피해 계산을 기준으로 삼도록 요청했다. 카르 요청만 Frontier 방어 화면을 첨부했으며 본체가 잘 보이지 않는다는 점을 명시했다.

| 과제 | 입력 토큰 | 출력 토큰 | 종료 사유 | 반환 본문 |
| --- | ---: | ---: | --- | --- |
| 카르 | 2,097 | 10,000 | max_tokens | 없음 |
| 발리스타 | 305 | 10,000 | max_tokens | 없음 |
| 나무 병사 | 309 | 10,000 | max_tokens | 없음 |

앞선 Fable 5.2 `max`의 16,000·32,000토큰 호출도 본문 없이 끝났다([기록](../arcana-fable-52-20261110/README.md)). 모델·effort를 임의로 낮추거나, 비어 있는 결과를 모델이 제시한 설계로 표기하지 않는다. 이전 3D 원본 보존 결과는 [모델 인계](../../art-source/defense/model-bridge-20261110/README.md)에 있다.
