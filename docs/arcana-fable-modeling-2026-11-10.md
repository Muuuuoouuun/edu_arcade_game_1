# Fable 모델링 검토 시도와 자산 인계

2026-11-10. 공식 Anthropic 모델 조회에서 `claude-fable-5-1`이 adaptive thinking과 `xhigh` effort를 지원함을 확인했다. Frontier 방어 화면 한 장과 기존 프로젝트·3D·에셋 문서의 일부를 전송해 카르·발리스타·나무 병사의 모델링 및 캠페인 연결을 검토하도록 요청했다.

- 첫 호출: `xhigh`, 최대 출력 6,000 토큰. 모델 `claude-fable-5-1`, 입력 12,675 / 출력 6,000 토큰, `stop_reason=max_tokens`. 출력 전부가 추론에 사용되어 **답변 본문 없음**.
- 두 번째 호출: `xhigh`, 최대 출력 16,000 토큰. 240초 수신 타임아웃. 최종 응답과 사용량·과금 여부를 확인하지 못했다. **Fable 검토 결과가 나온 것으로 간주하지 않는다.**
- 위 결과는 제작 기획을 위해 이미지와 문서를 외부 API로 전송한 실제 호출이다. API 키는 저장하지 않았다. 두 번째 요청의 과금·처리 상태는 이 기록으로 확인할 수 없다.

별도로 기존 Frontier 브랜치 `bec8041`의 모델과 Blender 원본 8개를 [제작 인계 폴더](../art-source/defense/model-bridge-20261110/README.md)에 모으고 SHA-256 및 GLB 클립을 확인했다. 이는 기존 자산의 사본이지 새 모델이나 기존 캠페인의 실시간 3D 적용이 아니다. 엔진 상태·명중 시점, 피벗·방향·접지와 모바일 성능을 검증하는 작업이 남았다.
