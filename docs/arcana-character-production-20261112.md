# 공통 캐릭터 제작본 01 — 이미지·모델·움직임 적용

도마뱀 궁수, 브론, 눈곰 포포의 **기존 Blender 모델을 기반으로** 표면 질감과 다리 관절을 추가하고 마을 수비(Rush)에 연결했다. 컨셉 이미지와 기존 원본은 수정하지 않았다. 새 고해상도 조각 모델이나 모든 캐릭터의 재제작 완료를 뜻하지 않는다.

## 확인 경로

- `/defense/models/characters-v2/sheets.html`: 정면·측면·후면·입체 렌더, 대표 색상, 재질·동작 설명, GLB 다운로드.
- `/model-lab.html?model=ranger-v2`: 도마뱀 궁수의 회전·호흡·보행·공격 및 공격 포즈 스크러빙.
- `/model-lab.html?model=bron-v2`, `/model-lab.html?model=bear-v2`: 같은 검토 기능.
- `/rush.html`: 기존 영웅 해금 규칙에 따라 실제 전투에 적용. 플레이어 세이브나 해금 규칙은 변경하지 않았다.

## 모델과 질감

| 캐릭터 | 원본 삼각형 수 | 적용한 표면/구조 | 전투 공격 |
|---|---:|---|---|
| 도마뱀 궁수 | 7,948 | 비늘, 잎맥, 가죽 봉제선, 나뭇결, 입체 잎맥과 어깨끈 | 씨앗 쇠뇌 |
| 브론 | 23,190 | 금속 명암, 수염 결, 가죽, 천의 짜임 | 망치 강타 |
| 눈곰 포포 | 9,176 | 털의 결, 갑옷, 얼음 무늬 | 눈덩이 투척 |

캐릭터당 1024×1024 색상·노멀·ORM 맵을 단일 재질에 모았다. 컨셉의 재료 구분을 참고한 절차적 텍스처이며, 그림을 자동으로 입체 복원하거나 그대로 투영한 결과는 아니다. 시트는 실제 전달 모델을 Blender에서 렌더한 이미지다.

Rush와 새 작업실 항목은 공통 툰 셰이더에 색상·노멀 맵을 사용한다. ORM의 거칠기·금속도는 GLB와 Blender에 보존되며 현재 툰 셰이더에서는 사용하지 않는다. 시트의 PBR 조명과 게임의 툰 조명은 달라 보일 수 있다.

Rush의 기존 메시 결합 과정에서 UV를 삭제하던 부분을 수정했다. 모든 애니메이션 클립의 관절을 보존해 다리가 몸에 합쳐지지 않도록 했다. 원본 잎 프리즘의 뒤집힌 면 방향도 새 제작본에서 교정해 외곽선이 검은 면으로 보이는 문제를 해결했다.

## 움직임

각 GLB에는 이름이 명시된 호흡·보행·공격 3개 클립이 있다. 기존 공격을 보존하고 독립된 양쪽 다리 관절과 호흡/보행을 추가했다.

- 이동 거리로 보행 주기를 계산하며 정지 후 약 0.1초에 기본 발 자세로 복귀한다.
- 보행은 하체 트랙만 사용하고 공격은 상체 트랙을 사용한다. 공격 중 호흡의 상체 가중치는 0으로 내려 반동이 희석되지 않는다.
- 일시정지와 히트스톱은 현재 포즈를 유지한다. 모션 감소 설정에서는 추가 호흡·보행을 끈다.
- 포포의 원본 망치는 전투에서 숨기고 기존 눈덩이 장착·투척·재장전 규칙을 유지한다. 작업실에는 원본 장비가 보인다.
- 관절별 강체 애니메이션이다. 피부 변형 스키닝, 손가락/얼굴 리깅, 지형에 맞춘 발 IK는 아직 없다.

## 재생성 및 검증

```sh
npm run models:characters
node --experimental-strip-types --test src/rush/heroAssets.test.ts src/rush/heroMotion.test.ts
npm test
npm run build
npm run build:mobile
# Vite가 3110 포트에서 실행 중이고 Playwright/Chromium이 설치된 환경:
node tools/character-production-smoke.cjs /tmp/arcana-character-smoke
```

생성기는 `art-source/defense/characters-v2/<캐릭터>/`에 수정 가능한 Blender 파일, 3개 텍스처, 4방향 렌더, 원본 참조 해시와 클립 정보가 담긴 manifest를 저장한다. `public/defense/models/characters-v2/`의 GLB/렌더와 `src/rush/models/`의 실행용 GLB도 함께 갱신한다. `--skip-render`는 렌더만 생략하며 이전 시트 이미지를 갱신하지 않는다.

실행용 GLB는 현재 비압축 사본으로 세 종 합계 약 3.8 MB다. 다운로드 용량은 이전 메시 전용 모델보다 커졌다. `tools/rush-glb.sh`는 선택적 meshopt 압축 경로이며 이 제작본 검증에는 사용하지 않았다. Android 패키지에서는 작업실용 중복 GLB와 렌더를 제외하고 실제 게임에서 가져오는 세 모델을 보존한다.

검증: 전체 자동 테스트 732개, 웹 빌드, 모바일 빌드 및 자산 계약 검사. 실제 브라우저에서 세 영웅 각각 PC/모바일 이동, 공격, 정지, 일시정지/재개, 포포 눈덩이 재장전을 확인한다. 소프트웨어 WebGL 검증이며 실제 휴대폰 성능 측정은 아니다.

## 공통 스타일의 적용 범위

[전체 모드 공통 미술 기준](arcana-character-art-standard.md)은 계속 유지한다. 이번에 실제 연결한 범위는 **Rush 영웅 3종과 작업실**이다. 캠페인·Legion·Frontier의 전체 모델 교체, 적 캐릭터의 재제작, 표정·피격·쓰러짐의 추가 제작은 이 변경에 포함되지 않는다. 다른 모드로 확장할 때 같은 GLB/팔레트/재질을 재사용하고 각 모드의 공격 시간과 화면 크기에 맞춰 연결한다.
