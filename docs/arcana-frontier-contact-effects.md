## 실제 구현

- `EffectsView`가 전장의 기존 단일 Three.js 장면에서 효과를 관리한다. 고리·탄선·접촉 형상은 공유하고 슬롯을 재사용한다. 최대 128개 효과/1,024개 파편으로 장식 자원 수를 제한한다. 초과 시 오래된 장식부터 생략하며 전투 피해나 준비 예고는 변경하지 않는다.
- 망치·충격파의 **접촉 이벤트**마다 8개의 작은 입체 파편을 하나의 `InstancedMesh`로 그린다. 사전 준비나 빗나간 기본 공격에는 생기지 않는다. 월드 접촉점에서 퍼지고 위로 떴다가 내려오며 조명·깊이 검사를 받는다.
- 파편 위치·회전·크기는 기존 효과의 남은 시뮬레이션 시간과 ID로 결정한다. 독립 벽시계나 난수를 쓰지 않아 일시정지·배속·같은 상태 재렌더에서 타격 위치가 달라지지 않는다.
- 동작 줄이기는 비산 파편과 고리 확장을 없애고 기존 접촉 고리를 유지한다. 공격 예고와 피해 시점은 유지한다.
- 효과가 사라지면 슬롯을 숨기고 다음 효과에 재사용한다. 장면 종료 시 공유 형상·재질·인스턴스 자원을 한 번 해제한다. 기존 매 프레임 GPU 자원 폐기를 없앤다.
