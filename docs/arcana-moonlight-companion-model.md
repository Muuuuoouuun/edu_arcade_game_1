## 컨셉과 구현

실제로 연 `public/defense/snow-atlas.png`의 둘째 줄 왼쪽 동료와 `art-source/defense/concepts/2026-10-29/variants/silverfrost-wolf-variants.png`를 기준으로 삼았다. 기존 게임에서는 동료 삽화가 루나보다 크게 보였고 좌우 반전과 공통 몸 흔들림을 사용했다. 이미 완료된 적 서리늑대의 보행을 반복하는 대신 **작고 둥근 동료의 첫 실제 모델**을 제작했다.

은빛 몸통·상아색 주둥이와 가슴털·짧고 둥근 네 다리·큰 귀·초록 눈·말린 꼬리·초록/금 목장식이 독립 메시다. 처음 렌더에서 막대처럼 보이던 다리를 둥근 표면과 엉덩이 털로 수정했다. 동일 카메라의 대기 렌더 알파 높이에 전투 표시 크기(동료 73, 루나 84)를 적용하면 동료는 루나의 약 64~78%다. 초상화와 적 서리늑대는 기존 자산을 유지한다.

몸·머리·턱·귀·꼬리·목걸이와 네 다리의 상하부/발을 포함한 20개 노드가 실제로 움직인다. 스킨 대신 변환 노드에 메시를 붙이고, 다리 연결점을 계산해 분절의 회전과 길이를 조절한다. 고정 길이 뼈대 IK는 아니다.

- 물기: `moonlight-bite`, 0.41초. 네 발을 디딘 채 몸을 모아 입을 벌리고 0.13초에 턱을 닫으며 앞으로 내민 뒤 복귀한다. 귀·꼬리·목걸이가 따라 움직인다.
- 보행: `moonlight-walk`, 0.8초. 대각선 발을 짝지어 지지와 회수를 반복하며 항상 두 발 이상이 로컬 바닥에 닿는다.
- 전투: 8방향×물기 4포즈, 8방향×보행 8포즈를 실제 시뮬레이션 시간과 누적 이동 거리에 연결한다. 입 소켓을 같은 카메라로 투영해 타격 이후 0.12초 동안 작은 접촉 표시를 그린다. 완전한 모델 세트가 준비되면 기존 일반 발톱 궤적은 표시하지 않는다.
- 실패/접근성: 16장 중 한 장이라도 로드하지 못하면 동료 전체가 기존 삽화로 돌아간다. 동작 줄이기는 중립/타격 포즈를 사용한다. 전투에서 GLB나 유닛별 WebGL 렌더러를 만들지 않는다.

실제 UI 검증에서 기존 따라가기 오류도 발견했다. 빠른 동료가 매 프레임 이동 중인 주인의 목표점에 도착하면 남은 거리가 0이어서 보행 속도도 0으로 기록됐다. 이제 실제 이동량으로 보행 속도를 계산하고 준비 화면에서 완전히 정지하면 시뮬레이션 시간을 진행시키지 않고 속도를 0으로 정리한다. 영웅/용병 어느 쪽이 주인이어도 같은 회귀 검사를 통과한다. 위치·표적·피해 규칙은 유지했다.

## 원본과 재생성

```sh
npm run models:pet-wolf
npm run models:pet-wolf -- --check
npm run models:pet-wolf -- --preview
```

Blender 4.3.2, ffmpeg가 필요하다. 기본 렌더는 Cycles CPU 64 samples다. `--check`는 출력물을 덮어쓰지 않고 포즈 경계를 검사하며 `--preview`는 일부 방향을 `/tmp/arcana-pet-wolf-preview-*.png`로 렌더한다.

| 산출물 | 경로/규격 |
| --- | --- |
| 제작 코드 | `tools/blender/build_pet_wolf.py` |
| 편집 원본 | `art-source/defense/moonlight-wolf.blend`, `moonlight-wolf-walk.blend` |
| 공통 카메라 렌더 | `art-source/defense/moonlight-wolf/`, 투명 PNG 96장, 384×384 |
| 작업실 모델 | `public/defense/models/moonlight-wolf.glb`, `moonlight-wolf-walk.glb` 및 PNG 미리보기 |
| 전투 베이크 | 같은 폴더의 `moonlight-bite-{0..7}-atlas.webp`, `moonlight-walk-{0..7}-atlas.webp` |
| 메타데이터 | `public/defense/models/moonlight-wolf.json`: 기준 이미지 해시, 카메라, 클립, 경계, 입 소켓, 출력 해시 |
| 런타임 소켓 | `src/games/defense/petWolfSockets.ts`, 생성 코드가 함께 출력 |

카메라는 기존 영웅과 같은 정사영 크기 6.8, 위치 `(7,10,7)`, 목표 `(0,0,1.7)`이다. 원본 지면 기준 `(192,330)`, 배포 프레임 256×256의 기준 `(128,220)`을 공유한다. GLB에는 이미지 평면이 없다. 작업실은 하나의 기존 장면에서 모델 교체·회전·와이어프레임·물기 재생·보행 반복을 제공한다.

각 GLB는 20,712 삼각형·39 메시·10재질이며 물기 1,350,552바이트, 보행 1,370,648바이트다. 전투 WebP 16장은 합계 397,750바이트다. 전체 디코딩 시 추가 RGBA 크기는 24MiB이며, 실제 기기의 GPU 메모리 측정값은 아니다.

## 검증

증거 폴더 `/tmp/arcana-hourly-20261107-0840/`에 작업 전 소유권·범위·수용 기준부터 최종 결과까지 기록했다. 임시 증거는 새 환경에서 보존되지 않을 수 있으므로 재생성에 필요한 원본·코드·규격은 저장소에 둔다.

- 전체 테스트 215개 중 214개 통과. 기존 무관한 수학 `(3×7)÷5`의 기대값 4.2/실제 4 실패만 남았다. TypeScript/Vite 빌드 통과.
- 따라가기 회귀 테스트를 수정 전 실패시킨 뒤 수정 후 통과시켰다. 영웅/용병 주인, 이동·정지·일시정지·입력 상태 불변을 확인했다.
- 기준과 8개 전투(스테이지 1/4/5/8, 강화/판매)를 매 프레임 비교했다. 의도적으로 바뀐 `locomotion.pet.speed`만 제외하고 모든 상태가 일치했다. 별도 준비 이동 600프레임도 시간과 최종 정지를 확인했다.
- 원본/GLB의 모든 프레임에서 연결된 다리, 물기 중 발 고정, 보행 중 두 발 이상 접지를 검사했다. 발바닥 최소 높이 0.005, 최대 0.115; 다리 연결 오차 최대 약 1.02e-6, 원본/GLB 변환 오차 약 5.97e-7이다. PNG/WebP 경계·알파·해시·클립 길이 검사 통과.
- 실제 Board의 640개 조합(8방향, 공격 시점/보행 위상, PC/모바일/동작 줄이기/물기 이미지 실패/보행 이미지 실패) 통과. 입 표시의 화면 좌표 오차 최대 약 0.0000056px. 전투 GLB 요청과 예상 밖 페이지 오류가 없었다.
- Chromium PC 1440×900, 모바일 390×844에서 실제 진입·이동·8보행 프레임·정지·웨이브·물기·일시정지/재개·2배속·동작 줄이기를 조작했다. 관측 공격 길이는 PC 419/215ms, 모바일 437/201ms(1배/2배, 브라우저 관측 간격 포함). 실제 모바일 기본 확대 화면과 같은 조건 전후 화면을 확인했다.
- 작업실 PC/모바일에서 실제 GLB 물기·보행, 회전·와이어프레임·정지·동작 줄이기·다운로드와 GLB 실패 시 PNG 대체를 확인했다. main에서 가져온 청운/물/번개 색 구분도 PC/모바일에서 검사했다.

초기 검사 로그도 남겼다. 중복된 단위 배율을 거부한 검사식과 공격 후 정지만 기다린 UI 관측기는 검사 스크립트를 수정했다. 실제 따라가기 속도 오류와 구분했다.

## 남은 차이와 다음 후보

컨셉의 풍성한 털 덩어리와 얼굴 표정은 아직 단순화된 형태다. 로컬 바닥 접지 검증이 전장 이동 중 수평 미끄러짐까지 해결했다는 뜻은 아니다. 다음 후보는 **동료의 보행→물기 자세 연결과 전장 이동 거리에 맞춘 발 보폭**이다. 연속 방향 전환·지형 IK·실제 Android 기기의 메모리/성능 검증도 남아 있다.

Claude API는 사용하지 않았다. 이번 회차는 예약 설정·활성 상태를 조회하거나 바꾸지 않았으며, 개발 결과와 예약 실행 성공 여부를 구분한다.

후속 회차의 [8단계 물기](arcana-moonlight-bite-sequence.md)에서 물기 동작·아틀라스·소켓과 용량을 갱신했다. 위 4포즈/96PNG/24MiB 규격은 최초 제작 당시 기록이다.

후속 [달리기와 전장 보폭](arcana-moonlight-running-stride.md)에서 기본 보행을 지지·비행 구간이 있는 달리기로 갱신하고 실제 이동량·방향·표시 크기에 보폭을 연결했다. 위의 항상 두 발 접지 규격은 최초 보행 당시 기록이다.
