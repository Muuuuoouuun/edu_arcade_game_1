## 이번에 구현한 것

나무 병사는 실제 Blender 메시와 강체 관절 계층으로 제작한다. 나이테는 이미지가 아닌 메시이고, 발·팔·머리·등 잎을 따로 움직인다. 한 주기 1초의 GLB 보행 클립과 같은 동작의 8단계 전투용 WebP를 출력한다. 디딘 발은 지면에 맞추고 반대쪽 발을 들어 옮기며, 팔은 다리와 반대로 움직이고 잎은 조금 늦게 따라온다. 스킨 리그나 지형을 읽는 실시간 IK는 아니다.

전투에서는 나무 병사가 52 논리 단위를 이동할 때 8프레임을 한 번 순환한다. 이동 거리와 속도는 시뮬레이션 상태에 기록한다. 둔화·물길·얼음·일시정지를 그대로 따르고, 넉백 속도 7 초과일 때는 보행보다 버티는 동작을 우선한다. 뒤로 밀리는 거리는 보행에 더하지 않으며 몸은 길의 진행 방향을 유지한다. 완성된 보행에는 기존 전체 몸체의 추가 튀기기를 겹치지 않는다.

보행 아틀라스를 못 불러오면 같은 모델의 기존 3포즈로 대체한다. 기본 모델 아틀라스까지 실패하면 삽화 세트로 대체한다. 동작 줄이기에서는 새 보행 순환을 끈다. 피해·공격 속도·적 이동 속도·보상은 이번 모델/보행 변경에서 조정하지 않았다.

실제 게임 전투는 **3D 원본을 베이크한 2.5D**다. 모델 작업실은 **실시간 3D**로, `/model-lab.html?model=wood-soldier`에서 보행 재생/정지, 회전, 메시 보기, GLB 내려받기를 제공한다. 전체 전투를 실시간 3D로 전환했다고 보지 않는다.

## 재생성과 납품물

```bash
npm run models:wood
```

- 제작 코드: `tools/blender/build_wood.py`
- 편집 원본과 고정 카메라 렌더: `art-source/defense/wood-soldier.blend`, `art-source/defense/wood-frames/`
- 3D 검토: `public/defense/models/wood-soldier.glb`와 미리보기 PNG
- 전투: `wood-soldier-atlas.webp`(3포즈, 약 31KB), `wood-soldier-walk-atlas.webp`(8포즈, 약 76KB)
- 규격·클립·해시: `public/defense/models/wood-soldier.json`

블렌더의 공통 384px 카메라, 지면 기준 (192, 317.61), 동일 배율을 유지한다. 보행 전체 메시가 카메라 안에 있는지 생성 시 검사한다. GLB는 약 539KB이며 전투 이미지 로더는 내려받지 않는다. GLB의 실제 렌더 비용은 작업실에서만 발생한다.

## 검증과 다음 범위

엔진 검사에서는 순방향 거리 누적, 역밀림 때 보행 정지, 길을 향하는 방향, 둔화 비율, 일시정지, 시간 분할 일관성과 이전 상태 불변성을 확인한다. 이미지 검사에서는 8포즈의 동일 지면·크기, 아틀라스 경계와 부분 로딩 실패를 확인한다. Blender 원본 재열기·GLB 재가져오기, Chromium의 실제 전투와 작업실 재생도 확인한다.

이번 확인 결과:

- Claude 30회차의 동일한 64px 비교 도구에서 돌·나무 기본 포즈의 실루엣 겹침은 0.70 → 0.58, 새 보행 8포즈는 0.50~0.59였다. 해당 도구의 잠정 혼동 기준 0.65 아래다. 자동 실루엣 측정이며 사용자 인지 실험을 대신하지 않는다.
- 전투·보행·에셋 검사 74개 통과, 전체 검사 162개 중 161개 통과. 기존 수학 엔진의 `(3 × 7) ÷ 5` 정답 4/4.2 불일치 1건은 남아 있다. 프로덕션 빌드 통과.
- `http://localhost:3100/` 및 `/model-lab.html?model=wood-soldier`, Chromium 1440×900 / 390×844에서 확인했다. 연결형 Browser 실행 도구가 없어 설치된 Playwright·Chromium을 사용했다.
- 실제 웨이브에서 8포즈 순환, 일시정지/재개, 이미지 요청 실패 시 기존 2포즈 보행, 동작 줄이기의 고정 포즈를 확인했다. 작업실은 보행 재생/정지·메시 보기·동작 줄이기·브론 공격/화염탑 전환을 확인했다. 빈 화면·프레임워크 오류 화면·가로 넘침·예상하지 않은 콘솔 오류는 없었다.
- 작업실의 나무 병사는 GLB 로딩 후 6,884 삼각형, 92 메시, 9재질로 측정됐다. 이 수치는 전투 WebGL 예산을 충족했다는 의미가 아니며, 실제 전투는 해당 GLB를 로딩하지 않는다.

다음 모델 묶음은 서리늑대의 웅크림·도약·착지와 영웅의 방향별 공격이다. 모든 적을 한 번에 같은 몸 튀기기로 처리하지 않고 체형별 걸음과 무게를 분리한다. 완전한 3D 전투 전환은 단일 장면 렌더러에서 지형 가림·화면 좌표 입력·유닛 수별 성능을 검증한 뒤 확장한다. 실제 Android 기기 성능과 사용자 재미 검증은 별도다.
