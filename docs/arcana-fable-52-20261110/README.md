# Claude Fable 5.2 max 모델링 검토 시도

2026-11-10. 사용자의 요청에 따라 Anthropic 공식 모델 조회에서 `claude-fable-5-2`의 adaptive thinking 및 `max` effort 지원을 확인하고, 공식 Messages API에 해당 설정으로 호출했다. 입력은 Frontier 방어 시제품 화면 한 장, 프로젝트 통합 방향 문서, 카르·발리스타·나무 병사 GLB 메타데이터다. 기존 캠페인 엔진과 타격 판정을 유지하는 모델링 인계안을 요청했다.

- 첫 호출: 입력 7,800 토큰, 출력 16,000 토큰 전부 추론, `stop_reason=max_tokens`. 반환 텍스트 없음.
- 두 번째 호출: 입력 7,800 토큰, 출력 32,000 토큰 전부 추론, `stop_reason=max_tokens`. 반환 텍스트 없음. [응답 메타데이터](receipt.json).

두 요청 모두 실제 과금 대상 호출일 수 있다. 정확한 비용은 Anthropic 계정의 가격과 사용 내역으로 확인해야 한다. 모델링 제안 본문을 받지 못했으므로 Fable의 추천이나 검토 결과로 인용하지 않는다. 더 큰 한도의 재호출은 추가 비용과 같은 실패 가능성이 있어 자동으로 이어서 실행하지 않았다.

기존에 인계한 모델은 [모델 폴더](../../art-source/defense/model-bridge-20261110/README.md)에 있으며, 이 API 호출은 새 3D 모델을 제작하거나 캠페인에 연결하지 않았다.
