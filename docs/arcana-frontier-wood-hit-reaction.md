# 변경 전장 통나무 병사 피격 반응

2026-11-09 KST. 기준 `09b9094eb3d1edacf51bee0e2d1fbdb6a16a3ede`, 소유 브랜치 `codex/arcana-stage-experience-20261106`.

통나무 병사 컨셉 비교 시안과 실제 가로 전장을 보았다. 기존 전장 모델은 관절 보행과 몽둥이 공격은 재생하지만, 영웅·분대·포탑 공격이 명중해도 체력만 줄어드는 데 그쳤다. 맞은 개체를 알아보기 쉽게 기존 3D 모델의 몸 전체가 공격원에서 멀어지는 방향으로 0.24초 기울었다가 원래 보행·공격 자세로 돌아오게 했다. 기울임의 상한 계수는 0.32라디안이다. 시뮬레이션 시각을 쓰므로 일시정지에서 멈추고 2배속에서 함께 빨라진다. 동작 줄이기에서는 기울임을 생략하며 체력·피해 표시는 유지한다.

실제 게임 위치·속도·피해·공격 시간·범위는 바뀌지 않는다. 발은 기존 관절별 지면 보정으로 받치며, 간이 박스 폴백은 지면에 파고드는 경우 위로 보정한다. 사망 적은 기존처럼 즉시 제거되므로 쓰러짐 애니메이션을 추가한 것이 아니다. 새 Blender 원본·GLB·스프라이트를 만들지 않았고 기존 단일 Three.js 전장과 배치된 모델을 재사용한다. 2.5D 캠페인에는 적용되지 않는다.
