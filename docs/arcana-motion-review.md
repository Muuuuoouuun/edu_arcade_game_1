# 이동·모션·전투 그래픽 검토

2026-10-28. 기존 8스테이지 디펜스의 전투 감각을 개선했다. 교육 요소는 기존 재질·속성 상성에 유지했다.

## 구현

- 여섯 영웅과 늑대의 공격 준비·타격·회복 포즈, 이동 방향과 걸음 흔들림, 고정된 발 기준을 적용했다. 두 모션 아틀라스는 거점에서 미리 읽으며 실패하면 기존 캐릭터 이미지로 대체한다.
- 영웅은 지정 지점까지 이동하고, 용병은 영웅을 따라가며, 늑대는 공격할 적에게 접근한다.
- 화살·마법탄은 실제 이동 구간에서 충돌한다. 포탄은 조준한 지점에 떨어지며 적이 움직이면 빗나갈 수 있다. 근접 공격은 준비 후 사거리 안의 생존한 대상에 한 번 피해를 준다.
- 충격은 경로상의 실제 위치를 뒤로 민다. 무거운 적은 덜 밀리며 마찰과 재피격 면역으로 무한 밀침을 제한한다.
- 포탑 반동, 포탄 그림자, 공격 궤적, 파편, 피해 숫자, 처치와 코인 효과를 연결했다. 일시정지·배속은 이동·모션·투사체·날씨에 함께 적용된다.
- 공격별 효과음을 기존 음소거 설정에 연결했다. 재생 빈도와 동시 소리를 제한하고, 비활성 오디오 상태에서는 재생하지 않는다.

## 평가와 다음 우선순위

준비 동작 뒤 공격이 닿고 적이 밀리므로 공격의 시작과 결과를 읽기 쉬워졌다. 늑대가 직접 접근하고 도약하여 소환 동료의 역할도 화면에서 구분된다. 포격의 비행 시간과 착탄 지점은 배치 판단에 영향을 준다. 작은 화면에서는 전장 전체를 보여 주는 대신 각 포즈가 작게 보이는 한계가 남는다.

현재 걷기는 기존 이미지의 방향·기울기·상하 운동을 조합하고, 공격은 3포즈를 사용한다. 다음 개선은 발걸음 연속 프레임과 방향별 자세, 적의 피격·사망 전용 프레임, 모바일 전장 확대 조작 순서가 적절하다. 물리는 투사체와 경로 위 이동·충격에 한정하며 전신 관절이나 래그돌은 구현하지 않았다.

검증은 자동화된 Chromium과 직접 확인한 캡처 기준이다. 실제 모바일 기기의 프레임 성능, 플레이어 대상 재미 평가, 효과음의 주관적 청감 평가는 별도로 필요하다.
