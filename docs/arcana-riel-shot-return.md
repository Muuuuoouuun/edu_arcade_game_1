## 컨셉 대비 개선

[원본 컨셉](../art-source/defense/atlases/ranged-motion.png)과 PC/모바일 전투를 비교했다. 큰 후드·금발·긴 귀·곡선 활은 기존 모델을 유지하고, **발을 벌린 사격 회수 자세에서 보행으로 갑자기 바뀌는 부분**을 개선했다. 기존 [보행→사격 진입](arcana-riel-shot-entry.md)은 재제작하지 않았다.

화살을 놓은 자세에서 여덟 걸음으로 각각 이어지는 실제 0.12초 관절 클립을 만들었다. 몸통·머리·양팔·활·망토·머리카락을 정리하고 돌아오는 발을 조금 들어 올린다. 다른 밑창은 지면을 지지한다. 시작 자세는 기존 사격 0.10초, 끝 자세는 각각의 기존 보행 자세와 일치한다. 접지는 모델 내부 좌표 기준이며 전장 좌표의 발 고정은 아니다.

전투의 복귀는 0.16–0.28초에 적용한다. **현재 이동 방향과 사격 방향의 8방향 구간이 같고 이동 중일 때만** 현재 보행 거리에서 목표 걸음을 선택한다. 공격 시작 때 기록한 걸음에 머물지 않는다. 정지·방향 전환·필살기·돌파·동작 줄이기와 이미지 실패는 기존 표시를 따른다.

| 공격 경과 시간 | 표시 |
| --- | --- |
| 0.16–0.175초 | 기존 화살을 놓은 자세 |
| 0.175–0.22초 | 첫 복귀 베이크: 클립 0.04초 |
| 0.22–0.27초 | 늦은 복귀 베이크: 클립 0.10초 |
| 0.27–0.28초 | 현재 걸음의 기존 보행 이미지 |

발사 0.10초·전체 공격 0.28초·화살 소켓·피해·이동 규칙은 그대로다. 새 화살은 클립 0.06초, 전투 0.22초에 다시 보인다. 초기 모바일 2배속에서 두 중간 자세를 모두 건너뛰는 경우를 관찰해 표시 구간을 위와 같이 넓혔다. 60Hz 고정 스텝의 2/4/6틱 게시 주기와 모든 시작 오프셋에서 적어도 한 중간 자세가 표시되는 것을 검사했다. 이는 방향이 맞는 복귀 구간에 한정하며, 임의의 낮은 프레임률에서 모든 자세가 보인다는 보장은 아니다.

## 남은 범위

전투는 두 중간 베이크로 표시하므로 연속 관절 보간이 아니다. 현재 걸음이 바뀔 때 중간 자세도 바뀌며, 사격과 이동 방향이 다른 경우는 기존 회수를 사용한다. 방향 전환 연결·월드 좌표 발 고정·실제 Android 메모리/성능은 미구현 또는 미검증이다. 새 이미지 디코드 비용도 실제 기기에서 측정해야 한다.

다음 후보는 **브론의 강타 회수→보행 연결** 또는 리엘의 방향 전환을 동반한 복귀다. 예약 상태 조회/변경·Claude API 호출·main 병합·서비스 배포는 수행하지 않았다.
