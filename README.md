# 아르카나 수비대 · ARCANA

동료를 모으고 마을을 지키는 **독립 모바일 판타지 타워 디펜스**입니다. 오락성·전투 피드백·캐릭터와 마을의 시각적 완성도를 우선합니다. 학습 문제나 계산 과제 없이, 불·얼음·충격·전기 같은 개념을 짧은 선택형 전술 힌트로 녹입니다.

## 플레이와 빌드

Node.js 22.12 이상에서 `npm ci`, `npm run dev`로 실행합니다. 기본 포트는3100입니다.

| 주소 / 명령 | 용도 |
| --- | --- |
| `/` | 아르카나 전용 타이틀 → 마을 → 동료/성장/원정 → 전투 |
| `/arcade.html` | 보존한 기존 교육 미니게임 허브 |
| `/model-lab.html` | 개발용 3D 모델·동작 검토 작업실 |
| `npm test` | 게임 규칙·캠페인·저장·모바일 입력 등 검증 |
| `npm run build` | `dist/` 웹 빌드: 아르카나와 별도 기존 허브·작업실 |
| `npm run build:mobile` | `dist-mobile/` 아르카나 전용 빌드 |
| `npm run android:debug` | 아르카나 전용 웹 동기화 후 Android 디버그 APK |

Android 설치판은 미니게임 진입점·코드와 제작 작업실용 GLB를 포함하지 않습니다. 모바일 렌더러는 기존 React/TypeScript 기반 2.5D 전장입니다. Three.js 실시간 모델은 웹 제작 작업실에서 검토합니다. [Android 빌드·설치 안내](docs/android-install.md)를 참고하세요.

[기본 게임 규칙 v1 — 현재 규칙·설계 결정·적용 순서](docs/arcana-game-rules-v1.md)

## 현재 게임

- 숲·설산의8개 스테이지, 마을 구조 요청과 추가 퀘스트 자동 보상.
- 이안·리엘·브론·청운·카르·루나의 순차 합류. 영웅 상세 미리보기 후 무료 편성 확정.
- 타워 건설·강화·속성 분기, 영웅 전직·용병·펫, 서로 다른 적과 지역 보스.
- 컨셉아트 중심 거점4테마, 브론 대장간의 영구 강화와 강화 전후 비교.
- 영웅 이동·자동 공격·필살기·돌진, 투사체·넉백·피격·타격 정지 연출.
- 짧은 전술 힌트: 실제 등장 상대의 약점을 원하는 경우에만 확인. 읽기·정답·암기를 진행 조건으로 삼지 않습니다.

## 저장과 프로젝트 경계

게임 소스 저장소는 `Muuuuoouuun/edu_arcade_game_1`을 유지합니다. 독립 앱 진입점과 설치 패키지를 분리했으며 원격 저장소를 새로 만들거나 이름을 변경한 것은 아닙니다. `defense_atlas`는 별도 국방 데이터 서비스이므로 이 게임 변경을 적용하지 않습니다.

동일 웹 주소의 기존 캠페인·테마·설정은 기존 저장 키를 읽어 이어갑니다. 새 Android 패키지는 `io.github.muuuuoouuun.arcana`이며 기존 `arcade` 설치판과 데이터 영역이 다릅니다. 기존 설치판 또는 브라우저의 진행도가 새 앱으로 자동 이전되지는 않습니다. 앱 삭제·데이터 초기화 시 진행을 잃을 수 있으며 클라우드 저장은 아직 없습니다.

이미지 생성·OpenAI/Claude API 호출은 제작 환경에서만 수행합니다. 앱 실행에 계정이나 외부 API 키가 필요하지 않습니다. 키를 클라이언트 코드나 APK에 넣지 않습니다.

기존 수학·단어·퀴즈·레이싱의 상세 기록은 [이전 허브 README](docs/legacy-arcade-README.md)에 보존했습니다. 그 문서의 상대 파일 경로는 당시 저장소 루트 기준입니다.
