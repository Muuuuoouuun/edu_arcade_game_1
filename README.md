# 플레이그라운드

**한 판 더, 똑똑하게.** 재미 → 그래픽 → 자연스러운 학습 순서로 만드는 교육용 미니게임 허브입니다.

## 지금 플레이할 수 있는 게임

- **숫자 팡팡**: 60초 연산 아케이드. 4개의 정답 버블, 키보드 1–4 입력, 연속 정답 콤보, 5콤보부터 피버 점수 2배. 6문제마다 난도가 올라갑니다.
- **워드 캐치**: 뜻에 맞는 영어 단어를 빠르게 잡는 60초 게임. 기본 어휘 24개를 한 바퀴 안에서 반복하지 않습니다.
- **짝꿍 찾기**: 뒤집힌 영어·뜻 카드 6쌍을 찾는 기억력 게임. 남은 시간에 따라 완주 보너스를 받습니다.
- **사이언스 카트**: 과학 문제를 풀며 컴퓨터 카트 3대와 겨루는 3바퀴 아이템 레이싱. 자동으로 가속하며 방향키·터치로 조향합니다. 상자 약 330m 전 문제를 먼저 보여 주고, 약 245m 전 세 보기와 아이템 상자를 보여 줍니다. 답을 누르거나 1–3 키를 누르면 해당 차선으로 이동하며, 실제 상자 통과 위치로 정답을 판정합니다. 정답은 부스터·쉴드·번개를 얻고, 오답은 꽝 또는 2.8초 감속과 짧은 해설을 받습니다. 24개 기초 과학 문제 중 한 레이스에 9개를 중복 없이 출제합니다. 제한 시간은 3분입니다.
- **상식 팡팡**: 국기·한국사·세계사·사자성어, 분야별 16문제로 구성된 60초 퀴즈. 한 분야 또는 모두 섞기를 선택합니다. 섞기에서는 4문제마다 네 분야를 한 번씩 만나며, 한 판 안에서 같은 문제를 반복하지 않습니다. 시간이 끝나거나 해당 모드의 문제를 모두 풀면 종료됩니다. 결과에서 국기 이미지, 내가 고른 답, 정답과 해설을 확인하고 같은 주제로 재도전하거나 주제를 바꿀 수 있습니다.
- **아르카나 수비대**: 숲과 설산의 8개 스테이지를 지키는 판타지 타워 디펜스. 거점에서 영웅을 편성하고 구조 요청을 받아 출발합니다. 방문하는 동료와 시설, 속성 타워, 전직, 펫, 지역 보스와 추가 퀘스트를 지원합니다.

효과음, 일시 정지(Esc), 결과 화면, 틀린 문제 다시 보기, 다시 도전, 게임별 최고 기록과 누적 플레이 수를 지원합니다. 기록과 프로필은 해당 브라우저에 저장됩니다. 최근 기록은 100개를 보관하며 최고 기록과 플레이 수는 별도로 유지합니다.

## 실행

Node.js 22.12 이상이 필요합니다. 이 클라우드 환경은 Node.js 22.23.4를 사용합니다.

```bash
export PATH=/workspace/.cloud-setup/tools/node-v22.23.4-linux-x64/bin:$PATH
cd /workspace/edu_arcade_game_1
npm ci
npm run dev
```

개발 서버 포트는 3100입니다. 모바일 터치와 데스크톱 키보드를 지원합니다. 게임 실행에 계정이나 외부 API 키는 필요하지 않습니다.

```bash
npm test
npm run build
npm run preview
```

`dev`와 `preview`는 같은 포트를 사용하므로 동시에 실행하지 않습니다.

현재 자동 테스트 103개는 기존 게임 규칙과 저장 기록, 디펜스 전투·상성·보스·펫, 투사체 충돌·넉백·가속·돌진, 난이도별 편성과 보상, 캠페인 해금·기존 저장 호환, 전술 구매와 모바일 입력, 테마 해금·독립 저장, 관찰노트와 실제 전투 규칙의 일치를 검증합니다. `npm run test:prototype`은 별도 카드 수비 시뮬레이션의 63항목과 750판 비교를 검증합니다. 화면·터치 조작은 브라우저 검증으로 별도 확인합니다.

## 사이언스 카트 조작

| 조작 | 키보드 | 모바일 |
| --- | --- | --- |
| 조향 | ← / → 또는 A / D | 좌우 버튼을 누르고 유지 |
| 정답 차선으로 이동 | 1 / 2 / 3 | 답 버튼 터치 |
| 드리프트 | Shift를 누른 채 조향 후 놓기 | DRIFT와 조향 버튼을 함께 누른 뒤 놓기 |
| 아이템 사용 | Space | 오른쪽 아이템 버튼 |
| 일시 정지 | Esc | 우측 상단 정지 버튼 |

드리프트를 0.85초 이상 유지하면 놓을 때 짧은 부스터가 발동합니다. 부스터는 3.2초 가속, 쉴드는 8초 동안 충돌과 잔디 감속 방어, 번개는 라이벌을 3초 동안 느리게 합니다. 얻은 아이템은 순서대로 보관·사용합니다. 화면을 떠나거나 일시 정지하면 시간과 라이벌도 함께 멈춥니다. 도로 밖, 고깔과 다른 카트의 충돌은 속도에 영향을 줍니다.

완주 시 순위·시간·정답 상자·콤보로 점수를 계산해 기존 개인 기록에 저장합니다. 결과에서 틀린 과학 문제를 다시 볼 수 있습니다. 레이스는 로컬 컴퓨터 상대이며, 생성한 카트·상자·배경 이미지와 Canvas의 원근 도로·충돌 계산을 결합한 2.5D 방식입니다.

## 아르카나 수비대 프로토타입

청록의 숲 4개와 서리산맥 4개, 총 8개 스테이지를 각각 4웨이브로 진행하는 판타지 타워 디펜스입니다. 거점에서 출전 영웅과 지역·스테이지를 선택하고, 구조 요청을 받아 전투를 준비합니다. 건설 지점을 선택해 석궁탑·마법탑·포격탑을 세우고, 전투 코인으로 속성 분기와 최종 강화를 선택합니다. 영웅은 자동 공격하며, 필살기(Space 또는 버튼), 이동 위치, 용병 고용을 직접 결정합니다. 2웨이브 뒤에는 공격 또는 제어 중심의 전직을 선택합니다. 정지(Esc), 2배속, 재준비를 지원하며 창을 떠나면 자동 정지합니다.

처음에는 인간 마법사 이안과 작은 숙소로 시작합니다. 1-1 이후 엘프 궁수 리엘, 1-2 이후 드워프 공병 브론, 1-3 이후 동방 도사 청운이 찾아옵니다. 숲의 마지막 1-4를 지키면 설산에서 구조 요청이 오고, 2-1 이후 바바리안 전사 카르, 2-3 이후 수인 드루이드 루나가 합류합니다. 여섯 영웅을 출전 영웅이나 용병으로 편성할 수 있고, 루나의 늑대 영물은 별도로 자동 공격하며 적을 둔화합니다.

정착한 동료에 따라 거점에 정찰 초소·대장간·도원·영물의 쉼터가 늘어납니다. 드워프 합류 후에는 성장 골드로 공용 장비를 강화합니다(최대 5단계, 단계당 영웅·용병·펫·타워 공격력 +8%). 전투를 마치면 거점으로 돌아와 장비를 정비하거나 다음 원정으로 바로 출발할 수 있습니다. 1-4와 2-4에서는 두 번째 진입로·건설 지점·마을이 열립니다. 마지막 웨이브에 각각 고목왕과 서리군주가 등장하며, 서리군주의 눈보라 충전은 필살기로 차단할 수 있습니다. 외곽 마을을 잃어도 주 마을이 살아 있으면 기본 클리어는 가능합니다.

첫 클리어, 반복 클리어, 실패 보상이 구분되며, 추가 퀘스트 80 G는 스테이지마다 한 번 수령합니다. 퀘스트는 마을 체력 유지, 외곽 거점 보호, 몬스터 60마리 격퇴 등 지역마다 다릅니다. 캠페인 해금·골드·장비는 `playground:defense:v1`, 허브 기록은 기존 `playground:v1`에 저장합니다. 기존 4스테이지 클리어 저장은 골드·영웅·강화·수령 기록을 유지한 채 설산을 해금합니다. 맞이하지 않은 방문자는 새로고침 후에도 나타납니다. 진행 중 전투 배치는 새로고침하면 초기화되고 거점으로 돌아오며, 완료한 원정과 성장은 유지됩니다. 영구 성장과 전투 중 건설 비용은 별도입니다.

몬스터의 외형·체력·속도가 다르고, 나무/얼음의 불 약점, 돌/얼음의 충격 약점, 금속/젖음의 전기 연쇄, 절연체의 전기 내성을 전투 규칙으로 사용합니다. 비와 물길은 젖음을, 물 공격은 둔화를, 고지대는 사거리 보너스를 줍니다. 설산의 빙판에서는 적이 빨라지며, 서리군주의 눈보라는 타워를 잠시 얼립니다. 퀴즈는 없습니다. 포격은 주 목표 외에 가까운 적 2명까지 폭발 피해를 주며, 주변 피해는 주 목표의 40%입니다. 서리군주는 전장에 진입한 뒤 충전 주기를 시작합니다. 사막·성채·무림·도원 등 전체 세계 확장은 후속 범위입니다.

낮은 노트북 화면에서도 지도와 건설·시작 버튼이 함께 보이도록 배치합니다. 모바일 용병 선택은 전투가 잠시 멈추는 창에서 진행하며, 기존 일시정지 상태는 보존합니다. 퀘스트는 전투 중 조건 유지와 실제 보상 수령을 구분합니다. 거점과 전투를 전환하면 화면 맨 위로 돌아옵니다.

영웅·용병·늑대는 목표까지 실제로 이동합니다. 여섯 영웅과 늑대에 공격 준비·타격·회복 포즈를 추가했고, 걷기·피격·타워 반동·처치 효과를 전투 시간에 맞춰 재생합니다. 화살과 마법탄은 이동 구간의 충돌을 검사하고, 포탄은 곡선 궤도로 날아가 조준한 지점에 착탄합니다. 근접 공격도 준비 시간이 지난 뒤 범위 안의 적에게 피해를 줍니다. 충격 공격은 적의 경로 위치를 뒤로 밀며, 무거운 몬스터와 보스는 덜 밀리고 연속 넉백에는 짧은 면역 시간이 있습니다. 전투는 1/60초 단위로 계산하며, 배속·일시정지에 모션과 투사체가 함께 반응합니다. 기기의 동작 줄이기 설정에서는 장식 흔들림과 입자를 줄입니다. 공격 종류별 효과음은 기존 소리 설정을 따르며 동시 재생 수를 제한합니다.

타워는 기본 3종과 분기 6종의 외형이 다르며, 강화 버튼에서도 완성될 모델을 미리 볼 수 있습니다. 나무·빙결 기사·돌 갑옷병·서리늑대는 두 보행 포즈와 피격 포즈를 사용하고, 두 보스는 시전·격노·피격·쓰러짐 자세를 가집니다. 건설·강화 연출과 지면 그림자를 추가했으며, 마지막 적 처치 후 남은 효과를 보여 준 뒤 결과 창을 엽니다. 종료 연출 동안 전투 판정과 보상은 다시 계산하지 않습니다.

`src/games/defense`의 전투 엔진·캠페인 저장·데이터와 `DefenseGame`/`DefenseBoard` 전투 화면, `DefenseEffects` 효과, `DefenseCamp` 거점 화면이 분리되어 있습니다. 아트는 `public/defense`의 로컬 생성 이미지이며, 이동 경로·건설 지점·체력·공격 궤적은 실제 판정과 일치하는 SVG/HTML로 표시합니다. 모션은 스프라이트 포즈와 변환을 조합하며, 물리는 투사체와 경로 위의 이동·넉백을 대상으로 합니다. 별도 대화의 작업 범위와 붙여 넣을 요청문은 [작업 분담 문서](docs/arcana-workstreams.md)에 있습니다.

성 테마는 녹음 성채(기본), 청강 요새(1-2), 운령 산성(1-3), 황혼성(2-4) 순으로 방어 완료 후 해금됩니다. 거점 삽화와 전장 성문 외형만 바뀌며 전투 수치는 같습니다. 외형 선택은 별도 `playground:defense:appearance:v1`에 저장합니다. 해금된 시설은 삽화 아래에서 확인합니다. 원정 준비와 정찰의 **수비대 관찰노트**에서는 실제 편성의 재료에 맞춰 전장 규칙과 자연의 원리를 선택해서 읽을 수 있습니다. 읽기나 문제 풀이를 보상 조건으로 요구하지 않습니다. [교육 방향](docs/arcana-world-planning/education-direction.md)을 참고하세요.

## 세계관·캐릭터 확장 기획

설정·스토리 채팅에서 정리한 [세계관·성장·아트 기획](docs/arcana-world-planning/README.md)과 [시안 갤러리 33장](docs/arcana-world-planning/concept-gallery.md)을 보존했습니다. 동양 지역, 짐승·수인·도깨비·서양 판타지, 영웅 스킬·포탑·마을·성 테마를 다루며 사용자 결정과 미확정 제안을 구분합니다. 이미지는 `art-source/defense/concepts/2026-10-29/`의 원본 콘셉트입니다. 이 중 성 4종은 WebP 거점 삽화와 단순화한 SVG 성문으로 연결했습니다. 나머지 시안과 성별 특수 능력·신규 지역·인물은 후속 기획이며 구현 완료를 뜻하지 않습니다. `npm run art:themes`로 배포 삽화를 다시 만들 수 있습니다.

## 모델 제작 도구

Blender 4.3.2와 FFmpeg를 확인했고, 모델 작업실용 Three.js 0.186.1을 추가했습니다. [모델 제작 안내](docs/arcana-asset-pipeline.md)에 원본 수정·내보내기·실행 방법을 정리했습니다.

- 편집 원본: `art-source/defense/towers.blend` — 화염 수정탑·관통 발리스타·물폭탄포, 개별 메시·재질·조작 피벗 포함
- 재생성: `npm run models:build` — Blender에서 GLB와 투명 PNG 3종 출력
- 검토 화면: 개발 서버의 `/model-lab.html` — 회전·확대·메시 보기·발사 동작·GLB 다운로드

게임의 2.5D 아틀라스는 전투 화면에 사용하고, 3D 모델 3종은 제작 작업실에서 편집·검토하는 원본으로 제공합니다. Three.js는 작업실 전용 번들에 포함됩니다.

## 세 저장소의 역할

| 저장소 | 역할 |
| --- | --- |
| `edu_arcade_game_1` | React + Vite 웹 허브, 여섯 미니게임, 브라우저 개인 기록 |
| `math_speed` | Flutter 앱 골격과 Firebase 서버. 웹 게임이 `functions/src/mathEngine.ts`의 1–10단계 문제 생성기를 직접 공유 |
| `Word_check` | 기존 교사·학생·학부모 단어 숙제 관리 서버. Node.js + SQLite |

빌드·테스트 시 두 저장소가 `/workspace/edu_arcade_game_1`과 `/workspace/math_speed`에 나란히 있어야 합니다. Vite는 공유 수학 엔진을 웹 번들에 포함하므로 게임 중 Firebase 연결은 필요하지 않습니다.

기존 엔진은 9단계 나눗셈에 나머지가 있어도 정수로 잘라 정답을 반환합니다. 웹 게임은 해당 단계의 곱셈 인자를 조정해 항상 나누어떨어지는 수식만 출제합니다. 전체 단계에서 표시 수식과 정답의 일치를 검증하며, 기존 모바일·서버 엔진은 별도로 수정해야 합니다.

현재 웹 기록은 기기 내 개인 기록이며 공식 서버 랭킹이 아닙니다. 워드 캐치는 기본 어휘를 사용하며 교사 과제 DB와 아직 연결하지 않았습니다. Flutter 네이티브 플랫폼 셸과 실제 Firebase 프로젝트 연결도 후속 작업입니다.

## 구성

`src/games/race`는 과학 문제·순수 레이스 시뮬레이션·Canvas 렌더러·입력을 나누어 관리합니다. 레이스 모듈은 진입할 때 불러오며, 이미지와 스프라이트 팔레트는 한 번 준비해 프레임마다 재사용합니다. `public/race`의 아틀라스와 배경은 로컬 이미지입니다.

`src/components`는 화면과 공통 UI, `src/games`는 게임 엔진과 라운드 상태, `src/lib`는 브라우저 저장과 효과음을 담당합니다. 모든 화면 문구·조작·점수는 실제 HTML과 React 상태로 렌더링합니다. `public/art`에는 생성한 캐릭터 일러스트가, `public/fonts`에는 OFL 글꼴과 라이선스가 있습니다.

상식 문제는 `src/games/quizData.ts`에 정답·오답 보기·해설을 함께 편집합니다. 국기는 [flag-icons 7.5.0](https://github.com/lipis/flag-icons)의 SVG 16개를 로컬에 포함했습니다(MIT, `public/flags/LICENSE`). 국기 문제에는 국가 이름 대신 모양을 설명하는 대체 텍스트를 제공합니다. 기존 브라우저 기록은 그대로 유지되며 상식 게임의 기록과 선택 주제가 추가됩니다. 게임별 최고 점수는 주제 통합 기록입니다.

클라우드 설정의 설치 스크립트와 시작 안내에는 세 저장소의 재설치·실행 방법이 저장되어 있습니다. 현재 Firebase Admin SDK 12는 이 환경의 기본 인증 파일 형식을 처리하지 못해 함수의 실제 호출에 실패합니다. Auth·Firestore 에뮬레이터와 함수 빌드/도메인 로직 검증을 구분해서 사용해야 합니다.

### 전투 조작·난이도 개선

빈 땅 클릭으로 영웅 이동, Shift 또는 돌진 버튼 후 땅 클릭으로 5초마다 짧은 돌진이 가능합니다. 이동에는 가속·제동, 포탄에는 대칭 포물선을 적용했습니다. 거점에서 여유롭게·기본 원정·정예 원정을 선택하며, 정예는 빠른 증원과 기본 보상 +40%를 제공합니다. 웨이브 정찰은 실제 편성과 같은 데이터를 사용합니다. 난이도 선택과 최근 원정의 난이도·지역은 브라우저에 저장됩니다.

[게임성·물리·난이도 평가](docs/arcana-gameplay-review.md)와 `tools/balance-defense.ts`에서 36조건의 자동 전투 비교를 확인할 수 있습니다. 실행: `node --experimental-strip-types tools/balance-defense.ts`.

### 모바일 전투 화면

원정에 들어가면 전투 전용 화면으로 전환합니다. 세로에서는 하단 두 줄, 가로에서는 양쪽 조작부를 사용하며, 짧은 가로 화면의 용병·정찰은 전술 메뉴에서 엽니다. 건설·강화·고용·정찰을 고르는 동안 전투와 재사용 시간이 멈추고, 구매·취소 후에는 이전 진행 상태로 돌아갑니다. 화면 회전이나 앱 이탈 뒤에는 명시적으로 돌아오기를 눌러야 하며, 기존 수동 정지도 보존합니다.

돌진 조준 중에는 건설 지점을 눌러도 해당 위치로 돌진합니다. 같은 버튼·Escape·pointercancel·드래그·화면 변화로 조준을 취소하며, 취소에는 재사용 시간을 쓰지 않습니다. 작은 화면에서 겹친 건설 지점은 후보를 먼저 고릅니다. 화면을 확대해 글자를 크게 쓰면 보조 설명을 접어 전장과 주요 조작을 유지합니다.

구매와 정지 사유는 `src/games/defense/tactics.ts`, 전투 화면·전술 패널은 `DefenseBattle`, 포인터 판정은 `defenseInput`에 분리했습니다. [모바일 기획·구현 현황](docs/arcana-mobile-layout-plan.md)에 실제 구현과 남은 확대 카메라·실기기 검증 범위를 구분했습니다. Claude 검토용 키는 웹 앱에서 사용하지 않습니다.

### 카드 수비·3D 프로토타입

별도 브랜치에서 만든 카드 수비 모드의 기획과 2D/3D 프로토타입을 함께 보존했습니다. 이 모드는 문제 정답으로 마나를 얻어 카드를 소환하는 5웨이브 실험작이며, 기존 영웅·용병 중심 4웨이브 캠페인과 규칙·진행도를 공유하지 않습니다. [기획 문서](docs/arcana-guard/README.md), [3D 수비 모드](prototype/3d_game.html), [2D 기준판](prototype/index.html), [실행·검증 안내](prototype/README.md)를 참고하세요.

허브의 전체·디펜스 목록에서 **3D 수비 시작**을 선택하면 독립 화면으로 이동합니다. 현재 수학 문제, 네 지역, 세 난이도를 지원하며 한 판의 진행도는 저장하지 않습니다. 다른 과목과 기획 문서의 24스테이지는 아직 연결되지 않았습니다. 일시정지와 허브 복귀를 제공하고, 창을 떠난 뒤에는 직접 이어하기를 눌러야 합니다.

수호자는 마법사·물의 사제·왕국 기사·숲 수호자의 3D 모델로 표현하며, 4단계 강화에 따라 장비가 달라집니다. 임프·날개형·갑옷형·왕관 보스도 서로 다른 외형을 사용합니다. `prototype/graphics/models.js`에서 모델을 한 번 만들고 재사용하며, 지형·성채·소품을 묶어 그려 화면당 60드로우콜·4만 삼각형 이내를 목표로 합니다. 공격 반동·타격 링을 추가했고 모션 감소 설정에서는 장식 움직임을 줄입니다.

짧은 가로 화면은 확대 카메라로 적을 따라갑니다. **전체 보기**를 눌러 지도 전체를 살펴보고 **전투 따라가기**로 돌아올 수 있습니다. 큰 가로 화면은 기존 45도 전체 지도를 유지합니다. `prototype/graphics/ui.css`의 조작 버튼은 최소 48px이며, 개발용 수치는 주소에 `?debug`를 붙였을 때만 표시합니다.

`npm run build`는 Vite 빌드 뒤 `tools/build-prototypes.mjs`로 독립 HTML·시뮬레이션·Three.js와 라이선스를 `dist/prototype/`에 복사합니다. 전체 `dist/`를 배포해야 모드가 열립니다. 별도 프로토타입의 CommonJS 테스트는 `prototype/package.json`으로 루트의 ESM과 분리합니다. 허브 수학 문제는 같은 상위 폴더에 체크아웃한 `math_speed/functions/src/mathEngine.ts`를 사용하므로 두 저장소를 함께 준비해야 합니다.

Playwright와 Chromium이 설치된 환경에서 `npm run preview`를 실행한 뒤 다음 명령으로 배포 산출물의 3D 게임을 검증할 수 있습니다. 스크린샷은 지정한 외부 폴더에만 기록합니다.

```bash
BASE_URL=http://127.0.0.1:3100/prototype/ OUT_DIR=/tmp/arcana-3d-qa node prototype/tests/game3d_test.js
```
