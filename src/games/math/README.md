# 수학 엔진 사본

`mathEngine.ts`는 같은 소유자의 `math_speed/functions/src/mathEngine.ts`를 변경 없이 복사한 고정 사본이다. 출처 저장소는 <https://github.com/Muuuuoouuun/math_speed>, 확인한 체크아웃은 `8a316f3b6095db0ccf285e4ef43db6fd9a560275`, 해당 파일의 마지막 변경 커밋은 `143b2c535a463bc994f33083a765fcdc73562410`이다. 사본 SHA-256은 `8189b4f8be1acc3ef586b82ebdf1e184f713348d0ca2f8c4df17420f5f327a3b`이다. 원본 저장소에 별도 라이선스 파일은 확인되지 않았으며 새로운 라이선스를 부여하지 않는다.

이 사본은 자동으로 갱신되지 않는다. 원본 변경을 가져올 때는 소유권과 사용 권한을 확인하고 파일 차이와 결정적 문제 생성 결과를 검토한 뒤 출처 커밋·해시를 갱신하고 전체 테스트와 빌드를 실행한다. 원본 저장소는 수정하지 않는다.
